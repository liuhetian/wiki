# 把下午调回可用状态：三个五分钟的小动作

下午坏掉时，先别修意志力。**先把环境、身体和任务入口各调一下**——桌面给出边界，凉意把人叫回来，一件小事让大脑重新找到抓手。

![把下午调回可用状态：清空桌面、给身体一点凉意、最后只做一件事](assets/afternoon-reset.png)

## 先把桌面擦空

桌面乱的麻烦不只是难看，而是每件东西都在发出一个很小的请求：杯子要洗、线要收、纸要看。单个请求不值一提，叠起来却会把注意力切成碎片。

给自己五分钟。拿一块干净布和一杯冷水，把手肘能碰到的地方擦空。最后只放回**下一件事需要的东西**。不是整理房间，也不是建立一套收纳系统——只给接下来的半小时腾一小块边界。

## 再给身体一点凉意

闷热下午的疲惫，有时不是思想问题。身体在努力散热，大脑自然不愿意接复杂任务。

冰块、薄荷叶、柠檬皮和气泡水不是固定配方，重点是造出一个清楚的感官信号：凉、香、微酸。喝不了冰的，就换成凉水洗手、湿毛巾敷后颈，或站到窗口吹两分钟风。**先让身体收到“环境已经变了”的消息。**

## 最后只做一件事

恢复工作的入口不能写成“把项目做完”。它必须小到一眼能看见动作：

- 打开文档，补第一段结论
- 找出报错前最后一条正常日志
- 给表格加上缺失的三列标题
- 写下要问对方的第一个问题

把这句话写在纸上，关掉消息，定二十五分钟。计时结束可以停，也可以继续——这一轮只负责重新启动，不负责证明自己今天有多自律。

!!! tip "卡住时只缩小入口"
    如果二十五分钟仍然不想开始，别继续加压。把任务再缩小一层，直到它能用一个动词说清楚：打开、圈出、删掉、回复。

## 重启不需要一套新系统

这三个动作都很小，因为它们本来就不是长期方法。它们只是一个手动重启键：擦空桌面，给注意力画边界；制造凉意，把身体拉回现场；只做一件事，让任务重新出现入口。

下午不必被彻底拯救。调回可用，就够了。
