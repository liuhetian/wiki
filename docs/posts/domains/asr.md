# 语音识别（ASR）：给一段录音，出里面说的话

**语音识别（ASR）的通用功能只有一件事：给一段录音，把里面的话转成文字。** 细分方向都是在这个基础上被新需求逼出来的：要边说边出字，要知道每个字什么时候说的、谁说的，口音和专有名词认不准，环境吵，要能直接用的稿子，只听几个词。分类参考了百度智能云语音识别的文档[^baidu]，文档里不是转文字的几样收在文末[相邻任务](#neighbors)。在[领域地图](index.md)上它在「信息提取与结构化」一组，处理对象是语音；最对称的是[文字识别](ocr.md)：一个从图里取字，一个从声音里取字。

## 通用功能：录音里有话，就能转成文字 { #basic }

- **输入**：一段完整的录音，wav、mp3、m4a 都行；视频先把音轨抽出来。转成 16 kHz 单声道再传，体积小很多，结果不变 —— 本站一段 14 秒的录音从 2.7 MB 压到 57 KB，转出来的字一模一样
- **输出**：一整段文字，现在一般自带标点
- **顺手处理的**：自动判断是哪种语言，中文里夹几个常用英文词照常认
- **典型用途**：语音输入，录音整理成文字稿，给视频做文字版
- **管不了的**：它只管说了什么，不管什么时候说、谁说的。静音的音轨转回来是空的，按时长计费的照样收钱 —— 先测一下音量再送

本站 Agent 怎么转录，见[转录音频](../../skills/agent-io/reference/transcribe.md)。

## 细分方向：一个新需求，一个方向 { #needs }

### 要边说边出字：实时识别（streaming ASR） { #streaming }

- 整段录音传上去再出结果，是录音识别；边说边传、边出字，是流式识别 —— 先出临时结果，一句说完再改成最终结果
- 用在：语音输入法、直播和会议的实时字幕、语音助手
- 一分钟以内的录音整段传更简单，真要实时才用流式，一般走 WebSocket

### 录音很长：长音频转写（long-form transcription） { #long }

- 几十分钟到几小时的会议、课程、播客，一般是提交任务，过一会儿再取结果
- 也可以自己切块：本站读视频时每 10 分钟切一块分别转

### 要知道每个字什么时候说的：时间戳（word-level timestamps、forced alignment） { #timestamp }

- 返回每句、甚至每个字的开始和结束时间
- 用在：做字幕，点哪句跳到哪，剪辑时按文字定位
- 本站实测字级时间戳很准：第一个字从 2.32 秒开始，音量正好在 2.25 到 2.5 秒之间跳起来

### 要知道谁说的：说话人分离（speaker diarization） { #diarization }

- 给每句话标上说话人 1、2、3；要知道具体是谁，再配声纹识别
- 用在：会议记录、访谈、客服对话
- 本站踩过的：有的服务不开说话人分离，句子起止也不准 —— 整段只算一句，从 0 秒到结尾

### 方言和外语：多语种识别（multilingual ASR、code-switching） { #language }

- 粤语、四川话这些方言，英语和其他外语，一般要选对应的模型或指定语种
- 中英夹杂、一句话中间换语言，是难点

### 专有名词认不准：热词与定制模型（hotwords、contextual biasing） { #hotword }

- 人名、产品名、行业术语，通用模型常写成同音字
- 轻的办法是传一张热词表；重的是上传行业语料，自己训练模型

### 环境吵、离得远：降噪与远场识别（far-field ASR、speech enhancement） { #far-field }

- 背景音乐、几个人同时说话、离麦克风远，都会让结果变差
- 智能音箱、会议室这种远场场景有专门的模型，常配多个麦克风
- 降噪（speech enhancement）是前处理：先把录音洗干净，出来的还是录音；远场识别才是变体

### 电话录音：窄带识别（narrowband / 8 kHz telephony ASR） { #telephone }

- 电话音质只有 8 kHz，普通模型认不好，要用针对电话的模型
- 用在：呼叫中心的通话转写和质检

### 要能直接用的稿子：顺滑与规整（disfluency removal、inverse text normalization、ITN） { #clean }

- 照录会把「嗯」「那个」、说错重来都留下；顺滑会把它们去掉
- 规整：「二零二六年」写成「2026 年」，金额、电话号码写成数字

### 只听几个词：唤醒词与命令词（keyword spotting、KWS、wake word） { #keyword }

- 「小度小度」「打开空调」这种只认固定几个词，常在设备上本地跑，不联网
- 不用转出整句话，要的是又快又省电

## 相邻任务：常一起出现，但不属于这个领域 { #neighbors }

- 情绪、声音事件、语音质检（speech emotion recognition、audio event detection）：生没生气、笑声掌声咳嗽、客服有没有说违规用语，一般先转完文字再分析，处理对象同是语音，但属于识别与分类；没有地图
- 语音翻译、语音大模型（speech translation、speech LLM）：说中文出英文字幕，或者不先转文字、语音直接进大模型听完就答 —— 信息提取加内容生成跨了两组，语音识别成了它的一项能力，不再是单独一环；没有地图
