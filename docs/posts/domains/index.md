# 领域地图：一个领域一张，按任务类型分组

**一张地图讲一个领域：固定一种输入数据、一种输出，讲这个研究社区的全部任务。** 先讲最简单的那一步 —— 通用功能，再一个需求引出一个细分方向，方向带英文名，照名字去搜就有现成的工具和做法。手里有个需求不知道归哪时，先问模型最终要给出什么结果，定任务类型；再看处理对象是什么，到下面那一组里找。在板块那根轴上它是[文章](../index.md)：一个领域里所有项目共用的 baseline 和问题清单 —— [细讲项目](../../skills/project-research/dissect.md)要先定的「领域是 X、baseline 是 Y」，X 就是这里一张地图的名字，Y 是它的通用功能。

## 任务类型：模型最终要给出什么 { #tasks }

九种，按要解决的问题分，不按模型分 —— 同一个模型可以出现在几组：多模态大模型既做信息提取也做内容生成，GPT-image-2.5 既做内容生成也做内容变换。地图按任务分，模型只在方向下面当方案列。

| 任务类型 | 要解决的问题 | 输出 |
|---|---|---|
| 识别与分类 | 这是什么？属于哪一类？ | 类别标签 |
| 数值预测 | 数值是多少？未来会是多少？ | 连续值 |
| 检测、定位与分割 | 目标在哪里？范围多大？ | 框、掩码、坐标 |
| 信息提取与结构化 | 输入里有哪些信息？怎么整理成字段或关系？ | 文本、字段、结构 |
| 内容生成 | 怎么从条件生成新内容？ | 高维信号，没有同模态参照 |
| 内容变换 | 怎么把内容转成另一种形式？ | 高维信号，输入就是参照 |
| 检索、匹配与排序 | 哪些最相关？先展示哪个？ | 排好序的候选 |
| 模式发现与数据表示 | 数据里有哪些群体、规律、潜在结构？ | 簇、低维表示 |
| 决策、规划与控制 | 为了达到目标，下一步做什么？ | 动作、策略 |

- **一张地图按通用功能定组，不按最深的方向**：[文字识别](ocr.md)里文字定位是检测，表格识别是提取，修图是变换，鉴伪是分类；通用功能是「图里的字取出来」，所以在信息提取。检测、定位与分割在地图这一层常是空的，检测多半是某张地图里的一个方向
- **生成和变换分开**：有没有同模态参照，决定了数据是配对还是非配对、指标是保真度还是分布距离、失败模式是改过头还是不够多样
- **处理对象是任务里那份高维数据**：预测类看输入，生成类看输出，文生图的处理对象是自然图像。文档图像和自然图像分开算，分属文档分析（ICDAR）和计算机视觉（CVPR）两个社区、两套术语；多模态不单列，多模态大模型是方法不是对象。每张地图的钩子开头标处理对象

## 一个领域怎么定 { #domain }

- **边界看术语**：一个社区用一套术语、一份工具目录就能搜全，是一个领域；要换一套术语才搜得到工具，是另一个。厂商的产品线、软件手册的一章只是证据，不是边界 —— [文字识别](ocr.md)照百度 OCR 产品线收，把条码、切题批改也收了进来，现在它们是[相邻任务](ocr.md#neighbors)
- **领域分两种**：能力领域固定输入和输出，下面九组里全是；产品领域看给谁用、替代什么，[项目](../../projects/index.md#projects)按它分组 —— AI 角色扮演、AI 辅导、agent harness。产品领域的地图将来一张对一组项目，不进这九组

## 一张怎么写 { #write }

- **标题**：中文名加括号英文，冒号后一句通用功能 —— 「文字识别（OCR）：给一张有字的图，出能复制、能搜的文本」
- **开头一段**：通用功能只有一件事是什么，方向是被哪些需求逼出来的，分类参考了谁，在哪一组、处理对象是什么
- **「通用功能」一节**：输入、输出、顺手处理的、典型用途、管不了的
- **「细分方向」一节**：一个需求一个方向，小标题写「需求：方向中文名（英文名）」。方向只有三种：
    - 变体：同一任务，输入或输出多了一个条件 —— 手写、流式、时间戳、表格。写一节
    - 前后处理：另一种任务，但这个领域的流水线少不了它 —— 识别前的修图，合成前的抠像和追踪，合成后的质检。写一节，小标题末尾标「· 前处理」或「· 后处理」，活例[抠像](video-compositing/index.md#matte)
    - 相邻任务：另一个领域，只是厂商目录里挨着 —— 条码、切题批改、鉴伪、情绪识别、语音大模型、生成式补画。不写节，收进文末「相邻任务」一节，一行一个：它是什么、为什么不在这张，有地图就链过去，没有就写在哪一组，活例[文字识别的相邻任务](ocr.md#neighbors)
- **一件事只在一张地图里展开**：谁的流水线天天用谁写，别的地图提到它只链过去 —— 抠像在视频合成里展开，视频理解写到分割时链过去
- **方向是钩子**：方向往上挂讲几种方案的选型文章，选型文章往上挂只留一种方案的项目；扩散模型、Transformer 这类技术方法不单成层，就在那条链上
