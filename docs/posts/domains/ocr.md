# 文字识别（OCR）：给一张有字的图，出能复制、能搜的文本

**文字识别（OCR）的通用功能只有一件事：给一张有字的图，把字变成能复制、能搜索的文本。** 细分方向都是在这个基础上被新需求逼出来的：要知道字在哪，字写得不规整，要表格和公式，要整篇文档的结构，只要几个字段，图片太烂。分类参考了百度智能云文字识别的接口目录[^baidu]，目录里不是认字的几样收在文末[相邻任务](#neighbors)。在[领域地图](index.md)上它在「信息提取与结构化」一组，处理对象是文档图像；最对称的是[语音识别](asr.md)：一个从图里取字，一个从声音里取字。

## 通用功能：图里有字，就能取出来 { #basic }

- **输入**：照片、截图、扫描件都行。扫描版 PDF 每一页就是一张图，逐页识别；文字版 PDF 里本来存着文字，直接抽取更准，用不着 OCR
- **输出**：按行返回文字，每行带一个置信度
- **顺手处理的**：图片转了 90°、180° 会自动摆正，中英文混排照常认
- **典型用途**：纸质资料、扫描件变成可搜索的文本，截图里的字直接复制
- **管不了的**：它只认字，不管排版 —— 表格会被拆成一行行，双栏文章的行序会乱

## 细分方向：一个新需求，一个方向 { #needs }

### 要知道字在哪：文字定位（text detection、bounding box） { #position }

- 除了文字，还返回每一行、甚至每个字的坐标框
- 用在：在原图上框出、高亮、打码，点哪翻译哪，按位置把散开的字拼成字段

### 字不规整：场景文字、手写（scene text recognition、handwriting recognition） { #irregular }

- **场景文字**：艺术字、复杂背景、街景门头、商品包装、网页配图。本站一张手绘信息图，通用识别把手绘体标题里的「Skills」认成了「Sks」—— 这类字要换专门针对场景文字的模型
- **手写**：笔迹因人而异，还有涂改、连笔。用在作文、笔记、手填的表单

### 不止中英文：多语种和特殊文字（multilingual OCR、vertical text） { #language }

- 日韩、俄文、阿拉伯文、泰文这些外文和小语种，可以指定语种，也可以自动检测
- 繁体、竖排、生僻字、古籍是另一类难点，通用模型常认不准

### 只要数字：数字、读数（digit recognition、meter reading） { #digits }

- 数字识别只挑号码：手机号、快递单号、充值码
- 仪表读数：电表、燃气表、血压计上的数字

### 要表格：表格识别（table recognition / table structure recognition） { #table }

- 还原行、列和合并单元格，有线表、无线表都要能认
- 输出 Excel 或 HTML 表格，不再是一行行拆散的字

### 要整篇文档的结构：版面分析与文档解析（layout analysis、document parsing、PDF to Markdown） { #layout }

- 分出标题、正文、图、表、页眉页脚，按人的阅读顺序排好，双栏、跨页的表格也要接上
- 输出 Markdown 或 JSON。大模型兴起后，这是给知识库、问答系统喂文档的主要入口

### 有公式：公式识别（formula recognition、LaTeX OCR） { #formula }

- 把数学公式转成 LaTeX 这类可编辑的式子
- 用在论文、教辅、试卷；现在不少文档解析模型能连公式一起出

### 有印章：印章识别（seal / stamp recognition） { #seal }

- 圆章、椭圆章上的字是弧形排列的，普通识别认不了
- 用在合同、票据：章盖了没有、盖的是哪家

### 只要几个字段：关键信息抽取（key information extraction、KIE） { #fields }

- **版式固定的**：身份证、银行卡、营业执照、驾驶证、发票、火车票、快递面单、医疗发票。有专门的识别，直接返回「姓名」「号码」「金额」这样的字段，不用自己写正则
- **版式不固定的**：各种证书、许可证、表单。告诉它要哪些字段，它去图里找值 —— 多模态大模型让这个方向变得好用
- 混贴：一张图里拍了好几张票，先切开、分类，再逐张抽

### 图片太烂：识别前先修图（document dewarping、image enhancement、moiré removal）· 前处理 { #preprocess }

- 拍歪的文档找四个角、拉平；翻拍屏幕的去摩尔纹；去掉底纹
- 去手写：擦掉作答痕迹，还原成空白试卷
- 先判断图里是什么：身份证、发票还是普通文档，再交给对应的识别

## 相邻任务：常一起出现，但不属于这个领域 { #neighbors }

- 条码、二维码（barcode、QR code）：不是认字，是解码，厂商目录常跟 OCR 放一起；没有地图
- 试卷切题、作业批改、拍照解题（question segmentation、auto grading）：认完题还要判对错、给解析，是 AI 辅导的活 —— [DeepTutor](../../projects/deeptutor/index.md)拆的就是这个领域
- 核验与鉴伪（document forgery detection、tampering detection）：发票验真、证件鉴伪、图片有没有被 P 过，是认出来的字段拿去核对的下一步，归取证和风控；没有地图
- 视频里的字（video OCR、subtitle extraction）：先抽帧、再按图片识别、前后帧去重，归[视频理解](video-understanding.md)
