# 视频生成的维护记录：AutoDL 上的 MiniMax H3 等工作流

这是[生成视频](../../../skills/agent-io/reference/video/index.md)背后的维护记录。用接口时不用看，接口出问题或者想换工作流时再看。

## 接口从哪来 { #upstream }

- 工作流列表页 [autodl.art/large-model/comfyui](https://www.autodl.art/large-model/comfyui) 是单页应用，抓不到正文。列表接口是从前端 JS（`assets/comfyui.*.js`）里找到的：`POST /api/v1/comfyui/workflows`，请求体 `{"page_size": 100, "page_index": 1}`，不用鉴权。
- 每个工作流的详情走元数据接口 `GET /api/v1/comfyui/workflows/<id>`，也不用鉴权，[语音合成](tts.md#upstream)那次就用过。里面有参数定义 `input_rules`、带中文说明的 `input_example`、计费 `billing_config` 和一段介绍。
- 官方文档 [`/docs/comfyui_api/`](https://autodl.art/docs/comfyui_api/) 是所有工作流共用的一篇，只讲提交、查询两步，示例就是文生视频的 `minimax_h3_lightx2v_no_pic`。没有讲怎么写 prompt，多张参考图在 prompt 里怎么分别指代也没写。
- 2026-10-02 列表里一共 17 个工作流：15 个 MiniMax H3、1 个 Wan2.2 Animate 动作迁移、1 个 IndexTTS2。MiniMax H3 底层是什么没写，有几个 ID 里带 `lightx2v`，那是一个开源视频推理加速框架的名字。

## 价格怎么算 { #pricing }

- `billing_config` 里的数字除以 1000，就是每秒多少元。这是从详情页前端的格式化函数里看到的：把数字除以 `1e3`，保留三位小数，后面接「/ 秒」。拿用户贴的 `minimax_h3_z0903` 页面价格核对过，四档都对得上。
- MiniMax H3 的计费类型是 `minimax_h3`，按分辨率分档。`price` 是高峰（08:00–24:00）价，`off_peak_price` 是空闲（00:00–08:00）价。页面上只写了「/ 秒」，没写是按输出视频的秒数还是按运行时间算。
- 动作迁移的计费类型是 `video_sec_cost`，页面上写明了「根据生成视频的实际时长进行计费」。
- 顺带查清了语音合成的单位：IndexTTS2 的 `audio_sec_cost` 是每秒 0.001 元，最低收 0.01 元。

## 实测 { #tests }

2026-10-02 10:10 经中转只测了一次，用户要求不要逐个测：

| 请求 | 排队 | 运行 | 结果 |
|---|---|---|---|
| `minimax_h3_zm_u24`，参考图是 512 px 的马克笔草图（猫坐在书堆上），JPEG 48 KB，用 data URI 传；`duration: 3`、`resolution: "480p(1:1)"`；prompt 要猫跳下书堆、抬头看镜头、保持草图风格、镜头固定 | 0 秒 | 81 秒 | `SUCCESS`，mp4 966 KB |

- 输出：480×480，24 fps，73 帧，3.04 秒，H.264；带 AAC 音轨（32 kHz 立体声），平均响度 -26 dB，不是静音，虽然请求里没给音频。
- 画面：猫跳下书堆、落地、抬头看镜头，跟 prompt 一致，草图风格保持住了。原图里手写的「wiki」和箭头从第二帧起就没了；书堆的位置在后面几帧变了，镜头没有完全固定。
- 返回：`results[0]` 除了 `url`、`file_type: "mp4"`，还有 `alias: "final_video"` 和 `description: "最终生成的视频"`；`msg` 是「任务处理完成。」；`data.duration` 是运行秒数。
- 结果链接跟语音合成一样在火山引擎 TOS 上，签名 `X-Tos-Expires=86400`，24 小时有效。
- 图片用 data URI 传可以，跟语音合成那次传音频一样。

## 没做的 { #not-done }

- 没对账单。按输出秒数算这次是 0.09 元，按运行时间算是 2.43 元，看一眼 AutoDL 的账单就能确定是哪种。
- 除默认工作流以外的七个都没测，包括高清档 `z0902`、`z0903`。
- 多张参考图在 prompt 里怎么分别指代（比如「图 1 的人走进图 2 的场景」），官方没写，也没测。
- 参考音频怎么影响视频（当背景音、配音还是对口型）没测。
- 冷门工作流的冷启动要多久没测。
