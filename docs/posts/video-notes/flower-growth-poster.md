# 花卉动态生长海报：效果锁进两个技能，首尾帧补出生长动画

## 一句话总论

先在生图里调出满意的效果，再让平台的 Agent 把它存成技能；两个技能串成「照片 → 肌理插画 → 排版海报」，最后用首尾帧视频把空白纸面接到成品，生长过程交给模型补[^asr]。

## 要点

1. 图片模式选 Seedream 5.0 Pro、3:4，上传一张随手拍的花，写转绘描述：插画风、重质感、几何感花瓣、颗粒纸或丝网印刷肌理，花瓣和花茎都做渐变[^style]
2. 出图满意后在 Agent 对话里让它照这次效果做一个可复用的技能，存成「花卉转插画肌理」，以后从技能菜单直接调[^skill]
3. 同样把海报排版的提示词做成第二个技能「极简花卉插画海报设计」，放进转绘好的插画出海报；满意的那张是多试几次挑出来的[^poster]
4. 视频模式用首尾帧，5 秒：首帧是只有纸纹的空白底，尾帧是成品海报，描述写固定镜头、花茎从下往上长出侧枝和花苞、花苞逐层绽放、文字最后浮现[^video]

## 画面里的信息

转写只有 300 字，参数和规则都在画面上：

- 两个技能各管一半：第一个只管肌理（颗粒、渐变、纸感），第二个只管排版 —— 花居中、文字和花同色系、左上竖排大标题、两侧中英混排小字、大面积留白的米纸底[^poster]
- 视频模型是 Seedance 2.0，720P；界面显示生图一次消耗 16 积分[^video]
- 首帧用和成品同一种纸纹的空白底：背景从头到尾不变，模型只需要补花的生长和文字出现

## 拿来怎么用

- 调了很多轮才满意的生图效果都可以这样收：满意那一刻让 Agent 把参数和约束写成技能，比自己存一段提示词多了 Agent 总结的避坑规则
- 风格和排版拆成两个技能，换主题时只动其中一个；看到喜欢的海报想倒推风格描述，可以用本站的[图片提示词反推](../../skills/collab/image-prompt-reverse/index.md)
- 「空白底 → 成品」的首尾帧适合所有从无到有的画面：生长、手绘、拼装
- 用本站接好的模型照做了一遍：做法收成了 [视频制作 · 花卉动态生长海报](../../skills/video-production/flower-growth-poster/index.md) skill，成品在 [Gallery](../../gallery/video/flower-growth-poster.md)
