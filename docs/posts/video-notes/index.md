# 视频笔记

用[整理视频为笔记](../../skills/video-note/index.md) skill 把别人的视频整理成的学习笔记，一个视频一篇。

- **关键帧、截图直接用原图**：笔记里要看的画面放进同目录的 `assets/` 引用，见写作规范[别人的图和视频直接收原件](../../skills/wiki-guide/index.md#rules)
- 笔记用自己的话写，只摘短句；画面上的提示词、命令照原文抄。证据编号和原视频的时间点写在脚注里

- [花卉动态生长海报：效果锁进两个技能，首尾帧补出生长动画](flower-growth-poster.md) —— 抖音 46 秒设计教程的笔记：照片转肌理插画、插画套排版各存成一个平台技能，两个串起来出海报；再用首尾帧把空白纸面接到成品，出 5 秒生长动画。核心是把抽卡调出来的效果锁进技能，下次不用重写提示词
