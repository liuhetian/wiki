# 文章

文章讲一个通用问题：定义问题，给几种方案和依据，讲各自适合什么、怎么选，像一篇论文 —— 读完的人知道这个问题该怎么办，拿去用在哪个项目上都行。可以贴代码，但只是示意，换个项目照样成立。选型、横向对照几个项目怎么解同一个问题、论文笔记也是文章。在[板块那根从通用到具体的轴](../projects/wiki/sections.md#axis)上，往下是一门学问的[笔记](../notes/index.md)和拿来就挑的 [Gallery](../gallery/index.md)，往上是一个具体东西的[项目](../projects/index.md)；给 AI 照着做的影子在 [Skills](../skills/index.md)。

## 领域地图

一个领域一张：先讲通用功能，再一个需求引出一个细分方向，方向带英文名，照名字去搜就有现成的工具和做法。手里有个需求不知道归哪时，先问模型最终要给出什么结果，定任务类型，再看处理对象。

- [领域地图](domains/index.md) —— 按任务类型分九组，从识别与分类到决策、规划与控制，每张标处理对象；方向分变体、前后处理、相邻任务三种；写了文字识别、语音识别、视频合成三张，其余格子先占着
