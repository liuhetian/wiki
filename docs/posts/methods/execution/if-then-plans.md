# 别写“我要做”，写“如果……就……”

> 状态：待验证。

## 问题

“明天开始写”“有空去运动”“记得跟进”都只有愿望，没有启动条件。事情发生时还要再决定什么时候做、从哪里开始，最容易在这一步被拖走。

## 做法

把目标改写成一条**如果—那么计划**：

> 如果出现 **可观察的情境 X**，那么我立刻执行 **具体动作 Y**。

情境可以是时间、地点、前一个动作或内部感受；动作要小到能直接开始。

- 差：明天抽时间写方案
- 好：如果明天 9:30 坐到工位，我就打开方案文档，先写三个小标题
- 差：别再无意识刷手机
- 好：如果写作时拿起手机，我就把它放回抽屉，并继续写当前这一段
- 差：记得催接口
- 好：如果周三 15:00 还没收到接口，我就把预先写好的跟进消息发出去

写的时候检查四件事：

1. **X 能被认出来** —— 不用“有空”“状态好”这类模糊条件。
2. **Y 是动作，不是结果** —— 写“打开文档并列三点”，不写“把方案做好”。
3. **一次只绑一个动作** —— 触发后还要执行七步，等于没有减少决策。
4. **只给真想做的目标加触发器** —— 它解决的是执行，不负责制造意愿。

## 为什么

普通目标只规定“想要什么”；如果—那么计划提前规定“何时、何地、怎么开始”。研究者把它称为 implementation intention：明确的情境线索更容易被注意到，线索出现后也更容易直接带出预设动作。

关键不是句式好看，而是把一次临场选择提前做掉。写成“如果明天有空，我就多写一点”仍然没有用——条件和动作都无法判定。

## 先试一周

只挑一个反复拖延的动作，连续执行七天：

```text
目标：
如果：
那么：

成功触发次数：
看见条件但没行动的次数：
条件根本没出现的次数：
```

七天后只改一个地方：条件没出现就换条件；条件出现却没行动，就把动作再缩小。

## 来源

- Peter M. Gollwitzer：[Implementation Intentions: Strong Effects of Simple Plans](https://doi.org/10.1037/0003-066X.54.7.493) —— 论文把 implementation intention 定义为情境线索与目标动作之间的预先连接，并讨论了线索可及性和动作启动机制
