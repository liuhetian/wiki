# 收藏夹

外面的整个来源 —— 一个论坛、一个人、一个合集 —— 里面什么层的东西都有，放不进[板块那根轴](../projects/wiki/sections.md#bookmarks)上哪一层；拿来就用的工具站没什么可写，也放这里。只存链接，不存原件。单篇帖子、文章不收：要么写成页面按层进轴，要么不留。要 agent 定期去读的接成 skill，比如[获取热点](../skills/hot-topics/index.md)，这里不重复收。

按来源的形态分页：

- [社区和论坛](community.md) —— 很多人一起发帖的地方：linux.do
- [人](people.md) —— 一个人或一个工作室持续在发的：小红书、linux.do 上的作者，工作室 Lusion
- [合集和导航站](collections.md) —— 别人挑好、排好的一批：prompt 卡牌图鉴、agent 用例合集、梯子合集
- [工具和服务](tools.md) —— 拿来就用的站：接码、买号、下歌、内网穿透、社交平台数据 API、下小说

周刊、播客、资源库这些形态，有了第一条再开一页。

## 一条怎么写 { #entry }

每条一行：链接、一句为什么收、收录日期。外链直接写在条目上，不走脚注 —— 链接本身就是收的内容。从里面拆出过页面的，日期前写「拆出过」，标上板块、链到那几页，看得出哪个来源产出多 —— 活例 [linux.do](community.md)。

```markdown
- [站名](https://example.com) —— 为什么收，一句话；拆出过：Gallery [页名](../gallery/…) · 2026-10-28
```

从里面拆出一样写成页面，按层进轴：讲原理的帖子进[笔记](../notes/index.md)；一套配色、一种画风进 [Gallery](../gallery/index.md)，前端做得好、要当风格参考的进[前端特效](../gallery/web/index.md)，存截图和能跑的 demo；讲一个问题几种方案的进[文章](../posts/index.md)；一个仓库要弄懂它，粗讲或细讲进[项目](../projects/index.md)。拆完回到条目上补「拆出过」。
