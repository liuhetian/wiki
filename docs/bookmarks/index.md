# 收藏夹

外面的站点、论坛、合集，里面什么层的东西都有，放不进[板块那根轴](../projects/wiki/sections.md#bookmarks)上哪一层。只存链接，不存原件；从里面拆出一样写成页面，就按层进轴 —— 前端做得好、要当风格参考的进 Gallery 的[前端特效](../gallery/web/index.md)，存截图和能跑的 demo；一个仓库要弄懂它，粗讲或细讲进[项目](../projects/index.md)。

每条一行：链接、一句为什么收、收录日期。外链直接写在条目上，不走脚注 —— 链接本身就是收藏的内容。

```markdown
- [站名](https://example.com) —— 为什么收，一句话 · 2026-10-23
```
