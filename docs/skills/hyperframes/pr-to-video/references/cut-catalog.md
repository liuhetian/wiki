# 切法目录 —— 帧内接缝（由 worker 构建）

> **一份 worker 构建配方（Step 5）—— 是 `../../hyperframes-animation/rules/` 的同级文档，不是第二份动效文档。** 这些是 **frame worker 在它自己的 composition 内部构建**的帧内切换（Z 轴缩放 + 模糊 + 不透明度 tween，或者逐词的 x 方向错开，全都在这一帧自己那条暂停的 GSAP timeline 上）。它们**不是**帧与帧之间的转场：那由故事通过 `transition_in` 掌控，由 harness 的注入器从一套**独立的 registry 词汇**（`crossfade` / `blur-crossfade` / `push-slide` / `zoom-through` / `squeeze`）里盖印上去 —— 这里的目录名（**cut-the-curve / inverse-zoom / waterfall**）**不是**有效的 `transition_in` 取值。当一帧的镜头序列里有内部接缝 —— 场景内的文字 / 元素替换、一次 **Scene 到 Scene** 的切换（`Scene` 是一帧**之内**的一个时间窗口，**不是**帧与帧之间的边界），或者一次文字到文字的换行 —— 并且你希望它读起来是一个连续的运动，而不是生硬的幻灯片式切换时，就用这份目录。（`zoom-through` 两边都有：在 registry 里是整帧包裹层的转场，在这里是元素级的 Z 轴切换 —— 同一个思路，作用范围不同。）

四种营造纵深和连续性的技法：

1. **Zoom-Through** —— 场景内的文字替换，Z 轴，朝观众方向移动
2. **Inverse Zoom-Through** —— Z 轴替换，远离观众方向移动
3. **Cut the Curve** —— x/y 轴上的场景间转场
4. **Waterfall Cut** —— 逐词的 cut-the-curve，退场和入场都错开进行

四者底层是同一条原则：**在速度峰值处切，切点两侧的方向和速度保持一致。** 区别在于轴向、作用范围和粒度。

**在一个接缝处选哪种：** 对于一句**未完成**的话（跨越几个视觉上各不相同、但仍指向同一要点的场景，逐步构建一个更大的想法 —— 多行文字、一串连续的卡片），用 **cut-the-curve** / **waterfall**。对于一次**状态变化**（转入视频的一个**新**部分 —— 最常见的是钩子 → 背景，或两个截然不同的章节之间），用 **zoom-through**；遇到到达 / 揭晓的段落节拍，用 **inverse zoom-through**。把这些串起来，让这一帧的内部接缝感觉像一台摄像机在内容中连续穿行。

## 模糊逻辑（适用于所有 Z 轴变体）

模糊在切点处营造出速度感，但它必须随**主体尺寸**缩放：

| 主体 | 峰值模糊 | 原因 |
| --- | --- | --- |
| 文字尺度（标题、一行字、一组词） | **10px** | 到 20px 时文字会糊得无法辨认 —— 眼睛丢失了它正在追踪的那个词，切换读起来像故障，而不是速度。20px 时字形在切换中途会变得软烂；10px 能让它们保持可读。 |
| 满屏表面（终端窗口、卡片、截图） | **18–20px** | 大的表面有边缘和纹理，经得起重度模糊；满屏运动用较轻的模糊，读起来像渲染卡顿，而不是运动。 |

切点两侧使用**相同**的峰值模糊 —— 在替换那一帧，数值必须一致。模糊加在**包裹层**上，绝不加在单个子元素上。

## 1. Zoom-Through（向前）

### 问题

文字入场、停留、退场。然后下一段文字入场、停留、退场。每一块文字都是独立的 —— 没有纵深，没有连续性。视频感觉像幻灯片。

### 原则

Z 轴上的一次速度匹配切换。你**永远不会同时看到两段文字。**退场的文字朝观众方向放大（加速），模糊和不透明度在切点处达到峰值，掩盖掉一次硬替换，入场的文字则从后方继续放大（减速进入焦平面）。一个连续的向前运动，两段不同的文字。

### 三个阶段

**阶段 1：退场** —— 文字向前加速（朝观众方向）

- 缩放：`1.0 -> 1.2`，模糊：`0px -> 10px`（文字尺度；见模糊逻辑），不透明度：`1.0 -> 0.15`
- 缩放 / 模糊的 easing：`power3.in`（陡峭的加速）
- 不透明度的 easing：`none`（线性 —— 均匀变暗，与缩放分开）
- 时长：0.2 秒

**阶段 2：在速度峰值 + 模糊峰值处硬切**

- 退场方：`opacity: 0`（通过 `tl.set` 瞬间设置）
- 入场方：`opacity: 0.15, scale: 0.75, blur: 10px`（通过 `tl.set` 瞬间设置）
- 切点处所有属性都一致：模糊、不透明度，以及缩放的**方向**（两者都在放大）

**阶段 3：入场** —— 文字继续向前（放大进入焦平面）

- 缩放：`0.75 -> 1.0`，模糊：`10px -> 0px`，不透明度：`0.15 -> 1.0`
- Easing：`expo.out`（陡峭的初始爆发，匹配退场速度，然后长时间落定）
- 时长：0.5 秒

### 为什么退场时不透明度必须单独处理

缩放用的是 `power3.in`，但这会让不透明度在 tween 的大部分时间里都接近 1.0。把不透明度拆成单独的 tween、用线性 ease，变暗就会均匀。入场时，所有属性可以共用 `expo.out`。

## 2. Inverse Zoom-Through（向后）

镜像版本：摄像机"往后拉"，而不是往前推穿。退场的元素**远离**观众后退；入场的元素以**超大尺寸**到来（就像它原本就在摄像机后面一点），然后缩回到焦平面。两者都朝缩小的方向运动 —— 同方向规则仍然成立，只是反过来了。

**什么时候用它而不用向前的变体：**到达型段落节拍。入场元素是从比画面还大的尺寸收进来的，所以落地时很有分量 —— 适合揭晓那一句（"That changes today."）、一个巨大的回应，或者一个停留的终态。向前的 zoom-through 读起来是*穿过*内容向前推进；反向的读起来是*抵达*内容。

### 三个阶段

**阶段 1：退场** —— 元素后退（远离观众）

- 缩放：`1.0 -> 0.8`，模糊：`0px -> 10px`（文字尺度）
- 缩放 / 模糊的 easing：`power3.in`；不透明度：`1.0 -> 0.15`，用 `none`（单独的 tween）
- 时长：0.2 秒

**阶段 2：硬切**

- 退场方：通过 `tl.set` 设置 `opacity: 0`
- 入场方：通过 `tl.set` 设置 `opacity: 0.15, scale: 1.25, blur: 10px`

**阶段 3：入场** —— 入场元素缩回原位

- 缩放：`1.25 -> 1.0`，模糊：`10px -> 0px`，不透明度：`0.15 -> 1.0`
- Easing：`expo.out`，时长：0.5 秒

## 3. Cut the Curve（场景转场）

### 原则

**所有场景到场景的转场**都在 x 和 y 轴上用 cut-the-curve。退场场景的 hero 元素朝一个方向加速，切点落在运动途中，入场场景的 hero 元素继续朝**同一方向**运动并减速。没有东西会完全退出屏幕，也没有东西从完全屏幕外进入 —— **速度加上不透明度渐变就能骗过眼睛**；部分位移就足够了。

### 同一路径，同一方向

如果场景 A 的 hero 向左滑，场景 B 的 hero 就从右侧入场并继续向左滑。两者都向左移动。一个连续的运动。

| 方向 | 场景 A 退场 | 场景 B 入场起点 | 场景 B 入场终点 |
| --- | --- | --- | --- |
| 向左 | `x: 0 -> -230` | `x: +230` | `x: 0` |
| 向右 | `x: 0 -> +230` | `x: -230` | `x: 0` |
| 向上 | `y: 0 -> -230` | `y: +230` | `y: 0` |
| 向下 | `y: 0 -> +230` | `y: -230` | `y: 0` |

### 通过镜像 ease 实现速度匹配

最干净的匹配：退场用 `power4.in`，入场用 `power4.out`，距离和时长**相同** —— 从数学上看，它们正是一条 `power4.inOut` 复合曲线的两半，因此入场元素恰好从这条假想路径的 50% 处接上，速度完全相同（例如两侧在切点处都是 230px / 0.3s ≈ 3,070 px/s）。

渐隐技巧：退场的不透明度在它行程的约 25–30% 处就完成了（渐隐时长 ≈ 0.18–0.3 秒，而运动时长为 0.3–0.34 秒）—— 元素在仍明显加速时就消失了，什么都不必到达画面边缘。入场则在减速过程中从约 0.35 快速淡**入**。让**最后一个**渐隐的元素恰好在硬切那一刻消失 —— 没有任何东西在动的空档，读起来是尴尬的冷场。

### 规则

- 所有场景转场都用 cut-the-curve —— 它是默认做法，不是点缀
- 两侧同一方向；镜像的 `.in`/`.out` ease，相同的距离 + 时长
- 退场时长短（0.2–0.4 秒），入场时长 >= 退场时长
- 部分位移 + 渐隐，绝不做完全移出屏幕的运动

## 4. Waterfall Cut（逐词的 cut-the-curve）

**词**粒度的 cut-the-curve —— 用于文字到文字的接缝时，是向左切法中最强的版本。退场那一行的每个词都沿着自己明显的曲线加速离开；入场那一行的每个词都在飞行途中如瀑布般依次涌入。错开让切换变成一道波浪，眼睛乘着它越过接缝。

### 退场（逐词）

- 运动：`x: 0 -> -230`，历时 0.34 秒，用 **power4.in** —— 比常用的 power2 加速曲线明显得多：词先几乎是在蠕动，然后猛地**甩出去**
- 渐隐：`opacity -> 0`，历时 0.18 秒（单独的 tween，`power1.in`）—— 在词只走完行程的约 25–30% 时就完成
- 错开：按阅读顺序，每个词约 0.022 秒，时间安排成让**最后一个**词恰好在硬切那一刻淡出完毕

### 入场（逐词）

- `fromTo x: +230 -> 0, opacity: 0.35 -> 1`，历时 0.3 秒，用 **power4.out** —— 复合曲线镜像的后半段；每个词点亮时就已经以匹配的速度在运动
- 瀑布式错开，间隔**逐渐缩小**（从 0.05 秒开始，每个词乘以约 0.84），让这串级联在整行中加速 —— 级联应当一个词比一个词快，而不是以固定的每词延迟匀速推进
- 在构建时就把所有词预设为 `x: +230, opacity: 0` —— 只靠 `immediateRender: false` 的话，还没开始的词会在错开窗口期间以静止状态可见地停在原处

### 整行变体

单行的段落节拍（例如一句大号的开场行）作为一个整体退场，用同样明显的加速曲线，但把它的渐隐拉长到约 0.3 秒，在切点前约 0.02 秒结束 —— 一个孤立的元素如果过早淡出，会留下冷场，而逐词级联本可以把它填上。

## 选择变体

|  | Zoom-Through | Inverse Zoom | Cut the Curve | Waterfall Cut |
| --- | --- | --- | --- | --- |
| 作用范围 | 场景内的文字替换 | 到达 / 揭晓段落节拍 | 场景之间 | 文字到文字的接缝 |
| 轴向 | Z，朝向观众 | Z，远离观众 | X / Y | X，逐词 |
| 峰值模糊 | 文字 10px / 满屏 20px | 文字 10px / 满屏 20px | 不需要 | 无（靠渐隐完成） |
| 切点处的不透明度 | 0.15 | 0.15 | 退场在切点前已淡出 | 最后一个词在切点处消失 |
| 感觉 | 向前穿过 | 抵达 | 被侧向带走 | 一道越过接缝的波浪 |

## 反模式

| 不要 | 原因 | 改为 |
| --- | --- | --- |
| zoom-through 期间两段文字同时可见 | 文字重叠会打破 Z 轴错觉 | 在模糊峰值处硬切，一次只出现一段文字 |
| 对文字尺度的主体用 20px 模糊 | 字形糊掉；读起来像故障 | 文字用 10px，只有满屏才用 18–20px |
| 切点两侧的元素走不同路径 | 眼睛追踪一个方向，切换却走向另一个方向 | 同一属性，同一方向 |
| 替换处的模糊 / 不透明度不一致 | 可见的闪烁或亮度跳变 | 切点那一帧数值完全一致 |
| 入场用平缓的 easing（`power2.out`） | 入场速度感觉比退场慢 | 镜像退场：`power4.out` / `expo.out` |
| 完全移出 / 移入屏幕 | 浪费时间，打破速度错觉 | 部分位移 + 提前渐隐 |
| 孤立的元素在切点前很久就开始淡出 | 接缝处出现冷场 | 渐隐在切点前约 0.02 秒结束，或改用逐词级联 |
| 对正文文字用 zoom-through | 小字在 0.75 缩放下无法阅读 | 只用于标题和短语 |
| 场景切换不用 cut-the-curve | 静态切换感觉像幻灯片 | cut-the-curve 是默认做法 |
