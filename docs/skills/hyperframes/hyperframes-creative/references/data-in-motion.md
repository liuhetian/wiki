# 运动中的数据

关于视频 composition 中数据和统计数字的轻量指导。美学由 `house-style.md` 负责；这里只处理数据特有的坑。

## 视觉连续性

当连续出现的几个数字属于同一个概念时（Q1 → Q2 → Q3 → Q4，或者同一款产品的三项指标），让它们留在同一个视觉空间、保持同一种美学。只有数值（VALUE）在变。美学上的变化应该标志着一个新概念，而不只是一个新数字。

## 数字需要视觉分量

一个孤零零的数字会飘在空白里。给每个指标配一个让它有存在感的视觉元素 —— 按比例填充的条、背景色的变化、代表这个数值的形状、进度环。这个视觉元素不一定要是图表 —— 它只需要填满画面，让数据显得可触可感，而不只是背景上的一行字。

## 避开网页式图式

- **不用饼图** —— 难以比较，看起来像 PowerPoint
- **不用多轴图表** —— 观众在 3 秒的窗口里没法研究交叉点
- **不用 6 宫格仪表盘** —— 2-3 个相关指标并排可以，6 个以上就是网页式图式
- **不用网格线、刻度线或图例** —— 视觉噪音，在运动中毫无增益
- **不用图表库的输出** —— 用 GSAP + SVG/CSS 搭建，不用 D3 或 Chart.js
