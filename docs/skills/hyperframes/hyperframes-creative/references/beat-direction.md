# 段落节拍导演

如何规划和导演多场景 composition 中的单个场景（段落节拍，beat）。写任何多场景视频之前都要先读。

## 逐拍导演

每一拍都是一个**世界**（WORLD），不是一个版式。在写 CSS 规格和 GSAP 指令之前，先描述观众**体验**（EXPERIENCES）到的是什么。好分镜和平庸分镜的差别：

**平庸：** 「深海军蓝背景。'$1.9T' 白色，280px。logo 在左上。波浪图在右下。」  
**出色：** 「镜头已经在一片广阔的暗色画布上空飞到半途。渐变波浪像北极光一样横扫画面 —— 活的，流动的。'$1.9T' 以巨大的力量**砸**（SLAMS）进画面，连波浪都随之泛起涟漪。这不是一张幻灯片 —— 这是一个瞬间。」

第一种描述的是像素。第二种描述的是体验。先写出第二种，再去琢磨像素。

每一拍都应该包含：

### 概念

用 2-3 句话说清这一拍的核心想法。我们身处哪个视觉**世界**？驱动它的是什么隐喻？观众应该**感受**（FEEL）到什么？这是最重要的部分 —— 其余一切都从它生长出来。

### 情绪导向

写文化和设计上的参照，而不是 hex 色值：

- 「几何、有节奏、精确。想想 Josef Albers 或包豪斯的色彩研究。」
- 「温暖的工作空间。是好看的笔记本那种气质，不是技术蓝图。」
- 「电影片头。那种让你不由得往前凑的开场。」

### 动画编排

给每个元素写出具体的运动动词 —— 不是「它动画进场」，而是**怎么**进场。动词来自这一拍的概念和内容，而不是来自某个能量档位。一个健康养生品牌的「慢」拍，如果内容讲的是放下，里面照样可以有东西 DROPS（落下）。一个数据拍，如果品牌的身份是失重感，也可以 FLOAT（漂浮）。

运动动词的词汇表（按物理特性组织，而不是按能量高低）：

**冲击 / 重量：** SLAMS（砸入）、CRASHES（撞入）、PUNCHES（猛击）、STAMPS（盖章式落下）、SHATTERS（碎裂）、DROPS（带着力道落下）  
**方向性 / 从容：** SLIDES（滑动）、PUSHES（推）、PULLS（拉）、WIPES（擦除）、CUTS（切）  
**揭示 / 构建：** DRAWS（描画）、FILLS（填充）、GROWS（生长）、EXPANDS（展开）、ASSEMBLES（组装）、COUNTS UP（数字递增）  
**有机 / 氛围：** FLOATS（漂浮）、DRIFTS（游移）、BREATHES（呼吸）、PULSES（脉动）、ORBITS（环绕）、MORPHS（变形）  
**机械 / 精确：** TYPES ON（逐字打出）、CLICKS（咔哒）、LOCKS IN（锁定到位）、SNAPS（吸附）、STEPS（步进）

每个元素都要有一个动词。如果你说不出这个动词，说明这个元素还没设计好。动词应该从这一拍的概念推导出来 —— 而不是去查「高能量」或「低能量」的拍子通常用什么。

具体到文字元素，你可以按 ID 指定一个确定性的、有名字的效果（例如 `typewriter`、`kinetic-center-build`、`soft-blur-in`），而不必从头自己发明时序 —— 这套 24 种效果的词汇表以及加载方法在 `skills/hyperframes-animation/adapters/animate-text.md`。

### 转场

这一拍如何交接给下一拍。写明类型和参数。

**什么时候选哪种：**

| 以下情况选 shader 转场                                                    | 以下情况选 CSS 转场                                                           | 以下情况选硬切                                            |
| ------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| 揭示、大的反应镜头、产品 / logo 揭幕、能量转换、「哇」的时刻 | 连续镜头运动的段落，场景感觉像是一个运动被切成了几段 | 快速连发的列表、踩在节拍上的打击式剪辑、喜剧节奏 |
| 音乐 / 旁白用一个强拍或音效重击来强调的任何时刻                   | 用共同的运动语汇从一个 composition 平滑过渡到下一个的段落    | 3 次以上踩着速度的快速切换序列                   |
| 转场本身*就是*画面的品牌时刻                       | 极简 / 编辑式的节奏                                                            | 任何 0.3-0.8s 的转场都会显得太慢的时候              |

经验法则：如果这一拍是视频的*核心看点*，就用 shader 转场切进去。如果这一拍是连接组织，CSS 交叉淡化就够了。一支 5-7 拍的品牌短片通常需要 1-2 个 shader 转场（hero 揭示 + CTA）—— 用太多会削弱它们的冲击力。

**同一个 composition 里混用 shader 转场和 CSS 交叉淡化转场是受支持的。** 在任何一条转场配置上省略 `shader`，就会得到平滑的不透明度交叉淡化 —— 不管怎样，所有场景的可见性都由 HyperShader 管理。让 HyperShader 来创建 timeline（不要传入预先建好的 `timeline:` 选项），在 `init()` 之后把 composition 的所有 tween 加到返回的 `tl` 上。配置片段见 `skills/hyperframes-animation/transitions/overview.md` → 「CSS vs Shader」。

**CSS 转场** —— 13 个类别共 30 多种图式。完整代码在 `skills/hyperframes-animation/transitions/`（通过 `catalog.md` 路由）。按能量和感觉来挑：

| 类别           | 图式                                                                 | 运动特性                                                           |
| ------------------ | ------------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| **推入 / 滑动**   | Push slide、vertical push、elastic push、squeeze                         | 内容像在一块连续的表面上一样穿过画面              |
| **缩放 / 变焦**   | Zoom through、zoom out                                                   | 视角变化 —— 朝内容靠近或远离                    |
| **径向 / 裁切**  | Circle iris、diamond iris、diagonal split                                | 几何揭示 —— 内容从一个形状里显现，或被一个形状覆盖                |
| **3D**             | 3D card flip                                                             | 物理感 —— 内容像一个实物一样翻转                            |
| **溶解**       | Crossfade、blur crossfade、focus pull、color dip                         | 重叠与混合 —— 转场期间两个场景同时存在 |
| **遮盖 / 百叶窗** | Staggered color blocks、horizontal blinds（6/12 条）、vertical blinds | 结构感 —— 内容被切片、分层或遮盖                        |
| **光**          | Light leak overlays、overexposure burn、film burn                        | 有机的胶片感 —— 光漫溢过画面                               |
| **扭曲**     | Glitch（CSS RGB 抖动）、chromatic aberration、ripple、VHS tape          | 不稳定 —— 画面本身似乎出了故障                      |
| **模糊**           | Blur through、directional blur                                           | 柔和失焦 —— 内容模糊着进入或退出                                     |
| **机械**     | Shutter（两半式）、clock wipe（9 点扇形）                           | 精确 —— 带有可见机械逻辑的转场                      |
| **网格**           | Grid dissolve（12/120 格）                                             | 碎片化 —— 画面碎裂成小块                               |
| **破坏**    | Page burn（SVG clip-path + canvas 边缘）                                   | 戏剧性的衰败 —— 前一个场景被摧毁                           |
| **其他**          | Gravity drop、morph circle                                               | 不属于其他类别的物理或形状类运动           |

常用快选：

- **速度匹配上移**：退出 `y:-150, blur:30px, 0.33s power2.in` → 进入 `y:150→0, blur:30px→0, 1.0s power2.out`
- **甩镜（Whip pan）**：退出 `x:-400, blur:24px, 0.3s power3.in` → 进入 `x:400→0, blur:24px→0, 0.3s power3.out`
- **模糊穿越（Blur through）**：退出 `blur:20px, 0.3s` → 进入 `blur:20px→0, 0.25s power3.out`
- **变焦穿越（Zoom through）**：退出 `scale:1→1.2, blur:20px, 0.2s power3.in` → 进入 `scale:0.75→1, blur:20px→0, 0.5s expo.out`
- **硬切 / 猛切（smash cut）**：瞬间完成，用于快速连发的序列

时长 preset：snappy（0.2s）、smooth（0.4s）、gentle（0.6s）、dramatic（0.5s）、instant（0.15s）、luxe（0.7s）。

**Shader 转场** —— 14 种内置的 WebGL GPU 效果。用 `npx hyperframes add <name>` 安装（block 名 ≠ shader 名 —— 见 `skills/hyperframes-registry/references/discovery.md`）；完整 API 在 `packages/shader-transitions/README.md`。

| Shader                  | 视觉描述                                                                             | 时长范围 |
| ----------------------- | ---------------------------------------------------------------------------------------------- | -------------- |
| **domain-warp**         | 有机的 FBM 溶解 —— 两个场景朝彼此扭曲，中点处有一次强调色闪光 | 0.5–0.8s       |
| **ridged-burn**         | 多重分形遮罩通过一条燃烧渐变揭示进入的场景，边缘带火花       | 0.5–0.8s       |
| **whip-pan**            | 10 次采样的水平运动模糊 + 横向交叉淡化 —— 读起来像镜头在两个镜头之间横摇   | 0.3–0.5s       |
| **sdf-iris**            | 圆形 SDF 从中心扩张，扩张边缘带有强调色调的辉光环            | 0.5–0.7s       |
| **ripple-waves**        | 径向驻波 UV 位移 —— 场景交叉时内容向外荡出涟漪                 | 0.6–1.0s       |
| **gravitational-lens**  | 向中心收缩牵拉 + R/B 色散分离 —— 内容向内弯曲后再释放       | 0.6–1.0s       |
| **cinematic-zoom**      | 12 次 RGB 偏移的径向变焦模糊采样 —— 从中心放射出的运动拖影                   | 0.4–0.6s       |
| **chromatic-split**     | R/B 通道径向向外偏移，G 保持不动 —— 通道分离后再合拢                      | 0.3–0.5s       |
| **swirl-vortex**        | 带 FBM 噪声的逆时针旋涡 —— 内容旋转着离开，新场景旋转着进入                   | 0.5–0.8s       |
| **thermal-distortion**  | 垂直正弦 + FBM 水平位移 —— 整个画面上热浪般的闪烁               | 0.5–0.8s       |
| **flash-through-white** | 穿过白色中点淡化 —— 0.01s 时几乎不可见，0.3s 时明显可见                    | 0.01s–0.3s     |
| **cross-warp-morph**    | FBM 向量场同时位移两个场景；第三个 FBM 决定擦除方向的偏向                  | 0.5–0.8s       |
| **light-leak**          | 固定在画外的光源，带指数衰减、暖色调和一道脊状光晕               | 0.5–0.8s       |
| **glitch**              | 行位移 + RGB 横向分离 + 扫描调制 + 色调分离 + 闪烁              | 0.3–0.5s       |

**你不局限于这里列出的内容。** 这些是内置选项，但你可以、也应该：

- 从零**编写自定义 GLSL shader**，做出独特的转场效果
- **上网搜索** shader 代码（ShaderToy、GLSL Sandbox、GitHub）并加以改编
- **自己搭建不属于任何类别的 CSS 转场** —— 用新方式组合 clip-path、transform、filter
- 如果你需要某种专门的效果，**请用户**提供或去找

如果分镜要求的效果还不存在 —— 那就把它做出来。浏览器能跑的东西，框架都能渲染。

### 纵深层次

前景、中景、背景里各有什么。每一拍至少要有 2 层：

- 「BG：深海军蓝填充 + 微弱的径向辉光。MG：带投影的数据卡片。FG：右下角的品牌 logo。」

### 音效提示

什么时刻响什么声音：

- 「在捕捉脉冲那一下 —— 一声柔和、温暖的模拟快门咔哒声。」
- 「左侧带一层微弱的低频持续音。折叠时：持续音切断。静默。然后是一声干净的单音钟鸣。」

## 节奏规划

写 HTML 之前，先声明你的场景节奏：哪些场景是快速一击，哪些是停留，shader 落在哪里，能量在哪里达到峰值。在实现之前先给这个模式起名 —— fast-fast-SLOW-fast-SHADER-hold。

**节奏从分镜和品牌推导出来，而不是查表。** 一家建筑事务所的 15 秒社交广告，和一个游戏品牌的 15 秒社交广告，节奏是不同的 —— 都是 15 秒，但一个是 慢揭示-停留-CTA，另一个是 快速连发-SLAM-钩子。视频类型设定约束（时长、大致的拍数）；品牌和内容决定这些拍子是慢还是快，是疏还是密，是戏剧化还是克制。

驱动节奏决策的问题：

- 观众应该经历怎样的情绪旅程？峰值时刻在哪里？
- 旁白最重的强调落在哪里？能量通常就应该在那里达到峰值。
- 品牌自身的视觉节奏暗示了什么 —— 从容不迫还是急迫？
- 这个时长实际上能撑起多少拍，而不显得仓促或注水？

一支想在 15 秒里 2 秒抓住观众、展示 3 个功能、再以 CTA 收尾的社交广告，会让人觉得只是噪音。有时候，「钩子-停留-CTA」配一个强功能，才是 15 秒的正确节奏。在实现之前，说出你规划好的节奏。

## 速度匹配转场

用加速的 easing（power2.in 或 power3.in）加上逐渐增强的模糊让离场的那一拍退出。用减速的 easing（power2.out 或 power3.out）加上逐渐清晰的模糊让入场的那一拍进入。两条 easing 曲线最快的那一点在切点相遇 —— 观众感知到的是连续的镜头运动，而不是两段分离的动画。让退出速度和进入速度的差距保持在约 5% 以内。
