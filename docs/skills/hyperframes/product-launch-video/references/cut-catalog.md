# 切法目录 —— 帧内接缝（由 worker 构建）

> **一份 worker 构建配方（Step 5）—— 是 `../../hyperframes-animation/rules/` 的兄弟文档，不是第二份运动文档。** 这里是 **frame worker 在自己的 composition 内部构建**的帧内切换（Z 轴缩放 + 模糊 + 不透明度 tween，或逐词的 x 交错，全部放在该帧自己那条暂停的 GSAP timeline 上）。它们**不是**帧与帧之间的转场：那归 story 管，通过 `transition_in` 指定，由 harness 的注入器按一套**独立的 registry 词表**（`crossfade` / `blur-crossfade` / `push-slide` / `zoom-through` / `squeeze`）盖印上去 —— 这里的目录名（**cut-the-curve / inverse-zoom / waterfall**）**不是**合法的 `transition_in` 值。当一帧的镜头序列内部有接缝时使用本目录 —— 场景内的文字 / 元素替换、**Scene 到 Scene** 的切（`Scene` 是一帧**之内**的一段时间窗口，**不是**帧与帧的边界），或者一行文字换到另一行文字 —— 并且你希望它读起来像一个连续的运动，而不是生硬的幻灯片式切换。（`zoom-through` 两边都有：在 registry 里是整帧包裹层的转场，在这里是元素级的 Z 轴切 —— 同一个思路，作用范围不同。）

四种营造纵深感和连续性的技法：

1. **Zoom-Through** —— 场景内的文字替换，Z 轴，朝观众方向推进
2. **Inverse Zoom-Through** —— Z 轴替换，朝远离观众的方向移动
3. **Cut the Curve** —— 场景之间在 x/y 上的转场
4. **Waterfall Cut** —— 逐词的 cut-the-curve，退出和进入都交错进行

四者底层是同一个原理：**在速度峰值处切，切点两侧的方向和速度要匹配。** 区别只在于轴向、作用范围和粒度。

**在一个接缝处选哪种：** 对于一个**未说完**的短语（用几个视觉上各不相同、但仍朝同一个要点推进的场景，搭起一个更大的意思 —— 多行文字、一串连续的卡片），用 **cut-the-curve** / **waterfall**。对于一次**状态转变**（转到视频的一个**新**部分 —— 最常见的是 hook → 背景交代，即两个不同章节之间），用 **zoom-through**；到达 / 收获型的一拍则用 **inverse zoom-through**。把这些串起来，让帧内部的接缝感觉像一台摄像机在内容中穿行。

## 模糊逻辑（适用于所有 Z 轴变体）

模糊能在切点处把速度感卖出去，但它必须随**主体尺寸**缩放：

| 主体 | 峰值模糊 | 原因 |
| --- | --- | --- |
| 文字尺度（标题、一行字、词组） | **10px** | 到 20px 时文字会糊到无法辨认 —— 眼睛丢失了正在追踪的那个词，这一切读起来像故障，而不是速度。（2026-06-10 的教训：until-now 的 inverse zoom 当初以 20px 上线，看起来一团糊；10px 能让字形在切换中途仍可辨认。） |
| 全画面表面（终端窗口、卡片、截图） | **18–20px** | 大表面有边缘和纹理，经得起重度模糊；全画面运动上模糊太轻，读起来像渲染卡顿而不是运动。 |

切点两侧使用**相同**的峰值模糊 —— 在替换的那一帧，数值必须一致。模糊加在**包裹层**上，绝不加在单个子元素上。

## 1. Zoom-Through（前向）

### 问题

文字进入、停留、退出。然后下一段文字进入、停留、退出。每个文字块都是独立的 —— 没有纵深，没有连续性。视频感觉像一套幻灯片。

### 原理

在 Z 轴上做速度匹配的切。你**永远不会同时看到两段文字。**退出的文字朝观众方向放大（加速），模糊和不透明度在切点达到峰值，掩盖住一次硬切，进入的文字则从后方继续放大（减速进入焦平面）。一个连续的向前运动，两段不同的文字。

### 三个阶段

**阶段 1：退出** —— 文字向前加速（朝观众）

- 缩放：`1.0 -> 1.2`，模糊：`0px -> 10px`（文字尺度；见模糊逻辑），不透明度：`1.0 -> 0.15`
- 缩放 / 模糊的 easing：`power3.in`（陡峭加速）
- 不透明度的 easing：`none`（线性 —— 均匀变暗，与缩放分开）
- 时长：0.2s

**阶段 2：硬切**，发生在速度峰值 + 模糊峰值处

- 退出元素：`opacity: 0`（通过 `tl.set` 瞬时设置）
- 进入元素：`opacity: 0.15, scale: 0.75, blur: 10px`（通过 `tl.set` 瞬时设置）
- 所有属性在切点处一致：模糊、不透明度，以及缩放**方向**（两者都在放大）

**阶段 3：进入** —— 文字继续向前（长大进入焦平面）

- 缩放：`0.75 -> 1.0`，模糊：`10px -> 0px`，不透明度：`0.15 -> 1.0`
- Easing：`expo.out`（起始的陡峭爆发与退出速度匹配，之后长时间落定）
- 时长：0.5s

### 为什么退出时不透明度必须单独处理

缩放用的是 `power3.in`，但这会让不透明度在 tween 的大部分时间里都接近 1.0。把不透明度拆成单独的 tween 并使用线性 ease，变暗才会均匀。进入时，所有属性可以共用 `expo.out`。

## 2. Inverse Zoom-Through（反向）

镜像版本：摄像机"往后拉"，而不是往前穿。退出的元素**后退**、远离观众；进入的元素以**超大尺寸**到达（仿佛它原本就在摄像机正后方），然后收缩进焦平面。两者都朝缩小的方向运动 —— 同方向规则依然成立，只是反过来。

**什么时候用它而不用前向版本：**到达型的段落节拍。进入的元素从比画面更大的尺寸落下，因而带着存在感 —— 适合收获型的一句（"That changes today."）、一条巨大的回复，或一个停住的终态。前向 zoom-through 读起来是在内容中*向前推进*；反向读起来是*抵达*内容。

### 三个阶段

**阶段 1：退出** —— 元素后退（远离观众）

- 缩放：`1.0 -> 0.8`，模糊：`0px -> 10px`（文字尺度）
- 缩放 / 模糊的 easing：`power3.in`；不透明度：`1.0 -> 0.15`，用 `none`（单独的 tween）
- 时长：0.2s

**阶段 2：硬切**

- 退出元素：通过 `tl.set` 设为 `opacity: 0`
- 进入元素：通过 `tl.set` 设为 `opacity: 0.15, scale: 1.25, blur: 10px`

**阶段 3：进入** —— 进入的元素收缩归位

- 缩放：`1.25 -> 1.0`，模糊：`10px -> 0px`，不透明度：`0.15 -> 1.0`
- Easing：`expo.out`，时长：0.5s

已上线的示例：`boring → until-now` 和 `B3 → "That changes today."`（sfx-music-launch）；editorial-paper 里的第 3/4 个接缝（`follow-up → thinking`、`thinking → compose UI`）。

## 3. Cut the Curve（场景转场）

### 原理

**所有场景到场景的转场**都在 x 和 y 轴上用 cut-the-curve。退出场景的 hero 元素朝一个方向加速，切点落在运动途中，进入场景的 hero 元素沿**同一方向**继续运动并减速。没有任何东西完全退出到画面外，也没有任何东西从完全画面外进入 —— **速度加上不透明度渐隐会骗过眼睛**；部分位移就足够了。

### 同一路径，同一方向

如果场景 A 的 hero 向左滑，场景 B 的 hero 就从右侧进入并继续向左滑。两者都向左移动。一个连续的运动。

| 方向 | 场景 A 退出 | 场景 B 进入起点 | 场景 B 进入终点 |
| --- | --- | --- | --- |
| 向左 | `x: 0 -> -230` | `x: +230` | `x: 0` |
| 向右 | `x: 0 -> +230` | `x: -230` | `x: 0` |
| 向上 | `y: 0 -> -230` | `y: +230` | `y: 0` |
| 向下 | `y: 0 -> +230` | `y: -230` | `y: 0` |

### 用镜像的 ease 做速度匹配

最干净的匹配方式：退出用 `power4.in`、进入用 `power4.out`，距离和时长**相同** —— 在数学上，这两半正好构成一个 `power4.inOut` 组合曲线，所以进入的元素恰好在假想路径的 50% 处以完全相同的速度接上（例如 230px / 0.3s，切点两侧都约为 3,070 px/s）。

渐隐的诀窍：退出的不透明度在其行程约 25–30% 处就完成（渐隐时长 ≈ 0.18–0.3s，而运动时长为 0.3–0.34s）—— 元素在仍明显加速时就消失了，什么都不必到达画面边缘。进入则在减速过程中从约 0.35 快速淡**入**。让**最后**一个渐隐的元素恰好在硬切那一刻消失 —— 没有任何东西在动的空档读起来像尴尬的冷场。

### 规则

- 所有场景转场都用 cut-the-curve —— 它是默认做法，不是点缀
- 两侧同方向；镜像的 `.in`/`.out` ease，相同距离 + 时长
- 退出时长短（0.2–0.4s），进入时长 >= 退出时长
- 部分位移 + 渐隐，绝不做完全出画的运动

## 4. Waterfall Cut（逐词的 cut-the-curve）

**词**粒度的 cut-the-curve —— 文字到文字的接缝上，向左切的最强版本。退出那一行的每个词都沿自己一条明显的曲线加速离开；进入那一行的每个词都在半空中瀑布般依次切入。交错让切变成一道波浪，眼睛顺着它越过接缝。

### 退出（每个词）

- 运动：`x: 0 -> -230`，0.34s，用 **power4.in** —— 比常用的 power2 明显得多的加速曲线：词先几乎是在挪，然后**猛地撕开**
- 渐隐：`opacity -> 0`，0.18s（单独的 tween，`power1.in`）—— 在词只走完约 25–30% 行程时就完成
- 交错：按阅读顺序，每词约 0.022s，时间安排成让**最后**一个词恰好在硬切那一刻淡出完毕

### 进入（每个词）

- `fromTo x: +230 -> 0, opacity: 0.35 -> 1`，0.3s，用 **power4.out** —— 组合曲线镜像的后半段；每个词点亮时就已经以匹配的速度在运动
- 瀑布式交错，间隔**逐渐缩小**（起始 0.05s，每个词乘以约 0.84），让瀑布在整行上加速 —— 瀑布应当一个词比一个词快，而不是以固定的逐词延迟匀速推进
- 在构建时就把所有词预设为 `x: +230, opacity: 0` —— 仅靠 `immediateRender: false`，尚未开始的词会在交错窗口期间静止地显示在原位

### 整行变体

单行的一拍（例如一句大号的开场文字）以一个整体退出，使用同样明显的加速曲线，但把它的渐隐拉长到约 0.3s，在切点前约 0.02s 结束 —— 一个孤立元素过早淡出会留下冷场，而逐词瀑布本可以把它填上。

已上线的示例：`until-now.html` B1→B2→B3（sfx-music-launch）。

## 选择变体

| | Zoom-Through | Inverse Zoom | Cut the Curve | Waterfall Cut |
| --- | --- | --- | --- | --- |
| 作用范围 | 场景内文字替换 | 到达 / 收获型一拍 | 场景之间 | 文字到文字的接缝 |
| 轴向 | Z，朝向观众 | Z，远离观众 | X / Y | X，逐词 |
| 峰值模糊 | 文字 10px / 全画面 20px | 文字 10px / 全画面 20px | 不需要 | 无（靠渐隐完成） |
| 切点处不透明度 | 0.15 | 0.15 | 退出元素在切点前已淡出 | 最后一个词在切点消失 |
| 感觉 | 向前推进穿过 | 抵达 | 被横向带走 | 一道越过接缝的波浪 |

## 反模式

| 不要 | 原因 | 改为 |
| --- | --- | --- |
| zoom-through 期间两段文字同时可见 | 文字重叠会打破 Z 轴错觉 | 在模糊峰值处硬切，一次只出现一段文字 |
| 对文字尺度的主体用 20px 模糊 | 字形糊掉；读起来像故障 | 文字用 10px，只有全画面才用 18–20px |
| 切点两侧元素走不同路径 | 眼睛追着一个方向，切却走了另一个方向 | 同一属性，同一方向 |
| 替换时模糊 / 不透明度不匹配 | 出现可见的闪烁或亮度跳变 | 切点那一帧的数值完全相同 |
| 进入用平缓的 easing（`power2.out`） | 进入速度感觉比退出慢 | 镜像退出：`power4.out` / `expo.out` |
| 完全出画的退出 / 进入 | 浪费时间，并打破速度错觉 | 部分位移 + 提早渐隐 |
| 孤立元素远在切点之前就淡出 | 接缝处冷场 | 渐隐在切点前约 0.02s 结束，或改用逐词瀑布 |
| 对正文用 zoom-through | 小字在 0.75 缩放下无法阅读 | 只用于标题和短语 |
| 场景切换不用 cut-the-curve | 静态切换感觉像幻灯片 | cut-the-curve 是默认做法 |
