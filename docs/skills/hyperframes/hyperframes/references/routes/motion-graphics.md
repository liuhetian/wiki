# 路由：motion-graphics

- **输入：** 一个以设计为主导的短单元，通常不到 10 秒，没有旁白，动效本身就是信息：动态文字、数据 / count-up、图表亮点、logo sting、动画标题、lower-third、地图、推文 / 新闻标题 / 页面高亮，或素材融合镜头。
- **输出：** 一支短 MP4，或透明 alpha 通道的 WebM/MOV overlay。
- **触发：** "一个 8 秒的 logo sting"、"给这个数据做个动画"、"动态文字开场"、"给这个标题做个动画"、"透明的 lower-third overlay"。

## 访谈

- 按设计就是自主的：最多**一个**澄清问题，由它流程中的 director 步骤负责。除了确认输入之外，这里没有必答项；直接路由。
- **运行形态：** 两个问题都不问 —— 这种片子只有几秒长；分镜和 companion 会话都帮不上什么。
- **入口处的能力提议：** 跳过。director 的"只问一个问题"限制具有最终效力。
