# 路由：product-launch-video

- **输入：** 一个网站 URL；一份点名了某个网站的脚本或 brief；或者一份无法推出对应网站、或明确写了"不要抓取"的产品发布脚本。除非 brief 选了不抓取模式，否则抓取网站素材和品牌 token。用户提供了脚本文案时，要问清它是逐字照念的旁白，还是可以重组。
- **输出：** 一支产品宣传片、发布视频、网站导览或展示 MP4。最佳长度 30–90 秒，硬上限约 3 分钟。"原样展示"类的 brief 用抓取到的页面截图当主角，而不是另开一条路由。
- **触发：** "给 X 做个发布视频"、"给我们网站做个宣传片"、"把这份脚本做成 60 秒宣传片"、"纯文字的发布视频"、"把这个网站做成视频"、"用这个 URL 做个网站导览"。

## 访谈

- **先问：推销还是展示？** 请求没说清时问一个问题：是推销这个产品（宣传片），还是原样展示网站（导览 / 展示）？"展示"这个回答**是意图，不是另一条流水线**：把它写进 `BRIEF.md`（`## Intent` / `## Customizations` —— "以网站自己的抓取截图作为视频素材"），工作流的常规步骤会照此执行 —— 抓取到的截图成为主打的 `asset_candidates`。
- **必答项：** **角度（angle）** —— 从网站 / brief 自身的定位里找故事形状，推荐其中一个并给出依据 · **时长** —— 最佳 30–90 秒，按素材多少伸缩 · **投放渠道** —— YouTube / 嵌入 → 16:9 · X / LinkedIn / Instagram 信息流 → 1:1 · Shorts / TikTok → 9:16。
- **条件项：** 原样展示的请求追加问 **展示什么** —— 整个网站，还是指定的页面 / 区块（写进 `BRIEF.md` 正文）；粘贴来的脚本 / brief 追加问 **`VO_MODE`**（逐字照念还是重组？）；只点名了网站的脚本追加问 **要不要抓取？** —— 抓取网站拿品牌和素材（默认），或者纯文字 / "不要抓取"（不抓取模式，由一个 preset 提供设计系统）。
- **提案轮：** `message` + `angle`，在推销还是展示定下来之后进行 —— 各个提案继承这个意图。
- **运行形态：** 两个问题都问。
