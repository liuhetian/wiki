# 路由：faceless-explainer

- **输入：** 要讲解的一个话题、一篇文章、一份笔记或任意文字，没有要推销的产品，也没有要抓取的网站。
- **输出：** 一支无人出镜讲解视频 MP4，画面是自创的文字排版、抽象图形、图示或数据可视化。最佳长度 30–90 秒，硬上限约 3 分钟。
- **触发：** "做一个关于 X 的无人出镜讲解视频"、"用视频讲讲 DNS 是怎么工作的"、"把这篇文章做成讲解视频"。

## 访谈

- **必答项：** **角度（angle）** —— 概念 / 教程 / 清单 / 叙事，推荐文字自身形态所提示的那一种 · **时长** —— 在 30–90 秒的最佳区间内，按文字实际要讲的内容多少伸缩 · **投放渠道** —— YouTube / 嵌入 → 16:9 · X / LinkedIn / Instagram 信息流 → 1:1 · Shorts / TikTok → 9:16。
- **条件项：** 粘贴来的脚本追加问 **`VO_MODE`** —— 逐字照用，还是按场景重组？
- **提案轮：** `message` + `angle` —— 同一个话题的五种讲法就是五支不同的视频。
- **运行形态：** 两个问题都问。
