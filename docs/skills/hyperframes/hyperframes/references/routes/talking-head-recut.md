# 路由：talking-head-recut

- **输入：** 要包装的已有口播、访谈或播客素材画面。底下的片段原样播放。
- **输出：** 同一段素材画面，加上与转录稿同步的图形 overlay 卡片：动态标题、lower-third、数据标注、引语摘录、侧边面板或画中画。任意时长。
- **触发：** "包装一下这个视频"、"给我的演讲加图形 overlay"、"给这段访谈加 lower-third 或数据标注"。

## 访谈

- **必答项：** 哪个片段（输入文件）。
- **延后（需预告）：** 它的渲染策略问题 —— 画幅比例、布局、风格组、卡片数量 —— 留到它的 Step 7 再问，那时推荐会基于探测过的素材画面和转录稿给出。告诉用户之后会有这些问题。
- **运行形态：** 两个问题都不问。
