# 路由：embedded-captions

- **输入：** 要加字幕的已有口播素材画面。它是一个实际的媒体文件，不是 URL 或创意 brief。
- **输出：** 同一段素材画面，原封不动，加上一层字幕和选定的字幕风格（caption identity）。人物主体可以遮挡嵌入的字幕。任意时长。
- **触发：** "加字幕"、"加上字幕"、"字幕放在人物后面"、"给我的片段加电影感字幕"。

## 访谈

- **必答项：** 哪个片段（输入文件）。
- **延后（需预告）：** 字幕**风格（identity）**的挑选 —— 它的 Step 0 会先探测片段，再从目录里筛出 2–3 种风格并推荐其中一种。告诉用户之后会有这一步。
- **运行形态：** 两个问题都不问 —— 素材画面原封不动；没有分镜可评审。
