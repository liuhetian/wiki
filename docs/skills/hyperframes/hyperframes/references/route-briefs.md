# 路由 brief（已迁移）

每条路由的访谈条目 —— 必答项、条件问题、延后提问、可由提案回答的字段，以及运行形态问题是否适用 —— 现在都放在该路由自己的文件里，和它的输入 / 输出 / 触发契约在一起：

`references/routes/<workflow>.md` —— 例如 `routes/faceless-explainer.md`、`routes/pr-to-video.md`（包含 PR 规模 → 时长对照表）。

访谈流程本身（那八个步骤）在 `references/intent-interview.md` 里。字段语义和提问规则：`hyperframes/references/brief-contract.md` § 2–3。
