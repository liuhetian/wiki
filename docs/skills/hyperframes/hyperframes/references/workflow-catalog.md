# 工作流目录（已迁移）

每个工作流的输入 / 输出 / 触发契约现在都放在它自己的路由文件里 —— 每个候选读一个小文件，而不是读一整份目录：

`references/routes/<workflow>.md` —— 例如 `routes/product-launch-video.md`、`routes/general-video.md`、`routes/remotion-to-hyperframes.md`。

同一个文件还带有该路由的访谈条目（必答项、条件项、延后提问、运行形态），所以确认一条路由恰好只需要读一次。
