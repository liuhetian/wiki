# 电影感字幕的美学原则

这 18 条规则区分了「设计出来的」字幕作品和「preset 生成的」字幕作品。这是本 skill 里最重要的一份参考 —— 每个 plan.json、每个 Standard 模式的 HTML 在提交之前都要对照它们检查一遍。

整个竞争论点：2026 年的每一款 AI 字幕工具（Veed、Submagic、Opus Clip、Captions.ai、CapCut）都是 **preset 挑选器**。它们递给用户一盒蜡笔。这个 skill 是**导演** —— 它会做判断。靠品味赢过它们，而不是靠功能数量。

---

## 18 条规则

### 1. 主体永远优先

字幕的存在是为了服务这张脸，而不是和它抢。如果字幕比说话人先抓住视线，字幕就失败了。**交付任何 plan.json 之前，先问：「先被看到的是字幕还是主体？」** 如果字幕赢了，就缩小、压暗或挪开它。

### 2. 要遮挡，不要悬浮

世界级的字幕设计会把文字放*进*场景里。从肩膀、话筒或头部后面穿过的字母，让人感觉它属于画面内的世界。整齐地漂浮在下三分之一上方的字母，看起来就像 PowerPoint。用 matte 管线 —— 这是对所有竞品的护城河。

### 3. 对比度是层级问题，不是亮度问题

文字后面垫一个白色方框是品味的失败。优先级顺序：

1. `mix-blend-mode: overlay` 或 `screen`，吸收场景亮度
2. 2–3px 的深色描边 + 柔和投影
3. 窄的半透明渐变条（不是实心方框）
4. 把背景 plate 局部压暗 10–15%
5. （最后手段）硬边白色胶囊框 —— 在电影感方向上禁用

### 4. 干掉固定不变的下三分之一

固定在底部的字幕很单调。字幕区域随镜头变化：

- 紧凑特写 → 上方侧栏或 crown
- 中景 → 嵌在后墙 / 吸音棉 / 白板上
- 远景 → 经典的下三分之一，偏向没有主体的一侧

### 5. 一个字族，最多两种字重

层级体现在**字重**（如 500 → 800），而不是**字体**。在一支片子里混用 Montserrat + 手写体 + 衬线体是业余的头号破绽。用 Inter、SF Pro、Söhne、GT America、Aktiv Grotesk 或 Neue Haas Grotesk 这类字重 ≥5 档的字体，靠字重 + 字号来组织。

### 6. 字号越大，字距越紧

展示尺寸（>40pt）要用负字距（-10 到 -30 单位，或 `-0.015em` 到 `-0.035em`）。正文尺寸（相当于 14–20pt）要用正字距（+5 到 +15，或 `+0.005em` 到 `+0.015em`）。以 Apple SF Pro 的光学尺寸模型为参照。Submagic 的默认值恰好反着来 —— 它们看起来廉价就是因为这个。

### 7. 正文字幕的大写字母高度 ≈ 画面高度的 3.5–5%

- 1080p 竖屏（高 1920）：正文 65–95px，强调 / 钩子 130–170px
- 1080p 横屏（高 1080）：正文 40–55px，强调 70–100px
- Hormozi 尺寸（约画面的 7–9%）是**钩子**尺寸，不是正文尺寸。留给包袱句。

### 8. 视频文字里绝不用斜体做强调

斜体是**印刷**惯例，用于段落内部的行文。在 24fps 的运动画面上，它读起来是「歪了」，而不是「加重了」。用字重（特粗）、颜色（单一强调色）或字号（1.3–1.6×）来强调。斜体只在以下情况允许：

- 逐字引用书面材料
- 外来词
- 区分心里想的和嘴上说的

### 9. 色彩纪律：一个色相 + 中性色

每个视频只选**一个**饱和的强调色，用于关键词高亮。Hormozi 的黄 + 绿 + 红对他有效，是因为他的内容本身就很吵。电影感 = 单一强调色 + 白 / 骨白 / 炭灰。默认色板：

- 暗底上用暖白 `#F5EFE6`
- 亮底上用石墨色 `#1A1A1A`
- 强调色从场景采样中选取

### 10. 只给 transform 做动画，绝不动字母本身

`letter-spacing`、`filter:blur`、`font-weight` 的动画会引发 inline-block 重排 → 换行跳动。给 `translateY`、`scale`、`opacity`、`clip-path` 做动画。这条是 embedded-captions 调试过程中定死的。

### 11. 每个词至少可见 0.4s

BBC 的阅读速度是 160–180 wpm（0.33–0.38s/词）。电影感需要更多呼吸空间 —— 每个词 200–220ms 的错开，整句在退场前保持 0.4–0.6s。低于 150ms 的入场读起来很慌乱。

### 12. 错开（stagger）是主要的表达维度

同一句话，错开不同，感觉完全不同：

| 错开 | 感觉 |
| --- | --- |
| 40ms | 机关枪、紧迫、TikTok 钩子 |
| 80ms | 对话感，默认值 |
| 150ms | 从容、纪录片 |
| 250ms+ | 诗意、仪式感 |

按内容的语气来选，不要默认只用一个值。

### 13. 强调在一句话*之内*递进，而不是在句与句*之间*

每个词都加粗 = 没有强调。结构：

- 70% 普通正文
- 20% 轻微提升（颜色或字重，不要两者都用）
- 8% 完整强调（更大、更亮、停留更久）
- 2% 高潮（最大，停留 1.5s，前后各留一口气）

### 14. 每 30 秒打破一次节奏

每个词都用同一种方式 = 眼睛适应了，就不再注意到运动。大约每 30 秒埋一个节奏打破点：

- 一句话从相反方向进场
- 某一个词放到 2× 大小
- 一拍纯静默，不出字幕
- 一次颜色变化

这正是 Submagic preset 作品和设计出来的作品之间的区别。

### 15. 字幕只放增量信息，删掉复述

全部转录。**显示** 70–85%。去掉：

- 填充词（"um"、"like"、"you know"、"I mean"）
- 自我纠正（"I think... I mean actually..."）
- 明显的视觉重复（一边指一边说 "as you can see here"）

编辑判断 —— 现有的 AI 字幕工具都不做这件事。这是纯粹的增益。

### 16. 按换气断句，而不是按时长

在 ≥ 250ms 的自然停顿处分块。跨越换气停顿的字幕感觉不对。Whisper 的词级时间戳让这件事变得很简单。

### 17. 永远按平台设置安全区

- 宽屏和竖屏构图都用 `/hyperframes-studio` 里的安全框（Safe zones）；那个 skill 负责维护这些数值。

把它固化进布局求解器。绝不目测。

### 18. Letterbox / pillarbox 是字幕的用武之地

16:9 源素材转成 9:16 后出现黑边？那些黑边就是字幕的家。在 16:9 导出里放 2.35:1 的电影画幅？在 letterbox 里放衬线体引文，读起来就是纪录片。

## 修辞判断规则（编辑层面）

这些是「给什么上字幕」的决定。现有工具都不做。

- **填充词压制** —— off/light/strong。默认：纪录片用 light，vlog 用 strong。
- **自我纠正折叠** —— 只显示最终版本。
- **按换气分组** —— 在 >250ms 的静默处切分，绝不在一句话中间切。
- **语义强调** —— 对每句话跑一遍 LLM：「哪 1–2 个词承载了意义？」高亮那几个。不要默认高亮重读音节或最响的词。
- **尊重静默** —— 如果说话人为修辞效果停顿 1.5s 以上，不要用残留的上一句字幕去填。让静默呼吸。
- **识别引语** —— "he said, quote…" 或空中比划引号 → 斜体（允许斜体的例外之一）。
- **不要 `[laughs]` / `[sighs]`** —— 那些是无障碍字幕。对美学字幕来说，它们会污染画面。

## 自查清单（渲染前运行）

agent 自己在渲染前过一遍。标出违规项：

- [ ] 先被看到的是字幕还是主体？（规则 #1）
- [ ] 有没有硬边白色胶囊框？（规则 #3 —— 电影感方向上禁用）
- [ ] 特写镜头还在用下三分之一？（规则 #4）
- [ ] 超过 2 种字重或超过 1 个字族？（规则 #5）
- [ ] 用斜体做强调了？（规则 #8 —— 禁用）
- [ ] 超过 1 个饱和强调色？（规则 #9）
- [ ] 在给 letter-spacing 或 filter:blur 做动画？（规则 #10 —— 禁用）
- [ ] 纪录片和 vlog 用了同样的错开？（规则 #12）
- [ ] 每个 group 都做了强调？（规则 #13）
- [ ] 30 秒以上没有节奏打破？（规则 #14）
- [ ] 每个填充词都显示了？（规则 #15）
- [ ] 字幕跨越了换气停顿？（规则 #16）
- [ ] 字幕落在平台 UI 区域里？（规则 #17）

任何一个违规问题答「是」→ 重新生成受影响的片段。
