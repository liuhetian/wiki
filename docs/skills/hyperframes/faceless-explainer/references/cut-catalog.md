# 切法目录 —— 帧内接缝（由 worker 构建）

> **这是一份 worker 构建配方（Step 5）—— 是 `../../hyperframes-animation/rules/` 的兄弟文档，不是第二份运动文档。** 这里讲的是**frame worker 在它自己的 composition 内部构建**的帧内切换（Z 轴缩放 + 模糊 + 不透明度的 tween，或逐词的 x 轴错开，全部放在该帧自己那条暂停的 GSAP timeline 上）。它们**不是**帧与帧之间的转场：那个归 story 管，通过 `transition_in` 指定，由 harness 的注入器从一套**独立的 registry 词汇**（`crossfade` / `blur-crossfade` / `push-slide` / `zoom-through` / `squeeze`）里盖上去 —— 这里目录中的名字（**cut-the-curve / inverse-zoom / waterfall**）**不是**合法的 `transition_in` 取值。当一帧的镜头序列内部有接缝时用这份目录 —— 场景内的文字 / 元素替换、一次 **Scene 到 Scene** 的切（`Scene` 是一帧**之内**的一个时间窗口，**不是**帧与帧的边界），或者一行文字换到另一行文字 —— 并且你希望它读起来像一个连续的运动，而不是生硬的幻灯片式切换。（`zoom-through` 两边都有：在 registry 里它是整帧包裹层级的转场，在这里它是元素级的 Z 轴切 —— 同一个想法，作用范围不同。）

四种营造纵深与连续感的技法：

1. **Zoom-Through（穿越推进）** —— 场景内的文字替换，Z 轴，**朝向**观众运动
2. **Inverse Zoom-Through（反向穿越）** —— Z 轴替换，**远离**观众运动
3. **Cut the Curve（切在曲线上）** —— 场景之间在 x/y 轴上的转场
4. **Waterfall Cut（瀑布切）** —— 逐词的 cut-the-curve，出场和入场都错开

四者底层是同一个原则：**在速度峰值处切，切点两侧的方向和速度保持一致。** 区别在于轴向、作用范围和粒度。

**在一个接缝处如何选：** 对于一个**未完结**的语句（在几个视觉上不同、但仍指向同一个点的场景之间搭建一个更大的想法 —— 多行文字、一串连续的卡片），用 **cut-the-curve** / **waterfall**。对于一次**状态转换**（转到视频的一个**新**部分 —— 最常见的是 hook → 背景交代，两个不同章节之间），用 **zoom-through**；遇到到达 / 揭晓的段落节拍，用 **inverse zoom-through**。把它们串起来，让这一帧内部的接缝感觉像一台摄影机在内容中穿行。

## 模糊逻辑（适用于所有 Z 轴变体）

模糊能在切点处卖出速度感，但它必须随**主体尺寸**缩放：

| 主体 | 峰值模糊 | 原因 |
| --- | --- | --- |
| 文字尺度（标题、一行字、一组词） | **10px** | 到 20px 文字会糊到无法辨认 —— 眼睛丢掉了它正在追踪的那个词，这次切读起来像故障而不是速度。20px 时字形在切的中途会变得软烂；10px 能让它们保持可读。 |
| 满屏表面（终端窗口、卡片、截图） | **18–20px** | 大表面有边缘和纹理，扛得住重度模糊；满屏运动上用较轻的模糊，读起来像渲染卡顿而不是运动。 |

切点两侧使用**相同**的峰值模糊 —— 这个值在替换的那一帧必须一致。模糊加在**包裹层**上，绝不加在单个子元素上。

## 1. Zoom-Through（正向）

### 问题

文字入场、停留、出场。然后下一段文字入场、停留、出场。每个文字块都是独立的 —— 没有纵深，没有连续性。视频感觉像一套幻灯片。

### 原则

Z 轴上的速度匹配切。你**永远不会同时看到两段文字**。出场文字朝观众放大（加速），模糊和不透明度在切点达到峰值，掩盖一次硬切，入场文字从后方继续放大（减速落入焦平面）。一个连续的向前运动，两段不同的文字。

### 三个阶段

**阶段 1：出场** —— 文字向前加速（朝向观众）

- 缩放：`1.0 -> 1.2`，模糊：`0px -> 10px`（文字尺度；见"模糊逻辑"），不透明度：`1.0 -> 0.15`
- 缩放 / 模糊 easing：`power3.in`（陡峭加速）
- 不透明度 easing：`none`（线性 —— 均匀变暗，与缩放分开）
- 时长：0.2s

**阶段 2：硬切**，在速度峰值 + 模糊峰值处

- 出场元素：`opacity: 0`（用 `tl.set` 瞬时设置）
- 入场元素：`opacity: 0.15, scale: 0.75, blur: 10px`（用 `tl.set` 瞬时设置）
- 切点处所有属性都一致：模糊、不透明度，以及缩放**方向**（两者都在放大）

**阶段 3：入场** —— 文字继续向前（长大落入焦平面）

- 缩放：`0.75 -> 1.0`，模糊：`10px -> 0px`，不透明度：`0.15 -> 1.0`
- Easing：`expo.out`（起始一段陡峭的爆发，与出场速度匹配，随后长时间收敛）
- 时长：0.5s

### 为什么出场时不透明度必须单独处理

缩放用的是 `power3.in`，但这会让不透明度在 tween 的大部分时间里都接近 1.0。把不透明度拆成单独一个线性 ease 的 tween，变暗就均匀了。入场时，所有属性可以共用 `expo.out`。

## 2. Inverse Zoom-Through（反向）

镜像版本：摄影机是"往后拉"，而不是往前推穿。出场元素**后退**远离观众；入场元素以**超大尺寸**到达（仿佛它刚才就在摄影机后面），然后缩回焦平面。两者都朝缩小的方向运动 —— 同方向规则仍然成立，只是反过来了。

**什么时候选它而不是正向版本：** 到达类的段落节拍。入场元素因为是从比画面还大的尺寸进来的，落地时很有存在感 —— 适合揭晓句（"That changes today."）、一个巨大的回应，或者一个停住的终态。正向 zoom-through 读起来是*在内容中前进*；反向读起来是*抵达*内容。

### 三个阶段

**阶段 1：出场** —— 元素后退（远离观众）

- 缩放：`1.0 -> 0.8`，模糊：`0px -> 10px`（文字尺度）
- 缩放 / 模糊 easing：`power3.in`；不透明度：`1.0 -> 0.15`，用 `none`（单独的 tween）
- 时长：0.2s

**阶段 2：硬切**

- 出场元素：用 `tl.set` 设 `opacity: 0`
- 入场元素：用 `tl.set` 设 `opacity: 0.15, scale: 1.25, blur: 10px`

**阶段 3：入场** —— 入场元素缩回原位

- 缩放：`1.25 -> 1.0`，模糊：`10px -> 0px`，不透明度：`0.15 -> 1.0`
- Easing：`expo.out`，时长：0.5s

## 3. Cut the Curve（场景转场）

### 原则

**所有场景到场景的转场**都在 x 和 y 轴上用 cut-the-curve。出场场景的 hero 元素朝一个方向加速，切点落在运动途中，入场场景的 hero 元素沿**同一方向**继续运动并减速。没有东西完全出到屏幕外，也没有东西从完全屏幕外进来 —— **速度加上不透明度渐隐骗过了眼睛**；部分位移就够了。

### 同一路径，同一方向

如果场景 A 的 hero 向左滑，场景 B 的 hero 就从右侧进入并继续向左滑。两者都向左运动。一个连续的运动。

| 方向 | 场景 A 出场 | 场景 B 入场起点 | 场景 B 入场终点 |
| --- | --- | --- | --- |
| 向左 | `x: 0 -> -230` | `x: +230` | `x: 0` |
| 向右 | `x: 0 -> +230` | `x: -230` | `x: 0` |
| 向上 | `y: 0 -> -230` | `y: +230` | `y: 0` |
| 向下 | `y: 0 -> +230` | `y: -230` | `y: 0` |

### 用镜像 ease 做速度匹配

最干净的匹配方式：出场 `power4.in`、入场 `power4.out`，距离和时长**相同** —— 从数学上说，这正是一个 `power4.inOut` 组合的两半，所以入场元素恰好在这条名义路径的 50% 处以完全相同的速度接上（例如在切点两侧都是 230px / 0.3s ≈ 3,070 px/s）。

渐隐的诀窍：出场的不透明度在位移约 25–30% 时就已完成（渐隐时长 ≈ 0.18–0.3s，而运动时长 0.3–0.34s）—— 元素在仍然明显加速时就消失了，没有任何东西需要跑到画面边缘。入场则在减速过程中从约 0.35 快速淡**入**。把**最后一个**渐隐元素的消失时间卡在硬切那一刻 —— 没有任何东西在动的空档读起来是尴尬的冷场。

### 规则

- 所有场景转场都用 cut-the-curve —— 它是默认做法，不是点缀
- 两侧方向相同；`.in`/`.out` ease 镜像，距离 + 时长相同
- 出场时长短（0.2–0.4s），入场时长 >= 出场时长
- 部分位移 + 渐隐，绝不做完全出屏的运动

## 4. Waterfall Cut（逐词的 cut-the-curve）

**单词**粒度的 cut-the-curve —— 是向左切在文字到文字接缝上最强的版本。出场那行的每个词沿各自一条明显的曲线加速离开；入场那行的每个词在飞行途中瀑布式依次进入。错开让这次切变成一道波，眼睛顺着它越过接缝。

### 出场（逐词）

- 运动：`x: 0 -> -230`，历时 0.34s，用 **power4.in** —— 比常用的 power2 明显得多的加速曲线：词先几乎是在挪，然后**猛地撕走**
- 渐隐：`opacity -> 0`，历时 0.18s（单独的 tween，`power1.in`）—— 在词只走了大约 25–30% 的位移时就完成
- 错开：按阅读顺序，每词约 0.022s，时间卡好，让**最后一个**词恰好在硬切那一刻淡完

### 入场（逐词）

- `fromTo x: +230 -> 0, opacity: 0.35 -> 1`，历时 0.3s，用 **power4.out** —— 组合曲线镜像的后半段；每个词点燃时就已经以匹配的速度在运动
- 间隔**逐渐缩小**的瀑布式错开（起始 0.05s，每个词乘以约 0.84），让这串瀑布在整行上越来越快 —— 这串瀑布应该一个词比一个词快，而不是以固定的逐词延迟匀速推进
- 构建时把所有词预设为 `x: +230, opacity: 0` —— 只靠 `immediateRender: false` 的话，还没开始的词会在错开窗口期间以静止状态可见地待在原位

### 整行变体

单行的段落节拍（例如一句大号开场白）作为一个整体出场，用同样明显的加速曲线，但把它的渐隐拉长到约 0.3s，在切点前约 0.02s 结束 —— 一个孤立元素如果太早淡完，会留下冷场，而逐词瀑布本可以把它填上。

## 选择变体

| | Zoom-Through | Inverse Zoom | Cut the Curve | Waterfall Cut |
| --- | --- | --- | --- | --- |
| 作用范围 | 场景内文字替换 | 到达 / 揭晓段落节拍 | 场景之间 | 文字到文字的接缝 |
| 轴向 | Z，朝向观众 | Z，远离观众 | X / Y | X，逐词 |
| 峰值模糊 | 文字 10px / 满屏 20px | 文字 10px / 满屏 20px | 不需要 | 无（渐隐承担效果） |
| 切点不透明度 | 0.15 | 0.15 | 出场在切点前已淡完 | 最后一个词在切点消失 |
| 观感 | 在内容中前进 | 抵达内容 | 被横向带走 | 一道越过接缝的波 |

## 反模式

| 不要 | 原因 | 改为 |
| --- | --- | --- |
| zoom-through 期间两段文字同时可见 | 文字重叠会打破 Z 轴错觉 | 在模糊峰值处硬切，一次只出现一段文字 |
| 对文字尺度的主体用 20px 模糊 | 字形糊开；读起来像故障 | 文字用 10px，只有满屏才用 18–20px |
| 切点两侧的元素走不同路径 | 眼睛追踪一个方向，切却往另一个方向走 | 相同属性，相同方向 |
| 替换时模糊 / 不透明度不一致 | 可见的闪烁或亮度跳变 | 切点那一帧数值完全一致 |
| 入场用温和的 easing（`power2.out`） | 入场速度感觉比出场慢 | 镜像出场：`power4.out` / `expo.out` |
| 完全出屏的出场 / 入场 | 浪费时间，并打破速度错觉 | 部分位移 + 提前渐隐 |
| 孤立元素在切点前很久就淡完 | 接缝处冷场 | 渐隐在切点前约 0.02s 结束，或改用逐词瀑布 |
| 对正文文字用 zoom-through | 小字在 0.75 缩放下无法阅读 | 只用于标题和短语 |
| 场景切换不用 cut-the-curve | 静态切换感觉像幻灯片 | cut-the-curve 是默认做法 |
