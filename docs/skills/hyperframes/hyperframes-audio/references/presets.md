# Preset、具名任务（job）和单旋钮 profile

这里的一切都是通往某条效果链的捷径，而那条链你本来也可以手动搭出来。preset 写入的是标记了 `fromPreset` 的普通节点，具名任务写入的是一个带名字的普通节点，而 profile 是作用于一个效果多个参数的单一控件。没有任何东西是不透明的：打开其中任何一个，你看到的都是来自 [`fx-registry.md`](./fx-registry.md) 的效果，参数一览无余。

当其中某一个点出的正是你实际遇到的问题时，就用它。当没有一个对得上时，就手动搭建——因为离得近就随手套上的 preset，还不如三个经过斟酌的节点。

---

## 先诊断：听什么，以及用什么修

从症状出发，而不是从效果列表出发。大多数糟糕的音频都是下面其中一两种，而修法通常是一个具名任务，而不是一整个 preset。

| 听起来像                                | 所在频段 | 用什么                                                    |
| --------------------------------------------- | -------------- | ------------------------------------------------------------ |
| 嗡嗡声、低频隆隆声、车流、脚步声、手持噪声     | 20–80 Hz       | `rumble-cut` preset，或者 80 Hz 的 `highpass`                |
| 发轰、胸腔音重、离麦克风太近           | 80–250 Hz      | **Tame Boominess** 任务（200 Hz，−4 dB）                       |
| 发闷，像隔着纸板          | 250–600 Hz     | **Reduce Mud** 任务（250 Hz，−3 dB）                           |
| 箱体感，像在小房间里                       | ~400 Hz        | **Reduce Boxiness** 任务（400 Hz，−3 dB）                      |
| 字词听不清，缩在音乐后面 | 2–5 kHz        | **Add Clarity** 任务（3 kHz，+2.5 dB），或者挖空垫乐       |
| 刺耳、发脆，整段听下来很累    | 3–5 kHz        | **Soften Harshness** 任务（3.2 kHz，−3 dB）                    |
| 齿音重——`s` 音像在喷                | 5–10 kHz       | 现有功能都没法正确处理；见下文「现有功能都未覆盖的」  |
| 发暗、闷在里面、没有生气                     | 10–20 kHz      | `highshelf` 提升，或者自带一个提升的 `voice-broadcast`    |
| 有些字比其他字响很多            | 不是频段问题     | `compressor` 上的 **Evenness** profile，或者 `levellingResult` |
| 句子之间能听到房间底噪           | 不是频段问题     | `room-gate` preset（**Tightness** profile）                   |
| 峰值削波或尖刺                     | 不是频段问题     | 效果链最后放 `limiter`——每个人声 preset 都以它结尾 |
| 人声和音乐互相打架           | 主要在 1–3 kHz | **Voiceover carve**（旁白挖空），而不是在任何一条 track 上加 EQ               |
| 干巴巴的、贴着说话人、像不在任何空间里录的   | 不是频段问题     | `room-tight` 或 `room-natural`                               |

这些症状对应的**频段词汇**——和效果架上显示的名称相同：

| 范围          | 名称     | 那里有什么             |
| -------------- | -------- | ---------------------------- |
| 20–80 Hz       | Rumble（隆隆）   | 车流、脚步声、手持噪声 |
| 80–250 Hz      | Weight（厚重）   | 胸腔、声音的身体感、温暖感          |
| 250–600 Hz     | Mud（浑浊）      | 箱体感、发闷、纸板感     |
| 600–2000 Hz    | Middle（中频）   | 人声的主体          |
| 2000–5000 Hz   | Presence（临场感） | 辅音、可懂度  |
| 5000–10000 Hz  | Edge（锋利）     | 齿音、刺耳感         |
| 10000–20000 Hz | Air（空气感）      | 闪亮感、开阔感            |

### 操作顺序

按这个顺序诊断，因为每一步都会改变下一步听到的东西：

1. **先减后加。** 先切掉低频隆隆声和浑浊。一条听起来发暗的人声，往往是中低频太多，而不是高频太少——提升一条浑浊人声的高频，只会让它既浑浊*又*刺耳。
2. **先滤波，再调电平。** compressor 会对最响的东西做出反应，而它看不到的低频隆隆声，它也就不会再去追了。
3. **调完电平再处理关系。** 等人声本身稳定下来之后，再针对人声挖空垫乐，否则分析测量的会是一个你马上就要修掉的问题。
4. **先质感，后天花板。** 饱和与空间感放在后面；`limiter` 放在最后，在那里它才能真正充当天花板。它后面的任何东西都不受它约束。

## Preset

四个族，下面完整列出。应用一个 preset 时它会**追加**——在已经清理过的人声上再叠一个质感 preset，是真实存在的需求。重新应用一个已经存在的 preset，会原地替换它自己的节点，因为在效果链中的位置就是信号顺序。

### 人声——让真实的人声听起来像它更好的样子

| Preset            | 回应的问题                         | 效果链                                                                                               |
| ----------------- | ------------------------------- | --------------------------------------------------------------------------------------------------- |
| `voice-clean`     | 「我的声音听起来很业余」       | Remove Rumble → Reduce Mud → Even Out Loudness → Add Clarity → Peak Ceiling                         |
| `voice-broadcast` | 「我想让它听起来像电台」 | Remove Rumble → Reduce Boxiness → Even Out Loudness → Add Clarity → Add Air → Warmth → Peak Ceiling |
| `voice-warm`      | 「我想让它亲密、贴近」  | Remove Rumble → Add Weight → Even Out Loudness → Add Clarity → Peak Ceiling                         |

对于"把这段旁白修一下"，`voice-clean` 是默认答案。另外两个是同一个思路朝某个方向推进：broadcast 更密实、更靠前，warm 则是加入身体感而不是切掉它。

### 修复——一个问题，一个节点

| Preset       | 回应的问题                                 | 作用                                                                        |
| ------------ | --------------------------------------- | --------------------------------------------------------------------------- |
| `rumble-cut` | 「底下有嗡嗡声或砰砰声」     | 在人声下方做 high-pass                                                   |
| `room-gate`  | 「句子之间能听到房间声」 | 关掉停顿。**不能去除噪声**——语音下面的房间底噪还在 |
| `boom-tame`  | 「我的声音听起来发轰」                 | 切掉离麦克风太近带来的胸腔音                                      |
| `harsh-tame` | 「听起来刺耳、很累」    | 圆润发脆的中高频，宽频且始终生效                             |

### 质感——刻意为之，不是校正

`telephone`、`radio-am`、`megaphone`、`lofi-tape`、`pa-system`（Tannoy）、`intercom`、`doofus-worble`。

这些是戏服。每一个都是一个频段限制，加一个共振，再加它自己那种脏感，而且它们被调得彼此可以区分——在对数扫频上测量，没有任何两个之间的距离比信号本身更近。不要叠两个。

### 空间——把它放到某个地方

`room-tight`（有临场感而不糊）、`room-natural`（像是在某个地方录的，而不是在虚空里）、`hall`（远而大）、`slap-echo`（一次快速的重复）、`dub-throw`（重复远远地拖在后面）。

把它们用在任何应该坐在别的东西*后面*的那条上，并且湿声量要比单独听时觉得合适的量更低——尾音会占据人声需要的那块空间。

### 把整个 preset 当作一个控件

preset 的节点被包在一个干/湿混合里，所以 `presetAmount`（0..1）可以把整个 preset 淡入或淡出，而 `fx.preset.<id>` 是一个自动化目标，可以让它随时间渐变。这是把 preset 作为一个整体来自动化的唯一方式：它的节点之间没有共同的参数，而 worklet 效果（compressor、limiter、gate、bitcrush）根本不暴露可自动化的参数。

## 具名任务——频段**就是**模块

五个已经选好频率的具名 peaking 滤波器。选定任务就是选定频段，这正是让单一个"多少"旋钮名副其实的原因。

| 任务              | 症状                              | 设置                  |
| ---------------- | ------------------------------------ | --------------------- |
| Tame Boominess（抑制发轰）   | 胸腔音太多——发轰            | 200 Hz，−4 dB，Q 1.4  |
| Reduce Mud（减少浑浊）       | 发闷，像隔着纸板 | 250 Hz，−3 dB，Q 1.2  |
| Reduce Boxiness（减少箱体感）  | 听起来像在小房间里，或者箱子里   | 400 Hz，−3 dB，Q 1.4  |
| Add Clarity（增加清晰度）      | 字词听不清           | 3 kHz，+2.5 dB，Q 1   |
| Soften Harshness（柔化刺耳感） | 刺耳、听着累        | 3.2 kHz，−3 dB，Q 1.6 |

每一个底下都是一个普通的 `peaking` 节点——频率是一个起点，不是一个笼子。当有某个任务对得上时，优先用任务而不是光秃秃的 `peaking`：它一来就已经瞄准好了，而且效果架是按它做的工作、而不是按它的机制来命名它的。

手写一个任务时，**把名字放在 `label` 里**——`{"type":"peaking","id":"n2", "label":"Reduce Mud","params":{"frequency":250,"gain":-3,"q":1.2}}`。光有参数并不构成任务。一条带三个未加标签的 `peaking` 节点的效果链，会给作者显示三行一模一样的东西，而这正是具名任务存在要消除的问题。

**每个具名任务也都内置在某个 preset 里，设置完全相同**——这五个本来就是从那里来的。`boom-tame` *就是* Tame Boominess；`harsh-tame` *就是* Soften Harshness；`voice-clean` 包含 Reduce Mud 和 Add Clarity；`voice-broadcast` 包含 Reduce Boxiness。所以在某个 preset 上再加一个任务之前，先看看这个 preset 已经包含了什么，否则同一个切会落两次——`voice-clean` 加一个 Reduce Mud 任务，在 250 Hz 处就是 −6 dB，而本意是 −3。展开 preset 后，效果架会按名称显示它包含的节点，这是看出这一点最快的方法。

## 单旋钮 profile

有五个效果没有任何单一参数能如实地代表它——compressor 的 threshold 离开它的 ratio 就毫无意义。它们改为得到一个推导出来的控件，取值 0..1，同时设置多个参数。

| 效果       | 旋钮      | 0 → 1                                      | 设置                                      |
| ------------ | --------- | ------------------------------------------ | ----------------------------------------- |
| `compressor` | Evenness  | Barely touched（几乎不动）→ Very even, quite squashed（非常均匀，压得很扁） | threshold、ratio、attack、release、makeup |
| `gate`       | Tightness | Only true silence（只关真正的静音）→ Cuts quiet words too（连轻声的字也切掉）   | threshold、range、release                 |
| `saturate`   | Warmth    | Just a sheen（只是一层光泽）→ Openly distorted（明显失真）            | threshold、output                         |
| `reverb`     | Space     | A small tight room（一个紧凑的小房间）→ A big open hall（一个开阔的大厅）       | size、wet、dry                            |
| `bitcrush`   | Crush     | Slightly gritty（略带颗粒）→ Destroyed（彻底毁掉）                | bits、samples、mix                        |

**Evenness、Warmth 和 Space 是电平匹配的**——make-up 增益、输出微调和干声支路会随驱动量一起变化，所以把旋钮调高并不会同时把 track 调响或调轻。这些数值是通过测量求出来的，而不是挑出来的：compressor 最初在最大 evenness 时会让 track *变轻* 2.5 dB，而饱和的微调方向则完全反了。

Tightness 和 Crush 不做电平匹配，因为两者都没有可以调的微调——gate 只做去除，而 Crush 的 `mix` 就是效果本身，而不是 make-up。

效果链存储的是机制数值，而不是旋钮位置；旋钮位置是通过反算曲线读回来的。所以在 profile 之下手动编辑某个参数是允许的，只会让旋钮跟着移动。

## 测量型脚本，不是 preset

有两样东西在动手之前会先测量音频，所以它们不可能是一条固定的效果链：

- **Voiceover carve**（旁白挖空）——分析人声，并在人声占据的频段里切垫乐。它是"音乐在和人声打架"的答案。见 `SKILL.md` 里讲挖空的那一节。
- **Even Out Levels**（`levellingResult`）——测量这条 track 自己的说话窗口，并写入一条增益包络。它的目标是这条 track 的第 80 百分位，而不是一个绝对电平，所以一条本来就均匀的 track 不会被改动。当问题是整条录音中各段落电平漂移、而不是字与字之间的动态时，用它而不是 compressor。

## 现有功能都未覆盖的

说出这块空白，而不是随手拿最接近的 preset 并声称它就是那个东西——但接下来**还是要交付一个诚实的兜底方案**，并说明它的代价。一个请求修复、却只得到一番解释的作者，听到的是真话，拿到手的却是一场空。说出它是什么，说出它的代价，然后应用它。

- **去齿音。** `harsh-tame` 是一个宽频、始终生效的切，而且中心频率低了一个频段，它不是去齿音器。真正的去齿音器需要一个比这里可用的分析步长更快的检测器。*兜底*：在 Edge 频段做一个窄的 `peaking` 切——在 5–9 kHz 之间扫，找到这条人声真正喷的位置，Q 3–4，−3 到 −5 dB。它始终生效，所以每个字都会损失一点空气感；这个取舍通常是值得的，而要不要拒绝由作者决定。
- 把一条 track 的**音色匹配**到另一条。*兜底*：手动调 Tone EQ，它的可预测性是从两条录音推导出来的匹配曲线所不具备的。
- **降噪。** `room-gate` 关掉的是间隙；语音下面的噪声原封不动。字词底下的嘶嘶声没有兜底——带有可闻嘶嘶声的源需要一个更好的源，而把这一点说出来就是全部答案。
