# cta-morph-press —— CTA 变形与按压

**intent**（意图）：一个静止的品牌标志在同一个屏幕中心凝缩成一个更小、更亮的 CTA，然后一个光标从画外到来，在它上面落下一次像人瞄准过的点击。观众的视线被引导着从"这就是我们"走到"而这就是你要做的"。变形和点击是两个头条段落节拍。

**roles served**（服务的角色）

- CTA（from `cta-morph-press`）：当收尾从品牌身份过渡到单一的用户动作、两个元素先后共享同一个中心（是变形，不是切换），而回报是一次带物理反馈的模拟点击时。用于一个聚焦的"点这里"收尾 —— 没有空间布景，没有多步 UI（那是 `cursor-ui-demo`）。
- Hook（**角色扩展**，from `widget-morph-on-blank-field`）：同一套机制作为**开场**运行 —— 平坦背景上的一个孤立 `[widget]`（胶囊 / chip 组合）原地变形，完成它承载的内容，然后消失，留下一个素净的画面，由一个打出来的 `[title]` 收束。点击（如果有的话）是点燃变形，而不是结束它；也可能完全没有光标。当产品的钩子**就是**一个小部件做一件事时用它 —— 依然没有空间布景，没有多步 UI（那是 `cursor-ui-demo`）。重新考虑另立门户的触发条件：如果未来的挖掘又带来 2 个以上带"消失 → 打出标题收束"的小部件变形开场，就把这个变体提升为独立的 blueprint（到那时段落节拍的顺序已经完全颠倒了）。

**duration**（时长）：4–6s（Hook 小部件变形开场 5–7.5s）

**shot structure**（镜头结构）（一张 `[bg]` 画布；hero 和 CTA 是 flex 居中的兄弟元素，共享一个 `transform-origin`）

- **Scene 1 (0.0–~1.4s) —— 存在感。** `[hero mark / brand lockup]` 保持在正中央，有生气但处于静止 —— 只有标志上一丝淡淡的旋转呼吸；它下方的任何标题文字都保持纹丝不动。摄像机静止。
- **Scene 2 (~1.4–2.4s) —— 变形（招牌动作）。** hero 在同一个屏幕中心**凝缩**成一个更小、更亮的 `[CTA]`（按钮 / 卡片）：退场的标志缩小淡出，恰好与 CTA 在它的位置上放大同步。因为它们共享一个 `transform-origin`，眼睛会把它读作一个元素在变形，而不是一次替换。
- **Scene 3 (~2.4–3.4s) —— 接近。** 一个 `[cursor]` 沿着一条**减速**的路径从画外到来（它是"抵达"，而不是穿过），落在离 CTA 几何中心偏**开**几个像素的地方，让瞄准读起来像人，而不像脚本。
- **Scene 4 (~3.4–结尾) —— 按压。** 光标落下一次有物理感的**点击** —— 光标和 CTA 步调一致地一起压缩，然后带着反馈释放（可选的涟漪 / 辉光绽放）。保持在被点击后的状态上。
- **变体 —— Hook（小部件变形开场）**（from `widget-morph-on-blank-field`；重排了段落节拍 —— 先按压，再变形，最后标题）。**(1) 存在感**：一个孤立的 `[pill / chip lockup]` 居中位于平坦的 `[field]` 上；可选地 `[cursor]` 滑入，chip 背后出现一个悬停的胶囊背景，点击以同样的步调一致式按压落下。**(2) 变形**：小部件**原地**变形 —— 以顶边为锚点向下展开成一个 `[menu]`，或以弹簧方式向外变形成一个 `[prompt card]` 并带一个小小的过冲落定 —— 新内容淡入/滑入就位。**(3) 载荷**：变形后的状态开始表演 —— `[placeholder]` 带着闪烁的文字光标逐字打出，`[user text]` 逐字打出的同时一个控件从暗淡翻转为鲜艳的激活色，或者菜单急停式收起回胶囊，带着 `[new value]` + 一个对勾弹出；在常驻的前景卡片之下，背景可能急停式切换成新颜色。**(4) 收束**：小部件**消失**；一个素净的画面结束这一拍 —— 一个 `[closing title]` 在中心逐字打出，或者停留在翻转后的纯色上。

**motion vocabulary**（运动词汇）：淡淡的、只有旋转的静止呼吸（仅限 logo 范围）；同中心的变形替换（缩小淡出 ↔ 放大，共享 `transform-origin`）；光标从画外减速抵达；偏离中心、像人一样的瞄准；步调一致的按压压缩；释放时的反馈涟漪 / 辉光。Hook 开场：胶囊以锚定方式向下展开成菜单，再有弹性地急停收起回去；chip 到卡片的弹簧变形并带过冲落定；带闪烁文字光标的占位符 / 用户文字打字机（可能在单词中途切走）；控件颜色状态从暗淡翻转为鲜艳；常驻前景卡片之下的背景颜色急停切换；对勾弹出；小部件消失成空白画面；打出来的结束标题。

**rule mapping**（规则映射）

- hero → CTA 在同一个中心凝缩 → `scale-swap-transition`（共享的 `transform-origin: 50% 50%` 是让变形成立的关键；CTA 用 `position: absolute`，这样在短暂重叠期间不会把 hero 挤开）
- 静止 hero 的生气（只有旋转，范围限定在标志上，这样 Phase-2 的缩放不会与之冲突）→ `sine-wave-loop`（低幅度旋转语域 —— 细微抖动，不是缩放呼吸）
- 光标按下 + 释放步调一致（单一目标数组，让两者一起压缩）→ `physics-press-reaction`（PRESS_DOWN + RELEASE 部分）
- 光标接近（从画外减速、偏离中心落点、opacity 硬切入场）→ `gsap-effects`（在 `power2.out` 上做平移）
- 点击涟漪 / 释放辉光 → `cursor-click-ripple`（起音-衰减的圆环）和/或 `ambient-glow-bloom`（释放时的绽放）
- （Hook）chip → prompt 卡片在同一个中心的弹簧变形 → `scale-swap-transition`（基础的变形契约，按展开方向运行）+ `card-morph-anchor`（圆角 / 表面随之变化）
- （Hook）锚定边缘的展开 / 急停收起（胶囊 ↔ 菜单，顶边固定）→ `anchored-layout-expand`（边缘锚定的定向容器增长 —— 原点固定的展开，子元素做反向缩放；`card-morph-anchor` 仍只用于等比缩放的变形）
- （Hook）占位符 + 用户打字、闪烁的文字光标、单词中途切走 → `gsap-effects`（打字机）+ `context-sensitive-cursor`（闪烁）+ `discrete-text-sequence`（单词中途切走的状态）
- （Hook）控件颜色从暗淡翻转为鲜艳 → `press-release-spring`（颜色过渡变体）
- （Hook）对勾弹出 / 卡片到达时的过冲 → `spring-pop-entrance`
- （Hook）悬停胶囊背景 + 点燃式点击 → 基础形态中的 `physics-press-reaction` + `cursor-click-ripple` 映射原样适用

**camera modifier**（摄像机修饰）：摄像机静止 —— 变形和点击发生在元素空间里；摄像机运动会与作为高潮的点击争夺注意力。Hook 开场遵守同样的契约 —— 连背景颜色翻转也是元素层面的急停，而不是摄像机事件。
