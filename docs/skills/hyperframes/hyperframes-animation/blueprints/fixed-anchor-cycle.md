# fixed-anchor-cycle — 固定锚点，轮换世界

**intent**（意图）：一个元素被钉住 —— 一个 wordmark、一个输入框、一行锚定文字，它只进场一次，此后再也不动 —— 与此同时，相邻区域（或整个周边主题）围绕它轮换过许多离散状态，节奏常常被刻意操控（稳定步进、快速轮播，或由慢到快的密集连发），最后在一个强调段落节拍上收成一个完成的 lockup，或一个褪色的定格。锚点的静止本身就是主张：一切都在变，唯独这个不变。它不同于 `kinetic-type-beats` 的子形态 A —— 那里是一行居中文字里的某个词位在替换，句子本身就是主体，锚点是光秃秃文字场上的一个句子框架；这里的锚点是产品身份（PRODUCT identity），围绕它轮换的可以是非文字的东西（整套主题皮肤、外框 / logo 替换、带质感的标签 chip、轮播列表），轮换表达的是广度（「人人都在说 / 到处都能用 / 召集所有 X」），而收尾把锚点补全成一个 lockup。它也不同于 `ticker-takeover` —— 那里的轮换以一次碰撞结束，一个 hero 撞进来把文字挤开；这里没有任何东西会撞到锚点：轮换停下，最后一个元素悄悄加入它。

**roles served**（适用角色）

- Brand_Outro（来自 `static-anchor-rapid-text-swaps`）：当收尾是品牌名纹丝不动地待着，旁边或下方轮换着赞誉引语 / 标语词时 —— 稳定的逐词高亮步进，或一阵越来越快的硬切 chip 连发 —— 最后落在完成的 lockup 上（「bolt.new / prompt, run, edit, deploy / enjoy.」；「Opus 4.6 by ANTHROP\C」）。
- Benefits：当「到处都能用」被字面地展示出来 —— 一个产品界面（一个只有一行固定原文的提示词输入框）钉在正中央，而它的整个（ENTIRE）外壳原地变形，依次换成 N 套产品主题（背景、字体、圆角、外框、logo 全部同时交叉淡化），最后以一个褪色的定格结束。
- Hook：当开场是点名式的 —— 一行静态锚定文字保持不动，它下方一行强调色文字以快速纵向轮播的方式过一遍受众 / 选项列表，然后这一块清空，交给后续的陈述段落节拍，把品牌那一句落下来。

**duration**（时长）：6.6–11.1s（Benefits 最短，4 个主题段落节拍时约 6.6s；Brand_Outro 约 9–9.4s；Hook 最长，锚点轮换块交给后续陈述段落节拍时约 11s）。无论哪个角色，轮换引擎本身都占约 3–5s。

**shot structure**（镜头结构）（扁平的静止画面 —— 每个成员的镜头都锁定；一个 `[bg]` 场，纯色或轻微漂移；并入了两个子形态 —— **(A) 相邻区域轮换**：锚点保持，旁边一个槽位替换过 N 个状态；**(B) 整体语境变形**：锚点保持，它周围（AROUND）的一切原地换皮）

- **Scene 1 (0.0–~2.0s) —— 锚点落下并钉住。** `[anchor: wordmark / product name / composer box / lead line]` 只进场一次 —— 居中淡入 / 缩放进入、逐词搭建，或者第一帧就已在场 —— 落在一个它将在整个 clip 里保持的固定位置。从这里开始零运动：不漂移、不呼吸、不重新布局。如果锚点是一个 UI 界面（子形态 B），它带着一个 `[verbatim string]` 和一个闪烁的光标。

- **Scene 2 (~2.0s–约 70% 时长) —— 轮换引擎（标志性动作）。** 世界在不动的锚点周围变化。按子形态选择：
  - **子形态 A（相邻区域轮换）**：锚点旁边 / 下方的一个区域步进过 N 个离散状态 —— 挑一（ONE）种替换机制和一（ONE）种节奏：
    - _替换机制_：瞬间硬切的标签替换（一个 `[chip / tape label]` 啪地盖在旧的上面，质感 / 高光略有变化，chip 宽度按每个 `[phrase]` 重新适配 —— 朝远离锚点的方向增长，绝不压到锚点上）；逐词高亮依次步进（`[tagline]` 中的一个词猛然变亮 / 加粗，其余保持暗灰，高亮沿着这一行走过去）；或者快速纵向轮播（每个 `[list item]` 以约 0.5s/短语的速度滑动 / 淡化穿过强调色槽位）。
    - _节奏_：稳定步进（约 0.5–1s/状态），或**由慢到快的密集连发** —— 约 1s 的段落节拍压缩到每次替换约 0.15–0.3s，广度升级成一片模糊的状态流（12–16 个状态读作「人人」；3–8 个读作点名）。
    - 几何法则：轮换区域绝不（NEVER）与锚点重叠、接触或把它挤开；布局尺寸要保证最长的状态也能带着清晰的边距放进画面。
  - **子形态 B（整体语境变形）**：每隔约 1.3s，整个主题 —— `[bg color]`、字体、圆角、工具栏图标、页脚 `[brand logos]`、语境文字行 —— 通过快速（约 0.3s）的交叉淡化原地变形，依次换成 N 套 `[product skins]`，每个属性同时混合。没有硬切，没有划变；锚点的内容字符串在每套皮肤里都完全相同（像 `> ` 前缀这样的外框细节可以按皮肤调整）。

- **Scene 3 (~70–85%) —— 强调段落节拍。** 轮换要收住 —— 而不是简单地停下：
  - _变体 — Brand_Outro（高亮步进）_：整句 `[tagline]` 一下子全部变亮 —— 逐词走完之后整行点亮。
  - _变体 — Brand_Outro（密集连发）_：连发停住，并定在 `[longest / weightiest phrase]` 上 —— 加速之后的一拍静止。
  - _变体 — Benefits（主题变形）_：最后一拍褪色 —— 一层淡淡的 `[dot-grid]` 在背景上淡入，同时 UI 降到低不透明度，一个褪色的蓝图式定格。
  - _变体 — Hook（轮播）_：锚点块清空，交给 1–3 个居中逐词搭建的陈述段落节拍（kinetic-type-beats 的地盘），一路带到收尾。

- **Scene 4（最后一拍 → 结尾）—— lockup 补全并定住。** 最后一个元素加入仍然不动的锚点，完成后的构图静止保持到结尾：一个 `[closing word]` 从下方落入，与最后一个轮换状态对齐（「enjoy.」）；chip 在一次硬切中消失，`[brand sign-off]` 出现在锚点旁边、共用一条基线（「by ANTHROP\C」）；或者最后的 `[brand line]` 在正中央逐词搭建并保持（「with Copilot.」）。长时间的静止保持 —— lockup 就是收束，给它 20–30% 的时长。

**motion vocabulary**（运动词汇）：锚点淡入 / 缩放进场；永久钉住的锚点（零运动，没有闲置呼吸）；瞬间硬切的标签 / chip 替换（啪地盖上，带细微的质感 / 高光变化）；chip 宽度按每个短语调整适配（朝远离锚点的方向增长）；一行文字内逐词高亮依次步进；整行变暗为灰的状态；整行点亮的瞬间切换；静态文字下方一行快速纵向轮播的滑动 / 淡化；节奏加速（约 1s 的慢段落节拍进入约 0.15–0.3s 的连发）；定在最长短语上的强调段落节拍；原地主题变形交叉淡化（约 0.3s），背景 / 字体 / 圆角 / 图标同时混合；每拍的外框 / logo 替换；闪烁的文字光标；语境文字行在各拍之间出现 / 消失；点阵背景淡入；全局不透明度褪色；结尾定格；逐词短语搭建；场景之间的块清空；最后一个词落入进场；硬切到最终 lockup；长时间的静止保持。

**rule mapping**（规则映射）

- 在时间阈值处瞬间硬切的 chip / 标签 / 短语替换；逐词高亮步进（颜色 / 字重的状态替换）；暗行 → 整行点亮的瞬间切换；按状态设置 chip 宽度（一个按状态离散设置的布局属性 —— 绝不 tween）→ `discrete-text-sequence`
- 静态锚点下方强调色文字行的快速纵向轮播（在遮罩槽位里以滑动 / 淡化步进替换）→ `vertical-spring-ticker`（不用它的页脚揭示步骤 —— 由 Scene 4 的 lockup 取而代之）
- 从一份含 N 个状态的脚本（赞誉引语、受众列表、主题段落节拍）计算每个短语的状态窗口 → `dynamic-content-sequencing`（Accelerating cadence —— 对于密集连发，预先计算段落节拍数组，`hold` 值不断缩小，沿状态列表做几何衰减）
- 逐词短语搭建（锚定文字行、后续陈述、最后的品牌句）→ `dynamic-content-sequencing` + `waterfall-entry`（陈述需要打击式落下时用 `kinetic-beat-slam`）
- 锚点淡入 / 缩放进场；最后收尾词的落入 → `spring-pop-entrance`（克制的过冲 —— 这里的语气是编辑式的，不是弹跳式的）
- 钉住的输入框里闪烁的光标 → `context-sensitive-cursor`（在分段边界处按主题皮肤调整颜色）
- 整体语境主题变形 → `theme-crossfade-morph`（N 个预先设好样式的全场景图层叠在同一几何位置上，以不透明度交叉淡化，共享的锚点字符串只在最上层渲染一次）；只涉及输入框外壳的圆角 / 表面组件时 → `card-morph-anchor`
- 轮换下方轻微漂移的背景场 → `sine-wave-loop`（有界的漂移；锚点本身不漂移）
- 点阵淡入 + 全局不透明度褪色定格；长时间的静止保持 → `gsap-effects`（单纯的不透明度 tween）/ 静止保持（不需要规则）

**camera modifier**（镜头修饰）：无 —— 每个成员都完全镜头静止；轮换是唯一的运动，钉住的锚点的静止是承重的。不要为了「增加能量」加一个推进；那会破坏锚点契约。
