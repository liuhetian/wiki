# logo-assemble-lockup — Logo 组装 → Lockup

**intent**（意图）：一个品牌标志 / wordmark 在屏幕上诞生，并收成一个居中的 logo lockup —— 它可以由部件搭建而成（元素组装或沿轨道进入、字母级联、轮廓描画出来，或镜头推进穿过负空间），可以在清空的舞台上从零整体弹簧绽放（BLOOMED），可以从前面的短语 / 字形以一条不间断的链条变形（MORPHED）而来，可以从一道动态拖影中吸收而成，也可以本来就组装好、随着装饰清场而落定 —— 可选地再延展成最后的 URL / CTA / 结尾卡。

**roles served**（适用角色）

- Product_Intro（来自 product-intro-logo-system-assemble）：一个无文字、高级感的品牌 sting —— 一套抽象的元素系统围绕一个固定的（FIXED）中央 logo 脉动 / 生长 / 环绕并组装，由一次电影感的镜头倾斜承载；没有文案，没有 UI。
- CTA（来自 cta-camera-push-lockup）：logo 搭建是通往最终号召的引子（LEAD-IN）—— 一个 3D 标志组装 + wordmark 级联，然后一次快速的镜头穿透（PUSH-THROUGH）穿过标志的负空间，让巨大的 CTA 字母拖着残影掠过镜头，最后收在一个 `[url]` / `[CTA verb]` lockup 上。
- CTA（来自 cta-button-wordmark-build）：「自己描出轮廓 → wordmark 逐字母搭建」这一子形态 —— 一个 `[CTA button]` 胶囊描出它自己发光的边框，一次斜向色带擦除（WIPE）翻转画面，`[wordmark]` 在一道斜杠旁边打出来，落成 lockup。镜头静止。
- Brand_Outro（来自 brand-outro-assemble-logo-lockup）：收尾的标志 —— 一组 `[feature pills / UI elements]` 编队从四条边清场（CLEARS），然后在空画面上 `[logo mark]` 一笔一笔描画出自己，`[wordmark]` 显现补全 lockup，然后淡出。
- Product_Intro（来自 brand-reveal-assemble-zoom）：先给语境再聚焦的揭示 —— 一句伴随的标语打出来建立语境，hero 标志在它旁边弹入，然后伴随文字退场，布局重新居中，镜头推进（IN）到标志上的特写并保持（宽构图收窄成紧凑的焦点）。
- Product_Intro（来自 logo-parts-lockup-assembly）：字面意义上的部件搭建 —— `[icon parts]`（一个发光圆点描出一个圆，半圆放大并重叠，笔画旋转进入）在扁平 / 渐变场上汇聚成画面中央的 `[brand icon]`，`[wordmark]` 加入（± 一个 `[badge pill]` 弹到 lockup 上），然后是一个收束段落节拍：底部一条逐步切换的 `[subtitle rail]`，一个叠在淡淡素材网格上的大 `[count-up stat]`，或者 lockup 清空、一个 `[product UI window]` 缩放进入。静止画面，全部是元素级运动。
- CTA（来自 text-clears-mark-blooms-lockup）：文字清场后的绽放（BLOOM）—— 居中的 `[serif tagline]` 段落节拍（逐词错落淡入）保持，然后自行清空（CLEAR），留下空白画面；`[brand mark]` 在正中央从零（ZERO）开始弹簧绽放，向左滑动，同时 `[wordmark]` 在它右边显现，平衡的 lockup（几乎）静止地保持。恒定的暖色扁平背景，静止画面。
- Brand_Outro（来自 phrase-morphs-into-lockup）：变形链（MORPH chain）—— 一个居中的 `[phrase]` 原地变异，然后收拢 / 替换成一个 `[intermediate glyph]`，它的线条面板围绕一个中心轴扇形展开并翻转，带着可见的运动模糊（翻书的感觉），再互相咬合成 `[geometric mark]`，标志随后向两边滑开形成 lockup。一条不间断的变形链，绝不是切掉再替换的组装；完成的 lockup 在最后约 40–50% 的时长里完全静止地保持。
- Brand_Outro（来自 lead-text-then-mark-assembles）：部件到场式搭建 —— 一句 `[hand-off line]` 保持后离开，然后标志由陆续到场的部件搭建（BUILT）而成（`[icon]` 落入、字母逐个滑入、句末标点落下、一小簇彩纸迸发后立刻缩没），或者（OR）一个 `[pixel stack]` 拖成全宽的多色条纹，条纹尾部回缩并被吸收（ABSORBED）进像素标志 —— 最终成为一个 lockup，或一张完整的结尾卡（`[icon tile]` + `[title]` + `[URL pill]` + 应用商店徽章）并静止保持。
- Brand_Outro（来自 `settled-lockup-reveal`）：「零组装」的边界情形 —— `[lockup]` 从第一帧起就在舞台上；`[satellite shapes]` 向外漂移并淡出，一道强调色下划线从 wordmark 下方扫过，`[tagline]` 擦入将其补全。落定并揭示：没有前置段落节拍，没有变形，没有接力。

**duration**（时长）：约 4.4–11.0s（Brand_Outro 约 4.4–7.3s · brand-reveal 约 5s · CTA 文字清场绽放 6.0–8.9s · Product_Intro 环绕 sting 约 7s，部件组装 7.0–9.8s · CTA 推进 / 搭建 5.4–11.0s）

**shot structure**（镜头结构）（一份合并后的带时间码模板；`[slots]` 与具体产品无关）

- Scene 1 —— 清场 / 点燃（0.0–~1.0s）：为标志的搭建准备好舞台。
  - _变体 — Product_Intro_：以干净的 `[light bg]` 开场，在扁平的俯视视角下有淡淡的同心参考圆环；圆环从中心脉动并扩展；这一拍过半时背景交叉淡化 `[light]→[dark gradient: hero→secondary]`，圆环上出现细小的种子圆点，中央 `[logo mark]` 的辉光被点燃（IGNITES）（标志从 t=0 起就在，固定、正面朝向）。
  - _变体 — CTA 推进_：在 `[bg gradient]` 上，`[logo mark]` 正在物体空间里落定（一个带细线框边缘参考线的 3D 标志 + 中心背后淡淡的括号图形）；可能已经有一个非常缓慢的连续镜头推进在悄悄进行。
  - _变体 — CTA 按钮搭建_：在 `[dark grid bg]` 上，一个圆角 `[CTA button "label"]` 胶囊升起 / 缩放进入中央（前一个标题从顶部清走）；它细细的边框以一道动画化的发光轮廓描边（STROKE）描画出来（DRAWS ON），左边缘有一个小的 `[accent]` 彗星 / 火花图标。
  - _变体 — Brand_Outro_：一组预先排好（PRE-ARRANGED）的 `[feature pills / element grid]` 编队（每个都是 `[icon]`+`[label]`）散开（DISPERSES）—— 元素从各自的布局位置向外滑动，从画面四条边飞出（清边式漂移，不是（NOT）从中心发起的爆开），把画面清空，露出干净的 `[bg]`。
  - _变体 — Product_Intro 部件组装_（来自 logo-parts-lockup-assembly）：可选的文字钩子 —— 一行居中的「`[Meet product]`」从右向左擦除消失 —— 或者直接进入搭建；在扁平 / 渐变的 `[bg]` 上，第一批 `[icon parts]` 到场：一个发光圆点顺时针描出一个圆，一个渐变半圆在圆内放大，或者标志带旋转地放大进入中央。
  - _变体 — CTA 文字清场绽放_（来自 text-clears-mark-blooms-lockup）：一个居中的 `[serif tagline / question]`（± 一个描边的 `[badge pill]`）在最初约 0.5–1s 内完成从左到右的逐词错落揭示（每个词从浅灰过渡到深色）并保持；可选地逐词滚动替换成第二行 `[availability line]`。然后是清场（CLEAR）：文字退场 —— 向中心缩小 + 淡出，或者从左边开始逐词淡出 —— 留下一拍的空白画面。
  - _变体 — Brand_Outro 变形链_（来自 phrase-morphs-into-lockup）：一个居中的 `[phrase]` 原地补全或变异（纵向老虎机式的词替换 —— 一个词向上退出，替换词从下方升起，这一行其余部分固定 —— 或者逐词落下）并保持。什么都不清场：这个短语本身就是（IS）标志的原材料。
  - _变体 — Brand_Outro 部件到场_（来自 lead-text-then-mark-assembles）：一句居中的 `[hand-off line: tagline / "Brought to you by"]` 在扁平画布上保持，然后退场 —— 带着淡出笔直向下滑出画面，或者在到来的装饰动作后面淡去。
  - _变体 — Brand_Outro 落定揭示_（来自 settled-lockup-reveal）：`[lockup]` 在 t=0 时已经居中；`[satellite shapes]` 在它周围缓慢向外漂移 —— 一种反转的（INVERTED）清场：装饰离开，标志留下。

- Scene 2 —— 组装标志（~1.0–~Ys）：标志由部件搭建自己。
  - _变体 — Product_Intro_：种子圆点放大成排列在圆环上的扁平 `[accent]` 形状；同心色带向外泛起涟漪（隧道感），形状开始围绕仍然固定的中心环绕（ORBIT）/ 漂移。
  - _变体 — CTA 推进_：`[wordmark]` 从标志背后级联（CASCADES）而出（字母从左到右，带过冲），形成完整的 `[brand lockup]`；3D 标志可以分几拍组装（一个末端脱离 + 以弹簧圆点弹出，一个部件像弹性铰链一样张开再啪地合上）。可选的一拍：一个 `[cursor]` 划弧线进来，「点击」wordmark，或者（OR）一个装着过渡用 `[CTA line]` 的毛玻璃胶囊弹簧进入，同时层叠的标志外壳向边缘扇形展开。
  - _变体 — CTA 按钮搭建_：一次图形擦除（WIPE）把画面翻到 `[contrast bg]` —— 一条细的 `[accent]` 斜线扫入，膨胀成一条全画幅的斜向色带（BAND），然后收拢成一道小的 `[accent]` 斜杠。
  - _变体 — Brand_Outro_：在已清空的画面上，`[logo mark]` 通过描边描画出来（DRAWS ON）（一段弧一段弧 / 一段一段地搭建）。
  - _变体 — Product_Intro 部件组装_：重叠的部件补全（COMPLETE）`[brand icon]`（第二个圆重叠上来，闭合成球体；笔画互相咬合）；`[wordmark]` 从图标背后滑出，或从它右侧滑入；一个小的 `[badge pill]` 弹到 lockup 上。
  - _变体 — CTA 文字清场绽放_：在空白画面上，`[brand mark]` 在正中央从零（ZERO）开始以利落的弹簧缓动放大（轻微过冲，放大时带一点点旋转）—— 整个标志一次成形，没有部件。
  - _变体 — Brand_Outro 变形链_：短语水平收拢 / 擦入标志，或者（OR）在同一中心被瞬间替换成一个线稿 `[intermediate icon]`，它的笔画分裂成面板，围绕一个中心轴扇形展开并翻转，带着可见的运动模糊，最后互相咬合、落定成 `[geometric mark]`。绝不切到完成的 logo —— 变形必须保持不间断。
  - _变体 — Brand_Outro 部件到场_：标志由陆续到场的部件搭建（BUILT）而成 —— `[icon]` 从上方落入，字母逐个滑入，句末标点落下，一小簇彩纸迸发后立刻缩没 —— 或者（OR）一个彩色 `[pixel stack]` 在文字边缘弹出，水平射出、拉伸成全宽的多色条纹，然后条纹尾部回缩并被吸收（ABSORBED）进 `[pixel mark]`（遮罩回缩）。
  - _变体 — Brand_Outro 落定揭示_：一道强调色下划线从左到右扫过 `[wordmark]` 下方 —— 这是这个变体唯一的「搭建」。

- Scene 3 —— 收成 lockup（~Ys–end）：lockup 补全并保持（Product_Intro / Brand_Outro），或者被镜头飞入 / 延展成一个 CTA（CTA 各变体）。
  - _变体 — Product_Intro（唯一（ONE）的镜头运动）_：整个系统从扁平俯视平滑地倾斜（TILTS）成一个有角度的等轴测透视（ease-in-out），并略微拉远 —— 扁平的形状变成发光的 3D 形体，色带变成发光的轨道线，而中央的 `[logo mark]` 不（NOT）倾斜（保持 2D、正面朝向、固定）。镜头缓和地停下；元素持续环绕 / 漂移（内圈比外圈快）；标志保持稳定的辉光。最终落定的画面。
  - _变体 — CTA 推进（标志性动作）_：一次快速的镜头穿透（CAMERA PUSH-THROUGH），穿过标志的负空间 / 穿过毛玻璃胶囊 —— 浓重的水平运动模糊，巨大的 `[CTA]` 字母拖着残影掠过镜头（光标退出）。收在饱和色 `[bg]` 上的最终 lockup：一个 `[url badge]` / `[CTA line]` 由一次从左到右、前沿带 `[accent]` 的擦除（WIPE）揭示出来（或干净地淡入），实心的标志形状在后面以视差滑入。落定成完全静止的保持（缓慢拉远 / 落定）。
  - _变体 — CTA 按钮搭建_：`[wordmark]` 在斜杠右侧逐字母搭建（BUILDS），最终落成在新背景上居中的「`[slash] [WORDMARK]`」lockup。缓慢落定到静止。
  - _变体 — Brand_Outro_：`[wordmark]` 在描画好的标志旁边显现（滑入 / 淡入），补全 `[lockup]`；lockup 保持，然后淡出到 `[black / bg]`。
  - _变体 — Product_Intro 部件组装（收束段落节拍）_：完成的 lockup 保持，同时底部的 `[subtitle box]` 逐步切换过 `[tagline fragments]`（原地替换）；或者一行大的 `[count-up stat]` 落在淡淡的背景素材网格上；或者 lockup 缩小 / 淡出，一个 `[product UI window]` 在扁平背景上放大进入（它的面板内容可以替换一次）。搭建交棒给产品证明。
  - _变体 — CTA 文字清场绽放_：标志向左（LEFT）滑动一小段距离，同时 `[wordmark]` 在它右侧显现（逐字母 / 滑出式擦除，可以看到中间的部分状态）；平衡的「`[mark] + [wordmark]`」lockup 居中并保持，其中一个成员在保持期间继续几乎察觉不到的缓慢放大。
  - _变体 — Brand_Outro 变形链_：标志向左滑，同时 `[wordmark]` 拖着一道运动模糊拖影向右拉出，两者减速，进入居中的 lockup（± 下方淡入一行 `[sub-line]`）。保持时间很长（LONG）—— 在最后约 40–50% 的时长里完全静止。
  - _变体 — Brand_Outro 部件到场_：lockup 居中停住并保持；或者完整的结尾卡补全 —— 一个圆角方形的 `[icon tile]` 在标志背后放大，`[title]` 逐词淡入，底部一行（`[URL pill]` + `[store badges]`）淡入 / 上滑 —— 然后静止保持。
  - _变体 — Brand_Outro 落定揭示_：`[tagline]` 在 wordmark 下方从左到右显现；卫星形状漂移完毕并淡出；lockup 居中保持（至多一个非常缓慢的全局拉远，不摇移）。

**motion vocabulary**（运动词汇）：圆环脉动 / 扩展；背景交叉淡化（亮→暗）；辉光点燃；种子圆点放大；持续环绕 / 漂移（内圈比外圈快）；围绕一个固定 2D 锚点的单次 3D 透视倾斜（扁平→等轴测）+ 轻微拉远；3D logo 组装（部件脱离 + 弹簧圆点、场记板式铰链 / 啪合、外壳扇形展开）；带过冲的 wordmark 级联（字母从左到右）；按钮胶囊升起 / 缩放进入；动画化的描边轮廓描画（DRAW）+ 辉光（按钮边框和（AND）logo 标志）；彗星 / 火花强调；斜向色带擦除（扫入 → 膨胀 → 收拢成斜杠）；wordmark 逐字母搭建；预先排好的网格从四条边散开（DISPERSE）；logo 标志描边描画（依次的弧 / 线段）；带运动模糊的快速镜头穿透（CTA 的主心骨）；持续的缓慢推进 / 拉出；光标划弧进入 + 点击；视差形状滑入；从左到右、前沿发光的 URL / 徽章擦除；静止 / 淡出的结尾 lockup 保持；保持中的标志上可选的闲置呼吸；发光圆点沿圆形路径描绘；部件重叠补全图标（半圆放大 + 重叠）；带旋转的放大式标志入场；wordmark 从图标背后滑出；徽章胶囊弹到 lockup 上；逐步原地替换的字幕（底部 rail）；叠在淡淡素材网格上的统计数字跳动计数；lockup 缩小 / 淡出 → UI 窗口放大的收束；逐词错落、经由灰色的淡入（进入，以及从左边开始的退出）；逐词滚动替换整行；向中心缩小 + 淡出的清场退场；整个标志从零弹簧绽放（BLOOM）（过冲 + 轻微旋转）；保持期间几乎察觉不到的持续放大；纵向老虎机式词替换；短语水平收拢 / 擦入标志；同一中心瞬间的文字→图标替换；围绕中心轴的线条面板扇形展开并翻转的变形，带运动模糊（翻书感）；互相咬合、落定成几何标志；拖着运动模糊拖影拉出的 wordmark；引导句从底部向下滑出退场；图标从上方落入；字母依次逐个滑入 + 句末标点落下；彩纸迸发后立刻缩没；像素堆叠在文字边缘弹出；水平拖影拉伸成全宽条纹；条纹尾部回缩并被吸收进标志（遮罩回缩）；圆角方块放大、包住标志；底部元数据行淡入 / 上滑（URL 胶囊 + 应用商店徽章）；卫星形状向外漂移 + 淡出；从左到右的下划线扫过；从左到右的标语擦入。

**rule mapping**（规则映射）（逐个运动动词 → `rules/<id>.md`）

- 圆环从中心脉动 / 扩展 → `center-outward-expansion`（从一个共同的中心向外辐射；复用 0→1 的进度驱动）
- 背景交叉淡化（亮→暗渐变）→ 通过 `gsap-effects` 做单纯的不透明度 / 背景 tween（不需要专门的规则）
- 标志上的辉光点燃 → `asr-keyword-glow`（品牌元素上由包络驱动的辉光）
- 种子圆点放大成形状 → `spring-pop-entrance`（缩放弹入；如果圆点变形成形状，备选 `scale-swap-transition`）
- 围绕固定中心的持续环绕 / 漂移 → `orbit-3d-entry`（翻转进入后持续椭圆环绕；中心标签 = 固定的标志）

**camera modifier**（镜头修饰）（推进 / 倾斜）

- **CTA 穿透**（CTA 的主心骨）：在包住场景的镜头上编排一个强缩放阶段 → `multi-phase-camera`（「Steady push」/「Bookend pull」模式；推进阶段 = 高潮）。当标志偏离（OFF）中心、镜头必须飞过负空间中某个特定点时，配合 `coordinate-target-zoom`（外层缩放，内层反向平移，让目标负空间点随着缩放爬升落到 viewport 中心；在 setup 时测量偏移量）。拖影上标志性的浓重水平运动模糊（MOTION-BLUR）→ `motion-blur-streak`（作用在推进上的定向速度模糊）；在推进时间窗口内，用镜头上的 CSS `filter: blur()` / 复制出的拖影图层来实现。
- **Product_Intro 倾斜**（唯一的电影感动作）：扁平→等轴测的透视倾斜 + 轻微拉远是单独一个编排好的镜头段落节拍 → 拉远用 `multi-phase-camera`（缩放阶段 +「Targeted zoom into off-center element」/ 漂移机制）。`multi-phase-camera` 只有缩放 + 平移 + 漂移，所以整个舞台的透视平面（PLANE）rotateX（扁平俯视 → 有角度的等轴测）就是上面提到的 CSS-3D 动作 —— 用 `techniques.md` CSS-3D 近似，对舞台的 `rotateX` 做动画（最接近的参考是 `orbit-3d-entry` 的「Tilted orbit plane」变化形式随时间做动画）。
- **静止画面变体**：部件组装、文字清场绽放、变形链、部件到场和落定揭示这几个变体都是完全（COMPLETELY）静止的画面（只有元素级运动；落定揭示至多容许一个非常缓慢的全局拉远）。镜头修饰只适用于 CTA 推进和 Product_Intro 倾斜。
