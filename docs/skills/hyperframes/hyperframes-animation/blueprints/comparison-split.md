# comparison-split —— 对比分屏卡片

**intent**（意图）：两个分量相等的成对条目并排展示，带着镜像的 3D "翻书"式倾斜 —— 视线把它们读作一组平衡的对比，然后一个胶囊徽章落在每张卡片的内侧边缘来点题。运动**就是**对称本身：两张卡片从相对的两翼到来，形成一个保持住的对开页。

**roles served**（服务的角色）

- Key_Feature（from `comparison-split-cards`）：当两个分量相等、互补的功能 / 能力应该被**同时而不是先后**呈现时 —— A/B 对比、"X + Y 搭配"、观众必须并排权衡的成对概念。不适用于超过 2 个条目（用 `grid-card-assemble`）或先后的步骤。

**duration**（时长）：4–6s

**shot structure**（镜头结构）（一张 `[bg]` 画布，带两团淡淡的环境辉光 —— `[accent A]` 位于约 30% 处，`[accent B]` 位于约 70% 处 —— 让每一侧都以 50% 对称轴为界拥有自己的颜色身份；两张等宽的卡片位于同一个共享的透视父元素之下）

- **Scene 1 (0.0–~0.8s) —— 标题确立概念。** 一个居中的 `[title line]` 带着一个 `[accent keyword]`，从稍上方向**下**滑入就位（一次短促顺滑的落定）。从上往下到达是刻意的：它与接下来从两侧到达的卡片形成一个互不冲突的 T 字形。
- **Scene 2 (~0.4–1.9s) —— 分屏倾斜入场（招牌动作）。** 两张等宽的功能卡片从相对的两翼到来 —— `[left card]` 从左边，`[right card]` 从右边，晚约 0.2s —— 各自带着**镜像的 3D `rotateY` 倾斜**（左边的朝右，右边的朝左，像书一样打开），并在落地时从约 0.85 缩放到 1。入场与标题的尾巴重叠，让整体读起来是**一次**到达，而不是两拍。每张卡片承载 `[image / label / subtitle]`；投影顺着倾斜方向**朝外**落下（左边的投影向右，右边的投影向左）。
- **Scene 3 (~1.9–结尾) —— 徽章点题，然后保持。** 一个胶囊 `[badge]` 落在每张卡片的**内侧边缘**（先左后右，相隔约 0.3s），与它的卡片重叠约 15%，让它读起来是附着在卡片上，而不是在周围环绕。这是整个镜头中唯一的过冲 —— 它是为点题挣来的。落定并保持。

**motion vocabulary**（运动词汇）：标题从上方下滑；镜像的相对两翼卡片入场；静态的翻书式 `rotateY` 倾斜（左 `+tilt`，右 `−tilt`）；与倾斜匹配的朝外投影；内侧边缘徽章 spring-pop；轻柔的反相空闲漂浮（左与右，绝不同步），作为细微抖动注册；左右两侧双辉光的环境光。

**rule mapping**（规则映射）

- 两张卡片从相对两翼进场，带镜像的 `rotateY` 倾斜 + 与倾斜匹配的投影 → `split-tilt-cards`（招牌动作；保持两层拆分，让入场的 `x`/`scale` 与空闲漂浮绝不在同一个别名上冲突）
- 标题下滑落定 → `gsap-effects`（在长尾 `power3` 上做平移 + opacity）
- 内侧边缘胶囊徽章弹出（唯一的过冲）→ `spring-pop-entrance`（过冲语域 —— 为点题挣来的）
- 这一对上的反相空闲漂浮 → `sine-wave-loop`（低幅度语域 —— 细微抖动，**不是**慵懒的呼吸；左 `sin(t)`，右 `sin(t+π)`，让它们绝不像传送带一样同步）
- 卡片背后两团淡淡的侧边辉光 → `ambient-glow-bloom`（无触发的柔和光晕，每个强调色一团）

**camera modifier**（摄像机修饰）：默认摄像机静止 —— 对称是主体，一次运动就会打破平衡。
