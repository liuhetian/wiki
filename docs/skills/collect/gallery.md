# 收进 Gallery

Gallery 收的是一件件现成的东西，通用到不用提问题，拿来翻、来挑；进哪一类照写作规范[七问](../wiki-guide/index.md#where)第 2 问。别人的东西按来源分几种收：

- **有上游仓库、直接能用的效果，极简收**：页面只有标题（写效果）、一个能跑的 demo 和一句「使用 owner/repo 仓库即可」，不写复现方式、不存档源码和脚本、不建维护记录
- **图、版式、配色、视频原样收录**：只调排版和图片路径，来源和改动写进维护记录 —— 活例：[GPT Image 2 的动漫与漫画](../../gallery/images/gpt-image2/gallery-anime-and-manga.md)
- **没有仓库、要自己复刻的网页风格**：照[前端风格收集](../../gallery/web/frontend-styles/index.md)的「收录格式」
- **只存链接的整站、论坛**不进 Gallery，进轴外的[收藏夹](../../bookmarks/index.md)，一条一行；只想知道它是什么的仓库照[粗讲项目](../project-research/gist.md)进项目

**放哪**：单条放该类的 `collected/gallery-<名>.md`，素材放同级 `assets/`；成套的才开目录，`index.md` 只当索引、内容页不占 —— 活例：[彩色手绘三维穿梭视频](../../gallery/video/collected/gallery-parallax-ink.md)。
