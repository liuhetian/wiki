# 二创改写

拿别人的文案或小说做二创，先改写一遍。四种互不相干，按要改什么挑：

- [逐行洗稿](wash.md) —— 推文分镜文案要降重时用：逐行改写，行数和行号对齐原文，每行字数误差 10% 以内，靠换叙述视角降重
- [深挖仿写](imitate.md) —— 要仿写一篇文章时用：先挖出原文的核心要义，再模仿它的行文风格写出指定篇数的新作品
- [性别互换](gender-swap.md) —— 要把小说人物的性别整体互换时用：分两步，先列出所有人物和表示性别的词，再按姓名库换名、改写全部性别词
- [角色替换](rename.md) —— 要给小说人物整体换名时用：提取角色、判断性别和别称，生成同性别的新名字后全文替换

洗稿前后用 `python3 ../scripts/check.py lines 原文.txt 改写.txt` 核对行数、行号；每行字数偏差超过 10% 的只列出来，不算错。
