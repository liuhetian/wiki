# 角色与时期

后面每一步都按角色的标准名引用，所以先把角色提干净：

- [角色形象设计](design.md) —— 出图之前用：从小说里提取全部角色，识别别称和不同时期的形态变化，每个角色一行写年龄、发型、脸型、上下装和配饰
- [人物时期表](periods.md) —— 小说转剧本之前用：提取全部角色，给主角和关键人物标出时期变化节点，输出转剧本要照着用的人物时期表

形象设计的输出整理成预设信息，一行一个：`角色：名；别名：A、B 描述：……`，画面、视频、图文提示词都要粘它。
