# 小说与剧本互转

两个方向各一段：

- [小说转剧本](novel-to-script.md) —— 要把小说改成竖屏漫剧分镜脚本时用：一段约 1000 字地转，接着上一段的序号和结尾状态，人物名字和时期严格照人物时期表
- [剧本转小说](script-to-novel.md) —— 要把漫剧分镜脚本改回小说时用：把景别、镜头标签化成散文叙事，写成竖屏短篇连载的一章

小说转剧本前先出[人物时期表](../characters/periods.md)。长篇用 `python3 ../scripts/shots.py chunk 小说.txt --out 段落` 切成约 1000 字一段；下一段的起始分镜序号用 `python3 ../scripts/shots.py next 上一段输出.txt` 算。
