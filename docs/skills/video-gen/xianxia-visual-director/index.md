# 东方仙侠视觉导演

把一句场景构想、一段已有提示词或一张视觉参考，扩成结构清楚、可控、能继续衍生的电影级东方仙侠环境提示词。它不是一套固定的「白玉长廊模板」，而是共享仙界总则下的一套视觉路由：场景和风格可以变，但巨物尺度要能验证，五层空间要齐，呼吸空间要有内容，东方建筑语言要可信，边缘不加栏杆，人物和仙衣守同一套逻辑。默认只写提示词、不出图，也不绑定哪个生图平台；视频的关键帧和场景设定图同样用它。

拿到它之后：按[加载顺序](#loading)读 reference，[锁定参数](#parameter-lock)，走[导演流程](#workflow)，按[标准输出](#output)交付。目标是让同一套视觉语言反复使用时，不反复照搬同一条长廊、同一套色板、同一种建筑和构图。

## 加载顺序 { #loading }

1. 每次生成、衍生、优化、诊断都读[视觉 DNA](reference/visual-dna.md)
2. 每次都读[仙侠总则](reference/xianxia-master-rules.md)。它是所有场景路由和视觉风格路由的总规则
3. 读[画幅](reference/aspect-ratios.md)，只套用一种画幅策略，不削弱总则的五层空间和呼吸空间要求
4. 选了 `仙界大境原典` 就读[仙界大境原典](reference/celestial-grand-realm-canon.md)。它是独立的创作路由：继承总则，再加更严的内容、云海、动态和光线控制。这时跳过普通的场景路由和视觉风格 reference
5. 不走原典时，设计或改动构图、色板、光线、氛围、材质，读[构图、色彩与光线库](reference/composition-color-light.md)
6. 原典之外选中或推断出 `东方苍穹巨构` 时，读[东方苍穹巨构](reference/eastern-sky-megastructure-style.md)。它加的东西不能和总则冲突
7. 原典之外场景是有人居住的神域时，读[神域聚居地](reference/celestial-realm-route.md)。它的密度和拓扑不能和总则冲突
8. 只在用户要例子、要多个变体，或者给的构想太单薄、需要一个具体起点时，读[提示词示例](reference/prompt-examples.md)。示例的优先级永远低于总则和选中的原典路由

## 工作模式 { #modes }

从请求里推断一种：

- **创作**：把一句构想扩成完整提示词
- **衍生**：保留视觉 DNA，换主体、场景、构图、色板、光线、季节或氛围
- **优化**：改写已有提示词，让它更清楚、层级更分明、更可控、视觉更统一
- **诊断**：找出颜色发闷、透视弱、画面杂乱、尺度失败、材质像塑料、雾太重、奇幻风格太泛的可能原因，再给一版修正后的提示词
- **变体**：给几个真正不同的方向。每个变体至少换两个大模块，不能只换名词
- **直接出图**：只有用户明确要生成图片、直接出图时才出，走[直接出图](#direct-image)。只给一段参数块的意思是写提示词，不是出图

## 参数锁定 { #parameter-lock }

导演场景之前先把用户明确给的输入记下来，不要悄悄替换。

- `画幅比例`：`16:9`、`21:9`、`4:3`、`3:2`、`4:5`、`9:16` 之一；省略时补 `16:9`
- `共享总则继承`：一律记成 `已继承：巨物尺度、五层空间、40–60%有内容空气、东方巨构建筑语言、无栏杆、背影仙人与仙衣`。普通路由不能把它设成 `无`
- `独立总则路由`：`无` 或 `仙界大境原典`，默认 `无`。只有用户明确点名这条路由、说 `仙界总则` 或 `仙界原典`，或者给了那份原典时，才选 `仙界大境原典`
- `空间尺度强度`：`辽阔`、`史诗级`、`超宏大` 之一；省略时补 `史诗级`
- `饱和策略`：`自然鲜明`、`选择性高饱和`、`华丽高饱和` 之一；省略时补 `选择性高饱和`
- `场景路由`：`单体仙境` 或 `神域聚居地`；省略时从场景前提推断
- `视觉风格路由`：`华彩通透仙侠` 或 `东方苍穹巨构`；省略时补 `华彩通透仙侠`，除非请求明显指向巨构风格
- `镜头意图`：`繁华压迫`、`沉浸探索`、`城市总览` 之一；按用户在情绪和信息上的侧重推断。神域巨城或巨构、用户看重震撼胜过完整时，用 `繁华压迫`
- `机位与镜头`：机位高度、观看距离、倾角、焦段分开记。`远距离` 不是 `高机位`，`大全景` 不是 `俯拍`
- `核心场景`：地点或世界前提
- `主体建筑/景观`：主要的空间载体
- `视觉焦点`：`单体仙境` 是一个地标；`神域聚居地` 是一套统治性的建筑层级
- `构图`：用户指定的几何关系，或推断出的、和画幅相容的策略
- `人物`：人数、尺度、动作、朝向、服装、露不露脸
- `色彩`：明确的色板、饱和度、明度、对比要求
- `光线`：时间、方向、软硬、色温、轮廓光、光斑收敛到什么程度
- `材质与纹样`：建筑材质和选用的装饰母题
- `氛围`：云、雾、雨、粒子、空气透视、情绪基调
- `输出模式`：标准、精简、变体、诊断或直接出图

原典路由之外要补默认值时，明着写出来：`画幅比例：16:9（默认补充）`、`空间尺度强度：史诗级（默认补充）`、`饱和策略：选择性高饱和（默认补充）`、`视觉风格路由：华彩通透仙侠（默认补充）`。选了 `仙界大境原典` 时，保留所选画幅，锁定这条路由自己的巨物尺度和暖柔色彩逻辑，不套普通的场景、风格、镜头意图、密度和饱和默认值。

用户给了不支持的画幅或枚举值，不要悄悄取近似。`柔和鲜明`、`静谧朝圣` 这类不在内置列表里的值，可以当用户自定义的意图保留，但要说明它对应到哪个内置的镜头意图或饱和策略。

## 导演流程 { #workflow }

1. **锁定场景承诺**：概括不能动的主体、情绪、色板和画幅，不丢掉用户写明的细节
2. **套用继承的总则**：在套任何路由之前，先分配好可测量的巨物尺度证据、全部五层空间、40–60% 有内容的呼吸空间、巨大的东方建筑、无栏杆的边缘、协调的仙人与仙衣。后面的路由只能扩充，不能删掉这些分配
3. **处理独立总则路由**：明确选了 `仙界大境原典` 时，保留总则，绕过普通的场景路由、视觉风格、镜头意图、密度和饱和推断；用原典路由更严的提示词顺序，两套自检都过了才回复
4. **否则选场景路由**：一处局部地点或一个地标用 `单体仙境`。有人居住的神域用 `神域聚居地`，它的宫阙区、廊桥、台地、云上设施和远方城层都要看得见。不要把后者缩成一座孤立的宫殿，也不要违反总则的五层空间
5. **原典之外选视觉风格路由**：默认用 `华彩通透仙侠`。要巨型建筑切片、门槛视角、压住或取代天空的神性建筑、克制的高调色彩、孤独的尺度参照、低角度侧逆光时，用 `东方苍穹巨构`。场景路由和风格路由是总则之下互相独立的两项附加
6. **选镜头意图**：把情绪上的在场感和地理上的覆盖面分开。`神域聚居地 + 东方苍穹巨构` 默认 `繁华压迫`：远距离、低机位或平视、略微仰拍；密集的宫阙层要显得沉重时优先用长焦压缩。只有用户明确要求才用高机位总览
7. **选一种空间骨架**：一点透视、居中对称、对角纵深、S 形流线、框景、垂直攀升，或者别的单一主导几何。不要让几套透视系统互相打架
8. **定焦点层级**：`单体仙境` 选一个读得清的地标。`神域聚居地` 选一个主宫阙区或一条神性轴线，下面组织许多从属城区。`东方苍穹巨构` 定一个主导的空间事件，不要求一个完整可见的物体
9. **定可测量的尺度**：从总则要求的四项以上可见证据和人物对比出发，再按所选强度，套用[构图、色彩与光线库](reference/composition-color-light.md)里相容的附加项。路由可以加强尺度，但不能用形容词或密度代替可测量的证据
10. **做色彩预算**：先套所选的饱和策略，再套所选的风格路由。用户明确要的高饱和要保留，但 `东方苍穹巨构` 要留一大片明亮的中性底色，最强的暖色只放在有光源依据的点缀上
11. **设计光线**：建立一个有依据的主光方向、冷暖分离、读得出颜色的阴影、受控的逆光，光斑或星芒最多一处且要克制
12. **加材质证据**：有选择地写反射、透光、纹理、包浆、雕刻深度、描金边、湿润和磨损。别让玉、金属、玻璃和漆器看起来像塑料
13. **建纵深**：把场景映射到总则的全部五层。通过开口、庭院、水面、云隙、虚空和远方保住 40–60% 有内容的空气；用高能见度的空气透视，让云揭示建筑而不是吞掉建筑
14. **组装最终提示词**：用所选路由的提示词顺序。画幅、机位高度、观看距离、倾角、焦段都写明
15. **自检**：先跑总则继承自检，再跑所选路由的完整检查单。两个都过才输出

## 独立总则路由 { #canon-route }

- `仙界大境原典` 是给用户的第四条创作路由，不是总则的私有来源。它继承的巨物尺度、空间、建筑、栏杆、人物和仙衣语言，和其他所有方向一样
- 永远不要从这条路由推断出九张图、拼贴、序列或 `9:16`。用户要几张就一张一个提示词，所有列出的画幅都支持
- 不要引入别的路由的密集城市目标、巨构压迫式取景、硬侧逆光、高饱和默认值或装饰模块。栏杆本来就被总则禁止
- 保留总则的巨物尺度关系、五层空间、40–60% 有内容的呼吸空气、无栏杆建筑、背影仙人、仙衣语法和物理真实感；再加上这条路由更严的低位云海、有限的远景锚点、单一主要动态和温暖柔和的高空漫射光
- 用户要几条原典提示词时，变构图、主建筑、远景锚点、地面、人物距离和动态，所有硬性不变量保持不变

## 场景路由 { #scene-route }

- 长廊、门、亭、祭台、孤立浮岛、孤峰、神木、月环，或者别的围绕一处局部体验组织的场景，选 `单体仙境`。保留一个统治性的锚点，同时把它映射到总则的五层空间和 40–60% 有内容空气上
- `天宫`、`仙城`、`神都`、`九重天`、`云上帝都`、`神域`、`神仙居所`、`宫阙群`、密集有人居住的浮空文明，或者要城市尺度的神域世界，选 `神域聚居地`，读[神域聚居地](reference/celestial-realm-route.md)并照做
- 用户写明的布局、镜头、景深、密度、位置、色板和光线都是硬锁。选路由时不要拿熟悉的长廊、月洞门、居中宫殿或别的惯用构图把它们换掉
- 中国传统建筑是一种辨识度高的设计语言，不是复原的上限。允许物理上不可能的浮空大陆、云上设施、垂直神城、天界瀑布、层层嵌套的天，但透视、光线、材质反应和内部空间逻辑要自洽

## 视觉风格路由 { #style-route }

- 默认选 `华彩通透仙侠`：材质色彩丰富、装饰精密、建筑呈现清楚、云层透亮、电影感优雅壮观
- 用户提到或引用 `苍穹巨构`、`白玉京巨构`、`巨物压迫`、`建筑切片`、`巨构压顶`、`门槛窥视`、`不可抵达的天宫`、`孤寂神圣`、克制的蓝灰配金的光，或者给的视觉参考以这些特征为主时，选 `东方苍穹巨构`，读[东方苍穹巨构](reference/eastern-sky-megastructure-style.md)并照做
- 两条路由轴都写明。有效组合有 `单体仙境 + 华彩通透仙侠`、`单体仙境 + 东方苍穹巨构`、`神域聚居地 + 华彩通透仙侠`、`神域聚居地 + 东方苍穹巨构`
- 主导空间事件是一个互动关系：悬垂天门下的城市、消失在不可抵达宫殿里的桥、劈开天空之城的瀑布、透过门洞看见的远方神域。几个元素可以共同组成这个事件，但不能变成互相竞争的焦点

## 镜头意图 { #camera-intent }

- 用户明确给的镜头方向是硬锁
- 目标是震撼、威压、神性繁华、建筑重量，或者身在神域之中的感觉时，用 `繁华压迫`。机位放低或在人眼高度，平视或略微仰拍，地平线放低，主建筑占据画面中上部。要压缩密集的宫阙层，优先远距离 70–100mm；桥、台阶、门和底面揭示用远距离低机位 24–35mm；门槛框景用 35–50mm
- 长廊、台地、园林、桥、室内、穿行世界的旅程用 `沉浸探索`。机位靠近人的高度，焦段按空间路径选
- 只有用户明确要 `俯拍`、`鸟瞰`、`航拍`、`城市总览`、`地图感`、`城区分布`、`浮岛关系` 或同类地理信息时，才用 `城市总览`。只有这条路由可以默认高机位
- `远距离` 和 `高机位` 互相独立。机位可以离城很远但保持低位，这正是制造巨构压迫感的首选
- 不要单凭 `大全景`、`云海`、`仙城`、`浮岛`、`世界观` 或宽画幅推断高机位

## 画幅 { #aspect-ratio }

- 每条可直接复制的提示词，第一句写所选画幅
- 用[画幅](reference/aspect-ratios.md)把画幅翻译成构图行为，不要当成一个没有意义的标签贴在后面
- 用户同时给了像素尺寸和画幅时，两者分开写
- 用户点名了生图平台，只有确定它支持、也知道写法时，才加它原生的画幅语法。不要编造平台参数
- 提示词迭代时保持同一个画幅，除非用户改了

## 尺度与饱和 { #scale-saturation }

- `辽阔` 用于以风景为主、巨型建筑较安静、空气占主导的场景，仍要保留全部五层、40–60% 有内容空气和四项可测量的尺度证据
- 默认用 `史诗级`。加强统治主体和不连续的尺度对比，不丢总则底线
- 只有画面同时通过总则自检和[构图、色彩与光线库](reference/composition-color-light.md)里相容的超宏大附加项时，才用 `超宏大`：微小的成年人、出画或横穿云层的巨型形体、读得出的极远距离、更强的尺度断裂
- `神域聚居地` 把同一套总则映射到统治城区、相连的从属城区、承载人的交通面和极远的聚落上。密度永远不能代替固定的五层、可测量的对比和 40–60% 有内容空气
- `自然鲜明` 用于写实的中等纯度，只有一处克制的点缀
- 默认用 `选择性高饱和`：高纯度集中在小块点缀区，大面积亮面和远景保持平静
- 用户明确要求时用 `华丽高饱和`。限制同等强度色相的数量，保留中性锚点，维持层级
- 不要因为一个路由值去改另一个。`超宏大 + 自然鲜明`、`辽阔 + 华丽高饱和` 都可以

## 视觉约束 { #constraints }

- 用户明确要高饱和或亮色的，保留，但要经过所选的饱和策略来表达
- 与其只写一句 `高饱和`，不如写 `高明度、选择性高纯度、色彩分离清楚、阴影透明、亮而不荧光`
- 不要整体加橙金色偏。白玉、云的高光、皮肤和浅色石材在材质上要分得开；暖色溢光只落在有光源依据的受光面
- 没有可见的尺度证据，就不要声称画面宏伟。定稿前过一遍所选的尺度门槛
- 不要每个场景都默认白玉长廊、朱红柱、圆形月洞门、三位女性或蓝天。那些是可选模块，不是这个 skill 的身份
- 不用任何栏杆、扶栏、围栏、女儿墙、护栏或装饰性的边缘遮挡，除非用户明确要求
- `单体仙境` 不要组合几个主导地标。`神域聚居地` 可以有很多建筑和奇观，但要服从一个城市层级和一种统一的东方建筑语言
- 别让雾气形成灰纱、压平颜色或抹掉远处的剪影
- 环境全景里别滥用浅景深。`神域聚居地` 的建立镜头默认大景深，前景、中景、远景、极远景的建筑都读得清，除非用户另有要求
- `东方苍穹巨构` 里不要为了完整展示而缩小主建筑。保留有意的裁切、遮挡、门槛框景，以及至少一处不连续的尺度跳跃
- `繁华压迫` 不用高机位、鸟瞰、航拍或俯视。不要为了把整座城装进来，牺牲建筑的立面、悬挑的体量和观者的从属位置
- 镜头光斑要克制，并且有光学上的依据
- 不要用受版权保护的艺术家姓名模仿风格，直接描述视觉特征
- 人物默认是总则尺度的虚构成年人，背影或斜后方，动作平静，穿结构化的仙衣，只有一个统一的风向。只有用户自有或获得授权的图片，才保留参考图里的人物身份

## 标准输出 { #output }

用户没要别的模式时，返回：

1. `参数锁定`：紧凑的字段列表，包括 `共享总则继承`、写明的或补充的画幅；选了独立总则路由就写它，否则写场景路由和视觉风格路由；镜头意图、机位高度与镜头、空间尺度强度、饱和策略
2. `视觉导演方案`：简短说明构图、色板、光线、尺度和氛围
3. `完整提示词`：一个可直接复制的 `text` 代码块
4. `负面约束`：另一个 `text` 代码块
5. `可衍生方向`：三个简短变体，每个至少换两个大模块

用户说 `只要提示词` 或要精简模式，只返回完整提示词和负面约束。变体模式下，用户要求时每个变体给一条完整提示词，否则给简短的方向卡。

## 完整提示词的写法 { #prompt-construction }

完整提示词必须：

- 以 `<画幅> 画幅，<取景/机位>，<主导构图>` 开头
- 选了独立路由时，在开头附近点名 `仙界大境原典`，然后按它的组装顺序和自检来，不用普通的风格默认值
- 通过可见的尺度关系表达所选的空间尺度强度，不只靠一个形容词
- 分配全部五层，并说明 40–60% 有内容的呼吸空间如何保持可读
- `单体仙境` 写明地标在哪；`神域聚居地` 写明主城区如何统领从属的城市层
- `东方苍穹巨构` 写明主导空间事件、什么遮挡或裁切了巨构、人物、门槛或远方城市如何证明它不可能的尺寸
- 机位高度、观看距离、倾角和焦段分开写。不要用 `大全景` 或 `建立镜头` 代替机位
- 严格透视要紧时，说明尺度如何随纵深递减
- 至少包含四项可测量的尺度证据；除非用户明确推翻，所有边缘都不加栏杆
- 色板、高纯度点缀、中性锚点、阴影颜色分开写
- 只用一个主光源，并写明方向
- 有人物时，写明人物占画面高度的百分比、背影角度、平静的动作、仙衣结构和一个风向
- 风格和渲染措辞放在具体场景描述之后
- 以关键不变量和排除项收尾

正向和负向指令分开写。具体可见的关系优先于堆叠形容词。

## 直接出图 { #direct-image }

用户明确要出图时，走 Agent 基础能力的[生成、编辑图片](../../agent-io/reference/image.md)：接口、key、HTTP/2、超时、结果解码都照那页办。

- 用生成接口；用户给了参考图要保留构图时用编辑接口，参考图放进 `images[]`
- `prompt` 写完整提示词，负面约束接在末尾 —— 接口没有单独的负面字段
- `size` 写锁定的画幅，六种比例都能直接写
- 一次请求出一张；用户要几个变体就发几次
