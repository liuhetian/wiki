先套用[仙侠总则](xianxia-master-rules.md)，再从这里只挑能支撑场景的部分。本库可以变化几何、机位、配色和光线，但不得减少固定五层、40–60% 有内容空气、可测量的尺度、无栏杆建筑和仙人仙衣语法。

## 空间骨架 { #spatial-skeletons }

- **严格一点透视**：把一个偏心或居中的消失点放在刻意选定的位置。纵向边线向它汇聚；竖线保持平行；重复构件的间距和尺寸按统一规律递减。
- **中轴对称**：用于门阙、宫殿、祭祀空间、镜湖和庄严场景。加一处小的不对称，比如人物、飞鸟、飘动的布或枝叶，让画面不死板。
- **对角纵深**：从一个大的前景元素引向较小的中景锚点。用桥、台阶、屋脊线、岸线或光路。
- **S 形曲线**：用蜿蜒的小径、河流、云带、桥或行列逐步展开空间。
- **框景**：用边缘的门、柱、枝、檐、崖或织物揭示明亮的远方。
- **垂直上升**：用于 4:5 和 9:16。从下方的小主体引向高门、塔、瀑布、树或光的开口。

`东方苍穹巨构`：从它的专篇[东方苍穹巨构](eastern-sky-megastructure-style.md)里选主导空间事件。把框景、遮挡和建筑体量当作同一种几何，不要叠加几种相互竞争的骨架。

## 焦段与机位路线 { #lens-camera }

- **广角环境揭示（等效 20–28mm）**：用大的近景框架、深的引导线和远方地标夸大分离感。控制竖线，禁止鱼眼畸变。
- **均衡电影剧照（等效 35–50mm）**：用于可信的建筑、自然的人物尺度和不那么风格化的透视。通过尺度层级和出画延续加强宏大感，不靠镜头畸变。
- **长焦尺度压缩（等效 70–100mm）**：从远处取景，让巨大的宫殿、门、山或月亮压在小小的前景人物身后的地平线上。用大气和明度分离各层，不用广角汇聚。
- **低机位**：用于台阶、门、柱和塔，需要向上的压迫感时用。
- **高机位揭示**：只在用户明确把鸟瞰地理、城市规划、城区分布或岛屿关系放在身临其境的压迫感之上时用。不要因为有云海或城市就推断用它。

不要在同一画面里同时用极端广角畸变和强烈长焦压缩。

## 繁华与压迫的机位优先级 { #camera-priority }

用户既要繁盛的天界都城、又要巨构压迫感时，除非有明确的机位指令覆盖，按这个顺序选：

1. **远距离低视点 + 70–100mm 长焦压缩**：密集屋脊线、层叠城区、巨大宫殿或门阙压在后方时的默认选择。观者保持在台地、桥或人眼的高度。
2. **远距离低视点 + 24–35mm 直线广角**：用于通道、桥、台阶、门、柱阵和底面。保持足够的机位到主体距离，避免无意义的前景畸变。
3. **人眼高度的门槛视角 + 35–50mm**：用于门口、台地、崖、檐、室内和框景揭示。
4. **高机位总览**：只用于明确的 `城市总览` 意图。

不要混淆机位距离和机位高度。远处的机位可以低于主屋脊线并略微仰拍。

`繁华压迫`：地平线靠近下三分之一，成年人物约 1–3%，画面下部是承人的门槛，中部横贯密集的从属城区，统治体量在上方或后方出画。把 40–60% 的有内容空气穿插在天空、门洞、云隙、平台下的虚空、街道、庭院和城市中的大气分隔里；绝不拿总则的呼吸空间去换一整片屋顶地毯。

## 尺度构建 { #scale-construction }

### 辽阔

- 用齐总则五层、四项可测量尺度证据、一条读得懂的通往远方的路径，以及宽裕的有内容天空、水、云、山谷或庭院空间。
- 人物可以没有，或保持次要。

### 史诗级 —— 默认

- 用齐总则五层，加强近景巨型框架、已知尺寸的成年人或门槛、统治主体、从属天域和天际终点之间的不连续。
- 至少包含四项可见证据，其中一项是直接对比，比如成人对门、桥对宫殿、树对城市、瀑布对岛屿。
- 以环境为主的尺度参照保持在画面高度约 1–4%；只有需要读清完整剪影时才用 5–8%。

### 超宏大 —— 宏观尺度门槛

除非用户明确覆盖其中某一条，以下全部要满足：

1. 总则五层齐全：近景巨型框架、承人界面、统治性巨型主体、从属天域和天际终点。
2. 成年尺度参照约占画面高度 1–4%，除非用户明确要求更强的叙事存在感。
3. 一个巨型结构至少越过一条画框边缘，或被更近的框架部分遮挡。
4. 约 40–60% 的有内容呼吸空气，分布在天空、云海、虚空、水面、开放庭院、门洞或远方。
5. 有可见的极远层次，而不是空雾。
6. 四项或以上可测量尺度证据，各层之间有清楚的明度、对比或纯度台阶；不要把所有主体放在同一视觉平面上。

这些是视觉证据，不是可以机械粘贴的词。构图满足不了这道门槛时，标成 `史诗级`，不要声称 `超宏大`。

## 焦点层级 { #focal-hierarchy }

用三级：

1. 主导：空间载体或地标。
2. 辅助：人物、次级建筑、植物、瀑布或倒影。
3. 质感：雕刻、云、鸟、花瓣、小光点或远方屋顶。

不要给三级同等的对比、尺度和细节。

`神域聚居地`：主宫阙城区或神圣轴线是主导级，辅助城区是第二级，重复的屋顶、桥、台阶、庭院、云中交通和小奇观是质感级。保留密度，同时控制竞争。

## 配色方案 { #palette }

- **晴朗天界**：天蓝 + 玉白 + 朱红 + 暖金 + 深色木。
- **雨洗园林**：翡翠绿 + 孔雀蓝 + 珊瑚色 + 象牙白 + 湿炭灰。
- **明亮夜景**：钴蓝 + 紫罗兰 + 克制的洋红 + 琥珀金 + 月白；黑色保持通透、带色。
- **阳光山岳**：绿松石 + 松绿 + 朱砂 + 杏色天空 + 浅色石。
- **神圣黎明**：淡青 + 云白 + 藏红金 + 矿物红 + 冷蓝灰阴影。

目标是两个主导色系、一个高纯度点缀色、一个中性或深色稳定色。不要让配色里的每个颜色都同样强。

## 饱和策略 { #saturation }

把下面当作起始面积预算，再按主题调整：

- **自然鲜明**：70–80% 中低纯度底色，15–25% 中等纯度，最多 5% 高纯度点缀。
- **选择性高饱和 —— 默认**：65–75% 中低纯度的天空、云、玉、石，15–25% 中等纯度的结构和植物，5–10% 高纯度的朱红、珊瑚色、衣物、花或鎏金边点缀。
- **华丽高饱和**：允许 15–25% 的高纯度面积，但限制同等强度的色相家族数，并保留至少一大块中性或深色稳定区。

保持材质的色彩分离：

- 白玉、云的高光、浅色石和月白保持接近中性。
- 让暖色阳光作用于受光的边缘和平面；不要把所有材质都染成同一种橙色或金色。
- 冷色阴影和暖色高光要分得开。
- 远处逐步降低纯度和对比，但不让远方变灰。
- 鎏金保持细窄明亮，不要把金色铺满屋顶、云、皮肤和地面。

## 光线方案 { #lighting }

- **低角度金色逆光**：暖色定向光、明亮的材质边缘、冷色的内部阴影、一处克制的星芒。
- **雨后晴光**：清爽的天光、湿润的反射、饱和的植物、柔和的破云阳光、极少雾气。
- **云隙照明**：一束光照亮锚点，周围空间保持明亮，不变黑。
- **月光与灯火分治**：冷色的蓝紫环境光加局部的琥珀色光；阴影细节保持通透。
- **高空清晨**：干净的蓝色天光、暖色的掠射高光、体积云的边缘、通透的空气。

## 材质提示 { #materials }

- 玉：细微的内部散射、矿物纹理、抛光的边缘，不是均匀的塑料感。
- 漆木：深沉的有色本体、受控的镜面高光、磨损边缘处细密的木纹。
- 鎏金：细窄的点缀和凸起边缘的反光，绝不覆盖每个表面。
- 青铜：暗色包浆、较暖的磨损棱线、清晰的浮雕阴影。
- 玻璃或釉：有色的透射、锐利的边缘高光、可信的厚度。
- 湿石：基础明度变暗、破碎的倒影、局部的光泽。
- 丝绸：有方向的褶皱、随风的反应、柔和的高光过渡。

## 失败修正 { #failure-corrections }

- 画面沉闷：提高高明度曝光、色彩分离、带色的阴影细节和一处清晰的点缀色；减少灰雾。
- 廉价霓虹感：减少同等强度的点缀色，恢复象牙白 / 石 / 深色稳定区，把最高纯度局部化。
- 过饱和或过暖：缩小高纯度红 / 金的面积，恢复接近中性的玉和云，去掉全局橙色 LUT，把暖色溢光限制在有光源依据的受光面上。
- 物体大但不宏大：加入不连续的尺度层级，缩小尺度参照人物，引入极远层次，让一个结构延伸出画，并在广角揭示和长焦压缩两条路线中择一。
- 透视弱：简化几何，指明一个消失点，写明重复构件的尺寸递减，去掉相互竞争的轴线。
- `单体仙境` 杂乱：保留一个锚点，减少装饰物的种类，分开主导 / 辅助 / 质感三级。
- `神域聚居地` 杂乱：保留一个统治城区和相连的城市拓扑；简化重复的模块类型和对比层级，但不删除从属城区和城市的连续性。
- 建筑塑料感：加入表面变化、雕刻深度、边缘磨损、透光、包浆、纹理和不均匀的反射。
- 远景扁平：在前景、中景、背景和极远景之间建立对比和明度台阶。
- 光斑过量：只在一处逆光边缘保留一个有光学依据的光斑，其他装饰性光斑全部去掉。
- 巨构泛化：裁切或遮挡主体量，恢复东方的人尺度门槛，加入不连续的尺度对比，减少巨大表面上的均匀装饰，用高明度的冷暖分离替换均匀的灰色调色。
- 航拍地图感：把机位降到人或台地的高度，恢复可见的立面和底面，从远处用 70–100mm 压缩密集的宫阙层次，压低地平线，放大并裁切主体量；只有明确要求总览时才保留高机位。
