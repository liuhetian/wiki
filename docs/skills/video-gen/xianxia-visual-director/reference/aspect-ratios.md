# 画幅构图路由

在[仙侠总则](xianxia-master-rules.md)之下只套用一条画幅路由。画幅改变的是取景方式，不改变继承来的五层空间、40–60% 有内容呼吸空气、可测量的尺度、无栏杆建筑，以及人物与仙衣规则。

## 16:9 —— 默认的电影横幅 { #16-9 }

- 用于平衡的建立镜头、建筑加风景、一般的电影场景。
- 把固定五层在均衡的电影宽度上铺开，统治主体偏好放在偏离中心、靠近三分线交点的位置。
- 可以用强对角线、一点透视长廊、中轴对称或框景。
- 以环境为主的尺度参照人物保持在画面高度约 1–4%；只有需要读清完整剪影时才用 5–8%，不要因为画幅宽就把人放大。
- 给天空、云体、倒影或远方岛屿留出呼吸空间。
- 天城压迫感的画面：地平线放在下三分之一附近，用远距离低机位或平视机位，让主体体量占据画面中部和上部。宽画幅不等于航拍视角。

提示语：`16:9 横向电影画幅，宽阔建立镜头，五层空间与有内容空气清晰`

## 21:9 —— 全景奇观 { #21-9 }

- 用于浩瀚云海、浮岛链、长桥、仪仗行列和横向展开的建筑。
- 环境叙事横向铺开，同时保留一个主导锚点。
- 在一侧或两侧边缘放前景元素，避免画面成为空荡的长条。
- 不要让竖向地标被裁掉；降低它们的相对高度。
- 用分层的横向节奏，不要在中间塞满物体。
- 要宫阙密度和压迫感时，偏好横跨画宽的低视点长焦压缩；不要把全景拍成俯视的城市地图。

提示语：`21:9 超宽银幕画幅，横向展开的史诗尺度，边缘框景与远景层叠`

## 4:3 —— 古典画面 { #4-3 }

- 用于庄重的建筑、庭院、亭阁、对称的门阙和故事书般的电影画面。
- 偏好中轴对称、稳定三角或略偏中心的一点透视。
- 比 16:9 分给屋顶、云、树和倒影更多的纵向空间。
- 构图庄严、饱满，但不挤到四角。

提示语：`4:3 古典横幅画幅，稳定庄严的空间组织，建筑与天空比例均衡`

## 3:2 —— 摄影胶片剧照 { #3-2 }

- 用于自然主义的电影剧照、对角运动、旅途瞬间和以环境为主的人物场景。
- 偏好非对称三分法、引导线、可信的机位，以及不那么正式的调度。
- 前景到中景的过渡保持自然；除非用户要求，避免过于完美的对称。

提示语：`3:2 摄影横幅画幅，自然电影剧照构图，非对称三分法与明确引导线`

## 4:5 —— 杂志竖幅画布 { #4-5 }

- 用于高耸的门阙、亭阁立面、瀑布、古树、以服装为主的环境场景和海报式构图。
- 把前景、主体、锚点和天空纵向叠放。
- 重要建筑远离左右裁切边；用较窄的小径或台阶作纵深轴。
- 人物仍作尺度参照时，放在下三分之一，让地标保持主导。
- 在锚点上方留出受控的空间给云、树冠或光柱。

提示语：`4:5 竖幅画面，纵向层叠构图，下方人物尺度参照，上方建筑与天光主导`

## 9:16 —— 沉浸式竖屏奇观 { #9-16 }

- 用于高耸的塔、天阶、崖壁瀑布、巨树、深渊和移动端优先的画面。
- 建立明确的自下而上的阅读路径。用纵向重复和高位或低位消失点。
- 不要把横向全景硬塞进窄画布。
- 主地标放在中央的纵向通道里，两侧建筑作框景。
- 限制横向的浮岛链和大范围的群组排布；优先表现高度和上升。

提示语：`9:16 沉浸式竖屏画幅，自下而上的视觉路径，强烈高度感与纵向空间层叠`

## 画幅自检 { #audit }

定稿前确认：

- 提示词第一句写明了一个支持的画幅。
- 构图遵循该画幅的阅读方向。
- 焦点锚点不太可能被裁掉。
- 人物保持在预定尺度。
- 负空间是有意的，不是偶然留下的。
- 总则五层都能读清，裁切后仍保有 40–60% 的有内容空气。
- 边缘保持无栏杆，人物保留总则的背影仙衣语法。
- 机位高度符合情绪意图；没有把 `大全景` 或宽画幅误读成可以用高机位。

## 与空间尺度强度的配合 { #scale-intensity }

- 先定画幅，再定空间尺度强度。不要为了宏大而改动用户要的画布。
- 镜头意图独立于画幅。没有任何支持的画幅默认用鸟瞰或高机位取景。
- 每种强度都保留总则五层和至少四项可测量尺度证据。
- `史诗级`：加强统治主体和不连续的对比，不删减呼吸空气。
- `超宏大`：即便是 4:5 或 9:16，也通过纵向叠放五层，加入出画或穿云的延续。
- 21:9：用横向的极远层次和边缘框景；不要在宽幅上散布许多同样大的地标。
- 4:5 和 9:16：用下三分之一的微小人物、纵向主导的出画结构，以及高处或低处的极远目的地。

## 与 `仙界大境原典` 的配合 { #canon }

- 在每种支持的画幅里都保留继承来的固定五层和 40–60% 有内容呼吸空气；原典路由在此基础上加更严的云、锚点、动态和光线控制。
- 主云海保持在人物所在平台之下，主要位于画面底部 20–35%，只调整它的形状，不把它移到建筑上方。
- 画幅只用来改变阅读方向、裁切和摆位。不改变该路由的可测量尺度、有限的远景锚点、无栏杆建筑、单一主要动态和温暖漫射光的基线。
- 9:16 默认就是一张竖图。不得从画幅推断出九张图、系列、拼贴或人物分布排期。
