# 神域聚居地

用这条路由设计一个神仙在神话尺度下真实居住的地方。先套用[共享仙界总则](xianxia-master-rules.md)；城市密度和拓扑只能扩展、不能取代总则里的尺度、五层空间、呼吸空间、建筑、栏杆、人物和仙衣规则。结果不是历史复原，也不是一座孤零零浮在云上的宫殿。

## 路由承诺 { #route-promise }

按这个优先级排：

1. **神话创造**：让世界在现实中不可能存在 —— 浮空大陆、公里级的云上城市、垂直叠起的诸天、悬空交通、天界瀑布、神树、星河，或其他自洽的奇观。
2. **东方辨识度**：用飞檐、斗拱、重檐、开敞平台、庭院、门阙、楼阁、长廊、台阶、漆木、矿物颜料、青铜、玉和克制的鎏金表达这个文明。
3. **电影可信度**：保持一个透视系统、有来由的光、物理真实的材质、体积云、尺度比较和读得清的空间连续性。

别让历史营造做法给尺度和几何封顶，只把它当词汇和排布逻辑用。

## 继承总则 { #master-inheritance }

- 把固定五层空间对应为：近景巨型门槛；宽阔、有人居住的通行界面；一个统治城区或神圣轴线；相互连通的从属城区；极远聚落、更高的天界或天际终点。
- 在城区之间、下方、后方和内部保留 40–60% 有内容空气。用庭院、街道、门洞、云隙、开阔水面、平台下的虚空和大气分层；别用一整片连绵的屋顶毯子取代呼吸空间。
- 写进至少四项尺度证据。除了密度和重复，还要有成人对柱、门、平台、桥、树、崖壁或城市轴线的比较。
- 所有平台、桥、台阶、长廊、露台、街道和云港都不加栏杆，除非用户明确要求。
- 看得见居民时，默认是 1–4% 的成年人，背影或斜后方，动作平静，穿结构化仙衣，只有一个风向。城市活动可以让微小人物成倍增加，但不能把他们变成正面肖像或泛泛的剪影。
- 城市里最大的结构保持巨大、平静、结构清晰。精细装饰集中在人看得清的门槛处，不涂满每个巨大表面。

## 群体层级 { #ensemble-hierarchy }

用一个统治层级取代单一地标规则：

- 定一个主宫区、神圣轴线、城冠、圣山核心或高起的帝域作为主导体块。
- 加二到四个从属城区，尺度或反差更低。
- 用大量次要的屋顶、楼阁、庭院、开敞平台、桥、台阶、瀑布和云港做城市肌理。
- 城区之间看得出连通。聚居地必须露出交通或基础设施，而不是散在雾里互不相干的纪念物。
- 屋顶高度、平台标高、间距、遮叠和朝向都要有变化。避免盖章般一模一样的建筑。

高密度是好事，同等的视觉分量不是。靠层级、重复和连通的空间逻辑减少杂乱，而不是把城市删掉。

## 城市拓扑 { #world-topologies }

挑一种贴合请求的拓扑；别一再默认同一种构图。

- **轴线升天**：门阙、庭院、平台和宫区一路升向高处的天界城冠。
- **梯级浮空大陆**：一块广阔的悬空陆地承载层层跌落的城市、崖上宫殿、瀑布和下层云港。
- **悬岛网络**：几座有人居住的岛靠长桥、飞廊、云渡和礼仪堤道相连。
- **九重天叠层**：多个有人居住的层面上下悬浮，越往顶层越小、越亮或越神圣。
- **神轴环城**：城区环绕一棵巨树、一根巨柱、一座山、一架星仪、一面日轮或一道瀑布井，又不变成西式科幻巨构。
- **云崖都会**：宫殿攀附在巨大的垂直崖壁上，向上、向下、向画外延续。
- **天际宫带**：横向连绵的庭院与楼阁天际线横贯云海，适合 16:9 或 21:9 的大场面。

## 超宏大门槛 { #ensemble-macro-gate }

史诗级或超宏大的神域聚居地，要求看得见的证据：

1. 固定五层齐全：近景巨型门槛、站着微小居民的承人通行界面、统治城区、相互连通的从属城区、极远聚落或更高的天界。
2. 环境主导的成人约占画面高度 1–4%；只有完整剪影必须读清时才用 5–8%。
3. 让建筑越过一侧、顶边、下层云层或地平线延续出去，让聚居地显得比画框还大。
4. 通常让建成区铺满大部分可用宽度，近、中、远三层都有建筑。别把一座宫殿孤立在空荡的云野里。
5. 一个主体块、二到四个辅助体块、大量小型建筑重复。
6. 写进连通证据：廊道、桥、台阶、平台、云路、渡船平台，或像引水渠一样的瀑布。
7. 云放在城区之间、下方和后方。用云隙和受光的云边让云揭示尺度，而不是抹掉建筑。
8. 保留约 40–60% 有内容空气。把它分散到开放庭院、街道、门洞空气、水面、云隙、平台下的虚空和垂直城区之间的间隔里，而不是留出一整块空天。

如果画面里只有一座宫殿、一道门或一个平台，即使提示词写着 `天宫`，也改回 `单体仙境`。

## 机位与清晰度 { #camera-clarity }

- `繁华压迫` 偏向远距离低机位或人眼高度机位加 70–100mm 长焦压缩，让密集的宫殿层次在微小人物身后、统治巨构之下层层累积。
- 引道、桥、台阶、门和底面揭示用远距离低机位 24–35mm 直线广角；门槛视角和可信的建筑比例用人眼高度 35–50mm。
- 要低角度的宏伟，机位放低，但要远到能露出整个城市层级；控制垂直线汇聚，禁止鱼眼畸变。
- 默认大景深。近景门槛、承人界面、主城区、从属城区和天际终点都要读得清。
- 只有用户明确选 `城市总览`，或要求鸟瞰地理、城区关系、浮岛分布时，才用高机位揭示。不从 `大全景`、`云海`、`浮岛` 或 `仙城` 推断高机位。
- 靠更小的尺度、更冷的远景和分级的反差制造大气感。不靠铺一层均匀的灰雾制造纵深。
- 前景观景平台保持从属，通常约占画面面积 8–15%，用户要求时与画框边缘脱开，永远不挡住主城体块。

## 繁华压迫 { #prosperity-under-pressure }

不靠航拍地图表达繁华：

- 微小的背影仙人和承人门槛放在画面下部；主要的尺度参照人物穿结构化长袍，统一一个风向。
- 中景铺满遮叠的屋顶、庭院、桥、长廊、云上交通、瀑布、平台、灯火和仪仗行进。
- 一座统治性的宫殿、门阙、平台、墙或神圣轴线放在这些城区的后方或上方；用顶边或侧边裁切它，让它无法丈量。
- 保留看得见的立面、基座、柱子和底面。光有屋顶覆盖只能证明密度，证明不了压迫。
- 地平线压低，让城市越过画框和云层继续延伸。

## 奇观密度但不落俗套 { #fantasy-density }

加二到四套相互自洽的不可能系统，不是随手列一张清单：

- 嵌在浮空山陆里的宫殿；
- 穿过数层云的瀑布；
- 连接城区的云阶和悬空长廊；
- 主城之外看得见的更高天界或远方神都；
- 融进城市规划的巨大天树、巨钟、星仪、日轮或玉柱；
- 暗示有人居住的云港、鹤道、飞舟、光桥或仪仗行列；
- 受同一套世界逻辑支配的倒悬山峰、空中花园、空中河流或发光云渠。

避免：加了中式屋顶的欧洲城堡、现代摩天楼网格、科幻霓虹天际线、游戏地图式的杂乱，或者只是把一座历史宫殿贴到云上。

## 宫殿色彩的真实感 { #palace-color-realism }

用户想要鲜艳色彩时，走 `华彩但不过曝` 的材质路线：

- 允许朱红漆、青绿彩画、鎏金或青铜屋顶细节、白玉、深色木、彩色琉璃和明亮天空保持看得出的饱和。
- 按材质分配饱和度，而不是把整座建筑都降成点缀色。
- 云、浅色石材和白玉保持接近中性，作为明亮的稳定色。
- 暖金只留给受光边、屋脊、金属和选定的受光面。不铺全局橙金。
- 阴影按光线设定保持通透的青、蓝灰、蓝绿或紫灰。
- 保持高能见度、干净的色彩分离和读得清的远景剪影；禁止浑浊的灰调。

## 提示词组装 { #prompt-assembly }

`神域聚居地` 的提示词按这个顺序：

`画幅 → 机位高度、距离、倾角与焦段 → 继承的可测量尺度证据 → 固定五层空间与 40–60% 有内容空气 → 不可能的居住世界设定 → 选定的城市拓扑 → 统治城区与从属城区 → 无栏杆的连通基础设施 → 东方巨构建造与局部装饰 → 微小背影仙人与仙衣语法 → 鲜明的材质配色 → 一个有来由的光源 → 分散的体积云与高能见度大气 → 大景深电影级渲染 → 总则与路由的不变量`

按城区和纵深给建筑分组，不要堆一长串无结构的名词。

## 路由自检 { #route-audit }

任一项答「否」就驳回或改写：

- 画面是一个有人居住的世界，而不是一座装饰性地标吗？
- 继承的五层都读得清，并且有 40–60% 有内容空气吗？
- 除了密度之外，还有四项以上尺度证据吗？
- 近、中、远和极远几层都有建筑吗？
- 一个主层级明确占主导，又没有删掉从属城区吗？
- 城区之间看得出连通吗？
- 尺度来自体量、数量、高度、连续性和微小居民的共同作用吗？
- 云在揭示城市，而不是藏住它吗？
- 材质色鲜明，并且和光线调色分得开吗？
- 把人物去掉，城市仍然显得巨大吗？
- 结果一眼是东方的，又没变成历史复原吗？
- 除非用户明确要求，所有边缘都没有栏杆吗？
- 有人物时，背影角度、尺度、平静动作、仙衣和单一风向都写明了吗？
- 目标是繁华压迫时，观者在城市下方或人眼高度，而不是在城市上方吗？
- 任何高机位总览都是用户明确要求的，而不是为了显出尺度推断出来的吗？
