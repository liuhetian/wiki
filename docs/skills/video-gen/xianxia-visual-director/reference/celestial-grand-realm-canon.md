# 仙界大境原典

先套用[共享仙界总则](xianxia-master-rules.md)。把 `仙界大境原典` 当作一条封闭、独立的创作路由：它继承共享的尺度、五层空间、呼吸空间、建筑、栏杆、人物和仙衣规则，再加上更严的云、远景锚点、动态和暖光控制。它不是九图系列模式，也从不强制 `9:16`。

## 路由权限 { #route-authority }

- 只有用户明确说 `仙界大境原典`、`仙界总则`、`仙界原典`，或要求按用户提供的那份天界原典来时，才选这条路由。
- 选中后，在共享总则之后、所有常规的场景、视觉风格、镜头意图、密度、色彩和氛围默认值之前套用本页。别悄悄混进 `单体仙境`、`神域聚居地`、`华彩通透仙侠` 或 `东方苍穹巨构` 的附加规则。
- 画幅那一篇只用来调整阅读方向。通用的构图库只用于不与本原典冲突的技术执行。
- 用户明确追加的要求，只有不破坏本路由的硬不变量时才能扩展它。明确的请求有冲突时，把冲突点出来，不要悄悄换掉原典。

## 世界承诺 { #world-promise }

保持这个阅读顺序和情绪：

`第一眼：无法丈量的天界建筑 → 第二眼：一个完整的远方天域 → 第三眼：一位小小的背影仙人 → 第四眼：一条继续通向看不见的天界的路`

让世界 `空而不寂，满而不塞，巨而不乱，动而不躁，华丽而克制，通透而安静`。

## 继承的硬尺度系统 { #hard-scale-system }

- 主柱直径约等于五到十个成人身高，完整高度约等于四十到八十个成人身高。
- 巨大的开口、玉屏、门洞或结构孔洞约等于二十到五十个成人身高。
- 主屋檐跨越数百个身体宽度，并延续出画。
- 台阶踏步和桥面保持人能用的尺寸，但整段台阶、桥、长廊、屋脊线或平台要穿过云层，汇向一个看似无穷尽的远方。
- 每条提示词都写进至少四项看得见的尺度证据：出画的巨构片段；成人对柱、门洞、屏或台基的比较；向纵深汇聚的重复构件；人物周围十到三十个身长的开阔空间；上下分离的宫殿；跨越云海；近处与远处的巨大形体；或只露出局部的远方巨构。

别用 `宏大`、`史诗` 这类形容词单独取代这些关系。

## 继承的固定五层空间 { #five-layer-space }

画幅变了也要五层齐全：

1. 近景巨型框架：柱、檐、屏、松干、崖壁、门洞边缘，或其他巨大片段。
2. 宽阔的承人界面：平台、台阶、长廊、镜面地、浅水地面，或它们开敞的边缘。
3. 一座统治性的天界巨构。
4. 一到三组更轻淡的从属群组：远方宫阙、桥、平台或建筑片段。
5. 天际终点：巨月、低位天光、天河、银河、低位云海，或无边的晴空。

- 保留约 40–60% 呼吸空间。把它当作有明暗变化、有远方剪影的分层天界空气，而不是空白天空。
- 实体与空气交错。让天空穿进门洞、柱列、屏风、廊道和檐下。
- 近处的形体更重、更锐、更暗、细节更多；远处更轻、更柔、反差更低、更概括，但不变灰。

## 低位云海与局部仙雾 { #low-cloud-sea }

- 主云海保持在建筑平台标高以下。云海顶面必须低于人物脚底和平台边缘。
- 云海主要占画面底部 20–35%，是圆润、厚实、成团的积云体量，地平线低而稳。
- 人物、平台、台基、柱、廊、屏、檐和屋顶全部位于主云层之上。
- 上空和人物周围的空气保持清澈通透。
- 把局部仙雾和云海分开。只允许在基座下方、瀑布旁或选定的远景层之间出现薄、透明、近乎无色的雾。绝不把整座城裹进雾里。

## 受控的天界内容 { #controlled-content }

每张图恰好有：

- 一座统治巨构；
- 一个远景锚点；
- 一个主要动态现象，或一个安静的生命迹象；
- 一个近处的尺度参照；
- 一位或少数几位仙人。

选一到两种相容的远方关系，不列清单：远方巨大宫殿的片段、一座极长的天桥、沿云边退远的殿宇、一道亮着的门阙剪影、一道透明瀑布、一面弧墙、一条天河、月前一只鹤，或彼此分离的浮空平台。

只用一套主要动态：云瀑、透明水瀑、天河、浅水涟漪、风吹的幡或纱、一只鹤、高空水渠，或平台下流过的薄云。让它缓慢、宽阔、合乎重力，并从属于建筑的静。

## 可选世界模块 { #optional-modules }

- **巨月**：每张图可选。选了就用真实的月面：月海、环形山和明暗交界线；约占画面宽度 25–50%；放低、偏离中心、局部裁切，或被建筑分割。
- **迎客古松**：可选，从不自动加。树干直径约一到三个成人身高，树冠横跨二十到四十个身体宽度。让出画的树干或一根长枝去框景，而不是当装饰。
- **地面**：选一种自洽的类型：带克制涟漪的薄透明水膜；无边的巨大镜面平台；浅浮雕白石台阶；抛光的悬浮平台；一条以落水收尾的弧形浅水道；或一片宽阔空旷的玉面。

## 天界建筑 { #heavenly-architecture }

- 用中式空间秩序，但不复原某个具体朝代。
- 把延展的屋檐、巨大柱列、月洞、巨型石屏、廊道、天阶、重檐、云台和悬空门阙重新组合成独有的天界语言。
- 建筑保持巨大、简洁、安静、结构清晰：大片不间断的材质面，很少的组织线，用重复构件表现远，用宽阔的素面表现重。
- 装饰集中在一个局部。用取材于云流、水纹、星轨、月晕、风痕或天穹弧线的大面积浅浮雕；其余表面保持平静。
- 偏向厚重的浅色石材、珍珠灰石材，屋顶和承重顶部用克制的朱红或赭色木构，屋脊用窄的淡金线，上部结构附近可选用矿物宗教色彩。
- 地面、桥、平台、台阶和建筑上不用任何栏杆，除非用户明确推翻本原典。

## 仙人与仙衣 { #immortals-costume }

- 默认一位虚构成人或极少的一小群，看全背影、30–60 度斜后方、侧后方行走，或越肩背影。
- 环境主导的人物默认占画面高度 1–4%。仙人完整剪影必须读清时用 5–8%。只有用户明确要越肩或以服装为主的画面时才用 12–20%，并靠出画的建筑和远方天域保住尺度。
- 动作平静自主：缓步行走、远眺、立在开敞的平台边、登阶、走进弧形长廊、双手放松，或轻轻拢起一只袖子。
- 身体和头发保持稳定，所有布料都响应同一个高空风向。
- 遵循 `衣有骨、纱有气、饰有止、色有主`：两条有韧性的受风长幅从肩、臂或腰伸出；二到四层不等长的后摆落后于动作；一件曳地长袍加一件鲜艳的拖尾外披，可以承担受控的点缀色。

## 光线、色彩与真实感 { #light-color-realism }

- 用宽广、柔和、通透的高空漫射光照亮天域。低位太阳靠近地平线或在画外，只提供轻微的方向、暖黄金色温和极薄的轮廓光。
- 让天空成为一个巨大的柔光源，照在石、玉、木、瓦、水、布料、松、月和云海上。高光温暖细腻，阴影明亮、开放、通透。
- 整体保持午后偏晚的暖意，但不加一层统一的橙色滤镜。浅色石材、珍珠灰、朱红或赭色木构、淡金、晴空和服装点缀色之间保持材质分离。
- 用大画幅建筑摄影和实景片场的真实感：石的重量、暖玉的透光、清晰的木构和屋顶构造、真实的树皮、水的表面张力、连续的水流和云流、积云的体积、布料的垂坠与透光、真实的月面细节、可信的人体比例。

## 画幅适配 { #ratio-adaptation }

- `16:9` 和 `21:9`：屋檐、长廊、云边和远景锚点横向展开，五层保留。
- `4:3` 和 `3:2`：统治结构与宽阔平台、清晰的天际终点相互平衡。
- `4:5` 和 `9:16`：五层竖向叠放，用台阶、柱、瀑布、月弧或高处的开口维持向上的阅读路径。
- 绝不从 `9:16` 推断出系列、拼贴或多图输出。一次请求出一条提示词，除非用户明确要几条。
- 默认低机位或人眼高度。只有用户明确要求时才用高机位或航拍视角；绝不只为了多露出建筑而用它。

## 提示词组装与必过自检 { #prompt-assembly-audit }

按这个顺序组装：

`画幅 → 机位高度、距离、倾角、焦段 → 统治结构 → 四项以上尺度证据 → 固定五层空间 → 40–60% 呼吸空气 → 一个远景锚点 → 低位云海 → 一个主要动态 → 无栏杆的建筑与地面 → 仙人与仙衣 → 宽广温暖的漫射光 → 物理材质 → 不变量与排除项`

输出前，每一项都要答「是」：

- 路由明确标为 `仙界大境原典`，并保持独立了吗？
- 保留了用户要的画幅，没有任何九图假设吗？
- 有四项以上看得见的尺度证据，并带可测量的人体比较吗？
- 五层都分配了、读得清吗？
- 40–60% 呼吸空间填的是分层空气，而不是空白吗？
- 主云海在平台以下，主要位于底部 20–35% 吗？
- 远方宫殿数量有限、更轻、更柔，密度不像城市吗？
- 恰好一座统治结构、一个远景锚点、一个主要动态或生命迹象吗？
- 所有栏杆都没有吗？
- 人物尺度、背影角度、仙衣和风向都写明了吗？
- 光线宽广、温暖、柔和、通透，而不是硬、灰或全局橙色吗？
- 材质和透视物理可信吗？

任一项答「否」，改完再回复。不要拿泛泛的宫殿城市、密集的屋顶毯子、孤立的亭子、灰雾全景、硬朗的金色逆光、装饰过度的历史宫殿或自动套用的巨构压迫构图来顶替。
