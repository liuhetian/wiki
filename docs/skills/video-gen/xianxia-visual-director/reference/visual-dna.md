# 仙侠电影视觉 DNA

把这些原则当作可迁移的视觉语言，置于[仙侠总则](xianxia-master-rules.md)之下。总则里的尺度、五层空间、呼吸空气、建筑、栏杆、人物与仙衣规则在每条路由都是强制的，本篇不得削弱它们。不要把任何单一题材或配色当成必选项。

## 核心特征 { #core-identity }

1. **有可见证据的巨物空间**：让建筑、山、水、天空或云占主导。用不连续的尺度层级、部分出画的结构、负空间和克制的人物尺度证明体量。
2. **一种决定性的空间几何**：通过消失点、对称轴、对角线、曲线、框景或垂直上升，让视线立刻读懂纵深路径。
3. **东方营造逻辑**：用可信的梁、斗拱、屋顶、柱、开敞台地、桥、阶、庭院或园林关系。除非用户明确要求，边缘不设栏杆。结构清楚之后再加装饰。
4. **明亮的选择性色彩**：画面明亮、色彩分离，最高纯度局部化。保留接近中性的浅色材质、冷而透明的阴影和干净的高光，不要灰雾、全局橙色溢光或死黑。
5. **有动机的电影光**：建立可信的光源、方向、边缘反应和大气效果。逆光和光斑有选择地用。
6. **层叠的空气**：建出前景、中景、背景和极远景，对比逐层变柔、明度逐层变亮，同时保留可辨认的剪影。
7. **材质的具体性**：通过可见的表面表现区分玉、石、漆、木、青铜、玻璃、水、丝、云、植物和鎏金。
8. **梦境般的合理**：世界可以浮空或违背重力，但透视、光、构造、反射和尺度必须内部自洽。
9. **观者从属的机位**：宏大意味着压迫或神圣权威时，让观者处在人的高度或低于建筑。用距离和焦段把世界纳入画面；不要只为多拍一点就飞到它上方。

## 可变的场景家族 { #scene-families }

- 天界建筑：天宫、悬空藏经阁、观星台、祭台、天门。
- 有人居住的天域：云上都城、九重天聚落、浮空大陆宫城、相连的神岛文明、云崖都市。
- 山水：浮空山峰、镜湖、崖上圣所、瀑布峡谷、云海港湾。
- 园林幻境：桃花岛、发光的莲庭、古松平台、紫藤桥。
- 旅途空间：天阶、长桥、山口、悬空堤道、空中渡船。
- 神圣地标：月环、巨钟、天界仪器、古树、雕刻的门、鹤像。

## 避免重复套路 { #avoid-repetition }

不要用白玉、朱红柱、蓝天、圆形月洞门、云的倒影和三名女性人物的反复组合来定义这种风格。保留空间的宏大、明亮的色彩、电影光、精致的材质和空气纵深，同时更换具体模块。

## 视觉处理家族 { #treatments }

- `华彩通透仙侠`：强调明亮的材质色、精细的装饰、优雅的建筑、干净的云和清晰呈现的风景世界。
- `东方苍穹巨构`：强调单一空间事件、被裁切的神圣建筑、门槛揭示、不连续的尺度、克制的高明度色彩、孤独的人物和低角度侧光 / 逆光。使用前先读它的专篇 [东方苍穹巨构](eastern-sky-megastructure-style.md)。

不要把视觉处理和场景尺度混为一谈。两种处理都能用于单一地标，也都能用于有人居住的天域。

## 尺度语法 { #scale-grammar }

- 每种强度都用总则的五层空间、四项或以上可测量尺度证据和 40–60% 有内容空气来建。
- `辽阔`：让层叠的空气、水、云隙或开放庭院占主导，同时统治结构仍保有可测量的神级尺度。
- `史诗级`：加强近景巨型框架、小小的成年人、统治结构、从属天域和天际终点之间的不连续对比。
- `超宏大`：让一个巨型元素延伸出画布或穿越云层，同时保留同样的五层基线。
- 用大尺度的前景树、崖、柱、门缘或屋檐去揭示远方世界，而不是遮住它。
- 不要把所有建筑和人物放在同一个视觉平面上。
- 有人居住的天域：用连续的城市延展、多个相连城区、高低错落的天际线、可测量的人物对比和五层都有建筑来证明尺度。把 40–60% 的空气保留在城区之间、下方、后方和内部；不要缩成一个地标加一片空云，也不要用屋顶地毯抹掉呼吸空间。
- `繁华压迫`：在微小人物和统治巨构之间放置密集的次级建筑。繁华来自重叠、重复、动线和有人生活的细节，主体巨构则升起于城市之上或悬压在城市上方。

## 推荐的色彩措辞 { #color-language }

可用的措辞：

- `高明度、选择性高纯度、饱满但克制`
- `色块清楚，冷暖关系明确`
- `阴影保持透明的蓝灰、青灰或紫灰`
- `亮部通透，材质高光干净`
- `rich but elegant chroma`
- `luminous saturated colors`
- `clean color separation`
- `no gray veil or muddy grading`
- `no global orange-gold cast`
- `near-neutral jade and cloud highlights`

不要只靠 `高饱和` 一个词。把饱和度和面积预算、明度层级、中性锚点、阴影颜色、材质真实感配在一起写。除非用户明确选了 `华丽高饱和`，高饱和是一种点缀策略。
