# 东方苍穹巨构

把 `东方苍穹巨构` 当作一种视觉处理，不当作场景类别。先套用[共享仙界总则](xianxia-master-rules.md)，再加上裁切、门槛揭示和尺度断裂，不得削弱继承来的五层空间、40–60% 有内容空气、东方巨构语言、无栏杆边缘和仙衣。它既能用于 `单体仙境`，也能用于 `神域聚居地`。

## 继承总则 { #master-inheritance }

- 把固定五层空间对应为：近景巨型框架或门槛；站着微小背影仙人的承人界面；被裁切的统治巨构事件；更轻淡的从属天域；天际终点 —— 天空、月亮、云海、更高的天界或极远聚落。
- 写进四项以上尺度证据。光靠裁切证明不了尺寸，要补上成人对柱、门洞、桥、平台、墙、树、崖壁或远方天域的比较。
- 在事件内部和周围保留 40–60% 有内容空气：门洞、开放庭院、基座下的虚空、云隙、水面、天空和远方。别把一整片实心的灰当成呼吸空间。
- 所有门槛、平台、桥、台阶、长廊和建筑边缘都不加栏杆，除非用户明确要求。
- 有人物时，保持约 1–4% 画面高度，背影或斜后方，动作平静，穿结构化仙衣，只有一个风向。

## 核心处理 { #core-treatment }

- 建立一个主导的**空间事件**，而不是一座完整可见的地标。例如：悬挑天门下的城市、一座桥伸进不可抵达的宫殿、一道瀑布劈开云上都城、透过圆形门槛露出的神域。
- 把巨构呈现为片段、底面、墙体、门洞、巨大平台、被裁切的屋顶体块、垂直基座或远方的建筑天际线，让它至少越过一条画框边出画。
- 有意遮挡、用门槛取景。让屋檐、门洞、崖壁、古松、柱列、开敞的暗色平台或云隙把世界揭示出来。
- 让尺度在继承的五层之间断裂式跳变：近景巨型框架 → 承人门槛与微小成人 → 统治性巨构事件 → 从属天域 → 天际终点。
- 保持内部物理可信，同时允许不可能的悬浮、倒置的重量、云上基座、天空瀑布，以及取代地平线的建筑。

## 构图库 { #composition-library }

选一个主导的事件几何，在衍生方向里轮换。

- **压天悬挑**：被裁切的天门、宫殿底面或巨大平台占据画面上部，下方是城市或云海。
- **门槛揭示**：背光的门洞、开敞平台、崖边或柱列向外打开，外面是亮得多、无法抵达的天域。
- **画中之孔**：月环、门洞、拱券、成对的屋檐或松与崖之间的缺口，把远方主体框在里面。
- **桥入不可知**：一座窄桥或云阶从微小人物身边起步，消失在云、光或巨大宫殿的基座里。
- **垂直断裂**：瀑布、光柱、悬垂基座或天河，竖着劈穿城市、云层和虚空。
- **底面揭城**：巨大的上部结构悬浮在一片连绵的从属屋顶与庭院之上。
- **建筑切片**：近景或中景拍一段巨墙、雕刻石板、基座、柱列或局部屋顶系统，暗示更大的整体。

别自动重复月环或居中的桥。按场景承诺挑几何。

## 尺度与取景门槛 { #scale-framing-gate }

史诗级或超宏大的输出，要求：

1. 一座主结构被裁切、被遮挡，或延伸出画。
2. 成人尺度参照一般约占画面高度 1–3%；只有用户明确要求读清完整剪影时才用 5–8%，并保留背影角度和仙衣语法。
3. 继承的五层齐全，至少四项尺度证据，其中包含一项直接的、不可能的比较。
4. 前景有一个无栏杆的门槛或承人界面，它揭示主事件，而不是挡住它。
5. 有从属天域和读得清的天际终点，不是一片空雾。
6. 约 40–60% 有内容的云、虚空、天空、水面、开口、庭院或远方，用来交代悬浮和高度，又不把建筑缩成孤立的物件。

巨构大约可以占画面的三分之一到三分之二；如果更狠的裁切或揭示更能服务事件，别拘泥固定比例。

## 机位 { #camera }

- 默认让观者处于从属位置：远距离低机位或人眼高度，平视到略微仰视。不默认鸟瞰、航拍、高机位或顶视。
- 画面既要密集宫城的繁华、又要背后或上方压着一座巨构时，优先用远距离低机位 + 70–100mm。让屋脊线、平台、云层和主体块压缩成一堵厚重的、层层叠叠的文明之墙。
- 桥的引道、低视点、柱列、门和底面揭示用 24–32mm 直线广角。机位离得够远，层级才读得清。
- 人眼高度的门洞、平台、室内和可信的建筑片段用 35–50mm。
- 默认大景深，垂直线受控。靠大气、遮叠和反差阶梯分开各层，不靠焦外虚化。
- 机位保持足够距离，让广角透视揭示空间层级，而不是把最近的表面拉成无意义的畸变。
- 只有用户明确要求看清城市的地理布局时才用高机位总览。不能只因为场景里有云、浮岛或很多建筑就选它。

`繁华压迫` 的画面：地平线压在下三分之一附近，微小人物和观景门槛沿画面下缘放，密集的次级城区在中部压缩排开，被裁切的主巨构统治中部和上部。观者应该觉得自己在结构下方或前方，永远不在它上方。

## 高明度克制配色 { #high-key-color }

先用明度和冷暖制造通透，再提饱和度：

- 约 65–80% 画面是浅色石材、云白、柔和的玉色、蓝灰天空、冷色水面，或其他中低纯度的明亮底色。
- 约 15–25% 用中等纯度：石板蓝、矿物绿、深色木构、压低的朱红、风化青铜。
- 最强的暖色只留给约 3–8% 的受光屋檐边、漆面点缀、衣物、幡旗或金属反光，除非用户明确要更多。
- 场景保持高明度，色彩分离干净。低纯度绝不能变成脏灰、米色雾或死气沉沉的调色。
- 用户明确要高饱和时照做：有选择地放大材质色彩，同时保留大面积中性的天空、云、石、水或阴影做稳定。

## 光线与大气 { #light-atmosphere }

- 偏向侧面或后方的低位太阳，多在清晨或傍晚，高光是暖象牙、淡杏或克制的金。
- 用高空冷色天光做环境补光；阴影保持通透的青灰、石板蓝、蓝绿或紫灰。
- 让局部薄雾在门槛、瀑布、基座和云边散射光线。绝不铺一层均匀的雾幕。
- 高光柔和过渡，材质边缘的受光反应看得见。别让白云过曝、建筑底面死黑。
- 默认不加镜头光斑；只有能强化门槛事件时，才允许一处微弱、有光学依据的光斑。

## 材质方向 { #material-direction }

偏向厚重的浅色石材、风化玉、崖壁般雕凿的基座、哑光矿物表面、克制的漆木、深色青铜、窄的鎏金边、水和厚实的体积云。在最大的体块上减少装饰种类；把精细的中式细节放在门槛、屋脊线、门、柱础和人尺度的表面上，让结构读起来是建筑，而不是抽象的混凝土。

## 提示词顺序 { #prompt-order }

按这个顺序组装：

`画幅与机位 → 继承的可测量尺度证据 → 固定五层空间与 40–60% 有内容空气 → 场景路由 → 主导空间事件 → 裁切或遮挡 → 无栏杆的人尺度门槛 → 东方巨构建造与局部细节 → 背影仙人与仙衣语法 → 高明度克制配色 → 低位侧逆光 → 局部大气散射 → 大景深电影级材质渲染 → 总则与路由的不变量`

## 自检 { #audit }

任一项答「否」就改：

- 焦点想法是一个空间事件，而不是一份物件清单吗？
- 继承的五层都读得清，并且有 40–60% 有内容空气吗？
- 除了裁切之外，还有四项以上尺度证据吗？
- 至少有一座结构让人觉得比画框还大吗？
- 门槛、遮挡和尺度参照是有意地在揭示世界吗？
- 人物小到只是证据、而不是主角吗？
- 有人物时，背影角度、平静动作、结构化仙衣和单一风向都写明了吗？
- 画面通透，而不是靠处处高饱和吗？
- 暖色高光是局部的、冷色阴影是通透的吗？
- 薄雾在塑造纵深，而没有藏住建筑吗？
- 结果一眼是东方的，同时不像历史复原、欧洲城堡、现代巨型都市或科幻混凝土巨石吗？
- 机位始终从属于巨构，任何高机位总览都是用户明确要求的吗？
- 除非用户明确要求，所有边缘都没有栏杆吗？

避免：完整可见的宫殿居中摆在空云里，默认鸟瞰或航拍的城市视角，主题公园式的大片红金，每个巨大表面都铺满细碎雕饰，盖章般一模一样的屋顶，浑浊的蓝灰调色，不透明的雾，死黑的前景，鱼眼畸变，多个同等分量的奇观，以及缺少巨构证据的小巧画意亭子。
