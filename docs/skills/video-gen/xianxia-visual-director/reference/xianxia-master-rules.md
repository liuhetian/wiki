# 仙侠总则

创作、衍生、优化、诊断、多版本、直接出图，每个任务都读这一篇。这是 `单体仙境`、`神域聚居地`、`华彩通透仙侠`、`东方苍穹巨构`、`仙界大境原典` 共用的世界与设计规则。

各路由的 reference 可以通过场景拓扑、密度、构图、配色、光线或氛围扩展这些规则，**不得削弱、替换或与之矛盾**。只有用户的明确指令能覆盖某一条具名总则；未被覆盖的规则全部保留。

## 可测量的巨物尺度 { #scale }

- 用可见的人物对比证明尺度，不能只靠形容词。
- 每条完整提示词至少包含四项可读的尺度证据：出画的巨型片段；成人与柱、门、开口、屏、基座、树、崖或桥的对比；重复构件向纵深汇聚；人物周围十到三十个身长的开阔空间；垂直分离的建筑；跨越云海；近处与远处的巨型形体；或极远的天域。
- 有主柱时，柱径约为五到十个成人身高，完整柱高约为四十到八十个成人身高。
- 有主开口、门、屏、门户或孔洞时，尺寸约为二十到五十个成人身高。
- 由主屋檐、桥、廊、阶、平台、树冠、崖面或城市轴线承担尺度时，让它跨越数百个身体宽度、穿过云层或延伸出画。
- 有人居住的天域，把同一套尺度语法映射到一个统治城区、微小的居民、从属城区、连接性基础设施，以及一处极远聚落或更高一重天。数量密集不能替代可测量的对比。

## 固定五层空间 { #five-layers }

在每种支持的画幅、每条路由里都建齐五层：

1. 近景巨型框架或门槛：柱、檐、屏、松、崖、门缘、桥头、台缘或同等物。
2. 宽阔的承人界面或有人活动的门槛：平台、台阶、长廊、桥、街道、庭院、云港、镜面地面或开放边缘。
3. 一个统治主体：单一地标、主宫阙城区、城冠、神圣轴线，或一处被裁切的巨构事件。
4. 一组或多组更轻的从属群组：远方宫阙、次级城区、桥、平台、建筑片段、山峦或浮岛，组织在统治主体之下。
5. 天际终点：极远聚落、更高一重天、巨月、低空天光、天河、低位云海或无垠晴空。

- `单体仙境`：第 3 层保持为一个局部锚点，第 4 层克制。
- `神域聚居地`：第 4 层可以容纳相互连接的从属城区，但不与第 3 层争夺主次。
- `东方苍穹巨构`：第 3 层可以是被裁切或遮挡的空间事件，不必是一个完整可见的物体。
- 不得把五层压成扁平的前景 / 背景二分、空云里的单个物体，或没有垂直分离的屋顶地毯。

## 有内容的呼吸空间 { #breathing-space }

- 每条路由都保留约 40–60% 的有内容呼吸空间。它可以由层叠的天空、云隙、水面、开放庭院、门洞里的空气、檐下空间、浮空城区之间的虚空、远方天光或通透大气构成。
- 呼吸空间是空间信息，不是空白画布。给它明度变化、剪影、云缘、桥的穿越、远方建筑或光的过渡。
- 密集的有人天域可以把 40–60% 的空气分布在城区之间、下方、后方和内部，而不是留出一整块空白。密度来自重叠与连续，不来自消灭空气。
- 近处形体更重、更锐、更暗、细节更多；远处更亮、更柔、对比更低、更概括，但不变灰。
- 画面有主云海时，除非用户明确要求置身云中，否则把它放在人物和承人界面之下。用局部薄雾分隔层次；不得给整个天域罩上一层灰纱。

## 天界建筑语言 { #architecture }

- 用中国的空间秩序，但不复原某个具体朝代。把挑出的屋檐、巨柱阵、大开口、巨屏、长廊、天阶、叠落屋顶、云台、悬空门阙、园林和桥重组成独一无二的天界语言。
- 让最大的建筑巨大、简洁、安静、结构清晰：大面积不间断的材质平面、少量组织线、用于表现纵深的重复构件、用于表现分量的宽阔平静表面。
- 精细装饰集中在一到两个人能读清的区域。大面积浅浮雕取材于云流、水纹、星轨、月晕、风痕、山形或天穹弧线。不要把同等密度的细丝纹样铺满每一块巨大表面。
- 即使世界浮空或违背重力，也保持可信的传力路径、梁柱关系、平台厚度、桥的支承、屋顶构造、材料重量和透视。
- 偏好厚重的浅色石材、珍珠灰石、风化的玉、克制的朱红或赭色木构、暗青铜、矿物青绿、窄窄的淡金边、真实的水和体积云。路由可以换配色，但不能改变结构的平静和材料的可信度。

## 栏杆 { #railing }

- 地面、平台、台阶、桥、长廊、台地、云港和建筑上默认不用任何栏杆、栏板、围栏、女儿墙、护栏或装饰性边缘隔挡。
- 边缘保持开放、宏伟。用铺装、高差、柱列、光、水、植物或结构节奏来界定动线，不用栏杆。
- **只有用户明确要求时才加栏杆**。路由、示例、历史参照、安全考虑或熟悉的构图都不得自动引入栏杆。

## 仙人与仙衣 { #immortals }

- 画面有人时，默认是虚构的成年人，以完全背影、30–60 度斜后方、侧后方行走或越肩后视出现。不要把尺度参照变成正面肖像。
- 以环境为主的人物约占画面高度 1–4%。需要读清完整剪影时用 5–8%。只有用户明确要求越肩视角或以服装为主的画面时才用 12–20%，同时用出画的建筑和完整的远方天域维持尺度。
- 给人物平静、自主的动作：缓步行走、远眺、登阶、步入长廊、过桥或立于开放边缘。构图允许时，主要尺度参照人物周围保留十到三十个身长的开阔空间。
- 遵循 `衣有骨、纱有气、饰有止、色有主`：有韧性、能兜风的长幅从肩、臂或腰伸出；二到四条不等长的后摆滞后于动作；一件曳地长袍加一件受控的拖尾披风、纱幔或外层可以承担点缀色。
- 写明一个风向。身体和头发保持稳定，头发、衣袖、下摆、披风和纱幔一致地顺着同一风向。把服装当作材质证据，不当作装饰性的混乱。

## 总则继承自检 { #audit }

回复前逐条确认，每条都必须是「是」：

- 是否有四项或以上可见的可测量尺度证据？
- 五层是否都已指派且能读清？
- 40–60% 的呼吸空间是否有内容，而不是空白或被密度抹掉？
- 建筑是否依然巨大、平静、结构清晰，并且一眼认得出是东方的？
- 除非用户明确要求，是否所有栏杆都不存在？
- 有人物时，尺度、背影角度、平静动作、仙衣结构和单一风向是否都已写明？
- 路由附加的内容是否只扩展这些规则而没有与之矛盾？

任何一条为「否」，先修改再输出。
