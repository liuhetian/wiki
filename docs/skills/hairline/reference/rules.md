# 十条规则

每条写三样：它说什么，用引擎怎么守住，什么样的图形会被打回。

## 01 · hit：命中区不动

拿指针去比静止姿态或目标姿态，绝不比屏上此刻的姿态。否则几何体会从指针底下升走，悬停丢了，几何体落回来，悬停又回来：一个闪烁的死循环。

- **守住：** `unproj(C, sx, sy, 0)` 把指针放到永远不动的地平面上；按世界坐标挑选（Terrain）。对条目，沿它们静止时的边测试固定的条带（Riffle）。选择取决于一个在动的值时，读弹簧的目标（`.t`），不读它的位置（`.x`）。
- **守住，当部件站在不同高度、或被选中时会升起：** 一个固定平面不够。指针落在一个升起的顶面上时，会落到那个部件后面的平面上；在高度不同的部件之间，它谁也找不到。改为测试每个部件的静止姿态，像 Riffle 的条带那样。单排时，取静止中心 `P(…)[0]` 离指针屏幕 x 最近的部件。阶梯状的部件，把指针 `unproj` 到每个部件自己的静止顶面上（`z` 取它的高度），取让指针离自己中间最近的那个部件。
- **打回：** 指针停在一条运动的边上时图形来回振荡；挑选读的是弹簧当前值；一个固定平面挑中了升起部件后面的那个，或在高度不同的部件之间读到 `rest`；图形测量 DOM（`getBoundingClientRect`、`elementFromPoint`、`:hover`）或者自己加指针监听器。

## 02 · order：按距离错开

`delay = |i − a| × step`。动作从指针向外扩散，而不是沿着列表一个个跑下去。

- **守住：** `tset(tween, target, now, Math.abs(i - a) * step)`，step 取 30–60ms，读起来才是一个手势。
- **打回：** 不管碰的是哪个，条目都按索引顺序动；概念是扩散时却全部同时动；step 太长，最后一个条目在第一个落定之后才开始，手势读起来像排队。

## 03 · reach：限住范围

反应有远端，图形到了远端仍然是构好的图。

- **守住：** 衰减到一个下限就停（Terrain 的是：1 → 半径 42% 处 .31 → 更远 .09）；每个抬升、间隙和倾斜都 `clamp`；相机按最极端的姿态取景（`fit` 时带上抬起后的点），intensity 为 1 时也没有东西出 400 × 320 的画框。
- **打回：** 滑块到远端时图形散架、自己压自己或出框；一个没限住的值无止境地跟着指针走。

## 04 · accent：笔画是唯一的高亮

不用填充、辉光、阴影。活动的那条边从轮廓的笔画换成亮的那种，别的什么都不变色，颜色读起来才是信息。

- **守住：** `el.sil.classList.toggle("hi", active)`。点在 `dot`、`dot m` 和 `dot off` 之间切换。整个调色板就这些。静止时，一个亮标记说明眼睛该从哪里看起。指针做出选择时，亮给到它选的那个，静止标记把亮让出去。一个高亮可以覆盖同一样东西的几个部分 —— 托盘的边和它的珠子、一座沙丘的顶 —— 但它标一个地方、表一个意思。
- **打回：** 图形自己设任何颜色、填充、透明度花招、渐变、滤镜、阴影或笔画宽度；同时有两处亮；指针选了之后静止标记还在旁边亮着；亮被拿来当装饰。

## 05 · rest：静止姿态要设计，绝不平铺

指针离开后图形回到一个构图：一座沙丘、一个倾斜、一点点炸开。静止的那一帧就是缩略图，所以它得自己站得住。

- **守住：** 给每个部件一个不为零、也不整齐划一的静止值（Terrain 的沙丘是两个高斯；Riffle 的卡片往后仰 12°）。静止时在眼睛该看起的地方放一个亮标记。指针做出选择时，标记把亮让给它选的那个（规则 04）。
- **守住，当空就是概念：** 空状态画的是一个什么都没装的物件。物件本身构好了、不均匀、完整，再有一个亮标记说明看哪里，这样才对。托盘是空的；画不是空的。
- **打回：** 静止时图形是平铺的网格、一个因为什么都没画而空着的托盘、一排完全规整的东西；静止时什么都没说明图形讲的是什么；静止和「还没渲染出来」看起来一样。

## 06 · honesty：构造诚实

板是不透明的，填地面色。辅助线和虚线画在它们所属的板后面，所以画里绝不会露出不该露的线。

- **守住：** 从后往前追加（Terrain 从远角起一条对角线一条对角线地走它的网格）；必须遮住身后东西的形状保留填充（不加 `nf`）；辅助线用 `dash`，在它所属的板之前追加。深度顺序变了时移动组（`a.after(b)`），不要重画。
- **打回：** 远处的一条边透过近处的实体露出来；绘制顺序就是代码碰巧造出它们的顺序；一条虚线辅助线穿过它所属那块板的正面。

## 07 · cost：离屏就睡

只有环境动画在没有输入时运行，而且只在可见时运行。

- **守住：** 所有运动都发生在 `register(stage, tick)` 里。只有还有东西在动时，`tick` 才返回 `true`；有输入后调 `wake()`。每个图形都稳住后循环就停，离屏时睡，减弱动效时弹簧和补间立即落定。
- **打回：** 图形有自己的定时器、`requestAnimationFrame` 或 CSS 动画；不是环境动画的图形里 `tick` 永远返回 `true`；一条路径在它的值没变的帧上被重写（记下上次画的值，相同就跳过）。

## 08 · clock：两种时钟

离散的变化（哪一个）用一个长的缓出：`(.32, .72, 0, 1)` 上 700ms。连续的输入（指针在哪）用弹簧，`k 100 · c 18 · m 1`，因为它的目标每帧都在动，定时的缓动永远在追它。

- **守住：** 「哪一个」用 `tween` / `tset` / `tval`；「在哪」用 `spring` / `stepS`。用默认值，除非图形有你说得出的理由。
- **打回：** 用补间去跟指针的位置；用弹簧去动画条目之间的选择；时长或弹簧常数是编的；任何东西是线性的。

## 09 · radius：每个角都倒圆，然后少画

一个实体是两个圆角环（顶和底）的凸包。竖直的角从来不画。顶边变成轮廓里面一两个单位处的一道暗折痕。外亮内暗：这个层次就是大部分的精致感。

- **守住：** `rings(x0, y0, x1, y1, r, b)`，然后 `prism(P, front, ring, inner, z0, z1)`，用 `put` 写进 `solid(parent)`。薄板给它的厚度加第二条线，而不是第二个实体。平面轮廓用 `fillet` 倒圆。`rings` 每个角走四步，所以一个完整的圆有十六条边，屏上半径超过大约 20 个 viewBox 单位（r × S；S 为 1.9 时 r 12）时就看得出边。大的圆要自己用更多步数造两个环：`rrect(x0, y0, x1, y1, r, 14)` 和 `rrect(x0 + b, y0 + b, x1 - b, y1 - b, r - b, 14)`。
- **守住，当实体的顶比脚小**（一个车厢、一个屋顶、一座收窄的塔）：`prism` 把一个环笔直立起来，所以要你自己用两个环写它的两串路径。`foot`、`top` 和 `inner` 各是一个 `rrect`，`inner` 是 `top` 内缩 b：轮廓是 `poly(hull(ringAt(P, foot, z0).concat(ringAt(P, top, z1))))`，折痕是 `open(ringAt(P, run(inner, front), z1))`。然后 `put(solid(parent), { sil, crease })`，和 `prism` 一样。`prism` 做的就这些，所以不用去翻索引下面的代码。
- **守住，对标志：** 倒圆会让一个标志变成另一个标志的地方，它保留自己的角。用仍然读得出是搭出来的最小半径，半个单位到两个单位；不是标志的部分照常倒圆。
- **打回：** 盒子露出十二条棱或任何一条竖直的角线；有尖角；里面的线和轮廓一样亮；一个实体除了轮廓、一道折痕、最多几个物件真会有的标记之外还有别的。

## 10 · quiet：图里不放字

几何承载身份：卡片标签上的一个冲孔、板条箱盖上的一组点码、用一条亮边代替一个标签。名字放到角上的读数里，在画的外面。任何装饰都得是这个物件真会有的东西。

- **守住：** `read.textContent = …` 用几个字符说出指针下面是什么（`cell 4·2`、`08`），什么都没有时说 `rest`。给东西编号用点。
- **守住，对从标志做的图形：** 标志给别的东西当标签时不放。唯一的例外是从标志做的图形，标志就是物件本身：搭成实体，回应指针。属于标志的字形是一个面上的浮雕。这个图形里别的都不是字母，标志的名字仍然放到读数那边，绝不进画里。
- **守住，当一个字形就是主题：** 字形搭成实体、而且是图形的全部主题时，它可以是物件，就像包里的 Query：一个问号，用一根弯杆加一颗松动的球做成，回应指针。它是场景里的一样东西，不是贴在东西上的标签，这个图形里别的都不是字母。
- **打回：** svg 里有文字、字母或画成路径的数字、图标、箭头或徽标 —— 除了从标志做的图形里的标志和属于它的字形，以及搭成实体、作为图形全部主题的那个字形；不看读数就看不懂图形；读数是一句话。

## 画框

不在十条之内，但每个图形都共用它。

- viewBox 是 400 × 320。用 `fit` 把图形放在 (200, 166) 附近居中。
- 相机是 `Cam(45, 0.5, S)`：2:1 视角。改 `S` 来取景；除非相机就是概念，否则别动角度。
- 轮廓必须在 240px 宽时读得出来。超过一百个左右的实体，或者部件小于十个 viewBox 单位，就读不出来了。
- `mount` 不在自身之外保存状态，`destroy` 之后 svg 是空的、也没有任何东西在跑：拆卸逻辑收进 `disposer()`，返回 `bag.dispose`。
- 最多 200 行。更长的图形通常是两个想法。
- tour 是三到六个 viewBox 点，`null` 表示离开。停点选在不同的部件上，按手会够到它们的顺序排，以 `null` 结尾，这一圈才回到静止。
