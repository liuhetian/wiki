# 配图：手绘信息图

**AI 新生成的配图一律画成手绘信息图**：画面中间是一个具体物件，周围用带线的标签把它的结构讲清楚，标签文字直接抄正文。截图、数据图表、历史材料这类有证据作用的图不套这套。

## 拼 prompt { #prompt }

按这个顺序拼：

```text
主题：<一句话说这张图讲什么>。<画面主体：一个具体物件，写清每个部位在哪>
标题写「…」，副标题写「…」。
标签文字照下面原样写，每个标签一行粗体名称加一行小字说明，用线连到对应部位：
- 指向<部位>：「<名称>」，小字「<说明>」
所有标签文字按上面原样写，不增加、不改写其他文字。
<排版片段>
主题色：<色名（English Name）>。
画风：Editorial Doodle / 社论涂鸦：随手黑线、少量点色、人物 + 概念、白底。
```

- **主体是看得见的东西**：场景画成舞台盒子，分层画成叠起来的积木，跨局记忆画成订成册的复盘纸——抽象的方框和箭头读者记不住
- **标签抄正文**：名称就是正文里的叫法，一字不差；技术名可以中英并列，如「伏笔 plot_threads」；一张图不超过 9 个标签
- **画风固定**：全站都用上面最后那行
- **主题色画的时候定**：从[经典主题色](../../../gallery/colors/classic.md)里挑一种，同一篇文章的图用同一种；项目的一个目录算一篇
- **排版按内容的形状挑**，片段原文从[信息图排版](../../../gallery/layouts/infographics.md)抄：

| 内容的形状 | 排版 |
|---|---|
| 一样东西由哪几部分组成 | IG-002 中心主图标注 |
| 拆开看零件 | IG-026 拆解爆炸图 |
| 分几层 | IG-012 分层结构 |
| 按步骤走 | IG-008 流程步骤 |
| 绕一圈回到起点 | IG-019 循环闭环 |
| 有岔路、有回头路 | IG-020 路径地图 |
| 一栋楼里分几层空间 | IG-027 剖面 |

正文和图注不写用了哪个排版、画风、主题色。

## 生成与入库 { #generate }

1. 先把正文里的叫法定下来再画——画完再改一个词，所有图都得返工
2. 一张图一次请求，尺寸 `3:2`；调用照[生成、编辑图片](../../agent-io/reference/image.md)
3. **不检查**：生成完直接入库，不看图、不逐字核对，省 token。用户看到错字再改：先用编辑接口，prompt 写「只修改一处文字：……画面其他所有内容、文字、构图、颜色保持完全不变」，改不好就重新生成
4. 放进文章自己的 `assets/`，文件名 `<讲什么>-infographic.png`；alt 写这张图讲的内容
5. 图在前、文在后：整页的开屏图放在 `# 标题` 之前；讲某一节的图放在这一节的标题下、正文前

活例：[状态别漂移](../../../projects/liyuan/state.md)，开屏图用拆解场景的标注图，场记那一节用循环图。
