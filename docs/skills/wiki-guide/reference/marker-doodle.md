# 配图：白底黑色马克笔草图

概念配图不负责装饰，只负责让一个抽象关系更快被看懂。**AI 新生成的概念图统一画成白底黑色马克笔随手草图，每张图只讲一个概念。** 截图、数据图表、历史材料这类有证据作用的图不套这套风格。

## 视觉规矩

- 媒介 → 黑色马克笔或手机手写笔，不用蜡笔、水彩或铅笔
- 线条 → 实心黑线，粗细略有变化；允许重描、越界、歪斜和接缝不齐
- 造型 → 物体压成基础几何形，只留最关键的识别特征
- 构图 → 横版 3:2，主体居中，占画面约 60–70%，四周大量留白
- 色彩 → 纯黑线、纯白背景，不填色，不画阴影、灰阶或排线
- 气质 → 像不擅长画画的人临时拿笔解释概念 —— 直接、笨拙、未经修饰
- 信息量 → 一张图只讲一个概念，不放文字、标签、数字、箭头或装饰
- 避免 → 工整图标感、儿童绘本感、毛茸茸的蜡笔颗粒、刻意卖萌、专业插画质感

## 生成与入库

1. 先列清文章里真正需要画的概念 —— 能用一句话说清的才画；一句话里有两个关系就拆成两张
2. 每个概念单独生成，不让模型在一张画布里拼多张图或多个分镜
3. 逐张检查纯白背景、纯黑线、无文字、无阴影、主体比例和留白；不合格只改一个最明显的问题再生成
4. 图放进文章自己的 `assets/`，文件名用语义化 kebab-case，如 `random-sample-marker-doodle.png`
5. 相对路径引用，alt text 写这张图解释的概念，不写「马克笔」这类视觉描述：

    ```markdown
    ![从同一总体反复抽样，会得到略有不同的样本](assets/repeated-samples-marker-doodle.png)
    ```

活例：[抽样：检验之前，先把样本抽对](../../../notes/statistics/sampling/index.md)用四张图分别讲随机抽取、重复抽样、分层抽样和抽样框遗漏；[用西瓜搞懂准确率、精确率和召回率](../../../notes/machine-learning/classification-metrics/index.md)。
