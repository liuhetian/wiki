# 长文配图

给一篇长文规划插图：在哪插、每张图干什么、用哪个版式、prompt 怎么写，出图后再把图回填进文章，交一份图文定稿。画风和主题色的挑法、画风片段怎么展开，照[上级入口](../index.md#activation)；版式怎么用，照[出图提示词](../prompter.md#layouts)。

## 先判断文章类型 { #mode }

规划之前先定体裁，两类文章的做法完全不同。

### 知识类：降低理解负担 { #knowledge }

干货、教程、实操类文章最难读的是冗长的机制推演、层级漏斗、公式算法和多分支逻辑。配图的任务是帮读者理解：用图替掉繁冗的文字，但知识一点不能少。四条红线：

- **不要实物摆拍和微缩场景**：prompt 里不写微缩摄影、木质书桌、做旧白板黑板、咖啡杯、钢笔、放大镜、书本、杂物堆叠、大光圈虚化。实物环境和景深会吃掉 30%–40% 的画面，图表被压小，手机上满是噪点。画面只放图表，纯净留白或浅色纯色背景
- **不要和内容无关的角色**：不放小精灵、魔法棒、引路玩偶、小向导、花草动物这类装饰。知识图解的主角是几何流向、信息卡片、核心数据、步骤标签和结构
- **不删核心知识**：替换文字是为了好读，不是把干货删了换一张空泛的大图。这四样绝对不能删 —— 数学公式和权重（比如小红书 CES 评分：点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8）、量化阈值和判断标准（CTR > 8%、曝光 < 200、完播率 < 15%）、关键台词和话术模板、法律合规和平台禁忌。图里要把公式、权重、阈值直接画成标签；替换后留在正文里的精炼导读也要保留核心结论和数字（用公式块或极简清单）。只看图或只看字，都不能断档
- **要真的图形化**：图能降负担，是因为用空间和形状代替了文字推导，不是画几个方块把字抄一遍：
    - 层级跃迁、池子晋级 → 上升阶梯、金字塔（IG-010 阶段等级进阶、IG-001 标题金字塔图标）
    - 数据流失、筛选转化 → 逐层收窄的漏斗（IG-013 漏斗转化型）
    - 权重对比、方案取舍 → 天平、杠杆、双列对照（IG-004 双列多行对比）
    - 界面结构、系统拆解 → 中心主图加标注（IG-002 中心主图标注）
    - 多分支排错、SOP → 决策流转树（IG-008 多路径流程步骤图）
    - 心理锚定对比 → 三列高低梯形、视线焦点引导

知识类配图一定从版式库里挑，尤其是 36 种信息图（IG）和 23 种社媒卡（SC）：继承版式的构图指令（纯色背景、舒适留白、几何结构），再填入主题、步骤标签、画风和主题色。画风挑干净清爽、线条和块面分明、利于传达信息的，比如 FA-018 Minimal Deadpan Dialogue Cartoon、FC-029 Clean Airy Flat Vector Illustration，不推荐儿童童话风和抽象乱涂；主题色挑稳重专业的，比如 C-01 克莱因蓝、C-03 普鲁士蓝、C-10 鼠尾草绿、C-29 赭石、C-31 佩恩灰。

**间距**：相邻两张图之间至少隔 400–500 字，而且至少跨过一个完整的二级或三级标题，同一小节不连插；超过 2500 字的长文，连续 1000–1200 字以上（或跨过两个以上大章节）不能一张图都没有。把全篇大章节过一遍，底层原理、准备工作、定位和对标、SOP、数据诊断和排错、变现闭环这几类模块都要有图。2000–4000 字配 3–4 张，4000–8000 字配 5–7 张。

**最值得用图替文的七类段落**：

| 段落类型 | 原文特征 | 推荐版式 | 必须保留 | 图怎么画 |
|---|---|---|---|---|
| 算法与加权模型 | 加权公式、权重乘数、多指标计分 | IG-001 或 IG-006 多层标题图标对比 | 公式本身、各项权重数字（×1、×4、×8） | 权重天平或综合金字塔，正文留公式块，图示呈现加权层级 |
| 阶梯跃迁与等级晋级 | 流量池层级、长篇 ASCII 方块图 | IG-010 | 各级曝光区间（200–500、1000–5000）、晋级考核指标 | 向上的阶梯图，把原文的 ASCII 方块整个换掉 |
| 漏斗转化与逐层流失 | 曝光、点击、阅读、互动、转化 | IG-013 | 各层量化标准（CTR > 8%、完播率 < 15%）、对应的优化动作 | 上宽下窄的漏斗，右侧标出断点和优化动作 |
| 界面解剖与系统模块 | 主页五件套、配置隔离、模块拆解 | IG-002 | 核心要素清单、功能定位、避坑要求 | 中间是原型或手机界面轮廓，四周引线标注各模块的要求和雷区 |
| 正反案例与多方案对比 | 爆款和败笔、前后反差、几条商业路径 | IG-004 或 IG-011 前后变化对比 | 对比维度、适用人群、转化路径 | 左右双列分栏，左边低效、右边标杆 |
| SOP 与执行管线 | 多步骤时序、分支排错、四段式脚本 | IG-008 | 关键台词示范、先后顺序、排错分支 | 带图标的横向或 S 形步骤条，节点清楚、箭头可读 |
| 价格锚定与产品矩阵 | 多个 SKU、定价心理、主推款和陪衬款 | IG-007 粗体标题标签小图卡 或 SC-004 上下双格图文分区卡 | 价格数字（19.9 / 35.9 / 59.9）、主力款销量占比（70%）、锚定作用 | 三列并排卡片，中间主力款高亮，箭头标出锚定效应 |

### 叙事类：烘托意境 { #narrative }

抒情散文、叙事故事、随笔、小说：

- 不替换也不删改原文，作者的叙事和文风完整保留
- 画风可以自由些，叙事微距、诗意隐喻、手绘插画都行，重在烘托情绪、营造意境，给阅读节奏留呼吸
- 插在情绪转换、场景切换、时空跨越的地方

## 输入 { #inputs }

- 文章正文，或者本地文章路径
- 画风和主题色：可选。没给就挑一套贯穿全篇，**全篇只用一种画风、一种主题色**
- 画幅：默认 4:3，适合长文的阅读流；移动端社交卡可以 3:4 或 16:9
- 知识类图解一律纯净背景、舒适留白

## 交付什么 { #output }

先给总体决策：

- 文章类型：知识类 / 教程类 / 散文抒情类 / 叙事故事类，用哪种做法
- 全篇统一的视觉：版式基调（IG / SC）、画风编号和名称、主题色编号和名称、统一画幅
- 章节覆盖和间距：列出全篇章节，标出每张图覆盖哪一章，确认最小间距 > 400 字、最大间距 < 1200 字
- 建议配图数：通常 3–6 张，全篇均衡，不断档、不扎堆

再按阅读顺序给每张图：

````markdown
### 插图 N

**插入或替换位置**：`{紧邻的小标题或上下文关键句，10–20 字}`

**配图定位**：这张图在阅读流里起什么作用、怎么承上启下

**版式**：IG-013 漏斗转化型信息图

**图片类型**：流程图 / 概念图 / 对比图 / 信息图

**必须保留**：{这张图要保留的公式、量化指标、关键话术或业务红线}

**图文关系**：替换繁冗文字 / 补充内容 / 视觉停顿

**（替换时）被替掉的原文**：

> {摘录原文里要被这张图替掉并删除的推导、ASCII 图或嵌套列表}

**（替换时）精炼导读**：{替换后留在正文里的 1–3 句要点或行动清单，核心数字和公式一个不少}

**图形隐喻**：{用什么几何隐喻降低理解负担：上宽下窄的漏斗、上升阶梯、对比天平}

**画风与主题色**：FC-029 · Clean Airy Flat Vector Illustration + C-01 · 克莱因蓝

**中文 prompt**：

```text
小红书信息图。排版：{版式 prompt}。纯净背景，大面积舒适留白，严禁桌椅、文具、咖啡杯等任何物理杂物摆设，严禁童话/小精灵角色，图表主体占满画幅90%以上。核心内容：{图形隐喻和标签}。画风：{画风片段}。色彩：{主题色}。画幅比例 4:3。
```

**English prompt**：

```text
Xiaohongshu infographic. Layout: {layout prompt in English}. Clean background with generous negative space, strictly NO physical desks, stationery, coffee cups or props, strictly NO fairy/doll characters, chart fills over 90% of frame. Core content: {visual metaphor and labels}. Style: {style fragment}. Color palette: {theme color}. Aspect ratio: 4:3.
```
````

叙事类文章不套这段信息图 prompt：没有替换那两栏，prompt 照[出图提示词](../prompter.md)写，画风和主题色用全篇统一的那一套。

## 出图和回填 { #assemble }

规划交出去后，告诉用户两条路：

- **自己出图**：复制 prompt 去常用的生图工具，出好后把图发回来或给本地路径，你来替换文字、排好版，交图文定稿
- **全自动**：用户回「全自动生图」「帮我生成所有配图并插入」，就用上级入口说的 agent-io 图片生成逐张画，再回填

回填怎么做：

1. 图片按顺序存成 `<文章目录>/images/illus_01.webp`（或 `.png`），这是这一次实际生成的文件
2. 有「被替掉的原文」的，把那段原文换成图片、一行 `*▲ 图N：说明*` 和精炼导读；换完核对一遍，精炼导读里原文的公式和数字都在
3. 没有替换的，图片插在锚点后面
4. 输出 `{原文件名}_illustrated.md`

这几步可以交给 [`scripts/insert_illustrations.py`](scripts/insert_illustrations.py)，只用 Python 标准库：

```bash
python3 scripts/insert_illustrations.py --article <文章.md> --manifest <清单.json> --output <文章_illustrated.md>
```

清单是一个数组，每张图一项。有 `replace_text` 的先按原文替换（逐行去掉首尾空白再匹配一次），找不到就退回按 `anchor` 插入；锚点也找不到就追加到文末并报警。替换时如果原文里的百分比、公式在精炼导读里全没了，会打印一条保真提醒：

```json
[
  {
    "index": 1,
    "anchor": "### 1. 概念起源",
    "position": "after",
    "image_path": "images/illus_01.webp",
    "caption": "图1：概念起源与核心意象",
    "alt": "插图1：概念起源",
    "replace_text": "{被替掉的原文}",
    "simplified_prose": "{精炼导读}"
  }
]
```

`position` 写 `after` 或 `before`；`alt`、`replace_text`、`simplified_prose` 可以不写。
