# IP 形象设计

给一个品牌或角色做一整套 IP 设计手册：从「这个 IP 为什么存在」到三视图、表情、动作、周边，一共 5 层 18 张标准卡，每张卡一段 prompt。画风和主题色的挑法、画风片段怎么展开，照[入口页](index.md#activation)；有对应版式的卡，版式怎么用照[出图提示词](prompter.md#layouts)。

## 设计原则 { #principles }

- **字少，画面不碎**：prompt 直奔主题，只写主体和关键特征，不堆细碎小物件 —— 字越精炼，主体越明确，大图细节越清楚。单张卡克制：三视图只放三面，表情卡只放 4 个表情，动作卡只放 3 个招牌动作，周边卡只放 1–2 款核心实物
- **只有槽位，不带示例**：不预设任何角色名、道具或剧情，全部按用户给的品牌和角色诉求现生成，免得示例污染 prompt
- **一张卡只管一件事**：卡与卡之间内容不重叠
- **同一个角色**：先出三视图（IP-06），定稿后每张卡都把三视图当参考图垫进去，prompt 里不再重复写外貌 —— 文字描述外貌会漂，垫图才稳。垫图走入口页说的编辑接口；只写 prompt 时提醒用户自己上传三视图

### 每张卡写什么 { #card-details }

- **IP-01 定位卡**：IP 名称（中英）、一句话定位（身份 + 核心价值 + 情绪作用）、3 个核心调性标签、目标受众画像。角色全身主形象居中或偏一侧大图展示，视觉记忆点用小图标注，名称和定位金句大字排版，留白充足，纯色背景，有品牌封面感
- **IP-02 档案卡**：物种形态、体型身高、核心身份或职业、1 个独特的外貌记忆点。标准全身立姿大立绘，侧边 4–5 行精炼档案文字
- **IP-03 性格卡**：内在性格、招牌态度或口头禅。1 个最有性格张力的全身大动作，配 1 个情绪气泡或手写感的态度短句
- **IP-04 世界观场景卡**：栖息环境的名称、世界的生存机制或日常任务。沉浸式的环境大场景单幅插画，角色自然融进场景，景深和光影层次分明
- **IP-05 设计理念卡**：2–3 处核心特征的灵感来源和轮廓隐喻。主角色居中大立绘，引出 2–3 条极简指示线，每条说明不超过 15 字，图面清爽
- **IP-06 标准三视图**：正面、正侧面、正背面。3 个等高全身图横向并排，中性直立站姿，水平对齐，双手自然下垂微张，没有道具遮挡、没有倾斜透视，角色占画面高度 75% 以上
- **IP-07 比例结构卡**：精确的头身比、关键部位的对齐线。角色全身立姿大图，左侧带头身比标尺刻度，身上叠一层简洁的半透明几何轮廓线
- **IP-08 表情设定卡**：只放 4 个表情，展示五官的核心情绪变化
- **IP-09 动作姿势卡**：只放 3 个招牌动作
- **IP-10 服装与道具卡**：3–4 套典型场景的常服（带名称标签）、5–6 件核心随身小道具（带名称标签）。三段式手册构图：顶部大标题和角色趣味头像，中部常服全身立绘横向并排，底部整齐平铺专属道具，留白充足，有品牌手册封面感
- **IP-11 色彩与材质卡**：规范色彩配比和表面材质质感
- **IP-12 视觉识别卡**：外轮廓剪影、核心超级图腾。左侧纯黑实心剪影大图，右侧放大的超级符号特写，黑白强对比
- **IP-13 角色关系卡**：主角和搭档的名字、一句话互动模式金句、3 组日常互动小剧场。三段式关系看板：顶部双主角亲密互动大立绘和个人标签卡，中部互动金句横幅，底部 3 组日常微缩小剧场，留白充足，有角色档案和叙事手册的质感
- **IP-14 角色家族卡**：家族或系列的主题名、4–5 位成员的身份定位和技能标签、家族日常互动场景。双层手册看板：顶部品牌标题区，中部成员等高群像横向并排配胶囊名牌，底部「家族日常小剧场」微缩插画矩阵，有 IP 宇宙设定集的感觉
- **IP-15 商业应用卡**：核心衍生品类，比如毛绒公仔、马克杯、帆布袋、围裙、贴纸、钥匙扣、便当盒、礼盒包装。两段式衍生看板：顶部醒目标题和招牌主立绘，下部 8 宫格周边实物 Mockup，棚拍质感，有品牌授权手册封面感
- **IP-16 内容传播卡**：示范几种社交平台单图和封面（核心主题宣传、日常种草、栏目封面、节日限定）。三段式宣传看板：顶部醒目标题和招牌主立绘，中部 6 宫格社交单图或封面矩阵，底部传播形式标签和渠道说明，有社媒视觉手册封面感
- **IP-17 表情包卡**：16 宫格的日常高频聊天表情
- **IP-18 品牌总览卡**：IP 名称、一句话定位、3 个核心标签、3 个标准色标。品牌总览大看板，1 个标志性大主形象加极简信息排版

## 三档交付 { #tiers }

| 档位 | 张数 | 包含 | 适合 |
|---|---|---|---|
| 基础版（首选） | 6 张 | IP-01、02、06、08、09、15 | AI 出图首选：定位、档案、三视图、4 个表情、3 个动作、周边，张张是清楚的大图，出得快，核心资产齐 |
| 标准版 | 10 张 | 基础版 + IP-04、05、07、11 | 加上场景、设计理念、比例结构、色彩材质，适合建模生产和商业提案 |
| 完整版 | 18 张 | 全部 | 带系统层和全套商业传播卡，适合大型品牌全案 |

用户没说要哪档，就出基础版，按 IP-06 → 其余卡的顺序，三视图先定稿。
