# 海报

新一代生图模型（GPT Image 2 / 2.5）知道了业务场景、受众、渠道和审美风格，自己就能把构图、排版和字画融合做好。所以海报 prompt 不写物体细节、机位和光斑，只给 8 个字段，再接图文后缀。画风和主题色的挑法、画风片段怎么展开，照[入口页](index.md#activation)。

## 8 个字段 { #fields }

1. **主题**：海报要表达的核心概念或主文案
2. **业务场景**：投放或使用的场景
3. **受众**：目标人群
4. **内容密度**：只填等级：极低 / 低 / 中 / 高
5. **情感基调**：核心情绪和氛围的关键词
6. **主题色**：从 36 种经典主题色里挑，几种颜色看画面层次定：单色统领（克莱因蓝），双色搭配（主色克莱因蓝 + 点缀色芥末黄），或者三色调和
7. **editorial 风格**：照固定格式写「{英文风格名} Editorial 风格」，定海报的编辑排版和视觉调性，比如 `Clean Airy Flat Vector Illustration Editorial 风格`
8. **画风**：按入口页展开的画风片段 ——「风格名称：{风格名}。参考作者/风格名称：{参考作者}。」，要特征时接「核心风格特征：{正面特征}。」，要垫样片时接样片和隔离声明

海报靠文字和画面一起构图，所以不管用户开没开图文模式，末尾都接上[图文模式的后缀](prompter.md#graphic-text)。字段里不加修饰和套话。

## 交付什么 { #output }

先在 prompt 上面给推荐组合，再给 prompt：

```markdown
💡 推荐组合
- 画风：FE-061 · Contemporary Literati Ink Cartoon（当代人文水墨漫画）
- 激活：gpt-image-2 靠画法特征，写特征，不垫样片
- 主题色：主色 C-26 柿子橙 + 点缀色 C-03 普鲁士蓝
- 理由：一句话说清这种画风和颜色为什么配这张海报
（想换别的画风或颜色随时说）
```

```text
主题：{核心主题词或标语}
业务场景：{投放场景}
受众：{目标人群}
内容密度：{极低 / 低 / 中 / 高}
情感基调：{核心情绪关键词}
主题色：{单色，或主色 + 点缀色，或三色}
editorial风格：{英文风格名} Editorial 风格
画风：风格名称：{风格名}。参考作者/风格名称：{参考作者}。{要特征时：核心风格特征：{正面特征}。}{要垫样片时：样片和隔离声明}【如果主题直白包含画面元素那就按主题出图，文案由你来升华，但是不要直接描述画面。 如果主题比较概念化，那么文案和主题尽量保持一致，如果文案较长由你提炼，由你先设计画面隐喻（人类和非人类都行）再出图   。    文字参与构图，图文一体】
```
