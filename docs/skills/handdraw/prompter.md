# 出图提示词

[手绘风格出图](index.md)的默认入口：把编号和主题写成一张图的 prompt。查条目、展开画风片段、垫样片、推荐组合的规矩写在入口页，这里只写这一种用法多出来的。

用户这样说就是在用它：

```text
FB-006 号风格，主题：秋天的第一杯奶茶
图型：SC-001，风格：FB-006，主题色：C-01，主题：秋天的第一杯奶茶
图文模式，FE-060 号风格，主题：有很多事你当时想不通，别着急，过段时间你可能就忘了。
帮我生成猫咪在窗台晒太阳的治愈插画提示词，你帮我选风格和主题色
```

## 输入 { #inputs }

- 画风编号（FA-001–FI-034，或旧的三位数）、版式编号、主题色编号或色名，都可以不给，没给的按入口页推荐
- 主题没给也不停下来问，直接出 prompt，主题处写占位：「【请在此输入画面主题，或在生图模型中垫入你的照片】」，英文写 `[Enter theme here, or attach your photo in the image AI]`
- 还可以给画幅比例、主体约束、文字要求、模式。没给画幅就不写画幅

## 两种模式 { #modes }

默认纯图模式。用户说「图文模式」「切换为图文模式」才切过去，说「纯图模式」再切回来，编号和主题不用重选；用了版式自动是图文模式。

### 纯图模式 { #pure-image }

主题决定画面，只写主题里看得见的东西 —— 主体、动作、物件、环境，需要时加情绪。回复末尾加一句「当前处于纯图模式，可切换为图文模式。」

### 图文模式 { #graphic-text }

适合金句、海报和社媒配图，文字参与构图。`主题：` 后面照抄用户原话，不扩写、不解释、不加场景和隐喻，语义交给后缀。中英两段 prompt 末尾都接上下面这段，一个字不改、不翻译，空格也照留：

```text
【如果主题直白包含画面元素那就按主题出图，文案由你来升华，但是不要直接描述画面。 如果主题比较概念化，那么文案和主题尽量保持一致，如果文案较长由你提炼，由你先设计画面隐喻（人类和非人类都行）再出图   。    文字参与构图，图文一体】
```

两种模式都不替模型决定构图、版面、画面丰富度和质量，除非用户选了版式；用户要求的文字照写，没要求的不编。

## 用版式 { #layouts }

- 版式只管构图和文字结构，不管画风。取那一条的版式 prompt 原文，后面接用户的主题，主题是画面内容和文案的唯一来源
- 用了版式就是图文模式：版式 prompt 和后缀叠在一起，不加纯图模式那句提示，prompt 里不放样片地址
- 又给了画风编号，就把画风片段接上；样片只影响画法，不改版式、文字结构和主题
- **电商版式（EC）例外**：不加图文后缀；用户没点名画风就不接画风，商品本身保持写实
- 只出一段 prompt，语言跟着主题走：主题里有汉字就用中文段（中英混合也算中文），否则用英文段。只用画风、不用版式时照旧中英两段

### SC-021 自适应双拼照片转译社媒卡 { #sc-021 }

其他版式拿来就用；这一条不是固定线框，是一套构图语法，要 AI 先替模型拿主意 —— 把备选清单平铺给模型，它会在冲突里退回去照搬原照片的全景背景。

- **按画幅切**：竖版（3:4、9:16、1:2）上下 1:1，上面照片、下面手绘，顺着手机往下看；横版（16:9、4:3、5:2、21:9）左右 1:1，左照片、右手绘，像杂志跨页；方版自己定，或者照用户说的
- **七种转译类型只选一种**：用户没指定，就按主题推荐一种，或者按顺序轮着来；只给选中的这一种写执行 prompt，不把别的写进去
    1. 视线锚点跨界续绘：一个动态锚点（水、路、光、手势）越过中缝流进暖象牙纸的手绘区，下方长出绘本式的互动故事和极简黑线小人
    2. 撕纸裂变第二世界：不规则的手撕毛边接缝，现实穿过撕口后物理规则超现实地突变（水变成布匹、光能捧在手里、影子成了台阶），暖象牙纸配克制的拼贴
    3. 越界破框：几何色块或容器托住主体，主体的头、手、枝叶伸出色块边缘，有穿透感
    4. 微缩浮岛：主体缩成纸面 10%–25% 的小景，一抹色带或一个小基座托着，四周大片空白
    5. 记忆图谱平铺：手绘主体居中，留白里错落平铺 3–6 枚带 NO. 编号的原图记忆贴纸
    6. 经典悬浮落地：主体占 40%–55%，脚下只有一条极简的手绘地面线
    7. 正负形咬合：主体提炼成几何剪影，和背景的正负形互相咬合
- **净化背景**：剔掉原照片里的石墙、马路、树木这类环境杂物，转译那一侧四周留 40%–80% 的干净空白
- **每次都附七类清单**：prompt 后面列出七种类型，标明这次用的是哪一种，告诉用户回「换成 02」就能换

## 照片改画风 { #redraw }

传图是可选的：没传就纯文字出，模型自己画；传了照片要「改图」「转手绘」「换画风」，从照片里提取人物外貌、姿态、服装轮廓和场景概貌写成主题，并在画面要求后面接上这句，「选择的风格」换成具体的风格名。不加的话，模型会在照片表面叠一层滤镜，而不是重画：

```text
【请只提取人物的五官特征和姿态，场景轮廓，在画风上严格按 选择的风格重新画，不要在原照片上加质感。】
```

```text
[Extract only the character's facial features and posture, and the scene contours. Strictly redraw from scratch according to the selected style; do not add texture or filters onto the original photo.]
```

真出图时照片走编辑接口的 `images[].image_url`，SC-021 也一样。

## 交付什么 { #output }

1. 推荐了组合的，先写一行「💡 推荐组合：画风 FB-006 · Bendy Absurd Storybook + 主题色 C-26 · 柿子橙」，附一句理由，说一句想换随时说
2. 选用的画风：编号加风格名
3. 中文 prompt：以「风格名称：{风格名}。」开头；有主题色写「主题色：{中文色名}（{英文色名}）。」；写「参考作者/风格名称：{参考作者}。」；要特征时接「核心风格特征：{正面特征}。」；然后只写主题和用户给的约束。改图时接转绘那句；纯图模式要垫样片，接样片地址和隔离声明；图文模式接后缀，样片放在 prompt 外面
4. 英文 prompt：同样的结构，`Style name: {风格名}.`、`Theme color: {英文色名}.`、`Reference author/style name: {参考作者}.`、`Core style traits: {正面特征}.`，特征照抄中文原文
5. 一句说明：prompt 能贴进任何生图工具，出成什么样由那边的模型决定

不加通用的构图建议、质量词和负面词。
