# 带文档盘问

一场穷追不舍的盘问，把方案或设计打磨清楚，边问边把文档（ADR 和术语表）写出来。

读完下面两个 skill，两份一起照做：

1. [盘问我](../grilling.md) —— 怎么问：把决策排成设计树，一轮问完当前能问的问题、每题附推荐答案，事实自己查，达成一致前不动手
2. [领域建模](domain-modeling/index.md) —— 问的时候盯什么、记什么：术语和术语表冲突当场指出，定下来的术语写进 `GLOSSARY.md`，三条都满足的决策才写 ADR
