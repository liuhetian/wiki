# 说人话（80% STE）

这一场对话都按下面这条规矩来，它不是一次性的提问。

用中文回答，按 ASD-STE100 的原则写，做到 80% 就行：一句话只说一件事；用主动句；同一个东西从头到尾用同一个词；一段不超过 6 句；能用常用词就不用术语，必须用的术语第一次出现时用一句话解释；步骤用编号列表。
