# 对话提示词

一组现成的对话 prompt，每个是一个独立的 skill。按下面的场景挑一个，读那一页照做；人用的话，在那一页点复制按钮，整页粘进对话框。

## 理清问题、做决定

| 我想…… | 用 | 要准备什么 |
|---|---|---|
| 说不清自己到底卡在哪 | [苏格拉底式提问](socratic.md) | 发生了什么、我怎么理解、卡在哪 |
| 怀疑自己一直在修补表面问题 | [第一性原理](first-principles.md) | 问题本身 |
| 本行当的常规解法都失效了 | [跨领域借解](cross-domain.md) | 背景、当前做法、约束、卡点 |
| 在两个选项之间做决定 | [双向钢人论证](steelman.md) | 两个选项、目标、约束 |
| 问题复杂，需要多个专业视角 | [专家会诊](expert-panel.md) | 已知事实、目标、约束 |

## 和本站其他 skill 的分工

- **苏格拉底式提问和[盘问我](../grilling.md)方向相反**：盘问我拷问的是方案，事实让 AI 自己查代码库，只把决策抛给用户；苏格拉底式提问拷问的是困惑，事实只能从用户嘴里问出来。写代码之前用盘问我，想不清一件事时用苏格拉底式提问
- **说人话、人话翻译、[去 AI 味](../../writing/qu-ai-wei/index.md)管三件不同的事**：说人话放在对话开头，约束这一场所有回答怎么写；人话翻译只把一个概念压成 200 字大白话；去 AI 味改已经写好的稿子
- **实事求是、范围铁闸把[初始化项目](../init-project.md)的两条守则落成了可检查的条款**：「不要假设」只说了态度，实事求是规定文档只算线索、装包命令要匹配本机；「简洁优先」只是一句原则，范围铁闸要求先列至少 3 条不做的事。初始化项目写进项目、长期生效，这两个只管一场对话
