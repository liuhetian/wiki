# 图片提示词反推

把一张参考图反推成能直接出图的 prompt。两个版本内容各自独立，挑一个照做：

| | [七维拆解](seven-dimensions/index.md)（简化版） | [从图反推 prompt](get-prompt-from-image/index.md)（完整版） |
|---|---|---|
| 拆法 | 主体、风格、配色、光线、构图、质感、氛围七维，按五类图换观察重点 | 通用视觉维度 + 题材与媒介专项 + 插画风格专章，三份 reference |
| 产出 | 一条中文 prompt；出图后每轮只改偏差最大的一维 | 中文 + 英文正向 prompt、10–15 个英文负向词，不展示分析过程 |
| 适合 | 人想弄懂怎么拆图，自己跟看图模型分两轮问 | 交给 AI 一次出结果，要媒介边界、负向词和 IP / 文字的处理 |

用户没指定就用完整版；用户想看拆解过程、要自己一轮轮迭代，用简化版。
