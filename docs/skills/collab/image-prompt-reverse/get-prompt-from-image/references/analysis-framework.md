# 通用图像分析框架

以下内容仅供内部分析，不得展示给用户。

## 1. 用途

判断图片更接近广告素材、游戏主视觉、社交媒体内容、商业产品摄影、人像、电影剧照、插画海报、3D 角色主视觉、电商主图、建筑或室内展示、美食摄影、动物摄影、自然风景或城市场景、平面海报或视觉设计、字体或 logo 设计、抽象图形，还是其他用途。用途决定 prompt 应侧重叙事、商业呈现、人物表现、产品结构、空间设计还是视觉传达。

## 2. 媒介

判断图片属于摄影、写实 3D、半写实 3D、动漫风插画、绘画感插画、扁平矢量、产品渲染、UI 或平面设计、混合媒介，还是其他类型。最终 Prompt 必须明确写出媒介边界，负向 Prompt 必须排除容易混淆的媒介。

## 3. 主体类型

识别主要主体是人物、产品、动物、美食、建筑或室内、自然风景、城市场景、交通工具、植物或花卉、字体或 logo、IP 或潮玩角色、平面海报或视觉设计、抽象图形、多主体混合，还是其他类型。

只分析与主体类型相关的专项规则。没有人物，就不分析表情、视线或肢体；没有产品，就不分析包装或卖点；没有动物，就不分析毛发或视线；没有文字，就不分析字体排印。

## 4. 构图

分析画幅比例和横竖方向；主体位置及其占画面的比例；前景、中景、背景和留白；居中、三分法、对称、对角线、框景或散点构图；水平线、垂直线、对角线、三角形、S 形、圆形或放射状线条等视觉结构；视觉中心和视线动线；远近关系；以及各主体之间的大小、遮挡、重复、平衡和层级关系。

## 5. 镜头、视角与透视

分析平视、俯拍、仰拍、正俯视或航拍视角；特写、半身、中景、全身或远景；广角感、自然透视或空间压缩；近大远小和透视汇聚；前景遮挡和框景；隔着玻璃、窗户、门洞或树叶观看；景深和对焦位置；以及动态视角、倾斜镜头或运动感。

只有当图像证据或元数据足够明确时，才写出具体的焦距、光圈、快门速度或相机型号；否则只描述视觉效果。

## 6. 光线

分析主光方向；硬光、柔光、逆光、侧光、顶光或环境光；自然光、影棚光、三点布光、窗光、霓虹光或体积光；轮廓光、反射光、补光、局部高光和阴影位置；辉光（bloom）、彩色光晕、光斑和反光高光；整体色温和光比；以及光线如何塑造体积、材质、空间和情绪。

## 7. 色彩

分析主色、辅色和点缀色；冷暖倾向；饱和度、明度和对比度；单色、互补色、邻近色或冷暖对比；以及霓虹、高级灰、马卡龙色、复古、胶片感或商业通透感等倾向。说明色彩如何引导视线、分离主体、营造情绪。

## 8. 材质

分析主体和背景的表面质感，包括皮肤、毛发、羽毛、鳞片、爪子、布料、织物、皮革、纸张、金属、玻璃、塑料、树脂、PVC、亚克力、陶瓷、木材、石材、墙面、水、液体、冰、雾、烟、植物、花瓣、叶片、露珠、屏幕、包装和食物表面。

描述反光度、粗糙度、湿润度、透明或半透明、哑光、柔软、坚硬、纹理颗粒、织物纹理、划痕、褶皱、油亮、霜感和粉质感，并找出最重要的材质记忆点。

## 9. 景深、背景与空间层次

分析背景是清晰还是有不同程度的虚化；前景虚化；主体与背景的分离；焦外光斑（bokeh）、雾气、烟雾、渐变阴影、纹理、树影、倒影、水平或垂直线条、斜向网格、圆形光斑、大色块、层叠山峦、建筑剪影、城市灯光和街道透视线。判断背景是承载叙事信息，还是提供氛围衬托。说明前景、中景、背景之间的遮挡、比例和空气透视。

## 10. 内容与情绪

分析主体的外观、形状、大小、颜色、朝向和状态；辅助元素、道具、环境物件和装饰的位置；室内或室外、地点类型、时间、季节、天气和环境状态；主体的动作，以及主体、道具与背景之间的叙事或功能关系；整体情绪及其具体的视觉来源。

## 11. 后期与画质

分析颗粒、噪点、辉光、柔焦、动态模糊、胶片感、色差、锐化、局部高光和镜头光晕；商业修图、电影调色、CG 渲染后期、产品精修、肤色校正和材质增强；以及清晰度、细节密度、过曝、欠曝、过度磨皮、过度锐化或低分辨率。

把高分辨率、高细节或 8K 用作生成质量要求时，不要把它表述成对原图实际参数的判断。

## 12. 视觉锚点

从独特的构图、主体剪影/姿态/比例、不寻常的镜头关系、标志性的光线、关键材质、背景几何结构、色彩关系、空间层次以及由具体元素营造的情绪中，提取 3–5 个最影响相似度的元素。优先把它们放在正向 Prompt 的前三分之一。
