# 按主体与媒介的专项分析

按图片的实际类型选取相关小节。多主体的图片可以组合多个小节，但不得硬塞进不存在的特征。

## 通用图像

涵盖主体内容、艺术或媒介风格、配色方案、光线、构图逻辑、材质质感、镜头语言、空间层次、情绪、画质要求和细节处理。中英文正向 Prompt 的含义必须一致；不要在英文版里添加新元素。

## 人物与人像摄影

分析清晰可见的年龄线索和性别呈现、脸型、五官、发型、妆容、表情、视线、头部角度、身体朝向、姿势、肩颈位置、手和腿的摆放、重心、离镜头最近的身体部位、透视强调、服装、配饰、皮肤质感，以及人物与环境的关系。无法可靠判断身份、年龄或族裔时，只描述可见的外貌，不要推断身份。

## 摄影

分析自然光、硬光、柔光、逆光或影棚光；景深和对焦；广角、自然透视或长焦压缩效果；冷调/暖调、复古、商业通透感或胶片质感；清晰度、颗粒、噪点、锐度和动态模糊；以及纪实、影棚、随手快照、时尚人像或电影剧照式摄影。只有证据充分时才写具体的相机参数；不要编造焦距、光圈、快门速度、ISO、相机型号或摄影师名字。

## 产品与商业摄影

分析产品品类、形状、颜色、朝向、占画面比例、包装结构、边缘、按键、接口、标签位置、表面材质、镜面高光、粗糙度、透明度、阴影位置，水珠/粉末/液体/蒸汽/冰块/花瓣等道具，背景布置，以及哪些可见的结构和材质在传达产品卖点。不要生成清晰的品牌 logo、乱码包装文字或并不存在的功能结构。

## 字体排印、Logo 与文字设计

分析现代、复古、赛博、手写、极简或装饰风格；字形的宽窄、倾斜、圆润度、几何感和比例；笔画粗细、衬线或无衬线结构、斜切、切口、连笔、断笔和负形；字距、行距、层级和排版逻辑；描边、发光、渐变、浮雕、阴影和 3D 效果；金属、哑光、玻璃、塑料、霓虹或纸质材质；以及配色、构图、光线与背景之间的关系。

当 logo 或文字只是辅助元素时，把它转化为抽象符号、简化图案或模糊标记。只有当用户明确要求并提供了内容时，才在 Prompt 中写出具体文字。

## 自然风景与城市场景

分析地点和环境类型，季节，天气，黎明/白天/黄昏/蓝调时刻/夜晚，前景/中景/背景与地平线，天空/云/水/雾/空气透视，植被/山/建筑/街道/灯光/倒影，街道透视线和建筑几何结构，光线方向，冷暖变化，景深，透视，细节纹理，以及整体情绪。不要从模糊的视觉效果编造出具体的地点、城市或地标。

## 建筑与室内

分析空间类型和功能，透视方向，灭点，主要线条，前景/中景/背景，建筑/家具/墙面/地面/装饰材质，自然光/窗光/灯带/环境光等光源，空间尺度，秩序和情绪，空间是否应整洁/空旷/无杂物，以及室内外的衔接或窗外景色。

## 插画

当图片的主要媒介是手绘、数字绘画、平涂、绘画感、水彩、铅笔、版画、矢量、动漫风、儿童绘本或其他插画时，继续阅读并应用 [illustration-style.md](illustration-style.md)。该文件把主体内容与风格表达分开，优先采用线条、形状、明暗、色彩和纹理等可观察的技法。不要用它改写摄影、3D 渲染、产品图或其他非插画类型的分析规则。

## 3D 渲染

分析写实、半写实、3D 卡通、黏土、玩具或极简风格；建模比例、柔和边缘和细节精度；哑光、金属、玻璃、亚克力、树脂、PVC 或陶瓷材质；反射、折射、粗糙度、次表面散射和 PBR 质感；三点布光、柔光、轮廓光、体积光或环境光；阴影软硬、接触阴影、抗锯齿和后期辉光。只有证据充分或用户指定时，才写 C4D、Blender、Octane 等软件或渲染器名称；否则使用通用的 3D 渲染语言。

## IP 角色、Q 版、潮玩与盲盒

分析 Q 版、潮玩、治愈、国潮、黏土或卡通风格；头身比、体型、剪影、五官、表情、发型、气质、服装、装饰、动作，哑光/树脂/PVC/陶瓷/黏土质感，柔光，纯色背景，展示台，类产品化的呈现，全身设计，以及细节密度。最终 Prompt 应描述角色的视觉特征，而不依赖具体的 IP 或角色名。

## 动物

分析动物种类、体型、毛发/羽毛/鳞片颜色、姿态、动作、视线，毛发/羽毛/鳞片/皮肤/爪子的质感，与环境或其他主体的关系，轮廓光，以及整体情绪。无法可靠识别物种时，描述可见的姿态和外观，不要编造具体品种。

## 美食

分析食物种类、主要食材、形状、颜色、摆盘、占画面比例、油光、酱汁、热气、酥脆感、水润感、奶油、粉末、糖霜、拉丝、滴落、餐具、桌面材质、光线、阴影、景深、拍摄角度，以及哪些颜色、光泽、质感和温度感营造了食欲。

## 交通工具

分析交通工具类型、观察角度、车身或机身材质、反光、灯光、高光线条、静止或运动状态，道路/天空/城市/自然环境，以及速度线、扬尘、水花或动态模糊等实际存在的效果，还有透视和主体比例。默认排除清晰的品牌 logo、车牌、编号和可读文字。

## 植物与花卉

分析植物种类或可见形态、颜色、数量、生长状态，花瓣/叶片/花粉/露珠/纹理，光线是否透过花瓣或叶片，前景与背景的遮挡、虚化以及与背景的关系，还有柔美、清新、浪漫或宁静感的具体视觉来源。

## 平面海报与视觉设计

分析版式结构、主视觉位置、色块、图形元素、背景关系、留白、网格、对齐、视觉动线、前后层级、遮挡、比例、文字区域的位置和层级，主色/辅色/点缀色，颗粒、渐变、描边、阴影、拼贴或故障效果。如果目标是复刻版式而非文字内容，写「预留文字区域」；如果文字只是视觉元素，则排除清晰可读的文字。

## 抽象图形与多主体混合

分析基本几何形、曲线、色块、纹理、重复、主次关系、节奏、平衡、方向性、透明叠加、发光、渐变、材质，以及多个主体之间的距离、遮挡、比例和叙事关系。只组合真正相关的专项规则；避免一次把所有类别的特征都写进 Prompt。
