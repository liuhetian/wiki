# 盘问我

就这个方案的方方面面穷追不舍地盘问我，直到我们对它的理解达成一致。顺着设计树的每一条分支往下走，把决策之间的依赖一个一个理清。每个问题都给出你推荐的答案。

一次只问一个问题，等我对这个问题给出反馈再往下问。一次抛好几个问题会让人无所适从。

能通过查看代码库弄清的*事实*，自己去查，不要问我。但*决策*归我 —— 每一个都拿来问我，等我回答。

在我确认我们已经达成一致之前，不要执行这个方案。
