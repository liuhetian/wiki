# 插画风格分析

只有当插画是图片的主要媒介时才使用本参考。目标是把「画了什么」和「怎么画的」分开，并把可辨识的风格转化为可观察的视觉技法，而不是依赖艺术家名字、流派名称或含糊的情绪词。

## 1. 风格指纹

通过以下方面分析插画的风格指纹：

- 媒介与渲染方式：线描、平涂、赛璐璐上色（cel shading）、绘画感渲染、水彩、水粉、水墨晕染、铅笔、炭笔、版画、拼贴、剪纸、矢量、像素画或混合技法。
- 线条语言：无描边、细轮廓线、粗轮廓线、粗细变化的线、断线、草稿线、毛笔线、几何线条或柔和边缘。
- 形体与结构语言：写实、简化、几何化、圆润、修长、Q 版、夸张、符号化、有机形或建筑感。
- 明暗与光线语言：平涂明暗、硬边赛璐璐色阶、柔和过渡、带纹理的色块、水彩水渍晕边、枯笔痕迹、强烈明暗对比、轮廓光或漫射环境光。
- 色彩语言：有限色板、互补色对比、低饱和色、马卡龙色、高饱和、大地色、霓虹点缀、透明叠色或纸张般的色彩变化。
- 纹理与细节分布：干净的数字表面、纸张颗粒、笔刷纹理、可见笔触、网点（halftone）、颜料沉淀颗粒、划痕、噪点、主体细节密集或背景细节简化。

不要把风格指纹和主体内容混为一谈。风格指纹描述图像是怎么做出来的；主体描述说明图像里有什么。

## 2. 证据权重

按以下顺序排定风格证据的优先级：

1. 贯穿整幅画面、反复出现的特征，如线条逻辑、明暗结构或色板。
2. 影响剪影和主体的特征，如形体简化、轮廓或人体结构。
3. 影响表面的特征，如笔刷痕迹、纸张纹理或渲染方式。
4. 局部装饰细节，只有在视觉上显眼或反复出现时才写入。

不要把一处小痕迹当作决定性的风格。不要把低分辨率瑕疵、压缩噪点或生图缺陷误认为是刻意的技法。

## 3. 主风格与辅助风格；化解冲突

从风格指纹中选定一个主风格方向和最多两种辅助技法。主风格方向掌控媒介、线条和造型逻辑；辅助技法可以补充色彩、纹理或后期处理，但不得与主风格争夺主导权。

风格冲突时，保留证据更强、覆盖面更大或对主体影响更明显的一方，去掉另一方。尤其要检查：

- 扁平矢量处理搭配厚重的油画堆叠
- 无描边处理搭配粗黑的闭合轮廓线
- 硬边赛璐璐分层搭配连续的水彩晕染
- 极简低细节搭配铺满画面的极高密度照片级纹理
- 哑光纸感搭配强烈的塑料镜面反光
- 松散的手绘边缘搭配机械均匀的几何线宽

不要用堆砌艺术家名字、艺术流派或相互矛盾的氛围词来代替观察。把可辨识的参考风格转化为线条、形状、明暗、色彩、笔触、纹理和细节分布。

## 4. 插画视觉锚点

为插画提取 3–5 个复刻关键元素时，至少选两个风格锚点，并优先从以下清单中组合：

- 一种主要媒介或渲染方式
- 一个线条、形状或明暗锚点
- 一个色彩或光线锚点
- 一个笔触、纹理或细节分布锚点
- 必要时，最影响相似度的构图或空间关系

把这些锚点放在正向 Prompt 的前三分之一。主体身份固然重要，但不要把所有风格锚点都推迟到主体和故事描述之后。

## 5. 插画正向 Prompt 的信息权重

以下组织比例只用于插画的正向 Prompt。它们是写作权重，不是要机械计数的要求：

- 约 35–45% 描述风格指纹和关键风格锚点
- 约 20–30% 描述主体外观、动作、服装或设计
- 约 15–20% 描述构图、视角、光线和空间层次
- 其余内容描述背景、叙事关系、具体情绪、后期处理和媒介边界

先写主要媒介、线条与形状语言、明暗处理、核心色板和关键纹理，再自然衔接到主体、构图和场景。最终输出仍须遵循 `SKILL.md` 的默认长度、中英文语义一致和两段式格式。

## 6. 完成前检查

在内部确认：

- 风格指纹描述的是「怎么画的」，没有重复「画了什么」。
- 只有一个主风格方向，兼容的辅助技法不超过两种。
- 最影响相似度的风格锚点出现在前三分之一。
- 描述使用的是关于线条、色彩、明暗和纹理的可观察证据，而不是空洞的情绪词。
- 没有把摄影参数、3D 材质逻辑或其他类型的规则硬套到插画上。
- 没有添加原图中不存在的媒介、纹理、角色、道具或背景元素。
