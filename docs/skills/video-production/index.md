# 视频制作

用本站接好的生图、生视频接口做短视频成品。路数都一样：先用生图把关键画面定下来，再让视频模型补中间的动作，最后处理成要交付的格式。一种成品一个子 skill：

- [花卉动态生长海报](flower-growth-poster/index.md) —— 要做一张会长出来的花卉海报时用：照片转肌理插画、插画套排版出海报，首尾帧视频从空白纸面长成海报，最后接成循环；五步各一段 prompt，花名、颜色和海报文字填空（整理自抖音设计教程；[维护记录](../../maintenance/skills/flower-growth-poster.md)）

接口都在 [Agent 基础能力](../agent-io/index.md)：[生成、编辑图片](../agent-io/reference/image.md)、[生成视频](../agent-io/reference/video/index.md)。
