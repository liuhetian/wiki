# 生成配图

把 deck 里每张要 AI 生成的图写成一条 prompt，让同一套 deck 的图看起来是一家人，图里的字也不跟页面上的可编辑文字抢活。画风从 Gallery 的 [PPT 配图画风](../../gallery/images/ppt-master/index.md#renderings)挑，局部信息图的构图从 [PPT 配图版型](../../gallery/layouts/deck-image-types/index.md)挑，配色用[规划 deck](strategist.md#color) 定好的那套。

默认只写 prompt。用户说「出图」，用 [agent-io 的生成、编辑图片](../agent-io/reference/image.md)去画：prompt 里的画幅照样写像素，接口的 `size` 写成对应的比例（1280×720 写 `16:9`）。

## 先定两件事 { #role }

| 用途 | 是什么 |
|---|---|
| 局部配图 | 放进页面里的一块 —— 带框、不带框、当装饰反复出现，或者是页面里最大但不占满全页的画面；位置和组合由页面排版决定 |
| 主视觉页 | 图就是这页的主角：封面、章节页、情绪过渡页、单数字页、结尾金句；上面叠的文字可以很少，甚至没有 |

| 带不带字 | 是什么 |
|---|---|
| 图里不带字 | 图里没有任何文字 |
| 图里带字 | 稳定的文字作为画面的一部分：艺术字、wordmark、手写的词、图内部的标注 |

## 硬规矩 { #hard-rules }

| 约束 | 规矩 |
|---|---|
| deck 身份 | 一套 deck 的所有图用同一种画风、同一套核心配色 |
| 色值 | 色值和颜色名只是绘画指引，绝不能画成可见文字 |
| 文案 | 长文案、数据、要点列表、引语都留在页面上 |
| 图里的字 | 只放永远不用改的字：图里改一个字要重新生成，页面上改一个字只要敲一下键盘 |
| prompt 写法 | 写成一段连贯的画面描述，不堆标签 |

## 挑画风 { #pick-rendering }

先想清楚这套 deck 的配图要干什么、视觉风格是哪种，再去[画风目录](../../gallery/images/ppt-master/index.md#renderings)里比。话题、行业关键词不决定整套 deck 的画风，也不会把一个具名的真实对象变成 AI 生成图；视觉风格的配套画风只是一个候选，不是默认答案。

| 维度 | 拿什么比 |
|---|---|
| 主体身份 | 要还原真实样貌，还是虚构表达、隐喻、氛围、抽象结构 |
| 笔触语言 | 照片细节、矢量边缘、手绘线条、半调网点、像素网格，还是材质轮廓 |
| 纵深与材质 | 平涂色块、层叠纸张、玻璃、等距体块、水彩晕染、颗粒，还是自然光 |
| 页面角色 | 整幅构图、局部插画、可复用的透明元素，还是辅助的视觉提示 |
| deck 一致性 | 和视觉风格、配色角色合不合得来，又不抢页面真正要做的事 |

目录里没有合适的，自己写一段画风段落：2–5 句，线条、质感、纵深、材质、情绪五样都写到；借用了目录里的条目，只写真正用到的那几个。例：「手工丝网印刷海报的质感 —— 半调网点叠印略微错位，三种平涂油墨，网点图案可见、不透明度 12%，没有渐变，边缘不做抗锯齿；整体读起来像丝网印刷品。」

## 拼 prompt { #assemble }

每张图按这六段拼成一段话：

```text
[画风段落：从选定的画风条目里整段抄]
[配色行为：deck 的核心配色在这张图里怎么分工，比如「次背景色 #F8F9FA 铺出留白，主色 #1E3A5F 画主体，强调色 #D4AF37 只点一处重点；明暗、材质的过渡留在同一个色系里」]
[构图：选定版型条目里的构图写法，或下面五种构图之一]
[主体：这张图要画的东西，写成具体的名词]
[画幅：「画成 W×H 的图，用作局部配图 / 主视觉页」；主视觉页留出叠字区，局部配图只有页面真要在上面叠标注时才留]
[硬规矩：见下一节，每条 prompt 末尾都带上]
```

- **长度**：画风段落和末尾的硬规矩整段照抄，不算在内；自己写的配色、构图、主体、画幅几段合起来，日常配图 150–300 字，带字的长一些，纯背景短一些
- **专业图不设上限**：科学、学术、工程、医学、法律这类图，500–1000 字以上是常态，不要预先缩短。写明这个领域的视觉惯例：化学和材料（IUPAC 原子配色、化学键画法、晶格类型、Å 和 ps 单位、A/B/C 子图圆标、观察角度）、生物（区室配色、比例尺、细胞器和染色惯例）、物理（坐标轴符号、典型曲线形状、单位、峰值标注）、工程（原理图符号、尺寸标注、剖切面）；拿不准就回去读素材
- **不堆标签**：「现代、扁平设计、渐变、鲜艳、专业、干净、4K」这种写法只会出平均脸，要写成一个连贯的画面
- **配色从 deck 的角色出发**：背景色、次背景色铺满底，主色画主要形体，强调色少量；可以按光线、材质、语境派生深浅过渡，但绝不另起一套跟 deck 无关的配色
- **一套 deck 只用一种画风**：每张图都抄同一段画风段落
- **版型只给局部的结构信息图用**：单主体、人像和主视觉页不用版型，用下面的构图

## 五种不用版型的构图 { #primitives }

A、B 用于主视觉页或局部的单主体区域；C、D 用于主视觉页；E 用来写任何自定义构图，包括版型里没有的结构信息图。

- **A 单一主体**：一个焦点主体，有意识地摆位（居中、三分线、稍偏），大到能撑住画面，其余背景都是陪衬；页面需要时才故意空出一侧。用于产品亮相、概念引入、章节开篇、品牌宣言、局部的物件区
- **B 单人像**：一个人，正面或四分之三侧面，头部和上半身，脸是焦点，眼睛在上三分线附近，背景中性或柔和虚化，头顶留够空间。用于创始人、讲者、客户证言、高管、局部的人物介绍；人物画法跟画风走
- **C 文字主视觉**：一个大号文字元素 —— 一个词、一句话、一个标题、一个数字或几行短字组合 —— 画成艺术，占主导分量，其余视觉都是陪衬，留白按文字大小来。图里带字；必须一字不差或要能改的文字放到页面上，改用 D
- **D 氛围背景**（只用于主视觉页）：渐变、低调的纹样或克制的色块，没有主体（角落或边缘可以有一个小的几何点缀），画面的动静绕开页面计划叠字的区域，让那里保持安静。用于封面和章节页的背景、留白页、文字全由页面承担的页
- **E 自定义**：A–D 都不合适时（三联画、不对称的多焦点、叙事场景模型），直接把构图写进 prompt —— 一段 2–5 句，写清主体数量和版面结构，具体到能照着画；只写构图名字不算描述。例：三联画，三条等宽的竖条，每条在同一条低地平线上居中放一个象征物，竖条之间用 2px 细线分隔，整体读起来是一页完整的画面

示例（色值是示例 deck 的配色，换成自己的）：

````text
A · 3D 等距的产品亮相，图里不带字，600×600：真正 30°/30°/30° 投影的 3D 等距插画。画面中央是一个占主导的产品形态主体 —— 一件造型化的设备或流线型的科技物件，受光面用主色电光蓝 #0EA5E9，背光面深 15% 形成色调过渡，外围有 8% 不透明度的淡淡辉光。少量陪衬：三条强调色亮青 #06B6D4 的细连接线从主体向画面边缘划出弧线，一道 8% 的柔和投影把它落在地面上。背景是深沉的次背景色海军蓝 #0A0E27，阴影所在的平面也是这个颜色。主体是唯一的焦点，四周留出从容的空间。画成 600×600 的主视觉块。任何地方都不要出现文字、字母、数字或标签。色值只是绘画指引。
````

````text
B · 企业摄影风的高管头像，图里不带字，600×800：一位职业高管的社论式企业肖像，略偏左，胸部以上，平视，自信地看向镜头，表情放松自然。当代商务着装，中性色调。柔和的自然光从左上方来，脸的右侧有一道轻柔的阴影。背景是柔焦的办公室 —— 次背景色浅灰 #F8F9FA 的墙面，一处虚化的建筑元素带一点主色深海军蓝 #1E3A5F。克制专业的调色，浅景深，眼睛在上三分线附近，头顶空间宽松。画成 600×800 的人物介绍肖像。不要文字、姓名牌或说明文字。色值只是绘画指引。
````

````text
C · 墨迹笔记风的大数字，图里带字，800×500：专业的手绘视觉笔记风格，纯白底。画面中央是手写的数字「100x」，墨线粗重果断，居中，带一点手写字的抖动；下面一道手绘细下划线；旁边一个小涂鸦 —— 星星或向上的箭头 —— 增加节奏。强调色珊瑚红 #E8655A 只出现在一个很小的强调圆点上，不到画面的 4%。背景纯白 #FFFFFF。画成 800×500 的文字主视觉，给字形留足空间。除了「100x」和那个涂鸦，没有别的文字或标签。
````

````text
D · 矢量插画风的封面背景，图里不带字，1280×720：干净的扁平矢量背景，没有中心主体 —— 粗犷的几何形状沿画面边缘排布，让中间计划放标题的区域保持安静。主色深海军蓝 #1E3A5F 形成一块果断的斜向色块，横过左下方；次背景色浅灰 #F8F9FA 铺出留白；强调色金色 #D4AF37 只在右下角附近出现一条细几何线，不到画面的 5%。干净的 2px 描边，没有渐变，海军蓝色块下面一道 8% 的柔和投影。计划叠 SVG 标题的区域保持安静。画成 1280×720 的满版背景。任何地方都不要出现文字、字母、数字、标志、水印或书写符号。色值只是绘画指引 —— 不要把色值或颜色名显示成文字。
````

## 每条 prompt 末尾的硬规矩 { #append }

### 色值不是文字

模型偶尔会把颜色名和色值当标签画出来。每条都接上这句：

```text
色值（比如 #1E3A5F 这样的 HEX 代码）和颜色名只是绘画指引 —— 不要在图中任何地方把 HEX 代码、颜色名或配色标签显示成可见文字。
```

### 人物跟画风走

脸部细节、人体结构、质感和写实程度都按画风和这张图的用途来 —— 剪影、精细插画、绘画式人物还是社论摄影，看画风允许到哪一步。**绝不画可辨认的真人或名人**，除非用户明确说明是授权过的对象；泛指的人、虚构的人随便画。

### 文字分两层

| 层 | 归谁 | 例子 |
|---|---|---|
| 图里的字 | prompt 决定，烧进像素 | 图内部的标注（坐标轴、A/B/C 标记、单位、比例尺、子图标签）；原理图的模块名、节点标签、信号通路编号；本身就是画面的稳定艺术字 |
| 页面上的字 | 页面上可编辑的文字 | deck、页面、章节的正式标题；导航、页脚、要点、结论标注；要读的文案和图注 |

- 「带不带字」只管图里那一层，一张一张判断，不整体偏向哪边。这几种从「带字」起步，再按能不能改过滤：论文插图的子图对比（子图标签）、教科书里的数学或信号图（曲线名、坐标轴、单位）、按学科惯例画的原理图（`Self-Attention`、`FFN`、节点编号）、坐标轴固定的数据图、文字主视觉。因为「页面上总能再叠字」就把整批图都设成不带字，正是要避免的失败
- **按能不能改判断，不按模型能不能画判断**：图里的字没法改、没法纠错、没法搜、没法换样式、没法重排。属于画面、又稳定的字（艺术字、wordmark、手写短语、图内部的标识）可以进图；必须一字不差、要能搜、要能改、可能换说法的，一律放到页面上：正式标题、导航、页脚、要点、图注、数据值。标题类的字只有在规划里明确当成稳定画面时才进图；标题要能改，就用构图 D 再叠字
- **不按文字种类和长短预判**：不要因为觉得某种文字或长句「画不出来」，就把字挪到页面、缩短标题或改成不带字；几个词的短语、两行的字组合和一个词一样可以进图。prompt 里把确切的字原样写出来，不为核对文字回头看图 —— 唯一的例外：图里带中文、阿拉伯文、印度系、泰文等非拉丁文字时，允许看一眼生成结果，只回答字和原文是否完全一致；不一致就重新生成这一张，看这一眼不重新评审选图和审美；同一个字连续三次都画错，就停下，这个字改用页面上的文字，在备注里记下改了，页面上不解释

带不带字的写法：

| 带不带字 | prompt 里写 |
|---|---|
| 图里不带字 | 「图中任何地方都不要出现任何文字 —— 没有字母、数字、标志、水印、标签或书写符号。」 |
| 图里带字 | 写出确切的字、怎么画、在画面里怎么处理 |

**艺术字交给模型的东西**：确切的字、它的沟通角色、位置和与背景的关系、deck 的身份、相对分量、想要的能量；画风、语义色、情绪和页面层级划出范围。表现力落在字形本身：轮廓、笔画结构、内部材质和纹理、贴着轮廓的立体和光影、构图。照字面画主题插图或加游离的装饰，会跟字抢；要字加插画的组合，得用户明确要求或规划里定了。在选定的处理方式之内，手势、材质、立体感、纹理、光线和层级让模型自己组合或取舍 —— 这是可能性的空间，不是配方。拿不准合不合适就用低一档的密度；多行字的层级本身是画面的一部分时，作为一个整体元素。

**图里文字的字体**自由描述，不是从枚举里挑 —— 传统封面用哥特体，宣言用手刷毛笔字，Y2K 用复古镀铬，奢华感用装饰艺术风展示字，小刊用丝带花体。只有稳定的艺术字要和 deck 的字体看起来是一家时，才按这张表呼应：

| deck 字体 | 呼应写法 |
|---|---|
| 衬线 | 「优雅的衬线字，精致的字形」 |
| 无衬线（微软雅黑、苹方、Arial） | 「干净的几何无衬线，现代的字形」 |
| 展示字（黑体、Impact、Arial Black） | 「粗重的展示字，有张力的笔画」 |
| 等宽 | 「等宽的技术感字体，字宽固定」 |
| 手绘、墨迹类画风或没定字体 | 「手写的有机笔画，自然的变化」 |

装饰性或背景文字、海报、情绪词、要有自己身份的封面 wordmark、手绘画风、本身就带年代字形的画风，都不用这张表。

### 不画品牌

图里不要出现可辨认的 logo、商标或产品外形，除非用户明确说明是自己拥有的真实品牌资产。
