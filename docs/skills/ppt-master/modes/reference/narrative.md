# 叙事（narrative）

故事弧式的说服。带着受众走过情境 → 张力 → 化解，用悬念、转折和以人为中心的讲法，让论点先在情感上落地，再在逻辑上落地。适合路演、案例、品牌历程、融资。

## 叙事骨架

**弧线贯穿整套 deck，也贯穿合适的节拍**：情境 → 冲突 → 化解。立下利害、拉高张力、化解它，再接到下一个节拍，但不把完整的弧硬套到每一页上。

**悬念和兑现**：在对的时刻抛出问题，在证据落地的那一拍回答它。让好奇心拉着受众往前走。

**以人为中心**：把抽象的论点落到一个主人公、一个时刻、一个具体的利害上（「一个团队用两周而不是三个月就上线了」）。

**叙事要动起来**：素材支持的地方，用一次重新定义、一次揭晓或一次利害变化。顺序要真的往前走，而不只是给平铺的陈述换个标签。

标题读起来是推动故事弧的节拍（「然后，数字开始对不上了」），不是标签。

## 页面结构倾向

- 按张力、兑现和受众的疲劳程度，交替安排密集页和留白页；不强求机械的交替
- 用视觉分量引着视线走过每一拍（主视觉图、一个焦点数字、一段引语）
- 一章之内保持连贯，章与章之间变化

结构服务于故事弧，不服务于网格：页面上的结构到画页面时按内容现搭，数据图表和表格照常套模板。这个模式决定每页的情绪节拍。

## 演讲备注口吻

聊天式的讲述 —— 像在跟受众说话，而不是念报告。某一拍用得上时，在一页之内也走情境 → 冲突 → 化解。用比喻把抽象的东西讲具体（「就像加了一个涡轮增压」）。朴素的反问制造悬念；每页都从上一页接过来。数据说得口语化（「将近三分之一」「翻了一倍多」）。

## 页面骨架示例

```text
第 3 页（转折）：满版图片 + 一行字 ——「然后，部署崩了。」
第 4 页（兑现）：重新定义 —— 什么变了，一个焦点数字
备注：           「你可能在想，机会到底在哪……」（承上，蓄势）
```
