# 展演（showcase）

视觉领衔的冲击。让图像、尺度和节奏承载信息；文案压到最少，存在感拉满。适合产品发布、品牌亮相、活动开场、宣传 deck。

## 叙事骨架

**图或数字领衔，文字辅助**：用一张主视觉图、一个大数字或一句短语确立压倒性的视觉层级；辅助元素可以同页，但不抢焦点。

**情绪节奏**：蓄势再释放 —— 一串大胆的页面，中间夹一页安静的。为感受安排节奏，不为密度。

**主要想法要说得大**：每页围绕一个清楚的要点，用大尺度表达出来；受众需要背景才能理解或相信这个要点时，保留辅助背景。

**揭晓结构**：先按住，再揭晓（产品、结果、口号），把效果拉满。

标题短而有画面感 —— 一个短语，不是一句话。

## 页面结构倾向

- 满版图片加压在上面的文字；一个焦点主视觉数字或短语
- 主要的视觉关系周围留大片负空间
- 大胆用 deck 的主题色营造氛围（封面、章节页）

主视觉、满版、留白页的具体几何到画页面时再定；这个模式决定每页把什么放在最前面。

## 演讲备注口吻

有能量、有画面感 —— 定下情绪，制造期待。句子短而有力。让画面去干活，讲的是画面周围的那份感受。

## 页面骨架示例

```text
揭晓页：满版产品图 + 一行字 ——「新的标准，来了。」
证明页：一个巨大的数字「10×」+ 一个短语，大片留白
备注：  「想象一下，把它缩短到几秒钟。这就是它做到的事。」
```
