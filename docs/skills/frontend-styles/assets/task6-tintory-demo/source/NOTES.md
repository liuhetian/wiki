# Tintory Studio React 复刻

- 来源：用户提供的 86 秒录屏与首页截图。
- 模式：视觉复刻（L3，多栏目 React 单页站）。
- 技术栈：React + Vite，纯 CSS 动画与响应式布局。
- 已实现：首页、Graphic、Fashion、Culture、Journal、Contact；哈希路由；卡片悬停；平滑滚动；移动端菜单。
- 素材：Culture 图片从用户提供的录屏帧中裁切，仅用于本地复刻演示。
- 运行：`npm install && npm run dev`
- 已知差异：录屏没有提供原项目源码，因此字体、部分图片和长页正文为视觉拟合；登录、CMS 等后端能力不在范围内。
