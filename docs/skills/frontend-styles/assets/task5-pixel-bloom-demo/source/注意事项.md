# 鼠标网格揭示效果

## 效果总结

页面由一张简洁主图和多张隐藏状态图叠加组成。鼠标移动时，以网格化笔刷逐块显示隐藏图的真实纹理，形成连续的涂抹轨迹；点击可切换隐藏状态，一次涂抹只使用一种效果。该机制与具体主题无关，替换对齐后的图片即可复用。

## 注意事项

- 主图应简洁，隐藏图应有更丰富的纹理、结构或环境变化。
- 不同状态不能只改变颜色；黑白状态下也应能明显区分。
- 各图片的尺寸、构图、主体位置和关键轮廓必须保持一致。
- 所有图层必须使用相同的缩放、裁切和坐标映射规则。
- 每个格子应复制隐藏图的真实图像区域，不要用单个采样色填满。
- 一次连续涂抹只显示一种状态，切换时应清理上一条轨迹。
- 点击与拖动需要通过移动距离阈值区分，避免误触切换。
- 格子尺寸、笔刷半径、采样间距和轨迹时长不能使用固定像素。
- 响应式缩放必须匹配图片布局：`cover` 使用最大轴比例，`contain` 使用最小轴比例。
- 大画面应同步扩大笔刷并延长轨迹寿命，保证相对覆盖范围一致。
- 先验证采样、对齐、切换和响应式，再调整具体美术主题。
