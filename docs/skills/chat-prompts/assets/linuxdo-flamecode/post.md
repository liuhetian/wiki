土豆姐 Lauren Tan 的核心不是"更聪明的提示词"，而是"更可信的环境"。
信任倒金字塔：把精力从上到下投在确定性更强的地方。
1、代码库与架构：API 设计、目录边界、重构，让正确写法成为默认路径。
2、静态分析：Lint、类型系统、编译器、测试，机器自动拦截。
3、验证：运行时验证加形式化验证，确认真的跑通。
4、自然语言规则：AGENTS.md、Skills，只留需要判断的部分。
5、人工审查：成本最高，尽量收缩到只看验证产物。
关键动作是：每次纠正 Agent，先问"能不能变成一条确定性检查"，而不是往文档里再加一行规则。
内外双循环可以这样理解。
内循环：单个 Agent 自己跑、自己验证、自己举证，先别急着并行。
外循环：当内循环足够稳，再用编排层调度大量 Agent 并行干活，自动开 PR、跑验证、合入。
她团队一个月合入约 1.1 万个 PR，回滚率约 0.5%，前提就是内循环先不掉链子。
一句话概括：先修好 Agent 干活的环境，再谈规模化；内循环产出是垃圾，外循环只会更快地产出更多垃圾。
