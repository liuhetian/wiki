# 让AI说人话，1.3万人收藏了这招

让AI说人话，Karpathy 今天早上给了个很土的办法：照着一份飞机维修手册的写作规范来写。
	
这份规范叫 ASD-STE100，写给维修工看，一句指令最多 20 个词，一个词只许有一个意思。他这条长推收藏 1.3 万，比点赞还多。
	
他最看好的是 AI 做讲解视频，我不同意，至少现在不同意。我觉得视频治不了啰嗦，AI 写得绕，拍出来也是绕的。我不会先折腾视频，先用第一招。
	
图里有三段能直接复制的中文提示词，和一张什么内容用什么格式的选择表。规范是英文的，中文句子该卡多少字，我还没想好，你们试了可以说说。
