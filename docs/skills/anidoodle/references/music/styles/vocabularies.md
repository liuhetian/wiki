# 风格词汇

> 本页由 `node tools/music.mjs vocab --md` 从 `engine/src/canvas-core/music/vocab.ts` 和 `vocabMore.ts` **生成**。不要手工编辑；本站是中译版，重新生成会得到英文原版。一种风格是一套词汇：声音、律动、和声语言、旋律规则、编曲语法。它从不包含音符。音符由你来写（[../compose.md](../compose.md)）。

**电平是同一把尺。** 一个槽位里的每个音色，无论是调色板自带的、备选的还是你自己的，都校准到该槽位的分轨目标（即「分轨目标 dB」一列：这个声部发声时分轨电平表的读数）。你设的一切都是相对这个目标的 dB 偏移：`levels: { lead: 2 }` 是比目标高 2 dB，你自己音色的 `gainDb` 也一样（`voices: { counter: { inst: "strings", role: "color" } }` 落在 counter 的目标上；`gainDb: -3` 落在它下面 3 dB）。引擎增益（vocab.ts 里的 `Voice.gainDb`）是内部值，永远不在这把尺上。

## 律动族

挑一个族和它的旋钮（`density`、`variation`、`fill`、`accent`）；随机种子每小节都变。也可以自己写鼓的小节。

- `bounce`：lo-fi / 嘻哈的弹跳：第 1 拍底鼓加切分的弱起，第 2、4 拍后拍（backbeat），幽灵音，带重音的八分或十六分踩镲
- `fourFloor`：house / drive：每拍一个底鼓，第 2、4 拍拍手，反拍上的开镲，密的时候用十六分
- `halfTime`：半速：第 1 拍底鼓（加一个弱起），第 3 拍军鼓；同样的速度听起来慢了一倍（喘一口气，换一个场景）
- `broken`：碎拍（broken beat）/ garage：底鼓错开网格，后拍保留，十六分幽灵音；躁动、现代
- `shuffle`：shuffle：三连音网格，摇摆的踩镲，第 1、3 拍底鼓带一个跳音；俏皮、有弹性
- `pulse`：脉动：轻柔的心跳底鼓，没有后拍，稀疏的沙锤；氛围音乐和电影里垫在底下的配乐
- `brushes`：鼓刷：第 2、4 拍轻敲鼓边，沙锤的刷声，轻柔的底鼓；温柔、原声
- `build`：推进：军鼓先打八分再打十六分，整段里力度不断上升，底鼓打四分；结束在下一个强拍
- `tension`：张力：3-3-2 的底鼓固定音型，第 4 拍重音，轻声的十六分踩镲；电影式的紧迫感、追逐戏
- `skip`：跳跃：第 1 拍和第 2 拍的后半拍底鼓，第 2、4 拍拍手，一条跳跃的十六分打击乐；俏皮、轻盈
- `trap`：trap：稀疏的切分底鼓（808 贝斯跟着它们走），第 3 拍拍手，带力度渐变和连击的十六分踩镲，时不时一个开镲
- `epic`：史诗：3-3-2 或「第 1 拍和第 3 拍」型的大低音重击（底鼓 / perc 里的定音鼓），第 4 拍一个军鼓重音；管弦乐和预告片的分量
- `hand`：手鼓：每组开头一个 dum（低音），组内是 tek（鼓边），ka（perc）加花；分组跟着拍号走（7/8 = 2+2+3，9/8 = 2+2+2+3，5/4 = 3+2）
- `rock`：摇滚：第 1、3 拍底鼓带一个八分弱起，军鼓打后拍，八分踩镲，每段开头一记吊镲（perc）
- `swing`：爵士摇摆：叮叮镲打在拍上以及第 2、4 拍摇摆的跳音上，第 2、4 拍踩镲踏板（perc），轻踩的底鼓，军鼓的伴奏式幽灵音

## 段落类型（编曲语法）

段落类型决定哪些层可以发声；你写的旋律线只在你写了的地方发声。

- `intro`（鼓：无，贝斯：无）：只有和弦（以及你写的任何旋律线），没有鼓和贝斯：定下色彩，亮明调性
- `verse`（鼓：main，贝斯：有）：律动托着一条较轻的旋律线：给画面和文字留出空间
- `groove`（鼓：main，贝斯：有）：和弦、贝斯、鼓：打底的床，没有主旋律，除非你写一条
- `hook`（鼓：main，贝斯：有）：完整的律动托着动机：让人记住的那部分
- `build`（鼓：build，贝斯：有）：密度上升（军鼓从八分到十六分），旋律线上升，落在下一个强拍
- `half`（鼓：half，贝斯：有）：半速的鼓：同样的速度听起来更慢（换一个场景，一口带着脉动的气）
- `breakdown`（鼓：无，贝斯：无）：鼓和贝斯撤出，只剩和弦和一条单薄的旋律线：落地之前屏住的那口气
- `drop`（鼓：main，贝斯：有）：所有层在一个强和弦上回来：这就是落地，把它放在画面的关键拍上
- `bridge`（鼓：main，贝斯：有）：回到主调之前，离开主调的新和声（借用的或关系调的区域）
- `swell`（鼓：无，贝斯：有）：长音在 2-8 小节里渐强（管弦式的 swell），在紧随其后的强拍上达到顶点
- `breath`（鼓：无，贝斯：无）：近乎静默：一个延长的和弦或什么都没有，有意写出来的（最多 2 小节）
- `outro`（鼓：无，贝斯：有）：主和弦延长，动机的最后一句话，然后是尾音

## `lofiElectronic`：lo-fi 电子

温暖、放松但轻快、干净：会呼吸的铺底、穿过乒乓回声的拨奏 hook、圆润的超低音、有弹性的鼓组。速度 80-100 bpm，拍号 4/4，摇摆 0.52-0.56。

| 槽位 | 音色 | 分轨目标 dB | 备选（名称，音色） |
|---|---|---|---|
| chords | `warmPad` | -22 | strings (`strings`), piano (`piano`) |
| lead | `softPluck` | -15.5 | bell (`fmBell`), mallet (`marimba`), guitar (`guitar`) |
| counter | `softPluck` | -20 | - |
| bass | `sub` | -18.5 | warm (`bass`) |
| kick | `kick` | -14.5 | - |
| snare | `snare` | -19 | - |
| ghost | `snare` | - | - |
| hat | `hat` | -24.5 | - |
| arp | `softPluck` | - | - |
| perc | `hat` | - | - |

分轨目标：在一份有人听过的配乐上校准。

- **和声语言。** 调式：major、dorian、lydian、aeolian、mixolydian。和弦性质：七、九、十一和十三和弦；add9；sus2/sus4 用来透气；除了落点，避免光秃秃的三和弦。倾向：2、4 或 8 小节的循环；ii-V 进行、IV-iii-vi 的漂移、调式循环段（多利亚里的 i-IV，利底亚里的 I-II）、借用的 iv 或 bVII 做一个怅惘的转折；主和弦落在结构性的拍上。和声节奏：每小节一个和弦或两个和弦；换和弦可以比小节线早一个八分音符。声部排布：无根音的 3-4 音排布，在 E3 和 E4 之间级进移动（共同音保持不动）；根音归贝斯。张力与解决：sus4 和十三和弦带着倾向，maj7#11 漂浮，属 7b9 或借用的 iv 带着酸楚；把带倾向的声部向下解决一级。
- **旋律。** 音域：主旋律 C4-A5，副旋律线在高一个八度处。轮廓：短的拱形；最高点在乐句的后半；答句结束得更低。密度：每拍 1-3 个音；留出休止让回声来应答。动机：一个 2-5 个音、有自己节奏的小单元；先重复它，再变化它（上移一级、最后一个音程倒置、错后一个八分音符）；主旋律和副旋律之间一呼一应。
- **编曲。** 前奏 → 律动段 → hook →（半速段或抽空段）→ 落回主和弦的 drop → 尾奏；每次只加或减一层。过渡：一小节加花、一小节半速、鼓撤掉做一段抽空段，然后所有层在一个强拍上回来。结尾：主和弦延长并配上动机的最后一个音，或者在第 1 拍上一记干净的收尾短击（button）。
- **律动：** bounce、halfTime、broken、skip、pulse、build。**避免：** 合成 ePiano、黑胶噼啪声、降比特（bit-crush）、压暗的母带低通：那是尘感 lo-fi 嘻哈，不是干净的电子乐。

## `drive`：动感电子

向前、明亮、自信：四拍底鼓、泵动的超级锯齿波铺底、粗粝的贝斯线、拨奏琶音。速度 110-140 bpm，拍号 4/4，摇摆 0.5-0.52。

| 槽位 | 音色 | 分轨目标 dB | 备选（名称，音色） |
|---|---|---|---|
| chords | `strings` | -23 | - |
| lead | `strings` | -16 | pluck (`softPluck`) |
| counter | `fmBell` | -19.5 | - |
| bass | `bass` | -16 | sub (`sub`) |
| kick | `kick` | -12.5 | - |
| snare | `snare` | -17 | - |
| ghost | `snare` | - | - |
| hat | `hat` | -26 | - |
| arp | `softPluck` | -20.5 | - |
| perc | `hat` | -26 | - |

分轨目标：从中性测试信号得出的起始数值（有人听过之前仅供参考）。

- **和声语言。** 调式：aeolian、dorian、mixolydian、major。和弦性质：三和弦和强力和弦排布、sus2、add9；小调里用大三和弦的 IV（多利亚）来提气。倾向：i-VI-III-VII、i-v-VI-IV、bVI-bVII-i 的爬升；变化的和弦底下长时间的持续音；最后一遍副歌把调升高一级。和声节奏：每小节或每两小节一个和弦；反拍上的和弦短击。声部排布：铺得宽：低音区用根音-五度-八度，C4 以上用紧凑的三和弦；贝斯线走八分或反拍。张力与解决：移动的和弦底下一个持续音、扣住底鼓不放的推进段、冲进 drop 的上升音效（riser）；在强拍上全体一起解决。
- **旋律。** 音域 A3-E6。轮廓：重复的小单元级进上爬；drop 处大跳。密度：八分和十六分；4/4 里用 3 音一组的琶音（三对二交错，hemiola）。动机：一个 3-6 个音的节奏型 riff，重复时改掉最后一个音；在推进段里把它沿音阶往上模进。
- **编曲。** 前奏（滤波过的）→ 推进段 → drop → 抽空段 → 推进段 → 更大的 drop → 尾奏。过渡：4-8 小节的推进段，drop 前留一拍喘息。结尾：第 1 拍上一记收尾短击，或者律动滤波淡出。
- **律动：** fourFloor、broken、build、halfTime、tension。**避免：** 摇摆、主旋律用柔和的起音、抽空段里超过 4 层。

## `cinematic`：电影感 / 管弦

宽广而动情：弦乐渐强、制造张力的低音固定音型、竖琴和钟的色彩、到达时一记低沉的轰鸣。速度 60-120 bpm，拍号 4/4、3/4、6/8，摇摆 0.5-0.5。

| 槽位 | 音色 | 分轨目标 dB | 备选（名称，音色） |
|---|---|---|---|
| chords | `strings` | -18.5 | - |
| lead | `strings` | -17 | piano (`piano`), bell (`fmBell`), celesta (`celesta`) |
| counter | `harp` | -16.4 | piano (`piano`) |
| bass | `strings` | -19.5 | - |
| arp | `strings` | -21.5 | - |
| kick | `kick` | -16.5 | - |
| snare | `snare` | -24 | - |
| ghost | `snare` | - | - |
| hat | `hat` | -32 | - |
| perc | `fmBell` | - | - |

分轨目标：从中性测试信号得出的起始数值（有人听过之前仅供参考）。

- **和声语言。** 调式：aeolian、harmonicMinor、lydian、major、phrygian、dorian。和弦性质：空五度、add9、sus2/sus4、小调里用大三和弦的 IV；用半音中音关系（C 到 E、C 到 Ab）营造敬畏感。倾向：慢的和声节奏（每个和弦 1-2 小节）；史诗感用 i-bVI-bVII-i，戏剧感用 i-iv-V，奇妙感用利底亚的 II，张力用移动和弦底下的持续低音；大的到达落在半音中音关系的和弦上。和声节奏：每 1-2 小节一个和弦；张力段落在一个固定音型上保持一个和弦。声部排布：铺得很开：C3 以下的低音八度、空五度、高潮时旋律做八度叠加（把贝斯错开，让峰值保持音乐性）。张力与解决：与持续音相撞的小二度、倾向 5 级音的 b6、长时间保持的挂留四度、和声小调升高的 7 级音；解决到大三和弦或皮卡迪三度（picardy third）。
- **旋律。** 音域 G3-C6（弦乐），竖琴和钟在其上。轮廓：跨 4-8 小节的长弧线，一个大跳（六度、八度）后级进下行。密度：每拍 0.5-2 个音；张力用的固定音型每拍 2-4 个。动机：一个 3-4 个音的乐思，每次回来都经过变形：高潮时扩大（放慢），放到低音里表现威胁，放到竖琴上表现温柔。
- **编曲。** 前奏（一种色彩，一个持续音）→ 主题 → 渐强 / 推进 → 落在画面关键拍上的高潮 → 释放 → 安静的尾声。过渡：4-8 小节的渐强；到达前静默地喘一口气；强拍上一记低沉的轰鸣。结尾：一个延长和弦一直响进尾音，或者在剪辑点上硬收。
