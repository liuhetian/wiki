# 曲式、编曲、配器、对位

## 1. 歌曲曲式（以及引擎的段落种类）

| 曲式 | 形状 | 引擎的段落种类 |
|---|---|---|
| 主歌-副歌（verse-chorus） | 前奏、主歌、副歌、主歌、副歌、桥段、副歌 x2、尾奏 | intro, verse, hook, bridge, drop, outro |
| AABA（32 小节） | A（主曲调）、A（结尾有变化）、B（对比：新的调性区域）、A | verse, verse, bridge, hook |
| 循环 / beat | 4-8 小节的循环；每 4-8 小节有声部层进出 | groove, hook, half, breakdown, drop |
| 推进-爆发（build-drop，EDM、预告片） | 前奏、推进（riser）、换气、drop、尾奏 | intro, build, breath, drop, outro |
| 通谱体 cue（through-composed） | 动机陈述、发展、高潮、尾声 | intro, verse, swell, hook, outro |

- 副歌（hook）承载**动机最清晰的陈述**、最满的声部层次和最"在家"的和声。
- 主歌更轻，留出空间。
- 桥段去往新的地方：借用调或关系调的区域、新的节奏、更薄的织体。然后它**回归**。
- 回归造就曲式。A-B-A 令人满足，是因为 B 让 A 重新变得新鲜（Huron 2006：期待先被建立，然后被满足）。

## 2. 电影 cue 的结构（为画面配乐）

一线的电影作曲家围绕**卡点**（hit points）来组织一个 cue：卡点就是有事情发生的那些帧（Karlin & Wright 2004；Davis 2010）。

1. **定位 cue（spotting）。** 列出各个节点及其时间：揭晓、口号、剪切、logo。
2. **挑 1-3 个同步点**，给它们一个结构性的强拍：一次抵达、一次击打，或者一次声部层次的变化。不要什么都卡。每个剪切都卡点叫作"米老鼠式配乐"（mickey-mousing），用在喜剧里没问题，用在别处会让人疲惫。
3. **速度由画面决定。** 选一个 bpm，让关键卡点落在强拍上（引擎的 `fitScore` 和 `stretch` 能帮上忙）。一小节持续 `beatsPerBar x 60 / bpm` 秒。
4. **形状：**
    - 确立（动机，低密度）；
    - 发展（模进，和声上行）；
    - 一次换气（一小节近乎安静）；
    - 顶峰落在关键帧上（高潮音、全部声部层次、主和弦）；
    - 释放；
    - 一个收尾重音（button）或尾音。
5. **刺点（stinger）：** 在突发的画面事件上来一小节的击打，放在网格之外（`hit: true`）。
6. **给对白留出空间。** 在人声底下，削薄 1-4 kHz 频段。主奏保持在低位或者休止（tacet），让和弦承担和声。

## 3. 推进与释放

- 用 4-8 小节来**推进**：密度上升、音区上升、和声节奏加快（进入终止式时快一倍）。用属持续音或挂留和弦、动机的片段，以及渐强。结束在倾向上（V、sus4、一次换气），绝不结束在主和弦上。
- **释放：** 在强拍上落到主和弦，声部层次最多，动机以扩大形式或完整形式出现，并带上高潮音。
- **顶峰之前，先来一个下陷：** 一段 breakdown、一次换气，或者鼓组撤出。对比造就落地（见 [harmony.md](harmony.md) 里的张力曲线，以及 `craft` 的张力那一行）。
- **结尾：**
    - 一个保持的主和弦，加上动机的最后一句话；
    - 一个收尾重音（在 1 上的短促全奏击打）；
    - 只有循环曲才用淡出；
    - 只有悬疑才用开放的保持。

### 整体的形状，量出来

一首配乐可以有好曲调、好和声、干净的混音，却仍然让人觉得在游荡，因为里面没有哪里是最高点，也没有哪里是休息。`music.mjs check` 会根据成品声音（`arc.ts`）打印一行 **ARC**：通常电平、最响的时刻以及它出现在全曲多远处、开头比主体低多少、结尾比顶峰低多少。它和 `craft` 一样只是建议：逐条回应每一项发现，或者说明这首曲子为什么有意如此。

- **轻轻地进来。** 开头两三秒声部更少，也没有低音鼓，比主体低 5 到 12 LU。第 0 帧依然要有一个有理由的声音：一个持续低音、第一个和弦。用一小节从静默渐强进来，会被读作还什么都没发生。
- **一个最响的时刻，落在画面的回报点（payoff）上。** 至少比通常电平高 2 LU，通常位于全曲的三分之一到三分之二处。传入回报点所在的秒数（`--payoff 13.5`），检查就会告诉你最满的那一小节是否在别处。在那之前留一手：低音鼓、最高的八度、一层重叠。
- **对比就是弧线。** 20 s 及以上的曲子需要 5 到 8 LU 的响度范围。从头到尾只有一种织体，测出来大约是 2，不管每小节写得多好，听起来都密而平。
- **结尾是做减法。** 收尾是最有解决感的时刻，绝不是最响的：停在小节线上、一次换气、一个轻柔的元素，比顶峰低 8 到 20 dB。最响的时刻落在最后五分之一会被标记出来。
- **循环曲没有开头也没有结尾。** 只读取它的对比和它的接缝。当最后一秒和第一秒相差超过 3 LU、并且超过曲子内部任意两个相邻秒之间的差距时，接合处会被标记：一个收进安静小节的乐句是音乐本身，一个在别处都找不到的台阶才是接缝。

## 4. 配器：音区与频率槽位

每件乐器都拥有一个音区。处在同一音区的两个声部会打架（掩蔽，见 [sound.md](sound.md)）。编曲时给每个声部分配它自己的槽位：

| 槽位 | 范围（基频） | 归谁 | 规则 |
|---|---|---|---|
| 超低频（sub） | 30-60 Hz（B0-B1） | 底鼓的主体、808/sub 贝斯 | 同一时间只归一个；单声道 |
| 低频（bass） | 60-250 Hz（B1-B3） | 贝斯、大提琴/低音提琴、钢琴左手、大号 | 根音；只用空五度和八度 |
| 中低频（low-mid） | 250-500 Hz（B3-B4） | 和弦、pad、吉他的主体、低音铜管、男声 | 浑浊区：削薄它，别往上叠 |
| 中频（mid） | 500 Hz-2 kHz（B4-B6） | 旋律、主奏、小提琴、小号、长笛、女声 | 主奏的家；同一时间只有一个主奏 |
| 临场感（presence） | 2-5 kHz（谐波） | 起音、辅音、军鼓的脆响、拨片声 | 让声部被听见的东西；不是所有东西都要亮 |
| 空气感（air） | 5-16 kHz | 踩镲、沙锤、镲片、气息声、闪亮声（钢片琴、钟琴） | 轻轻点缀 |

指导原则：

- **间距遵循泛音列：** 低处用宽音程，高处用窄音程（Rimsky-Korsakov 1913；Adler 2016）。
- **重叠（doubling）：**
    - 八度重叠增加分量和亮度；
    - 同度重叠增加厚度和合唱感；
    - 用三度或六度重叠的旋律听起来甜美（流行、民谣）；
    - 在古典语汇里，不要重复导音或和弦七音。
- 高潮之外，**同时最多 3-4 个乐器族**，各占其槽位。同时五种功能是一个有用的上限：
    1. 基础（贝斯和鼓）；
    2. pad（持续的和声）；
    3. 节奏（移动的伴奏）；
    4. 主奏；
    5. 加花和对位。

    （Owsinski 2017，编曲的构成元素。）
- **用音色做对比：** 第二次陈述时把动机交给一件新的乐器。不改一个音，就有了新意。

## 5. 对位基础（一条起帮助作用的第二旋律线）

对位旋律（counter-melody）是一个保持独立的第二声部（Fux 1725，*Gradus ad Parnassum*；Jeppesen 1939）：

- **旋律保持时它动，旋律动时它保持**（互补节奏）。`counterMelody` 守卫要求共同起音最多占 50 %。
- 相对于旋律，**优先用反向进行和斜向进行**。以同向进行进入五度或八度会把对位声部藏起来。
- **强拍上用协和音程**（三度、六度、五度、八度）。不协和音在弱拍上以级进经过，或者作为向下解决的挂留音出现。
- **有它自己的音区**，与曲调相距三度到十度，最好音色也不同。
- **呼应（call and response）：** 对位声部在旋律的休止处作答。这是流行和电影里最容易、也最地道的对位。
