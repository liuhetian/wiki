# 和声：功能、声部进行、色彩、张力

罗马数字是相对于调而言的（大调中是 `I ii iii IV V vi vii°`，小调中是 `i ii° III iv v VI VII`，`b` = 借用或降低）。这些是惯用进行，也就是词汇。一个多小节的和弦进行连同它的节奏和律动就是一首作品了，新颖度检查查的正是这个。`craft` 在 **harmony** 那一行检测本页的内容。

## 1. 功能：家、离开、倾向、回家

| 功能 | 和弦（大调） | 感觉像 | 用途 |
|---|---|---|---|
| 主功能（T） | I、vi、iii | 家、休息 | 开头、抵达、结尾 |
| 下属 / 前属功能（S） | IV、ii、（bVI、借用的 iv） | 离开、打开 | 主歌、桥段、倾向之前 |
| 属功能（D） | V、V7、vii°、（摇滚 / 调式音乐中的 bVII） | 倾向、想回家 | 抵达之前的那一小节 |

标准的进行是 T -> S -> D -> T。电影和流行音乐常常跳过 D（`I bVII IV I`，一种变格或调式的世界），以获得温暖感，而没有古典式的"推力"。

## 2. 终止式：乐句在这里换气

| 终止式（cadence） | 进行 | 效果 | `craft` 标签 |
|---|---|---|---|
| 正格终止 | V(7) -> I | 句号，抵达 | `authentic` |
| 变格终止 | IV -> I（或 iv -> I） | "阿门"，柔和，像赞美诗 | `plagal` |
| 调式终止 / 后门终止 | bVII -> I、bVI -> I、bII -> I | 摇滚、电影、史诗般的温暖 | `modal` |
| 半终止 | ... -> V | 一个问题，一个逗号 | `half` |
| 阻碍终止 | V -> vi（或 bVI） | 意外，"还没完"，延长一个乐句 | `deceptive` |

把半终止和阻碍终止放在曲子内部，把完全终止放在结尾。`craft` 会列出每个段落的结尾。如果最后一段之前没有任何地方换气，或者一首非循环的曲子结束在离家之处（惯用法允许开放式结尾的情况除外），它会发出警告。**循环曲在结尾不应该终止回主和弦**。而是要倾向回第 1 小节（结束在 V、IV 或一个回转进行（turnaround）上）。

## 3. 声部进行

和弦是在移动的声部，不是一块块的积木（Aldwell & Schachter 2011；Tymoczko 2011）：

- **保持共同音。** 其余每个声部都移到下一个和弦里**最近**的那个音上。高效的声部进行平均每次换和弦、每个声部移动 1-3 个半音（`craft` 的 "voice motion" 一项）。
- 低音和旋律之间的**反向进行**带来独立性和力量。
- 在共性写作时期的语汇里（众赞歌、合唱、管弦乐、夜曲、摇篮曲、八音盒、电影感），独立声部之间**不要有平行五度或平行八度**。它们会把两个声部融成一个。`craft` 在这些风格里会发出警告，在其他风格里只做记录。平行五度正是摇滚强力和弦、爵士 / house / lo-fi 里的平移（planing）以及民谣持续低音的**声音**本身。用八度重叠一条旋律线是配器，不是毛病（`craft` 单独统计它），合唱除外。
- **内声部**级进或保持不动。内声部跳超过五度是声部排布上的失误。
- **倾向音：** 导音（7）上行到 1。和弦七音级进下行。挂留四音下行到 3。

## 4. 声部排布与低音区

- **低处疏，高处密。** 大约 C3 以下只用八度和五度。三度从大约 C3 往上放，二度从大约 E3 往上放。`craft` 会标记低于**低音区音程下限**（low interval limits）的密集音程（见 [sound.md](sound.md) 里的图表和 `craftTables.ts`），因为它们会变得浑浊。
- **根音归低音**（或者一个选定的转位）。和弦声部在它上方，自占一个八度。
- **按风格选声部排布：**

| 风格语汇 | 声部排布 |
|---|---|
| 古典 / 合唱 | SATB 四部，重复根音，密集或开放排列，V 中绝不重复三音 |
| 爵士、lo-fi、neo-soul | E3 到 E4 之间无根音的 3-7-9 或 7-3-13 骨架和弦；根音由低音负责（Levine 1995） |
| 流行 / 钢琴抒情曲 | 左手根音-5-8，右手三和弦或 add9 |
| 摇滚 | 吉他低音区的强力和弦（1-5-8）；键盘在更高处补上三音 |
| 电影 / 管弦乐 | 低音弦乐用空五度，中提琴和小提琴上用三和弦，用八度重叠增加分量 |
| 氛围 / pad | add9、sus2 和 maj7#11 音簇，放得又高又宽 |

## 5. 色彩：调式、借用和弦、扩展音

| 色彩 | 做法 | 感觉 |
|---|---|---|
| 利底亚（Lydian）`#4` | I -> II（大三和弦） | 惊奇、飞翔、魔法（电影里的"飞行"音乐） |
| 混合利底亚（Mixolydian）`b7` | I -> bVII -> IV | 阳光、摇滚、随和 |
| 多利亚（Dorian）`6` | i -> IV（大三和弦） | 苦乐参半，向前推进 |
| 弗里几亚（Phrygian）`b2` | i -> bII | 威胁、炽热 |
| 借用的 iv | I -> iv -> I | 突如其来的心痛，怀旧（"小 iv"） |
| bVI 和 bVII | I -> bVI -> bVII -> I | 史诗、英雄式的上扬 |
| 半音中音关系（chromatic mediants） | I -> III 或 I -> bVI（大三和弦） | 敬畏、场景的转折、电影里的"魔法"转换（Lehman 2018） |
| 扩展音（extensions） | maj7、9、11、13 | 温暖和精致（爵士、lo-fi）；三和弦听起来更朴素、更大胆 |
| 挂留和弦（sus） | sus4 -> 3、sus2 | 开阔；一种会得到解决的倾向 |

## 6. 副属和弦、持续音、转调

- **副属和弦（secondary dominant，离调属和弦）：** 在任意和弦 x 之前放 V/x（`V/vi -> vi`、`V/V -> V`）。它为一个和弦加入导音和能量，而不离开原调。
- **持续音（pedal point）：** 在上方和弦变化的同时保持低音（1 或 5）。主持续音带来平静或持续低音（drone）的效果。属持续音带来抵达之前的推进。
- **转调：**
    - 共同和弦转调（平滑，开启新的一章）；
    - 在最后一遍副歌直接上移一个全音或半音（带来能量；在该段落上声明）；
    - 半音中音关系（电影感）；
    - 关系大小调（情绪转变，用的是同一组音）。

## 7. 和声节奏：步调

和弦变化的频率和速度一样决定着步调。

- 每 2 小节 1 个和弦：平静、空旷、氛围、敬畏。
- 每小节 1 个：歌曲的默认值。
- 每小节 2 个：紧迫感、爵士、接近终止式。

**进入终止式时加快和声节奏**（就是句子的延续部分），抵达之后放慢。在强拍上换和弦。提前一个八分音符的先现没问题；在拍与拍之间换和弦会模糊节拍（`craft` 的 "chord changes on beats" 一项）。

## 8. 张力曲线

`craft` 会画出逐小节的张力曲线。感受到的张力首先跟随强度，其次才是和声（Farbood 2012），所以按下面的方式混合：

| 项 | 权重 | 它读取什么 |
|---|---|---|
| 响度（loudness） | 0.35 | 该小节里每个发声的声部，取力度的平方（包括段落的 `energy` 和 `chordVel`），按各自的分轨目标加权；曲子最响的小节记为 1，比它低 12 dB 时记为 0 |
| 密度（density） | 0.25 | 每拍起音数，与曲子最繁忙的小节相比 |
| 音区（register） | 0.15 | 旋律在其音域内的平均音高（旋律休止时取最高声部） |
| 和声倾向（harmonic lean） | 0.25 | 和弦根音离主音的距离（Lerdahl 2001，简化版；0.15）以及该音响的不协和度（Huron 1994 的音程类评分；0.10） |

所以一个落在主和弦上的全奏高潮或者一个 EDM drop 会被读作顶峰：它的和弦处于静止，但所有声部都在演奏，又响又高。一个安静地倾向着的属和弦则不会。`craft` 在曲线下方打印每个段落的这四项数值，让你看到是什么在驱动它。

在写音符**之前**先规划好这条曲线：上升，顶峰之前一个小下陷（一次换气或 breakdown），顶峰落在画面的关键时刻，然后释放。曲线平坦、第一段最紧张、或者最后一段没有释放时，它都会警告。循环曲、氛围曲或平静的曲子是有意保持平稳的（网站循环曲属于低唤醒度：见 [mood.md](mood.md)），所以在那里平坦的曲线只是一条提示，不是警告。
