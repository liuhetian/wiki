# 旋律：动机、轮廓、乐句

本页的记谱法：音级（`1 2 3 ... 7`、`b3`、`#4`；`5,` = 低一个八度，`1'` = 高一个八度），时值以拍为单位写在冒号后面（`3:.5`）。这些是拿来套用的形状，绝不是拿来照抄的曲调。`node tools/music.mjs craft <score>` 会检测下面的每一条规则（**melody** 那一行以及 `CRAFT melody:` 的各项发现）。

## 1. 从一个动机出发，然后发展它

动机（motif）是 2-5 个音，带着**它自己的节奏**。节奏就是它的身份：听众远在记住确切的音程之前，就已经靠节奏和轮廓认出一个动机了（Schoenberg 1967，第 2-3 章；Dowling 1978）。先写节奏，再写音高。

| 手法 | 改变什么 | 例子（从动机细胞 `1:.5 2:.5 3:1` 出发） | 效果 |
|---|---|---|---|
| 重复（repetition） | 什么都不变 | 再来一遍这个细胞 | 起锚定作用：耳朵把它学会 |
| 变化重复 | 最后一个音程或音 | `1 2 5` | 保住身份，增添趣味 |
| 模进（sequence） | 起始音高（形状不变） | `2 3 4`，然后 `3 4 5` | 推动感、能量上升；最多连 3 环，然后打断 |
| 倒影（inversion） | 每个音程的方向 | `3 2 1` | 一种回答，情绪的转折 |
| 逆行（retrograde） | 音的顺序 | `3 2 1`，并把节奏倒过来 | 少用，一种隐藏的回声 |
| 扩大（augmentation） | 时值 x2 | `1:1 2:1 3:2` | 分量、抵达感，用于高潮或结尾 |
| 紧缩（diminution） | 时值 /2 | `1:.25 2:.25 3:.5` | 紧迫感，推进 |
| 裂解（fragmentation） | 保留 2-3 个音并反复 | `2 3, 2 3, 2 3` | 顶峰之前的推进 |
| 移位（displacement） | 晚一个八分音符开始 | `r:.5 1 2 3` | 切分、律动、意外 |
| 重配和声（reharmonisation） | 下面的和弦 | 同样的音，下面换成 vi 而不是 I | 新的色彩，同一个曲调 |

一首成立的配乐通常只有**一个**乐思，出现 6-12 次，每次都不完全一样，最多再有第二个乐思来回答它或与它形成对比。`craft` 会报告每个乐句（或小节）与前面各句的关系：`exact`、`sequence`、`varied`、`new`。目标是大部分乐句都有回归（`motif returns` >= 50 %），而完全照抄的很少（<= 60 %；lo-fi、house 这类以循环为惯用法的风格可以重复得更多）。

## 2. 乐句与乐段

- **乐句**（phrase）长 2 或 4 小节，以终止式、长音或休止结束（Caplin 1998）。
- **乐段**（period）由两个乐句组成：前句（antecedent，提问）开放式结束，落在 V 上方的 2、5 或 7；后句（consequent，回答）以同样的方式开始，封闭式结束，落在 I 上方的 1。
- **句子**（sentence）是 2 + 2 + 4：乐思，乐思再来一遍（变化或模进），然后是一个延续部分（continuation），把乐思裂解开，并加快和声节奏推向终止式（Schoenberg 1967；Caplin 1998）。
- 乐器之间的一问一答是同一种手法：主奏提问，对位声部在一小节之内回答。

## 3. 轮廓与高潮

- **拱形。** 在成千上万首民歌里，最常见的乐句形状是先升后降（Huron 1996）。下行乐句排第二；乐句在末尾也会往下漂（"乐句末尾下倾"，late-phrase declination，Huron 2006）。
- **每组乐句一个最高点**，放在后半段，常常在大约三分之二处。整首曲子的最高音就是它的高潮：把它放在画面的关键时刻，不要随随便便重复使用。如果曲子在前 30 % 就到达顶点，或者频繁重复最高音，`craft` 会发出警告。
- 让不同乐句的轮廓有所变化：上升的提问，下降的回答。
- 小调主题的旋律线比大调主题位置更低、音程更小（Huron 2008）。这正是它们听起来悲伤的部分原因，所以要有意识地运用这一点。

## 4. 级进、跳进与回补

- **以级进为主。** 在各种文化中，小音程都在旋律里占主导（Vos & Troost 1989；Huron 2006，"音高邻近性"，pitch proximity）。好唱的曲调大约有 60-80 % 是级进。
- **跳进是一个事件。** 用四度或更大的音程来标记动机的开头，或者用来够到最高点。
- **跳进之后要回补。** 跳进之后改变方向，最好是级进，把留下的空隙填上。这在统计上真实存在（"跳进后反向"，post-skip reversal），部分原因是向音域中部的回归（von Hippel & Huron 2000）。`craft` 会统计那些继续朝同一方向走的跳进。
- **例外：** 分解当前和弦的琶音（号角式的 `1 3 5 1'`），以及以琶音或固定音型为惯用法的风格（八音盒、chiptune、synthwave、house）。
- **避免：** 同方向连续两次、又不构成和弦轮廓的跳进；增二度和三全音跳进（作为刻意的色彩时除外）；在任何要听起来像歌唱的旋律里跳超过一个八度。

## 5. 音域与常用音区

- 一个乐句保持在大约一个八度以内。整首曲调保持在十度到十二度以内，除非乐器本身就能覆盖更宽的音域（钢琴、竖琴、合成器）。
- 让每个声部待在它那件乐器的甜区音域里。`craft` 查的是 `craftTables.ts` 里的表（参照 Adler 2016）：超出乐器物理上能演奏的范围的音，是唯一一种手艺错误。
- 旋律位于和弦声部排布的**上方**。低于和弦最高音的旋律会被掩蔽，除非它更响、而且音色不同（男高音音区的主题）。

## 6. 节奏与旋律相结合

- 把动机的长音放在意义所在的地方：要抵达感就放在小节首拍上，要上扬感就放在弱拍上（切分）。
- 动机不从小节首拍起（用弱起，即 upbeat 或 pickup），会带来向前的推动。从首拍起则带来分量。
- 留出休止。从不换气的旋律无法分句，回声效果也需要这些空隙。
- 乐句之间的节奏对比和音高对比同样重要。改变其中一个，保留另一个。

## 7. 和弦外音：情感所在

强拍上用和弦音（`craft` 的 "strong beats on chord tones" 一项；低于 50 % 时曲调会和和声打架）。不协和音应当以下面这些形态出现，每种都有它自己的效果（Aldwell & Schachter 2011，第 9-10 章；Huron 2006 论张力与解决）：

| 类型 | 形态 | 效果 |
|---|---|---|
| 经过音（passing） | 级进、再级进，方向相同，落在弱拍 | 流动、平滑 |
| 辅助音（neighbour） | 级进离开再回来 | 装饰、轻柔的动态 |
| 倚音（appoggiatura） | 在强拍上**跳进**到不协和音，再朝反方向级进解决 | 渴望，那声"叹息"：情感牵引最强 |
| 挂留音（suspension） | 从前一个和弦保持过来的音，向下级进解决（4-3、9-8、7-6） | 隐痛、温柔、延迟的释放 |
| 先现音（anticipation） | 下一个和弦的音提前到来 | 急切，流行和爵士里的上扬感 |
| 逸音（escape） | 级进进入，跳进离开 | 轻轻一甩，俏皮 |

在共性写作时期（common-practice）的语汇之外，加六度和加九度算作色彩音，不算不协和音（Levine 1995）。

## 8. 乐句结尾

- 回答在稳定和弦之上结束于 1、3 或 5。提问结束于 2、5 或 7（在 V 之上），或者结束于一个色彩音。
- `craft` 会报告结束在和弦音上的乐句占比，并点名不在主三和弦上的最后一个音。情绪需要时（悬疑、氛围、好奇）允许开放式结尾，craft 也会如实说明。

## 检查清单

- [ ] 一个动机，先写节奏，出现 6-12 次，并且有发展（模进、倒影、裂解、扩大）。
- [ ] 乐句以 2 小节和 4 小节为单位。提问开放结束，回答回到主音。
- [ ] 拱形。只有一个高潮，在后半段，落在画面的关键拍上。
- [ ] 以级进为主。跳进之后折返。
- [ ] 拍点上用和弦音。想要情感的地方用倚音和挂留音。
- [ ] 每个声部都在它的甜区音域里。曲调位于和弦之上。
