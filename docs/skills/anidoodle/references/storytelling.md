# 故事才是重点

> 这些信条是制作 MECHANICAL LEPIDOPTERA 时挣来的，那部影片就是 [example/](../example/index.md) 里的完整范例。下面每条规矩都在那部片子上付过代价；凡是导演自己犯的错，都照实写明，因为带着伤疤的规矩，人们才会守。

**错误。** 我们起步时的 brief 是「一只发条蝴蝶，画四种样子」：蓝图、孔版印刷（risograph）、水彩、报刊插画式剖视图。四幕，四种好看的样子。我们做出了其中三幕。每一幕都从一张白纸开始，画出它的画面，扇五下翅膀，然后定住。那是一卷画风展示片，里面碰巧有只蝴蝶。没有人被打动，因为谁身上都没发生任何事。客户的修正只有一句话，也是这份文档里最好的一条意见：*它先被**造出来**，然后**活过来**，长得超出了自己的蓝图。* 报刊剖视那一幕整幕砍掉。孔版那一幕几个小时后也砍了。每拿掉一样漂亮的东西，影片就更好一些。

**为什么是这样。** 观众能原谅故事里一幅粗糙的画，却会嫌弃没有故事的精美画面。画风是你说一件事的方式。如果根本没有那件「事」，画风就只是屏保。

**一部影片需要什么，哪怕只有 60 秒：**

- **一个能用两个词加一个箭头说清的转变。** 我们的是：造出来 → 活过来。如果你的是一张清单（「接着我们看它的孔版版本」），那它还不是故事。
- **前三秒里的钩子。** 我们的是：一张白纸开始自己画自己。一个问题就此埋下：它在画什么？不放 logo，不留空白定格，不做任何「交代环境」的东西。
- **一个能在时间线上指出来的转折。** 我们的是第 545 帧：一滴水落在蓝图上。在那之前，是一只手在画一幅画；在那之后，是这幅画在做任何一只手都没做过的事。转折应该由影片世界**之内**的某样东西引起。水能让蓝晒图（cyanotype）显影，也能把它的蓝色洗淡，所以水是从蓝图通往水彩的一座诚实的桥。从油墨到水彩，我们找不到诚实的桥，我们就是由此知道孔版那一幕不属于这部片子。
- **一次实打实的物理升级。** 我们的是一次连续的拉远，从微距到全景，每一次变宽都由一次起飞释放出来。镜头不是在装饰故事，它**就是**故事：世界之所以变大，是因为这只生物变大了。
- **一个改变之后重新出现的视觉信物。** 我们的是那张蓝图纸。在第一幕里它就是整个世界。到了结尾，它是躺在草丛里的一个小小的蓝色长方形，原本画着图的地方空出一个蝴蝶形状，上发条的钥匙留在上面，已经用不着了。没有人指给你看。观众自己发现了它，这就是回报。信物要早早埋下，永远不要解释，让它变小之后再回来。
- **一个会愈合的缺陷。** 第一幕里有一块翅膀面板始终没有装到位。整张蓝图从头到尾，它都挂在自己的投影线上。生物苏醒时，那块面板滑回原位，从此永远是另一种颜色：蓝图的蓝，被带进了生命里。一处瑕疵，先铺垫再兑现，胜过任何程度的打磨。
- **先收束，再留白。** 签名落在最后一个强拍上，之后留五拍让人读它。在拍点上收束，然后让它喘口气。永远不要**正好**停在最后一个事件上。

**修改前 / 修改后。**

| | 修改前 | 修改后 |
|---|---|---|
| 一句话梗概 | 一只生物画四种样子 | 它被造出来，然后活过来，把自己的蓝图留在身后 |
| 结构 | 4 幕 ×（空白、搭建、扇翅、定住） | 第一幕把它造出来。一个不间断的长镜头让它活过来，并打开整个世界 |
| 媒介切换 | 3 次，因为我们有 4 种画风 | 1 次，因为故事有 2 个状态 |
| 结尾 | 定格在完成的版画上 | 草丛里的那张纸、留下的钥匙、一个签名 |

**动手之前的测试。** 用三句话把它说出来。说出转折发生在哪一帧。说出信物是什么，以及它出现的那两帧。对每个镜头都问一句「角色身上有什么变了」；答案是「渲染风格」的镜头，就该剪掉。还有：画面里每个元素都要有一句话的理由。在我们的草地上，每种花的颜色、那条小路和太阳都有理由。那些椭圆形的散景光斑没有，而它们正是眼睛最先认出是假的东西。

**不许冷场。** 最初的孔版幕和水彩幕有一半时长是静止的，开头还是三秒空白的纸面。从那以后的规矩是：从第 0 帧起，每一秒都有看得见的东西在动，而「定格」的意思是镜头缓缓蠕移、主体继续活着。用工具查（逐帧变化像素占比，没有完全相同的连续帧，没有哪个 15 帧窗口的变化低于百分之零点五），**也**用眼睛查：缓缓蠕移的镜头会让每个像素都变，工具满意了，眼睛看到的却是一张静帧。我们就交出过整整一秒这样的画面，后来我才在印样表（contact sheet）上发现它。
