# 剪纸拼贴，逐片贴上（`foxDraw.ts`，建在 `fox.ts` 之上）

按拼贴艺术家的做法来做 fox 样张：从叠层最底下往上贴。`fox.ts` 新增了一个可选的 `Stage`（每一片的状态：已贴好、尚未放上，或拿在手里、带一个偏移和一个抬起高度），一路传进它的图层函数；不传它时，输出和静帧逐字节相同（前后都核对过 md5）。第 0 帧是空白的底板。四遍，每两遍之间休息一拍：天空和暮色色带；山丘和松树，一层一层；狐狸，从远端那一扫尾巴（brush）往前一直到它眼里的那点高光；然后是叶子和草。每一片都悬在叠层上方移动（它的影子宽、远、柔），被放下、压实，影子随之收紧。满版出血的大纸从它自己那一侧的边缘快速滑进来；小片很费手，也很慢。所有图层都贴好以后，这一帧完全按 `fox` 的画法画出来，所以最后停住的那一秒和主图静帧逐字节相同。
