# 绘本铅笔加水彩，绘制过程（`storybookDraw.ts`）

**媒介。** 软石墨和固体水彩，画在暖色的冷压纸上，是 `storybook.ts` 的手笔。角色是 `drawBit`，**原封不动**地通过 `Phase` 调用；`Phase` 是 `Gfx` 的一个子类，由它决定每一遍里画哪些组、每一笔画到多远（先跑一遍普查，一次性记下每个组的类型、包围盒和笔画数）。

**笔触顺序。** (1) 用蓝灰色画结构：头和身体的椭圆、动势线、肩线、脸上的十字线、手臂的动势、脚印；像绘本那样留在完成的画页里。(2) 用铅笔轻轻画出 Bit，从头往下（各组按包围盒的顶边排序），每条轮廓都一笔一笔地画，alpha 0.36，线宽 0.62。(3) 淡彩：画纸的暖色底、天空、桃色的光、草地、阴影、四朵花，然后按 `drawBit` 自己的顺序由后往前画 Bit（腿、靴子、手臂、手、身体、领子、天线光晕、灯泡、头、脸颊），每一块都从形状的左上方（朝着光源的一侧）扩散开。(4) 最终的线条用全力度，先画头，然后是地面线、草、小石子、花茎；最后从笔上弹落颜料点。

**交过学费的坑。** 往一个**池化**图层里画一个渐变（`g.glow`），会改变 Chromium 之后往同一个图层里栅格化铅笔笔画的方式：每个笔画像素差 1/255，于是帧的渲染顺序泄漏进了像素（先是 5/6、后来是 4/8 的探测帧不一致）。现在光晕画在它自己的缓存画布上，再拷贝进来；池子里从来见不到渐变。现在 8/8 一致。
