# 橡皮管动画（rubber hose，1930 年代动画工作室卡通）

模块：`engine/src/canvas-core/rubberHose.ts`（+ `rubberHoseKit.ts`）。主画面：厨房台面上一只咖啡壶正跳到一个舞步的中间，蒸汽打着卷。

**媒介的物理形态。** 在打好定位孔的动画纸上用蓝铅笔画草稿；用**同一种**力度以墨汁描到透明的赛璐璐片上；在赛璐璐片的**背面**用平涂的不透明灰色上色；拍摄之后印到黑白胶片上。

**笔触。** 粗细均匀的墨线（没有粗细变化），带一点手抖，做动画时每张画重新取随机种子（一拍二的线条抖动，line boil）。轮廓在更近的形状开始的地方停下：每个部件都把自己内部区域下面的墨线挖掉，并集轮廓先描成双倍宽，再去掉内部，所以由六块互相重叠的部件组成的手套读起来是一个剪影。四肢是实心的黑面条：从肩到腕一道二次弧线，没有肘。白色四指手套，三道缝线，喇叭形袖口。切掉一角、像缺了一块的派那样的瞳孔（pie-cut）。大大的椭圆鞋，带一处反光。

**边缘。** 硬而均匀。颜色从不做明暗塑造；投影是半透明的平涂形状，不带墨线。

**顺序。** 草稿（先动态线，再大块，再部件）-> 上墨线（先角色，后布景）-> 上色，从笔碰到的地方一个区域一个区域地漫开（先角色）-> 下拉（pull-down）：画面穿过放映机的片门往下走，再作为一份拷贝回来 -> 两秒钟一拍二的舞蹈，落在关键姿势上 -> 定格（= 静帧）。

**调色板。** 只有灰：墨 #16130f，纸白，五种灰；拷贝做了暖色调色（正片叠底 #ecdfc6）。

**胶片。** 每帧偏移一次颗粒贴图（柔光叠加），灯光闪烁，灰尘（暗的 = 正片上的，亮的 = 底片上的），一根毛发，一道齿孔划痕，灯光造成的暗角，圆角片门。片门晃动（+/-1.7 px）只在放映运动画面时出现；静帧用种子 0，不晃动。

**不是马克笔漫画。** koi 是有明暗塑造的赛璐璐色，轮廓线在背光处变粗；这里是单一线宽，不做明暗塑造，只有灰色，外加一份胶片拷贝。

**运动语法。** 一拍二。关键姿势落在拍上（15 帧），身体领先，四肢沿着同一条弧线落后约 2 帧跟上，两个关键姿势之间跳约 26 px，在空中拉伸，落地时挤压。循环动画精确地落回关键姿势。
