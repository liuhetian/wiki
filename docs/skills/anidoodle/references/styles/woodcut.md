# 浮世绘套色木版画（`woodcut.ts`、`woodcutKit.ts`）

**媒介。** 水性颜料调米浆，刷在刻好的樱木版上，用马连（baren）手工拓印到湿润的楮皮和纸（kozo washi）上，一块版一种颜色，每次都把纸靠着见当（kento，版面边缘的一个 L 形缺口和一条直的定位边）放好。

**笔触。** **主版**线（墨，sumi）是两刀之间留下来的一道凸棱：在刻工重新下刀的地方宽度会跳一档，两刀之间略有游移（`carved()`），两条边各自抖动，每个端头都是一个平的斜凿切口。没有毛笔的膨胀，没有钢笔的收尖。实心黑（冠羽、初级飞羽、颈部条纹）是由刀刻出边缘的块面（`gouged()`）。颜色是**平**的，只由木头被留下来的地方决定形状；大面积的平色上显出木板的年轮，以及马连擦得薄的地方出现的胡麻摺（goma-zuri）斑点（`grain()`）。色调只靠**晕染（bokashi）**：上好墨的版用湿布擦过，颜色从满到无渐变，边缘起伏不定。

**边缘。** 主版线硬朗的刀口。平色块落得和主版线差那么一丝（见当套准做得很好，但从来不完美）：每块版都有自己的一点小偏移。凡是别的物体占据的区域，色版在那里都被**刻掉**（天空版绕着鹭和桥刻开），所以白色是裸露的纸，绝不是一种淡色的墨。

**顺序。** 先印主版（见当随它一起空压进底部页边，不着墨）。然后是各块色版，从浅到深：淡墨（usuzumi）天空，黄檗（kihada）黄，远岸，鹭灰，木头，近岸，水，雨灰。晕染版最后印：天空向顶部渐深，河水朝我们这边渐深，桥在它下方水面上的阴影。

**调色板。** 墨（sumi）#1f1b18，淡墨（usuzumi）#c6c1b0，黄 #d49c3a，鹭灰 #9fa4a4，远岸 #adaf9c，木 #a77a4a，水 #9ab5c4，近岸 #7d8a73，雨 #8a8983，普鲁士蓝（bero-ai）#2c4a78，靛蓝 #3a4557。

**纸。** 暖色的楮皮和纸，淡淡的云纹，长而柔软、卷曲的韧皮纤维；留一圈空白页边。

**不是孔版印刷（riso），也不是半调网点（halftone）。** 没有网屏，没有网点，没有荧光色叠印混出新的颜色。刀刻出形状的平色，一条刻出来的主版线，色调靠晕染。

**运动语法（拓印）。** 每块版都是**一次拓印**：马连在纸背上以相互重叠的之字形一行一行推过，它经过的地方颜色就透出来，只在这块版自己的区域之内（小版拓得快）。两次拓印之间喘一口气，给下一块版上墨。最后一次拓印落下，印出来的就是静帧。
