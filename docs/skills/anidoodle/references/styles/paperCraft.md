# 玩具剧场纸拼贴（`paperCraft.ts`）

**媒介的物理形态。** 一座纸板玩具剧场立在牛皮纸桌面上，用三种纸搭成。彩色纸和**印花**纸，剪的或撕的：深海用素色的粗糙彩纸（sugar paper），其余用印花纸（波浪纹、圆点纹、石纹、菱形纹、旧报纸）。**水粉剪片**：在白卡纸上用看得见笔触的平涂不透明颜料画好，四周像贴纸那样留一圈白边剪下来（太阳、灯塔、房子、海鸥、木桩）。还有卡纸本身：每一片都有**厚度**，在正面的右下方露出一道颜色更深的切边。

**笔触。** 水粉笔触（`gouache`：先平涂一层底，再朝同一个方向刷几道略浅、略深一档的宽笔触，裁在形内），沿背向太阳那一侧画上的一层阴影（`shadeSide`），以及印花图案（`wavePrint`、`dotPrint`、`diamondPrint`、`stonePrint`、`newsPrint`、`woodPrint`）。任何地方都没有画出来的线。

**边缘。** 剪刀剪出的利落边或撕边；然后是卡纸的切边（一份颜色更深的偏移副本）；再往外是贴纸式的白边，用圆角连接（round join）描一遍轮廓得到，这恰好就是剪刀留下的那种边。白边绝不紧贴凹进去的细节。

**纵深。** 各层布景片（flat）彼此分开站立。每一片都在身后那层布景片上投下一道柔和的影子，影子的偏移量就是两层之间的间距（`depth`）；台口沿着内侧上沿和左沿把影子投进舞台。布景片被裁在剧场箱体之内：它们从箱壁后面滑进来。

**笔触顺序。** 桌面（第 0 帧）。放下剧场（台口和台面）。然后由后往前布景：天幕吊下来，太阳挂在小棍上降下来，云，灯塔从岬角后面推上来，岬角从侧幕滑进来，一排排海浪和码头滑进来，房子一栋接一栋立起来，报纸船沿着它那道浪推上场，前景的海，木桩和海鸥，海滩地排（ground row），幕布摆进来，檐幕降下来。

**调色板。** 牛皮纸 `#b8905f`；台口青绿 `#2f6f73` 配金色 `#e1b54a`；剧场红 `#b8302c`；海 `#2c5d8a` / `#3d7db0` / `#4ba2a3`；房子用水粉的粉彩色。光源：太阳，在左上。

**和近邻不同。** `fox` 是剪纸，没有颜料，没有印花，层与层之间也没有空隙。这里是画过、印过的纸，立在有真实间距的舞台空间里，动起来像定格动画。

**运动语法。** **一拍二的定格动画**：每个姿势停两帧。一片纸被拿着悬在叠层上方移动（影子又宽又远，带一丝手抖），落下，晃几下（转几度，弹跳一两个像素，逐渐衰减），然后静止。墨和颜料永远不动。
