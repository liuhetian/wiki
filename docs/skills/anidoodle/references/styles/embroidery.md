# 手工刺绣（`embroidery.ts`）

**媒介，从物理上说。** 六股棉绣线，分成两三股使用（点缀处用一根金线），用一根绒线绣针（crewel needle）穿过天然平纹亚麻布绣，布绷在一只带黄铜螺丝夹的山毛榉绣绷里，绷得像鼓面一样紧。

**笔触。** 一针是两个针孔之间一段拧着的线（`St`：a、b、宽度、颜色）。

- 茎绣（stem stitch，相互重叠、倾斜：像一根绳）用于茎；主茎绣两行。
- 劈针绣（split stitch，每一针都从上一针中间穿上来）用于填充区要抵住的那些边缘。
- 缎面绣**横跨**形体并排铺，方向顺着形体：横过花瓣，绕着腹部。跨度超过约 9 mm 的在中轴处分开。
- 鱼骨绣：从叶缘绣到中脉，朝叶尖倾斜，两侧交替。
- 长短针绣：一排排从一条边缘朝一个目标绣，第一排长短交替，绣线从颜色 A 逐级过渡到颜色 B。
- 法式结粒绣（一颗珠子，带着缠绕的线圈和一点反光）用于花心、薰衣草、雄蕊、花粉。
- 平针绣（running stitch）用于飞行轨迹；单根直针用于腿和翅脉。

**边缘。** 每个形状的边缘就是它那些针脚的端头：一排掐进布里的收口。没有画出来的轮廓线；轮廓也是线绣的。

**渲染一针。** 收紧的端头，一个受光面和一个背光面（一个指定的光源，在左上方），线股拧转处的斜向沟纹，每个拧转上一点反光，以及往右下方投出的一丝影子。光泽强度取决于这一针和光线的夹角，所以针的方向读出来就是形体。

**顺序。** 茎（茎绣）、梗、劈针绣边缘；然后填充（叶子、带明暗的叶子、虞美人、雏菊、勿忘我）；然后结粒；然后是蜜蜂，最后绣；针停放在布里。

**调色板。** 燕麦色亚麻；鼠尾草绿、橄榄绿、苔藓绿；白和贝壳白；奶油黄和赭石；矢车菊蓝；两种薰衣草紫；从虞美人珊瑚红到牛血红；蜜蜂的金色和赭褐；翅膀用银色。

**底子。** 亚麻布逐设备像素计算：在交替的交织点上经线压纬线、纬线压经线，每根线是一条圆润的线绳，在跨过另一根线的地方隆起，带竹节，偶尔有一根颜色更深的线，线与线之间有针孔。绣绷外面的布松弛着，起柔和的褶。绣绷的圈把影子投在布上，绷内落在左上，绷外落在右下。

**是什么让它不是它的邻居**（`fox`，剪纸）：没有任何东西是一片平的纸片；每一个笔触都是一条有方向的线，色调来自针的方向，而不是来自填充。

**运动语法。** 针一针一针地绣出来：每一针从它穿上来的那个孔朝它要穿下去的那个孔长出去，针在线头处，绣线从针眼拖在后面；一个结粒先显示线圈一圈圈缠上去，再被拉紧成一颗珠子。一针花一小段固定时间，再按每毫米加一点；一个结粒要缠三圈。每 180 针存一个检查点图层，让每帧的开销保持很低。
