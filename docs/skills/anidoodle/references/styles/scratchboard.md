# 刮画板 · `scratchboard.ts`

**媒介的物理形态。** 一块白色瓷土板，上面覆着一层黑色墨汁。什么都不添加：每一道笔触都是用钢刀或刮笔把墨刮掉，所以每一道笔触都是黑底上的白，画面是通过去掉暗色找出来的。一刀在刀刃切入的地方最宽，随着抬刀逐渐变细；瓷土在刀口边缘崩掉一丝（在一份干净的刮痕副本上叠一层 `draftTooth` 贴图）。

**笔触。** 毛发是顺着毛的生长方向刮出的两头尖的白色挑线（手工布置的流场的流线，长度取自手工布置的毛长场）；每根挑线的宽度沿着长度方向跟随色调变化，所以一根毛穿过深色斑纹时，会在穿过的地方变细。无毛的表面用顺着形体的平行排线（鼻头的皮肤；虹膜则是放射状的刮痕）。一组更短的、呈 ±35° 交叉的刮痕给出中间调。亮部刮得极密，密到连成大片刮白的区域；眼神光用刀刃平刮出来。

**边缘。** 受光的轮廓是一排顺着毛的走向刮出的短而亮的挑线（耳朵这类皮肤边缘则是一道干净的刀线）。背光一侧的边缘消失在板子里，只被天空淡淡地勾一道边。

**顺序。** 刀从一片黑里一点点揭示：先刮月光照到边缘的地方的轮廓高光；在光照得到的每个地方刮一层稀疏的挑线，定下皮毛的走向；然后堆出亮部大块：中间调，交叉刮痕，亮部一直刮到连成一片；最后是细节（鼻头排线、虹膜、胡须）和眼神光。

**调色板与板子。** 板面 #0c0b0a，瓷土 #ebe5d8。没有灰墨：灰只取决于白色刮痕排得有多密。

**和近邻不同。** `mellan` 和 `pocketWatch` 是在浅色纸上添加深色笔触；这里每一道笔触都是去掉暗色，底是黑的，色调随着刮痕的数量和宽度上升。也有排线，但以毛发挑线为主。

**运动语法。** 第 0 帧是全黑的板子。长刀线能看着它被刮出来（刀尖沿线移动）；毛发挑线整根出现，每帧很多根，一个区域一个区域地来。没有任何东西淡入淡出；没有任何地方会重新上墨。
