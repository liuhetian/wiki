# 世纪中期水粉（1950-60 年代绘本）

模块：`engine/src/canvas-core/midCentury.ts`。主图：一个山坡上的村庄，一个女孩在放风筝。

**媒介，从物理上说。** 不透明、哑光的设计用水粉，画在暖色插画板上（Provensens、Mary Blair、Sasek）。一支平头笔铺出每个形状，只在它略显毛糙的边缘看得出笔迹；一支几乎干了的笔在平涂上拖过，让鬃毛跳过画板的纸齿；一条松散的笔墨线最后画上，在它自己的印版上，和色彩**套印错位**。

**笔触。** 平的不透明形状，边缘是按形状大小来定幅度的位移几何（多边形保留它们的角：房子是剪出来的，不是圆角的）；干笔的鬃毛条纹，随着笔里的颜料用尽而断开；一条细的、略有粗细变化的线，轮廓不闭合，游离出色块之外（印版偏移 +5，-4）。

**顺序。** 平的形状**从大到小**（按面积排序；层叠顺序不变，所以房子会围着已经画好的山丘填进去）-> 干笔（天空、云、山丘、墙、裙子的暗面、草丛）-> 线（先画女孩，然后是风筝、线绳、村庄、鸟）。

**调色板。** 暖色画板、芥末黄、番茄红、绿松石、橄榄绿、深绿黑、粉、奶油色。

**光。** 太阳在左上方高处：每座房子和尖塔的右侧更暗，女孩扁平的影子沿山坡往右下方延伸。

**人物。** 八岁，六头身（头 54 px，身体 324 px）：肩在 1.3 个头处，裆部 3.1，膝 4.5，脚踝 5.8。重心在伸直的后腿上；前膝向前弯。放风筝的手臂举起，肘部向外向下屈，拳头握住线绳，拇指压在上面；平衡的手臂向后，手张开，掌心朝下，四指一拇指。A 字裙、彼得潘领、泡泡袖、白袜子、玛丽珍鞋。风从左边来：裙摆、蝴蝶结的飘带、风筝尾巴都向右飘。

**不是剪纸（fox）。** 用画出来的边缘和干笔，取代撕开的纤维和抬起的纸片，还有一条浮离色块的线。
