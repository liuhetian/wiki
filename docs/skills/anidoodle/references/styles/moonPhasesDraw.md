# 黑板粉笔画，一笔笔写上去（`moonPhasesDraw.ts`）

黑板样张的绘制过程版（样张是 `moonPhases.ts`，配方在 [style-guide.md](../style-guide.md)）。样张可以接收一个可选的 `Clock`（`(id) => progress`）；不传时它逐字节画出完成后的黑板（已验证：在 scale 1 和 2 下 md5 都不变），所以影片的最后 30 帧就是静帧。

**顺序，照老师写黑板的样子来。** 先用毛毡板擦：昨天的课（「HOMEWORK P 42」「NEWTON / 3RD LAW」）从左往右擦掉，板擦经过的地方只剩残影，宽大的弧形雾痕随着擦拭一路变大。然后是标题，用黄色划两道下划线；接着用蓝色画出一个月的弧线和箭头，写上「29.5 DAYS」；然后逐个画月亮：先用粉笔侧面把整个受光面薄擦（scumble）一遍，再在上面堆出高地（月海只是粉笔少一些的地方），受光一侧的月缘再加工一遍，点上环形山，画出肯定的月缘线、淡淡的暗侧月缘、明暗界线，并且在下一个月亮开始之前把它的标注写在下面；满月用手指抹一圈。最后点上星星，北斗（the Plough）用蓝色点出并连线，写上粉色的批注并圈起来。

**运动语法。** 薄擦一拖一拖地出现（最后一拖只拖到一半）；线条连同粉尘沿着笔画生长；字母一笔一划地写出来（`drafting.ts` 的进度）。全片只有一张 cue 表，对齐 5 帧网格，加载时校验。

**第 0 帧**是老师走进教室时看到的黑板：昨天的课还在上面。残影是擦掉它擦出来的，真黑板上的残影也正是这么来的。
