# 民间故事绘本画

模块：`engine/src/canvas-core/folkTale.ts`（工具包：`folkTaleKit.ts`，过程运行器来自 `sumiEKit.ts`）。主图：一个男孩抱着一只公鸡，沿着小路穿过白桦林边上一处乡村菜园。画幅：16:9，1920 x 1080（W 和 H 取自 `meta`）。

**传统。** 绘本画手法的俄罗斯民间故事书插画：在一幅完整的铅笔画上画水粉和水彩，颜料只往前推进到需要的地方为止，画面的后方留作裸露的素描。

**媒介，从物理上说。** 在暖奶油色卡纸上用 HB 石墨起一幅画，然后上颜料：前景用半干的圆头笔铺不透明的水粉（body colour），中景用稀薄透明的水彩淡彩。凡是颜料薄的地方都透出奶油色的纸，这让整幅画有了光泽。

**纵深就是媒介。** 这是招牌，也是每一笔都遵守的规则。每个笔触都有一个深度 `d`，从观者脚下的 0 到地平线的 1：

- **前景（d ≈ 0）：** 不透明、饱和、有质感。叶子是在中脉处分开的双色两半，用笔刷沿侧脉拉出铺色，画上叶脉和干笔斑点。向日葵的舌状花一片一片地铺，每片都有折痕和条纹。草是成千上万根单独的草叶，成簇生长。
- **中景（d ≈ 0.3 到 0.6）：** 颜色朝暖色雾霭（`far()`）调和，颜料变薄，质感消失，颜料在它自己的铅笔线前面就停住。中景里的大物件（农舍、干草垛、中景的白桦）通过一个渐变蒙版（`faded()`）溶解进它们的素描里。
- **远景（d ≥ 0.9）：** 完全没有颜料。洋葱顶、钟楼、柱式风车、木屋和树都是奶油色纸上的铅笔线，树画成扇贝边的树冠。
- **金色雾霭**是在画前景之前铺在中景上的一条柔和暖色带，让近处的东西站在光的前面。

**笔触。** 在铅笔里，是一条柔和的线，粗细和深浅随手的压力起伏，落笔和抬笔处更淡，并且略微错开地再描一遍。在颜料里，是一块不透明的填色，边缘是摇晃的笔刷切边，里面有干笔拖痕（三四条断开的鬃毛线），水粉沉淀的地方有一圈略深的边。

**边缘。** 前景里边缘清晰，略深一点。中景里边缘柔和，颜料没对上线。后方的边缘就是铅笔线本身。

**顺序。** 空白纸 → 整个场景用铅笔画出，先画大形（地平线和村庄、白桦树干、干草垛、农舍、篱笆、小路、人物、菜园、向日葵、叶子）→ 天空的光晕 → 草地，从后往前 → 白桦林，从远（只有线）到近（上颜料）→ 农舍，逐渐淡出成它的素描 → 干草垛 → 金色雾霭 → 中景向日葵 → 枝条编的篱笆 → 白桦树冠 → 小路 → 中景的草和雏菊 → 男孩和他的公鸡（裤子和树皮鞋、衬衫、尾巴、鸟、头和鸡冠、手、头，最后是脸）→ 前景的草 → 南瓜叶、南瓜、卷须 → 大向日葵 → 犬蔷薇、风铃草、牛蒡 → 最前面一排草边 → 近处的雏菊 → 结籽的伞形花序。

**调色板。** 奶油色纸 `#f4edda`，暖色雾霭 `#f2e9c9`，树汁绿和橄榄绿，土黄，镉黄和镉橙（向日葵、南瓜），朱红（衬衫和鸡冠），钴紫（风铃草），熟赭，以及线条用的石墨色 `#6f665a`。

**人物。** 温暖的漫画化。圆脑袋，红扑扑的脸颊（柔和的径向腮红），点状眼睛带一点高光，纽扣鼻子，小小的微笑。大而简单的服装形状承载民间纹样：绣花的下摆和门襟，带流苏的腰带，用树皮绳绑住的裹腿，编织的树皮鞋。比例忠于年龄：男孩大约六岁，身高略不到六个头。

**不是它最近的邻居（`storybook`，铅笔加柔和水彩）。** `storybook` 把所有东西都画成同样稀薄的透明度。`folkTale` 随距离改变媒介：前面是不透明、干笔的水粉，中间是浅淡的淡彩，后面是裸露的铅笔。它的前景密密地画满一片片单独画出的叶子、舌状花和草叶，而 `storybook` 铺的是会积成水洼的淡彩。

**运动语法。** 画是被一笔笔画出来的。先是铅笔起稿，每条线的节奏按它的长度定。然后颜料从后往前上：大片淡彩在一道带噪声的湿润前沿后面扫过（`reveal()`），叶子从叶柄长出来再添上叶脉，向日葵的舌状花一片片落下之后才铺花盘，草一簇一簇地铺。遍与遍之间有短暂的停顿。没有任何东西淡入或缩放出现。最后 30 帧停在完成的静帧上。

**为这张样张写的工具包原语**（核心库的候选）：`pencil`/`sketch`、`gouache`、`reveal`、`faded`（+ `ramp`/`radial` 蒙版）、`leaf`/`lineLeaf`、`petal`/`sunflower`、`daisy`、`bell`、`dogRose`、`umbel`、`grass`（成簇，带跳过区域）、`limb`/`lineLimb`、`pumpkin`、`gourdLeaf`、`tendril`。
