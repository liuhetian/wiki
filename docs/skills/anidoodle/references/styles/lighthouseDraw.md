# 孔版印刷，一个滚筒一个滚筒地印（`lighthouseDraw.ts`，建在 `lighthouse.ts` 之上）

孔版印刷品不是画出来的，是喂出来的：同一张纸每种油墨过一次机器，每次装上一个不同的滚筒。`lighthouse.ts` 只是给它的三个样张函数加了 `export`（前后都核对过主图静帧的 md5：没变）。第 0 帧是带裁切标记的空白纸。先印黄色：油墨在压印线（nip）处落下，一道笔直的前沿以恒定的走纸速度沿纸往下移动（两端有短暂的咬纸和松开），滚筒的影子就骑在它前面一点。换滚筒时喘一口气。粉色叠在已经干了的黄色上，带着它自己的套印偏移，所以每一处叠印都在压印线上诞生（珊瑚色天空、橙色太阳）。换滚筒。最后印蓝色，也就是主版：暮色紫、绿色草皮、每个形体的背光面和蜡笔主线一扫而至。色条里每种油墨的色块都用它自己的滚筒印。停住的结尾就是 `drawLighthouse` 本身，所以最后一秒和主图静帧逐字节相同。运动语法：唯一移动的东西是压印线。永远不淡入淡出。
