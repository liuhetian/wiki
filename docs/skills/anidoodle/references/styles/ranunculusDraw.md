# 铅笔加水彩，绘制过程（`ranunculusDraw.ts`）

**媒介。** HB 铅笔和固体水彩，画在冷压纸上，是 `ranunculus.ts` 的手笔；这部影片原样复用它的几何、随机种子和调用（是重新编写的，所以主画面保持逐字节一致）。

**笔触顺序。** (1) 铅笔起稿，轻到可以藏在颜料底下：花朵的外包络、花心、花茎的动势线、叶片的轴线、外侧三圈花瓣的瓣缘。(2) 第一遍浅淡彩，每个大块一遍：花朵的淡彩顺着花瓣环的扇贝形剪影走（绕着中心一圈圈走过各个瓣缘的顶点，绝不是一个圆盘），每遍淡彩都从笔碰到的地方沿着一道参差的湿边扩散开，在轮廓线之前停住。(3) 朝着唯一的光源（左上）塑造形体：花茎、叶片、花萼，然后是花瓣，从外圈到中心，每一片都是一道从瓣基生长出来的湿边。(4) 在颜料之上画石墨线：瓣缘和脉纹，花茎和叶片的轮廓；凡是被后画的花瓣盖住的地方，每根线都被**擦掉**（用后画花瓣实际的形体轮廓做 `destination-out`），因为手不会去画它看不见的东西。

**为什么最后一帧不是主画面的像素。** 主画面是一片花瓣一片花瓣地交替上颜料和石墨的，而且没有起稿。按照媒介本身的顺序来画，完成稿还是同一朵花，只是颜料底下有一层淡淡的起稿，所有石墨线都在最上面。

**运动语法。** 铅笔又快又轻，淡彩慢（每遍 20 帧），花瓣越小画得越快，石墨线干脆利落。湿边的大小按形状来定，好让湿边在这个操作的最后一帧仍在移动。
