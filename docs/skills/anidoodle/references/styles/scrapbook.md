# 档案剪贴簿（`scrapbook.ts`，工具集在 `scrapbookKit.ts`，版画在 `scrapbookEngraving.ts`）

**媒介的物理形态。** 旧野外笔记本里的一页：棉浆纸已经泛黄成羊皮纸的颜色，长了锈斑似的霉点（foxing；聚在右侧页边、左下角和折痕一带，其他地方没有），越靠近常被手拿的边缘颜色越深，对折过一次，有一道淡淡的水渍痕。上面是从别的纸上撕下来的卡片（毛边，边沿发暗），用发黄的玻璃纸胶带粘住，或者用木衣夹夹在一根麻绳上。图画是**铜版雕版画**，之后用稀薄的淡彩手工上色。文字来自打字机、勒索信式的剪贴字母和一支红笔。最后盖一枚橡皮图章。

**笔触。**

- *雕刀线*（`burin`、`engrave`）：一条中心线，宽度随下方的色调膨胀，两端收成尖；色调低于阈值的地方，线断开，露出纸，所以高光处是空白的。轮廓排线顺着形体走（横绕管状物的环线，顺着花瓣的线）；只在色调深的地方才交叉排线；毛发是短而尖的挑线；花粉用点刻；投影用尺子画成水平线，边缘渐隐。色调是在每个部件自己的坐标系上算的「法线对光源」模型（`frame`、`tubeShade`），遮挡靠把每个采样点拿去和前面的部件逐一测试（`occluder`），所以被挡住的线绝不会被刻出来。
- *打字字符*（`typed`）：取自一张笔画字形表的粗衬线等宽字体，每次敲击浓淡各不相同，并且稍稍偏离基线，色带印出淡淡的重影。
- *剪贴字母*（`ransom`）：每个字母是一块剪刀剪下来的纸片，有自己的一对配色、字体（粗体、粗衬线、空心、斜体、窄体、宽体、圆体）、大小和倾斜；有些是从一栏印刷文字里剪下来的，字母落在一块清空的底上。字形是**描边**路径，绝不用 `fillText`。
- *红笔*（`handWrite`、`g.pen`）：两端收尖、微微抖动的批注：一条虚线趋势线、一个圈、读数。
- *图章*：双线边框，墨色被 `risoSpeck` + `risoMottle` 打碎，正片叠底。

**边缘。** 撕边（卡片），剪刀剪出的利落边（字母纸片），任何纸质的东西周围都没有画出来的轮廓线。每张纸都微微翘起，向右下方投下一道柔和的影子。

**笔触顺序。** 纸页（第 0 帧）。卡片一张一张地放下（先举高，影子远，然后压平），每张都贴上胶带；麻绳，花卉卡片，衣夹。分节标签，用打字机打出来。刻蜜蜂：轮廓，腹部，胸部和头，腿和触角，翅膀，交叉排线 + 眼睛 + 绒毛 + 花粉，投影。玫瑰：轮廓，花瓣，雄蕊，茎和叶，阴影。手工上色（淡彩从笔碰到的地方扩散开）。打图注。打标题纸条，勒索信字母一个一个贴上去。用笔画出摇摆舞示意图。画图表（坐标轴，柱子向上涂墨），然后加批注。图章，从一端滚压上去。

**调色板。** 羊皮纸色 `#e8d6b2`，深褐黑墨 `#2a2019`，青绿 `#4f8f8a`，灰粉 `#d9a5a0`，图章红 `#b8322a`，藏青 `#22335a`，芥末黄 `#d6a13c`。一盏灯，在左上。

**和几个近邻不同。** `fox`（剪纸）没有线，也没有字。`pocketWatch` 用粗细不变的圆珠笔线条叠出色调。`mellan` 是一条螺旋线。这里的色调是许多顺着形体走、粗细起伏的线，画在拼贴起来的零碎印刷品上，文字也是画面的一部分。

**运动语法。** 一张正在实时工作的书桌：纸会动（滑动、压平），墨一旦落下就再也不动。线一条接一条地刻，正在刻的那条向前推进；字母一次敲一个；字母纸片带着一点倾斜落下，然后放稳。
