# 点画（钢笔墨点）· `stipple.ts`

**媒介的物理形态。** 一支针管笔（0.25 mm），从不更换，垂直点落在热压布里斯托卡纸上成千上万次。没有线，没有排线，没有淡彩。笔握得略微偏离垂直，所以每个点都有点椭圆、有点毛糙；偶尔抬笔时拖出一丝小尾巴，偶尔墨水不足，点出来是灰的。

**笔触。** 一种大小的点。色调只取决于每平方厘米里有多少个点（加权 Voronoi / Secord 2002 分布：蓝噪声，不结团，1080 下间距约为 1.5 px / 色调^0.64）。实现方式是在一张 1 像素精度的色调栅格上做变半径的泊松圆盘采样，这张栅格由主体的真实结构和一盏灯算出来（`stippleKit.ts`）。

**边缘。** 没有轮廓线。边缘就是点的密度发生变化的地方；在全光下，边缘干脆就消失了（贝壳左上方的边沿）。

**顺序。** 先画最暗的大块（各个气室的阴影、住室的投影、接触阴影），然后向外扩展到中间调，最后在受光的珍珠层上稀疏地过几遍。每一遍都按小块横穿画纸（约 84 px 的格子，蛇形推进），而不是逐行扫描。两遍之间歇一拍。

**调色板与纸。** 略带一丝暖意的炭黑（#15120e），画在亮白的布里斯托卡纸（#fbfaf5）上；核心的 `paper` 贴图叠 5%，别无其他。

**和近邻不同。** `mellan` 是一条连续的线，靠线宽承载色调；`pocketWatch` 用排线的方向叠出色调。点画根本没有方向：唯一的变量是密度。

**运动语法。** 笔触只会出现，什么都不会移动。影片就是点画者的延时摄影：点一遍一遍地累积（每帧约 100 个），在任何浅色调出现之前，暗部大块就已经把这幅画立起来了。永远不要让点淡入；永远不要移动它们。
