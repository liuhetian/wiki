# 彩色铅笔（`colouredPencil.ts`，工具包 `colouredPencilKit.ts`）

**媒介，从物理上说。** 蜡基彩色铅笔，削尖但没有尖到针尖那么细，画在有真实纸齿的奶油色卡纸上。笔芯只落在纸面的凸脊上，所以每一段颜色都夹杂着凹处奶油色的斑点。用力越重，填进去的凹处越多。蜡层一层叠在一层上，第二种色相排线叠在第一种上，会产生视觉混色。

**笔触。** 一道短而直、略带弧度的排线：压力进得快，抬起时拖出一道长长的轻挑。笔触一条挨一条排成带状，几乎全部朝**一个**主导对角方向（左下到右上，`ANG = -1.02`）。色调来自压力（笔触的不透明度加上这一遍的纸齿阈值）和叠加的遍数，永远不来自平涂填充。

**边缘。** 大多没有：边缘就是排线停下的地方，有一两笔越过去。几条用更深的铅笔（棕褐石墨色）画的细而断续的轮廓**最后**才加上，在暗面一侧更重，在受光处消失。

**笔触顺序**（每样一遍，影片按这个顺序回放）：

1. 淡淡的石墨起稿：徒手拉直的作图线，越过角点
2. 大块固有色的几遍，由浅到深：墙、天空、木头，然后是每个物体
3. 在第一种色相上叠第二种色相（暮蓝上叠紫罗兰，蓝绿上叠蓝，赭石上叠红棕）
4. 暗部：投影和深处用第二个方向**交叉**排线（`X2`），永远不填实
5. 轮廓、铆钉、羽毛边缘、木纹
6. 灯的光晕：在刻意留得几乎空白的纸上叠黄色

**调色板。** 奶油色纸 `#f3ecdc`。暮蓝和紫罗兰色的墙，靛蓝到玫瑰色的天空，赭石和红棕色的木头，桃花心木色和毡红色的盒子，上面叠了蓝色的蓝绿色铁皮罐，砖红的搪瓷，一只带蓝紫光泽的石墨黑乌鸦，黄色和琥珀色的光。

**纸。** 每张纸一个纸齿场，沿排线的对角方向略带拉丝。每一遍都被**同一个**场按三个压力阈值之一（轻、中、抛光）打孔，所以凹处在所有层里都保持奶油色。正是这个共享的场让它读起来像铅笔。

**形体。** 一个光源。颜色在每个形体靠近边缘处变浓（密度场里的 `edgeDist`）。实心形体在**顶**面保留一条较浅的带。投影按灯的位置手工放置。

**不是蜡笔（balloon）。** 蜡笔是粗而油蜡感的来回涂抹，端头圆钝，有白蜡笔压光，有描了两遍的粗轮廓。彩色铅笔是细的、平行的、单一方向的排线，带斑点状的纸齿、色相叠加、交叉排线的暗部和稀疏的细轮廓。**不是圆珠笔（pocketWatch）。** 圆珠笔只有一种颜色，色调只来自线落在哪里。这里色调来自压力和颜色叠加。

**运动语法。** 影片就是这幅画的绘制过程。第 0 帧是空白纸。每一遍按顺序落笔，一条带接一条带，节奏由笔触长度加上每次抬笔的固定开销决定。遍与遍之间有 5 帧的一拍。已完成的遍被缓存为一张合成图，手上这一遍重画到手已经画到的那一笔为止。最后 35 帧是静帧。
