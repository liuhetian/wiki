# 炭笔，擦掉再画（`charcoalErasure.ts`）

**媒介，从物理上说。** 柳条炭（一根软软的灰色炭条，在纸齿上一滑而过，吹口气就掉粉）和压缩炭（黑、利落，咬进纸里，几乎擦不掉），画在同一张厚实、齿纹很重的奶油色棉浆纸上。纸擦笔把色调揉进纸纹的凹处；可塑橡皮把亮部提回来，而且从来不会全部提干净。

**笔触。**

- 用炭条的尖画结构：先用柳条炭（轻、粉状、被纸齿打断），最后用压缩炭（黑、利落）。
- 用炭条的**侧面**铺色调：宽而平行的拖抹，裁在一个区域之内（`sideMarks`）。
- 纸擦笔：宽而柔的之字形揉擦（`zigzag` + `rubMark`，模糊的图层组，`ce_blend` 纸齿），把拖抹变成氛围。
- 可塑橡皮：同样的揉擦，在炭层上用 `destination-out`，半透明度加一张条纹贴图，所以擦出来的亮部顺着拖动方向带条纹，而且总会留下灰色残留。

**边缘。** 柳条炭：粉状、被咬缺。压缩炭：利落。揉过的色调：完全没有边缘。擦出的边缘：带条纹。

**顺序。** 给纸铺色调（天空），用橡皮提出亮部（太阳），用柳条炭布置主体，搭结构，用压缩炭加重点，画地面和投影，提出高光。然后是招牌动作：**擦掉再画**。每一处改动都用可塑橡皮擦掉（只擦掉一部分），重新铺色调，再在它自己的残留上重画。没有任何东西会彻底消失。

**调色板。** 奶油色（`#ece5d5`）上的一种暖黑（`#1b1917`）。只有明度。

**纸。** 一张带毛毡压痕的纸面贴图以正片叠底叠在炭笔下面，纸齿则以正片叠底叠在炭笔**上面**，所以纹理会透过黑色露出来。炭笔放在它自己的透明图层上，这样橡皮才能把它去掉；纸永远不会被擦掉。

**是什么让它不是它的邻居**（`pocketWatch`，圆珠笔）：色调是揉出来、提出来的，永远不是排线排出来的；橡皮是一件绘画工具；纸面带着它自己的历史。

**运动语法。** 这部影片**就是**擦掉再画的循环。每一遍是一串依次落下的笔触（`runPass`）；一笔从炭条触纸的地方长出来，色调一道拖抹接一道拖抹地到来，纸擦笔和橡皮沿各自的之字形移动。遍与遍之间有一口气的停顿（一遍的 12%）。已完成的遍被缓存为图层，以遍序号 + 缩放 + 尺寸为键，所以一帧只画正在进行的那一遍。

**主图。** 一株在空旷处长大的英国栎，四个季节画在同一张纸上，完整，偏左，立在画面下三分之一处的地面线上，四周留着空白纸面。太阳在右上方，从一小团羽化的雾霭里提出来（永远不是从整张铺了色调的纸上提）。每个季节，旧的太阳被重新铺上色调，再提出一个新的；影子落向左下方（冬天长，夏天是一汪，秋天又长又低）。擦拭只局限在改动的地方，所以最后的静帧会露出同一棵树早先状态的淡淡痕迹：夏天的树冠体量像一声低语，还有被风吹弯的秋天细枝下面平静的冬天枝条。
