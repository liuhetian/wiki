# 等轴剖视 · `isometric.ts`

**媒介，从物理上说。** 一幅画在真正 2:1 等轴（二等角，dimetric）网格上的扁平矢量插画，按等轴插画师在钢笔工具软件里的工作方式搭建。世界坐标 x -> 屏幕 (u, u/2)，y -> (-u, u/2)，z -> (0, -1.2247u)：每条水平棱都是一条 2:1 的线，每条竖直棱都是竖直的，立方体看起来就是立方体（`isometricKit.ts` 里的 `Iso`）。

**笔触。** 平面：先用钢笔描出轮廓（保持在平面之内），再平涂填色。2:1 的细线。扁平的光形。

**边缘。** 矢量般清晰。没有轮廓线：色调与色调直接相接。每种材质恰好三个色调（顶面最亮，+y 面居中，+x 面最暗）；弧形的东西遵守同样的立方体规则（一个穹顶是三块平的区域，在投影后呈竖直的那条经线上分开，再加一个朝上的顶盖）。

**顺序。** 在地面上画出等轴网格 -> 体块（半透明的作图盒子，描边裁在盒子内部，这样一条都不会留下来）-> 墙和地板 -> 室内（烤炉、阁楼、架子、桌子、梯子）-> 道具（面包、麻袋、面包师）-> 光和影 -> 细节（瓷砖缝、砖层、木板线、灰泥斑点、窗上的星星、面粉）。

**调色板与光。** 暖色材质上的夜间冷色环境光（除了面包，所有东西都往暗处压一档），所以唯一饱和的暖色是烤炉。炉口是唯一的光源：能看见它的面加上**一个**平的暖色调，按距离分成三档（`warmBox`），地面的光池是三条平的色带，投影是从炉口往外抛出的单个平面形状。任何地方都没有渐变。

**人物。** 在屏幕空间里、在投影出的落脚点上方绘制，7.5 头身，每件衣服三个色调，朝向光源的一侧有一道暖光边。

**不是它的邻居。** `koi` 用手勾出粗细变化的轮廓；这里根本没有线，也根本没有手，投影本身就是画风，顺序是先搭结构。

**运动语法。** 施工延时：东西按画家算法的顺序铺下，但一个阶段一个阶段地显现；一个平面先描边再从上往下填；光最后倒进来。过程影片里镜头永远不动。
