# 扁平矢量（现代扁平插画）

模块：`engine/src/canvas-core/flatVector.ts`。主图：海湾上一场小帆船赛，背后是山丘；领头的船正绕过橙色浮标。

**媒介，从物理上说。** 矢量软件里的钢笔工具。每个形状是一条由手放锚点构成的闭合路径（帆和船身用角点，山丘和水面用平滑点）；路径闭合的那一刻，它唯一的平涂填色就落下来。长投影是单独的形状，带线性透明度渐变。质感是一支栅格颗粒笔刷，刷在形状的背光面上，裁剪在形状之内。

**笔触。** 锚点、锚点、锚点、闭合、填色。任何地方都没有描边：边缘只存在于两块填色相接的地方，而且在数学上绝对清晰。纵深来自重叠的平面和空气透视的颜色（丁香紫 -> 鼠尾草绿 -> 深蓝绿）。

**顺序。** 背景平面（天空、云、远山和中景山、海湾的色带、太阳的粼光）-> 中景（岸、城镇、岬角、灯塔、前景岩石）-> 船（尾迹、船身、帆、帆杠、桅杆、船首浪）、浮标、碎浪 -> 长投影和背光切面 -> 颗粒笔刷，一个形状一个形状地刷。

**调色板。** 同一个调子里的 13 个色样：暖奶油色天空，丁香紫/鼠尾草绿/蓝绿的山丘，三种蓝，珊瑚红，芥末黄，海军蓝，骨白。

**光。** 低低的太阳在画外**左侧**：粼光一直延伸出左边缘，朝右的坡面和岩石切面处在阴影里，每道影子都投向右边，并渐变到消失。

**不是剪纸（fox）。** 没有撕开的纤维，没有每一片下面都有的抬起投影，没有画出来的线。边缘完美；唯一的影子是投影。

**过程界面。** 一条路径正在画的时候：蓝色路径，白色方形锚点，当前锚点实心并带着贝塞尔手柄。界面不是笔触；路径闭合时它就消失。

**开销。** 每个形状画完的颗粒缓存在它自己包围盒大小的表面里；只有进行中的颗粒会重算。
