# 新闻纸半色调（`halftone.ts`、`halftoneScene.ts`、`halftoneKit.ts`）

**媒介。** 一台卷筒胶印报纸印刷机。照片被一张接触网屏打散成 AM 半色调：网点落在固定网格上，由它们的**面积**承载色调。只有两块印版：黑色在 45 度网屏上，一种暖橙专色在它自己 15 度的网屏上（相差 30 度，所以形成玫瑰斑，永远不出龟纹）。油性墨印在未漂白的机械木浆新闻纸上。

**笔触。** 只有网点。任何地方都没有线：每一条边缘都是网点大小发生变化的地方。网点面积准确（`sqrt(t / pi)`），超过 70% 后膨胀到连成一片带针孔的实地，并在中间调处**扩大**（网点增大），因为那里它们的边缘最长；每个网点是一个不规则七边形，被一个逐点哈希咬缺，下面垫着一圈晕开油墨的柔和光环（同一批网点的模糊副本）。低于约 4% 的高光掉成空白纸；暗部糊死。

**边缘。** 照片的矩形放在一张留有空白新闻纸边距的纸上。专色铺得略宽一丝（纸张在卷筒上横向伸展），并且套印不准，所以暗部边缘露出一道细细的橙色唇边。

**顺序。** 先建**原图**（`halftoneScene.ts`）：一台针孔相机对着以米为单位的真实结构，画进两个浮点分色（黑色密度、专色密度），天空、荒山、围墙牧场和溪流逐像素计算，高架桥和火车用画布绘制（材质 id 放在蓝色通道里，用来画石层），一团蒸汽羽流是若干带明暗的团块的并集，并朝太阳步进计算自阴影。然后把每个分色加网成网点。专色是一种**暖意**，不是一种颜色：只有向阳的石头、羽流受光的边缘和辉光带着较多专色。

**调色板。** 黑 #1d1a17，专色橙 #e86a2c，新闻纸 #e6dfcc。

**纸。** 新闻纸：一片缓慢起伏的灰奶油色纸浆云纹，短而深的机械木浆纤维，浅色的表面纤维，偶尔一粒树皮屑。

**不是孔版印刷（risograph）。** 孔版印刷是一面面平的模版滚筒，鲜亮的大豆油墨叠印出新的颜色，手刻的形状，专色平网。这是一张照片：每种油墨是一个连续调，只有网点大小，暗哑的油性墨，网点扩大和纤维，灰色世界里的一个暖色专色。没有形状，只有色调。

**运动语法（开机调试）。** 印刷机末端的收纸堆。每一拍，一张新纸被甩到最上面（从纸张的叼口端滑进来，6 帧内落定，影子落在下面那张纸上）。最先的几张只带专色机组，颜色正在上来：在墨辊供墨不足的地方又薄、又沿走纸方向拉出条纹，然后一个墨键一个墨键地沿整个宽度变均匀（是平滑地变匀，串墨辊会把墨键之间抹开）。然后黑色机组以同样的方式起来，叠在上面。最后，印刷工用几张纸把专色微调到套准；最后一张就是静帧。
