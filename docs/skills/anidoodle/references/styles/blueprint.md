# 蓝晒蓝图（`blueprint.ts`，工具包在 `blueprintKit.ts`）

**媒介，从物理上说。** 一支直线笔（ruling pen）和一只弹簧弓圆规，蘸白墨水，画在普鲁士蓝的蓝晒图纸上。这张图纸从来没有曝光均匀：弧光灯所在的那一侧更亮，带斑驳（`blueMottle`），有两道旧折痕，有灰尘。墨水在纸面的齿纹上断开（`draftTooth`），蓝底上的白色会晕开，所以每条线都带一圈淡淡的光晕（`inkGroup`）。

**笔触。** 用尺画的线从来不是绝对笔直的（有 0.6 px 的弯弧，带种子）。圆规画的圆**确实**是正圆（`circle`：圆规不会抖，徒手才会）。点划线，长划接短划，用于中心线和节圆（`chain`、`chainRing`）。45 度的剖面线，在每个零件内侧一点点开始、一点点结束（`hatch`），相邻零件的剖面线方向相反，薄截面涂实，轴和小齿轮（pinion）永远不剖。实心箭头。来自 `drafting.ts` 的单笔斜体哥特式大写字母；尺寸数字都从图纸底边方向读（单向标注）。

**边缘。** 一条细而均匀的笔线，笔尖抬起处略微收尖。除了剖面线没有任何色调。没有光，也没有投影：正投影图本来就没有，假造一个就破坏了这种媒介。

**线条层级。** 可见轮廓线用粗白线（1.4 到 1.9）；剖面线、节圆、尺寸线和引线用细青线（0.75 到 1）；作图线和投影线更细，用暗青色，像真实制图那样留在纸上。

**笔触顺序。** 空白图纸。边框一笔一笔用尺画出，然后是分区标记。标题栏方框用尺画出（较早）。作图：中心线、连心线、摆出节圆、引下投影线、横贯全图的基准线。用直线笔描轮廓：先是底板，然后从叠层最上面往下逐个画齿轮，先画轮缘和齿，再一个窗口一个窗口地画轮辐（crossings），每个小齿轮都先于它所骑在上面的那个齿轮（下层齿轮被上面每个零件的**金属**遮挡，永远不被它们的轮辐遮挡）。剖面轮廓，然后剖面线。细节。尺寸（尺寸界线、尺寸线、箭头、数字）。表格、注释、零件序号圈。标题栏的文字最后写，标题本身是最后的最后一笔。

**调色板。** 底色 `#123a63`，白墨 `#f1f7fb`，青色 `#a7d8ec`，暗青 `#7fbcd8`。

**不是它最近的邻居（pocketWatch，圆珠笔）。** 圆珠笔靠排线落在受光形体上的位置建立**色调**；蓝图根本没有光，它唯一的色调是一种约定（剖面线）。圆珠笔的线是徒手的、连续的；这里的圆是圆规画出的正圆，直线是用尺画的，中心线是断开的点划线。底子是负像（蓝底白线），图纸上还带着制图室的全套家当：边框分区、标题栏、比例、注释。

**运动语法。** 制图室里没有镜头运动，也没有任何东西淡入淡出：笔尖沿每一笔行进（`progress`），圆规画的圆从针脚落下的地方开始摆出，剖面线一次一笔地画出来，文字一笔一画地写。长的直线画得快，写字慢。画完的零件被压平到一个缓存表面上，以已完成零件的数量为键，所以只有正在画的那一笔有开销。

**机构的写实。** 要说出运动学关系，而不只是说出零件：每一对啮合的中心距 = 模数 x (Z1 + Z2) / 2；齿轮的一个齿在相位上对准连心线，正对着小齿轮的一个**齿间隙**；小齿轮的齿（leaves）齿侧平行、齿根深；轮系传动比明确写出而且是真实的（64/8 x 60/8 = 60，秒轮轴）。
