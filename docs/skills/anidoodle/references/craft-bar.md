# 手艺及格线

检验标准：一位对作品有自尊心的人类插画师会把它交出去吗，还是说它只是机械的形状拼装？

| 露馅之处 | 怎样才算过关 |
|---|---|
| 主体用椭圆和胶囊形拼起来 | 依照真实的解剖结构手工放置控制点 |
| 把一种画风换个配色，冒充另一种 | 笔触、边缘和落笔顺序全都跟着变 |
| 用方框和箭头代表一个想法 | 一台真正的机器，当着你的面做那个想法所描述的事，由许多各司其职的小零件组成（[machines.md](workflows/machines.md)） |
| 线条停在半空；纹理在表面中途戛然而止 | 线条要接上另一条线或一条边；一排肋条或销钉在表面转开的地方逐渐变稀 |
| 零件飘离出去，或者互相陷进去 | 零件像真实零件那样接触（用螺栓固定、搁在上面、抵在一起），每一个都有东西托着；把接合处放大到 3 倍检查 |
| 平涂色块 | 先铺淡彩，再趁半干（wet-on-damp）点入花纹，最后勾线；一个明确指定的光源；画出投影 |
| 每一笔粗细、速度都一样 | 长笔画快，琐碎的笔画慢，有粗有细，收笔尖细 |
| 均匀撒点，一朵花盖章盖 200 次 | 手工摆放的成片花丛，中间留出空地；每个物种手绘 4-5 个视角 |
| 渐变天空、圆盘太阳、椭圆形散景 | 带颗粒沉淀的淡彩，太阳是留出来的亮纸，边缘若隐若现（lost edges） |
| 装饰 | 每个元素都要有一句话的理由，否则不画 |
| 一串画风小品排成一排（影片） | 一条故事弧线。只有**故事**的状态变了，媒介才变 |
| 东西淡入或缩放出现 | 笔触是一笔一笔**画出来**的，顺序和人手画的一样 |
| 两侧同时做同一件事 | 一侧领先，只领先几帧，绝不领先半个周期 |
| 定格 | 镜头可以缓缓蠕移。主体永远不停 |
| 人物关节像橡皮、手像连指手套、脚悬在半空 | 有一套比例法则（按年龄定几头身），关节不超出活动范围，看得见手的地方画五根手指，重心落在脚上（[anatomy.md](anatomy.md)） |
| 同一个角色每个镜头画得不一样 | 一个角色模块；各镜头只给它摆姿势，永远不重画（[workflows/character-consistency.md](workflows/character-consistency.md)） |
| 剪影里填满纹理，没有嘴线，没有脚趾 | 内部轮廓线：嘴、眼睑、鼻孔、脚趾、形体之间的衔接（见下文的细节检查） |
| 绘制过程片里，成画直接淡入 | 按该媒介的顺序落笔；最后几帧就是那张静帧（[workflows/drawing-process.md](workflows/drawing-process.md)） |
| 文字压在繁复的画面、人脸或界面上 | 文字默认独占一帧；要压在画面上，只能作为经过构图的标签或动态文字行，放在画面平静的区域（[workflows/launch-video.md](workflows/launch-video.md) 的文字（Type）一节） |
| 原地播放的循环动画，却号称「活了」 | 在一个随主体移动而变化的世界里真正地行进 |
| 场景之间没有匹配的硬切，或者刺耳的「嗖」一下转场 | 温和的运动（绽开、翻转、推进、卡片长大直到填满画面），或者在形状、位置或拍点上对齐的切换 |
| 网站插画自带背景，放到别的颜色的页面上就露出一个浅色方框 | 把 `paper` 设成页面的准确颜色，所有中性色随之调整；浅色和深色主题出自同一份代码（[workflows/site-art.md](workflows/site-art.md)） |
| 某个零件、某块投影或某处高光闯进标题的空间 | 标题区内什么都不画，并由 `tools/placement.mjs` 证明这一点 |
| 旋转件画成静止的叶片在慢慢转 | 叶片后面跟着几层更淡的副本，每一层再往后一点，底下垫一个淡淡的扫掠形状（`spin`），这样才读得出速度 |

凡是会动的东西都**不许冷场**：从第 0 帧起，每一秒都有看得见的变化。用工具查，**也**用眼睛查：缓缓蠕移的镜头会让每个像素都变，工具满意了，眼睛看到的却是一张静帧。

**评判设计，不只是评判碰撞。** 一张审阅用的静帧可以没有任何重叠，却照样不及格：没有层次、间距局促、拿去当海报都不够格。看每一张审阅帧时，先当设计师，再当检查员。

**先预览选项，再完整渲染。** 有选择悬而未决时（一种转场、一种写字的媒介、一套配色），把各个选项并排做成一张廉价的静帧对照图，让对方来挑。每个选项都完整渲染一遍，就是把最贵的资源花在最便宜的问题上。

## 细节检查（每件作品拿出来给人看之前都要过一遍）

剪影里填满纹理不算一幅画。任何静帧、照片重绘或角色拿出来给人看之前，都要按原尺寸裁切放大，检查内部，因为观众的目光就落在那里：

- **脸**：嘴线和上唇正中的分界、下巴、鼻子的轮廓和鼻孔、上下眼睑和内眼角、眉部的斑纹、耳朵的内缘。
- **手、爪和脚**：每根手指或脚趾都分开，看得见的地方画出指节和肉垫，还有指甲或爪子，以及脚与地面相接的方式（接触阴影、重量）。
- **形体之间的衔接**：腿接上身体的地方、手臂横过胸前的地方、布料在关节处起褶的地方。这些是剪影内部的轮廓线，比外轮廓细，受光处断开。
- **斑纹和图案**：条纹、斑点、缝线和补丁顺着形体的表面走，而不是贴着画面平面走。
- **照着照片重绘的**：以上每一项都要从照片里描出来，再叠图核对；光靠明暗色调永远补不出内部线条。

每种媒介各有各的说法（主版上刻出的一道线、刮出的一道刻痕、一笔铅笔强调、一块颜色更深的积木），但哪一种都不许把它省掉。
