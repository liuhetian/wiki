# 讲解片和信息图

讲解片每章讲一个概念；信息图让数字一眼就能读懂。两者的评判标准都是观众看完之后是否懂了某件真实的事，所以文字和事实要先于任何绘制。

## 研究台账（在分镜之前）

作品提出的每一个论断都要记下：用一句话写出的论断、来源（URL 或确切的段落）、你的把握程度，以及你简化了什么。找不到来源的论断，要么删掉，要么明确地作为比喻呈现。屏幕上的数字都来自台账，而且每个数字都在绘制它的代码旁边用注释写明来源。记录受众（年龄段、专业程度），因为它决定了阅读难度和节奏。

## 分镜（`STORYBOARD.md`）

每章或每个镜头一行：论断编号、一句话的要点、屏幕上的字幕、视觉比喻以及它从哪里开始不再是字面意思、反复出现的角色或信物在做什么、在拍子网格上的帧范围、音乐和音效的 cue、出场转场。对方想要这一步时就拿给对方审；否则直接照着它做。

## 画面规则

- **屏幕上一次只放一个概念。** 按观众需要的顺序把它搭起来，笔触是画上去的，绝不是淡入的。绘制过程（[drawing-process.md](drawing-process.md)）是讲解片最好的工具：图解拼出来的过程**本身就是**讲解。
- **字幕是画出来的手写字**（`lettering.ts`、`drafting.ts`、某种画风自己的手笔），字号按作品发布的最小形状来定。字幕要短到在它停留在屏幕上的时间里能读两遍。
- **一个机构胜过一张图解。** 当概念里有活动部件时，把它做成一台真正的机器，能拆开、能读出自身的状态，用作品所用的任何一种画风都行：[machines.md](machines.md)。
- **一个反复出现的向导**（一个吉祥物、一只手、一件物品）让各章之间有连续性；把它作为角色模块，只建一次。
- **图表按比例绘制**，数据取自台账的数字，标出它们达到的数值，注释用画风的手笔（剪贴簿手笔的红铅笔标记、蓝图的尺寸线）。
- **适合讲解的画风**：剪贴簿（档案感、研究感）、蓝图（技术）、黑板（上课）、扁平矢量和等距（产品和系统）、纸艺（俏皮，给孩子看）、马克笔漫画（有活力）。说明你为什么选了它。

## 信息图静帧

同一份台账，一页。清晰的阅读顺序（从左上角进入，一条路径贯穿全页），一个主图形，三到七个辅助事实，每个数字都有来源。按对方需要的每一种形状各出一张静帧；竖版是重新排版，不是裁切。

## 检查

- 屏幕上每一条字幕停留的时间，都足够按选定受众的节奏读完（人工过一遍）。
- 每一章都占有一个非空的帧范围；各章首尾相接铺满整部影片，没有空隙。
- 用手机宽度检查发布的最小形状：没有哪条字幕小于可读的字号。
- 交付时说明哪些事实经过了独立核查，以及简化了什么。
