# 让布局说话

AI 做界面爱给每块都配个小标签、补一行说明，界面读起来像说明书。把下面这条守则写进当前项目根目录的指令文件，之后每次做界面都生效：

1. 写进你这个客户端每次启动都会读的那个文件：Claude Code 是 `CLAUDE.md`，Codex 等读 `AGENTS.md` 的客户端是 `AGENTS.md`；文件不存在就新建
2. 追加到文件末尾，已有内容不改不删；文件里已经有「界面守则」这一节就跳过，不重复写
3. 写完告诉用户写进了哪个文件

## 要写入的守则

```markdown
## 界面守则

不加不必要的次级标签和说明文字，让布局自己去说明。
```
