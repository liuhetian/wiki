# 分享文案

分享文案是**给外部观众看的传播卡片**：目的是让人愿意转发、收藏、复刻，或者自己也来调用这个 skill。它不是作品长评，也不是工作流状态提示。

**出图之前编好**：Shot 写完、调任何图片接口之前，先编好并给用户看，再出图，出图之后不用再补文字。用户说「只出图」「不要文案」时记为跳过。自主模式和抽卡模式用同一套结构，模式状态不污染对外的文字。

## 格式 { #format }

花括号里是要填的内容：

````markdown
**【分享文案】**

《{故事卡名}》

{1–2 句情绪或画面钩子}

**复刻提示词**
`@写真拍摄企划 {拍摄类型或主题}，{时空或地点}，{关键场景或时代}，{主色或造型}，{关系情绪或摄影气质}；{必要的自由度指令}`

{4–7 个标签，每个以 # 开头，空格分隔}

{1 句对外的 CTA}
````

## 规矩 { #rules }

- **故事卡名必须显示出来**，写成 `《短标题》`；不能只留在内部状态、方向卡或「抽中主题」的摘要里
- **钩子**优先组合当前的时空或地点、色彩或光线、人物关系或情绪，形成一句有记忆点的话；短、准、能截图传播，不写成长篇作品说明
- **「复刻提示词」这个标题不能省**，不能只放一句光秃秃的调用句
- **复刻提示词是短调用指令**，以 `@写真拍摄企划` 开头，浓缩拍摄类型、时空地点、关键场景或时代、主色或造型、关系情绪和摄影气质，留必要的自由度（比如「动作随机」）；它不是完整的生图 prompt，不放内部字段，也不放长 Shot List
- **标签 4–7 个**，围绕地点或时空、色彩、题材或关系、摄影风格、情绪记忆点，优先有辨识度、有搜索和传播价值的；每个以 `#` 开头、用空格分隔，比如 `#杭州情侣照 #曲院风荷 #江南雨景`；不写 `标签：A、B、C`，也不写不带 `#` 的关键词串
- **CTA 面向外部读者**，是自然的社交邀请，目的是让人继续玩：也来抽一张、选一个时空、用自己的关键词试一组。优先按当前作品给一个低门槛的二创动作 —— 只改地点、只改年代、换一个作品世界、用自己的城市复刻、@朋友接力 —— 但要写成传播句，比如「把‘洱海’换成你们的下一站，看看同样的默契会落进什么风景」；句式每次动态生成，不机械复读
- **CTA 里不写内部操作说明**：不写「下一次可以……」「你可以只改……」「保留这对情侣」「保留关系动态」「下一轮……」「继续执行……」
- **不写工作流和模式话术**：「新卡已生成」「抽卡结果」「当前处于抽卡模式」「切换回自主模式」「本次生成」都不能出现在分享文案或成片回复的结尾；也不暴露项目校验、`VALID`、内部文件路径、deliverables、schema、测试状态
- 不虚构真实的拍摄经历，不强制标注 AI，不写生图的技术说明

## 保存工程时 { #script }

写成 JSON 或 YAML，键名英文，交给 `share_card.py --share-file`：

```json
{
  "story_card_name": "……",
  "share_hook": "……",
  "reproduction_prompt": "@写真拍摄企划 ……",
  "share_hashtags": ["#……", "#……", "#……", "#……"],
  "share_cta": "……"
}
```

脚本校验五个键都有、标签 4–7 个且都以 `#` 开头、复刻提示词以 `@写真拍摄企划` 开头、没有「新卡已生成」这类话术，通过后存进 `deliverables/share-cards/` 并打印成上面的格式；用户不要文案时用 `--skip`。
