# 婚纱骨架

只有 2 人、以婚礼新人为中心、婚纱仪式是核心时，写每张 Shot 的出图 prompt 参考这个骨架；3 人以上（新人加伴郎伴娘、家庭）改用[单人与群像骨架](group-prompt.md)，再叠加婚礼仪式的语义。读者也可以在网页上填好直接复制去出图。

> 创作一张专业商业级婚纱摄影作品。
>
> **【拍摄任务】**
> 这是一组用于影楼婚纱客片、婚纱样片、婚礼品牌宣传、客户选片展示的正式婚纱摄影作品。照片必须有明确的婚纱摄影企划感、仪式感和纪念价值，不是普通情侣合照或旅行打卡照。
>
> **【人物设定】**
> 主体是一对即将结婚或已经完成婚礼仪式的新人。
>
> - 新郎：<input placeholder="年龄，比如 30">岁，<input placeholder="外貌特征、气质、身形">
> - 新娘：<input placeholder="年龄，比如 28">岁，<input placeholder="外貌特征、气质、身形">
>
> 如果提供了参考图：
>
> - 身份参考硬规则：除非用户明确指定改用美化后或后来生成的图片当人物参考，否则始终用最初上传的真人原图锁定人脸；后来生成的图只能当构图、姿势或风格参考，不能自动替换原图的身份锚点
> - 参考图只用于身份锚定，不锁定表情：保持脸型、核心五官比例、年龄感和辨识度，但不要机械复制参考图的微笑、嘴型、眼神、视线方向或头部角度；每张的表情按当前动作和情绪重新生成
> - 正式拍摄必须执行已确认的专业化妆师设计；即使跳过了参考图美化，也要有专门的皮肤优化和本主题妆面
> - 最终出图执行已确认的专业发型师设计和化妆师设计；原参考图或精修参考图的发型，只有用户明确要求保留时才是硬约束
> - 以参考图为身份依据，保持两人的核心五官特征、脸型比例和年龄感稳定
>
