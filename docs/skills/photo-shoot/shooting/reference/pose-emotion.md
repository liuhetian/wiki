# 姿势与情绪

出 Shot List 之前必须先做姿势与情绪规划，但它不是姿势词库，也不是全身参数表。每张 Shot 分层规划：

**动作意图 → 关键身体力学 → 人物关系与接触 → 情绪动机 → 景别适配**

## 动作意图 { #intent }

- 先回答人物正在做什么、准备做什么，或刚刚发生了什么
- 姿势由事件自然产生，不是先摆好姿势再硬补故事
- 动作要有情境原因，不写「自由摆拍」「自然互动」「放松一点」这种做不出来的描述

## 关键身体力学 { #mechanics }

每张只挑 2–4 个真正决定姿势成不成立的点，不机械填满全身：

- 脚位、前后脚关系、支撑脚和放松脚
- 脚尖、膝盖朝向
- 重心落点和转移
- 骨盆朝向
- 肩线
- 躯干前倾、后仰、侧倾、扭转
- 脊柱延展
- 手的落点、支撑点
- 身体和环境、道具的接触点

## 人物关系与接触 { #contact }

**情侣**还要规划接触关系拓扑：

- 谁主动、谁回应
- 身体距离
- 接触点
- 双方身体朝向
- 重心是否呼应
- 视线关系

接触不能为了「甜」机械加，要服务当前的关系状态和情境事件。两人不能长期保持同一种关系结构：8 张里要有接触和不接触、同向和相向、前后错位、共同动作等不同结构，但不拿固定示例当运行时模板。

**家庭、多人**规划高低层次、前后空间、重心稳定、身体接触、视线网络和陪伴关系，不把所有人排成同一个姿势。

**个人写真**优先动作意图、身体主轴、支撑关系、线条和服装受力，情绪动机要和当前主题一致。

人物关系描述是这一层的上游约束：Shot 级的关系和接触可以变化，但不能和已确认的关系描述冲突；多人不能只写「朋友们」「家人们」「一群人」，要写明每个成员或子群和核心人物的关系。

## 情绪动机 { #emotion }

- 情绪和姿势一起规划，根据当前主题、人物关系、场景和叙事即时生成
- **不建固定的情绪示例、固定词表、固定组合或硬编码例子**
- 优先写「为什么人物会有这个身体反应」的情境化心理或关系状态，不只贴一个抽象的情绪标签；再把它落成可执行的身体反应、视线和表情

## 景别适配 { #framing }

这是硬规则，不描述镜头看不见的部位：

- **全身**：重点脚位、腿部关系、重心和整体轴线
- **三分之二、半身**：重点骨盆以上、肩线、躯干、手和接触关系
- **近景、特写**：重点头颈、肩线、手、视线和微动作；不强行写镜头外的脚位

## 姿势家族去重 { #dedupe }

- 8 张不只动作文字不同，**姿势结构也要语义去重**
- 判断重复看承重结构、身体主轴、支撑方式、运动状态、环境接触和人物关系结构，不看「扶墙 / 扶栏杆 / 扶桌子」这种表面物件变没变
- 两张只换了墙、栏杆、桌子或道具，承重和身体结构不变，就是同一个姿势家族，必须重做
- 整组要在静态和动态、开放和收拢、对称和不对称、低位和高位、独立和接触、有环境支撑和没有支撑这些维度上拉开变化 —— 这些是去重的检查标准，不是固定示例

## 输出 { #output }

- 先给一段「本组姿势与情绪规划摘要」：姿势家族怎么分布、情绪和叙事的曲线、关系怎么变化
- 再出 8 张 Shot，每张都落到：动作事件、姿势结构、关键受力和重心、关系和接触、情绪动机、视线、景别适配
- 这些字段和场景位点、景别、构图、光线一起构成一张完整的 Shot，见 [Shot List](shot-list.md)
