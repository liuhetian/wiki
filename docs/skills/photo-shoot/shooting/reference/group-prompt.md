# 单人与群像骨架

1 人，或 3 人以上的群像（家庭、朋友、团队、乐队、婚礼派对、角色阵营）写每张 Shot 的出图 prompt 时参考这个骨架；婚礼群像在这上面叠加婚礼仪式的语义。读者也可以在网页上填好直接复制去出图。

> 创作一张专业商业级人物摄影作品，适用于单人或任意人数群像。
>
> **【人物名单】**
> 必须严格按确认的人物清单和人数生成，不得漏人、增人、复制人物或交换身份。逐人描述：<textarea placeholder="一人一行：P01：年龄 / 角色 / 外貌气质 / 完整服装 / 妆容整理；发型用已确认的专业发型师设计。P02 …… 一直写到所有人"></textarea>
>
> 如果提供了人物参考图，以各自的参考图作为这个人的身份依据，保持脸型、五官比例、年龄感和辨识度稳定。
>
> - 身份参考硬规则：除非用户明确指定改用美化后或后来生成的图片当人物参考，否则始终用最初上传的真人原图锁定人脸；后来生成的图只能当构图、姿势或风格参考，不能自动替换原图的身份锚点
> - 参考图只用于身份锚定，不锁定表情：保持脸型、核心五官比例、年龄感和辨识度，但不要机械复制参考图的微笑、嘴型、眼神、视线方向或头部角度；每张的表情按当前动作和情绪重新生成
> - 正式拍摄必须执行已确认的专业化妆师设计；即使跳过了参考图美化，也要有专门的皮肤优化和本主题妆面
> - 最终出图执行已确认的专业发型师设计和化妆师设计；原参考图或精修参考图的发型，只有用户明确要求保留时才是硬约束
>
> **【群体关系】**
> <input placeholder="比如：家庭 / 朋友 / 团队 / 乐队 / 婚礼派对 / 角色阵营 / 自定义关系">。明确视觉中心、人物层级、亲密度、距离关系和共同的事件。
>
> **【场景】**
> <input placeholder="具名主场景、具体区域、环境层次、和人数相匹配的空间容量">
>
> **【逐人服装】**
> 每个人都穿确认过的独立服装，不能用「其他人同款」「大家统一类似」代替逐人说明。
>
> **【逐人动作与视线】**
> 对这张里每个出镜的人分别写动作、身体朝向、视线、表情、手和道具的关系：<textarea placeholder="一人一行：P01：动作 / 身体朝向 / 视线表情 / 手和道具"></textarea>
>
> **【群体互动】**
> 所有动作属于同一个看得懂的事件，不是几个独立的人被摆进同一个画面。
>
> **【构图】**
> 按人数建立清晰的前中后层级、横向或纵向的节奏、主次关系和负空间；避免机械排队、证件照式站位和没有意义的对称。
>
> **【光线与质感】**
> 专业的摄影语言，真实的皮肤和织物纹理，光线统一但保留人物的立体层次。
>
> **【硬约束】**
> 不得漏人、增人、复制人物、合并人物、交换服装、改变确认的角色；不出文字、Logo、水印；不用默认西装或礼服替换没穿这种衣服的人。
