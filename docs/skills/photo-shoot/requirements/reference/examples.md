## 古风入口 { #ancient }

用户：想拍一套古风情侣照。

- 不先问服装细节
- 「古风」有大分叉：历史古典、武侠侠侣、仙侠影视感、古典爱情、新古风时装。不拿这几支出一道选择题，也不给它们编字母 —— 字母只给方向卡用；把分叉拉开到三张方向卡里，每张仍要有明确的时代 + 真实地点，或作品 + 地点
- 用户选了偏武侠的那张，后面直接推出窄袖、腰封、利于行动的层次、深浅对照这些服装逻辑，再展开成完整的情侣 Look

## 瑞士旅行入口 { #switzerland }

用户：想去瑞士拍一组情侣照。

- 地点明确，服装方向没定
- 瑞士是场景和气候语境，不等于民族服装
- 旅行感的分叉 —— 浪漫电影旅行、松弛生活感、时尚大片、轻婚礼 —— 拉开到三张卡里；用户限定了地点，A/B 都落在瑞士境内两个差异明显的具名地点，再在可行范围内给一个穿越方向
- 用户选完后继续推服装层次、季节适配、鞋履实穿性、场景位置和道具

## 波西米亚裙入口 { #boho }

用户：我想穿波西米亚裙子拍一组情侣照。

- 女装的核心单品是用户定的（`user_fixed`），风格语汇是波西米亚
- 不再问「女生想穿什么类型的裙子」
- 男装、地点、正式度由系统补全；海边度假、山野旅行、复古音乐节这几种气质拉开到三张卡里
- 选定后直接出完整 Look，不插一张简版确认单

## Cosplay 入口 { #cosplay }

用户：想拍一组 Cosplay 情侣照。

要确认的关键条件（用户没给时）：

1. 具体角色或 IP
2. 还原程度：高还原 / 真人影视化 / 时装化改编 / 只借角色气质

用户已经点名了角色，就不再问题材方向，直接围绕角色的标志性服装、色彩、配件和双方关系做方案。

## 婚纱三套 { #multi-look }

用户：婚纱照想拍三套，不要三套都太正式。

立刻记下 `look_count = 3`。可以推荐成一套完整的系列：

- LOOK 01：主视觉 / 正式婚礼
- LOOK 02：轻正式 / 情侣关系感
- LOOK 03：个性主题 / 时装或旅行

每套至少在正式度、廓形、配色、场景、关系气质里拉开 2–3 项，不只换颜色。

## 五人朋友群像 { #group }

用户：

> 我们 5 个大学同学想拍一组有点电影感的旅行写真，不想像普通团建照。

「5 人」和「大学同学」已经明确，性别构成没给，只补问这一项：

> 5 个人的性别构成分别是什么？

用户补充：3 男 2 女。人物结构确认到此结束，随后立刻出 A/B/C，不再追加问卷。

### 需求确认

```text
拍摄类型：朋友旅行群像
人数：5 人
性别构成：3 男 2 女
人物：P01（男）、P02（男）、P03（女）、P04（男）、P05（女）
人物关系描述：5 人是大学时期形成的长期好友，关系平等，没有单一的绝对主角；拍摄中保持熟悉感、互相回应和小群体交叉互动
套数：1 套
主题方向：旧城区旅行、生活流电影感
关系气质：熟悉、松弛、互相打趣
服装倾向：轻复古日常，每个人独立，但共享材质和低饱和色系
避免项：五人制服感、并排站队、旅游打卡手势
```

### Group Look

- **P01**：暖灰短风衣、旧白牛津纺衬衫、深炭直筒裤、黑色短靴；哑光棉和轻羊毛为主，整体利落但不过分正式
- **P02**：洗旧海军蓝工装夹克、米白针织、卡其长裤、深棕休闲皮鞋；比 P01 更松弛，材质更粗粝
- **P03**：暗酒红针织开衫、灰白 T 恤、深蓝洗旧牛仔裤、棕色德比鞋；用暗红形成次级色彩锚点
- **P04**：灰绿色轻薄外套、浅灰衬衫、黑色宽松长裤、旧白运动鞋；轮廓更宽，负责拉开群体的廓形差异
- **P05**：深灰短夹克、雾蓝针织 Polo、米灰长裤、黑色乐福鞋；材质更细腻，是群体里偏干净的一套

**群体搭配**：五人共享旧白、灰、深蓝、棕色母题，但每人通过不同的主色、材质和廓形保持独立；P03 的暗酒红是唯一的暖色锚点；没有任何两个人穿成完全相同的套装。

### 一张 Shot 的逐人调度

出镜人物：P01、P02、P03、P04、P05

- P01：走在左前侧，回头看 P02，右手轻抓风衣下摆
- P02：和 P01 并行半步，低头笑，左手拿折叠地图
- P03：在中间稍后，侧头回应 P04，手里拿饮料
- P04：身体朝向 P03，抬手做一个短促的解释动作
- P05：在右侧稍后，视线看向四人，双手自然插袋

群体互动：五人在移动中围着同一个话题自然交谈，形成错落的行进节奏，不是五人并排走秀。

## 地点精度 { #location }

需求确认只锁时空锚点，Group Look 只给可拍区域，Shot List 才决定微点位。规则见[地点](../../reference/location.md)。

### A. 现代现实室内｜巴黎

需求确认：

```yaml
location_mode: real_world
city: 巴黎
district_or_area: Paris 6e / Saint-Germain-des-Prés
street_or_route: Boulevard Raspail / Boulevard Saint-Germain   # 私人公寓概念方案至少锁到真实街道
named_place: Hôtel Lutetia Paris   # 或「Boulevard Saint-Germain 沿线的 Haussmann 公寓语境」
indoor_outdoor: indoor
verification_status: known_public_place_needs_current_verification   # 公寓概念方案用 conceptual_private_interior
```

此时不写哪一间套房、哪扇高窗、沙发旁哪个位置。

- Group Look 的可拍区域：酒店公共沙龙、客房起居区、楼梯和过厅空间
- Shot List 才细化：Shot 01 在公共沙龙临高窗区域，Shot 02 在主楼梯转角，Shot 03 在客房起居区靠壁炉一侧

用户坚持私人公寓又没有真实房源时，不能虚构门牌号并宣称是真实地址。

### B. 现代现实户外｜杭州西湖

需求确认：

```yaml
location_mode: real_world
city: 杭州
district_or_area: 西湖风景名胜区·孤山 / 北山街一带
indoor_outdoor: outdoor
verification_status: known_public_place_needs_current_verification
```

不要只写「西湖边」，但也不现在就锁某一棵树、某一段栏杆。

- Group Look 的可拍区域：北山街梧桐街景、孤山临湖步道、湖岸石阶和小尺度停留空间
- Shot List 才细化：每张按构图和出镜人数选具体的树影、栏杆、石阶或转角

### C. 文学作品｜《红楼梦》

需求确认：

```yaml
location_mode: source_work
source_work: 《红楼梦》
in_world_location: 大观园·潇湘馆
era_or_period: 清代小说语境
world_state_or_chapter: 大观园居住时期
```

这已经是合格的作品时空锚点，此时不强制写「竹影院落通向回廊的转角」。

- Group Look 的可拍区域：竹影院落、回廊、小轩窗内外
- Shot List 才细化：每张决定人物在回廊折角、窗外竹影旁还是院落入口

### D. 游戏作品｜《原神》

需求确认：

```yaml
location_mode: source_work
source_work: 《原神》
in_world_location: 璃月港·玉京台
era_or_period: 提瓦特当代世界状态
world_state_or_chapter: 璃月主城稳定时期
```

不要只写「璃月」「原神城市」，也不过早锁定某个栏杆角度。

- Group Look 的可拍区域：玉京台主平台、台阶与飞檐层次、临栏观景区
- Shot List 才细化：按景别、出镜人数和动作决定具体的台阶、临栏位置和背景纵深
