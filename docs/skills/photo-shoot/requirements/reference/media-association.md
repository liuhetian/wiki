# 影视与流行文化联想

用户用和影视、游戏、动漫、流行文化强相关的词时，帮 AI 把抽象风格翻成更具体的服装语言。

## 原则 { #principles }

1. 用户点名具体作品或角色：强参考
2. 用户只说宽泛风格：生成候选的视觉谱系，不擅自绑定某个 IP
3. 联想最后都要落到服装和「进入那个时代或世界」的场景上：廓形、层次、材质、色彩、配饰、身份感、时代或世界观、地点归属
4. 地点不自动等于民族服装
5. 古装不自动等于汉服，韩系不自动等于韩服，Cosplay 不自动等于二次元夸张服装
6. 用户点名作品或 Cosplay 的 IP 时，让所有人进入作品里认得出的时代和地点；全球真实景点只用于没有作品、时代或虚构世界观约束的普通现代人物摄影

## 古装 { #ancient }

可能的分支：

- 历史剧：真实形制、克制的材质、时代准确
- 武侠：利落、能行动，窄袖、叠穿、护腕、腰封
- 仙侠：飘逸、层叠、半透明、轻材质、幻想感
- 古典爱情：柔和、含蓄、精致，文人或闺阁气质
- 新古风 Editorial：古典元素 + 当代时装结构

地点和时代：

- 每个方向和完整 Look 都写明具体时代或架空的文化语境，历史题材尽量细到朝代和时期
- 用户没指定时代时，用不同年代或谱系拉开候选，不擅自绑定某一个朝代
- 让所有人回到那个时代正在运转的历史空间，比如唐贞观年间的大明宫、北宋汴京的樊楼；不用今天的遗址公园、博物馆、景区或复原街区，除非用户明确要在那里拍现实照片

## 韩系 { #korean }

- 韩剧都市爱情：克制、干净、轻正式、低饱和
- 韩式婚纱：简洁高级、柔光，白、米、灰，剪裁干净
- K-pop Editorial：强造型、廓形西装、亮面材质、冷感
- 校园青春：针织、衬衫、百褶、棒球夹克，清爽配色

## Cosplay { #cosplay }

要确认：

- 具体角色或 IP
- 还原程度：高还原 / 真人影视化 / 时装化改编 / 只借角色气质

地点：

- 没指定 IP 时，先要 IP 或给少量候选视觉方向，不随机选现实地点
- 指定 IP 后，让所有人进入那个游戏或动漫的世界，用其中认得出、适合当前人物关系或群体叙事的地点和时代、世界设定；几个候选地点可以用来拉开方向

## 影视、游戏、动漫和书籍 { #works }

- 用户点名具体作品时，让所有人进入作品世界，用作品里认得出的地点，已知且相关时写明作品设定的时代
- 不拿现实著名景点或现实取景地代替作品场景；场景不唯一时，用不同的作品内地点、事件氛围或空间层次拉开方向

## 纯虚构、融合作品 { #fictional }

- 用户明确要架空或融合时，创建原创的时空地点并清楚标明是虚构的，让所有人进入这个原创世界
- 写明它的时代或世界状态，参考一部作品还是融合几部作品的视觉语言；不声称原创地点是任何作品的官方场景

## 民国 { #republic }

- 都市摩登
- 文人青年
- 旧上海礼服
- 军装或制服叙事（需要用户方向支持）

## 赛博、未来 { #cyber }

- 赛博朋克电影
- 未来都市游戏的电影感
- 极简科技时装
- 东方未来主义

未来题材当方向卡的 C 时，要落在认得出的现实城市或地标的未来化版本上，见[时空方向](directions.md#time-travel)。
