# 时空方向

首轮三个方向固定是 **2 个现代现实世界的著名景点 + 1 个穿越方向**。三个方向都先定下明确的时空坐标，不能拿抽象风格代替。

## 宽泛请求不降级 { #generic }

- 「情侣照」「个人写真」「婚纱照」「全家福」这类宽泛请求**不降低时空锚点的要求**
- 「城市日常」「自然系」「高级影楼」「甜感」「电影感」这种纯风格卡不能当一级方向，只能当已定时空方向里的二级视觉描述
- A/B 必须出现认得出的真实世界著名地点；C 必须出现明确的古代时期 + 真实地点、未来化的现实地标，或已知作品 + 地点
- 三张卡固定编号 A / B / C，不改成 1 / 2 / 3 再让用户二次选择

## A / B：现代现实 { #reality }

- 当代现实世界里真实存在、全球有辨识度的著名景点、地标或城市空间
- **用户没指定地点时，A/B 的地理跨度尽量拉大**：优先跨大洲或明显不同的宏观文化区，至少在气候、建筑、自然环境、生活方式和色彩气质上形成肉眼可见的强差异；不给同国、邻国或同一文化圈的近似地点，除非用户条件本身限定了范围。两个太近或气质太像就自动重抽
- 连续「再来一版」「换地点」「再抽一张」时，新的现实地点优先远离最近出现过的现实地点，结合 `used_spacetime_set` 和 `spacetime_passport` 在地理、文化、气候、建筑上去重
- 地点要真正影响建筑、材质、气候、生活方式、服装适配和摄影语言，不能只把地名贴在普通背景上

### 地点和国籍解耦 { #nationality }

- **用户没明确指定拍摄地点时，人物的国籍、出生地、文化身份都不绑定随机地点**。用户说「中国情侣」「法国女生」「日本男生」，都不默认把地点锁到中国、法国、日本
- 国籍和文化身份可以影响人物身份、服装适配、妆发和叙事，但不当地点随机的先验
- 只有用户说「在某地拍」「想要本国文化背景」「就在某城市」「围绕某地点」，地点才受约束
- 不从外貌推断国籍，更不用推断出的国籍决定地点

## C：穿越 { #time-travel }

三类任选其一：

- **古代**：明确的历史时期 + 真实著名地点
- **未来**：明确的未来时代 + 认得出的现实城市或地标的未来化版本，不是无出处的泛未来城
- **已知作品**：已知的电影、电视剧、动漫、游戏、文学作品 + 明确的世界、城市或地点

### 已知作品怎么借 { #known-work }

- 借作品的世界观、空间、时代和视觉语境，做摄影化改编
- 默认把用户设计成「进入这个世界的人」，不让用户直接扮演原角色
- 不机械复制原角色的服装或经典剧照
- 用户明确要求 Cosplay 或指定角色时，才进入角色复刻

## 通用 { #common }

- 不自行创造无出处的一级世界坐标，比如「蒸汽朋克空中小镇」「未来东方城市」「梦幻森林王国」「赛博古城」；这些只能当辅助描述。用户自己明确提出原创世界时可以继承
- 三个方向在地域、世界观、人物身份、服装体系、色彩光线、空间结构和摄影语言上拉开
- 用户已经限定了时代、作品或地点时，先服从用户条件，再在可行范围内保持「2 现实 + 1 穿越」；用户明确只要单一时代或单一作品时，以用户为准
- 每个方向都要能继续拆成至少 8 张有明显差异的照片
- 真实性、few-shot、去重、跨度这些核验是内部检查，不在方向卡里写「已核验」「通过 few-shot 隔离」「官方信息确认」之类的回执，除非用户主动问依据，或现实拍摄许可确实需要说明

## few-shot 隔离 { #few-shot }

本 skill 里的示例（[需求示例](examples.md)、[地点](../../reference/location.md)和[影视与流行文化联想](media-association.md)里的示范锚点、分享卡里的例句）只用来示范结构、字段、长度、语气和交互，**不是创意来源，也不是运行时的推荐池**。

- 系统推荐、重新推荐、换主题后的推荐、抽卡自动选择，**都不能和任何 few-shot 方向相同**
- 「相同」按语义锚点判断，不只比标题：同一个「时代 + 真实地点」、同一个「作品 + 世界 / 城市 / 地点」、标题不同但核心时空坐标实际相同，都算命中
- 换标题、换身份、换服装、换妆发、换光线、换摄影语言都不能解除冲突
- 正式输出前先建立 `few_shot_exclusion_set`，逐个校验候选；命中就**丢弃 → 重新生成 → 再校验**，冲突的候选不给用户看，也不带着降级提示继续输出
- 自主模式的 A/B/C 三张全部通过才展示；抽卡自动选的方向也要先通过，才继续 Look、场景、Shot 和出图
- 用户自己明确点名某个 few-shot 里的地点、作品或方向时，可以照用户的要求做，这不算系统推荐；但系统不会主动推荐它
- 情绪层面同样不建固定的 few-shot 词库：姿势和情绪从当前主题、关系、场景和叙事动态生成

### 当前主题去重 { #dedupe }

`used_spacetime_set` = 当前主题里已经推荐过、抽到过、自动选中过、用户选中过的时空点。

用户说「换一个」「再来一版」时，从没出现过、也不在 `few_shot_exclusion_set` 里的时空点生成。用户条件太窄时继续找新的合法锚点，不因为候选不够就退回 few-shot。

## 抽卡池 { #draw-pool }

- 抽卡模式也必须保留穿越能力，不能退化成「全球现代旅游地点随机器」
- 用户没限制时代或作品时，四类同时开放：当代现实 `real_contemporary`、古代历史 `real_historical`、未来现实地标 `future_landmark`、已知作品世界 `source_work`；四类都有机会被抽中，不默认偏向当代现实
- 连续抽卡按 `direction_type_history` 轮换类型：最近的结果连续偏现实时，下一张优先从古代、未来、已知作品里抽
- 原创虚构世界 `original_fictional` 不在默认池里，只在用户明确要原创世界时开放
- 随机只作用在用户没锁定的字段上：人数、身份参考、关系、指定的服装或题材、安全和隐私需求、硬避免项都保留
- 抽出来的必须是具体的地点卡，不只是一种氛围：现实地点用真实具名地点并照[核验规则](../../reference/location.md#verify)办，历史要带时代，作品要写作品 + 作品内地点 + 时代或世界状态
- 有同样合适的选择时，避开最近用过的时空卡
