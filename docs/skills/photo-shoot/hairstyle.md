# 发型师

Editorial 专业发型师，正式拍摄的前置造型节点。方向卡已经有明确的时空、场景和逐人服装草案后立刻运行，给这个方向定正式发型；用户选中方向后，下游的 Look、Shot、出图只继承，不重新设计。

## 什么时候跑 { #when }

- 自主模式：A/B/C 每个合法方向在展示给用户之前，逐人做完
- 抽卡模式：AI 选定合法方向后立刻做，再展开 Look
- 改一个变量：只在依赖图判定发型失效时重跑 —— 换年代、换服装、换世界观，或地点环境的变化明显影响发型，见[改一个变量](reference/remix.md)
- 用户明确要改发型时重跑

## 参考图不锁头发 { #reference }

- 真人原图只提供脸的身份，不锁发型：发长、卷直、刘海、分缝、体积、轮廓、发色质感都可以重新设计
- 不能因为原图里头发看得清就默认沿用；用户明确要求保留原发型除外
- [参考图美化](beauty-prep.md)出的精修图里的发型也只是审美参考，不锁

## 可以改什么 { #variables }

除非用户明确锁定，下面每一项都是开放的设计变量：

- 长度：变长或变短
- 质地：直发、卷发、波浪
- 分缝：中分、偏分、没有明显分缝
- 刘海：保留原刘海、设计具体的新刘海，或露额
- 顶部体积
- 两侧：包裹、贴合、碎发
- 后区：收束、盘发、披发、马尾
- 整体轮廓
- 露不露耳、露不露颈
- 必要的发饰
- 必要且与主题一致的发色质感

**刘海策略必须明确决定**，不能无意识地沿用参考图。

## 依据什么设计 { #basis }

综合人物气质、脸型和五官重心、额头比例、头颈和肩部比例、逐人服装、领口和肩线、配饰、时代或作品世界、场景环境和摄影语言，直接设计最符合这个方向气质的发型。要具体可执行，不写「根据脸型优化发型」这种空话。

## 输出 { #output }

每个人一份 `hairstyle_design`，写进方向卡的「发型定稿」一行，保存工程时也写进交接文件：

```text
人物：{编号 / 称呼}
长度：{……}
质地：{……}
分缝：{……}
刘海：{保留原刘海 / 具体的新刘海形状 / 露额}
顶部体积：{……}
两侧：{……}
后区：{……}
轮廓：{……}
露耳露颈：{……}
发饰：{……}
发色质感：{……}
设计理由：{为什么这样最适合这个方向}
```

方向卡上直接显示定稿结果，不再给用户出 A/B/C 发型选项；用户明确要改发型时才重跑。
