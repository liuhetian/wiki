# 化妆师

Editorial 专业化妆师。方向卡有了明确的时空、场景、逐人服装草案，并且[发型师](hairstyle.md)已经定完发型之后，立刻给每个人设计这个方向的正式妆面和皮肤优化。用户选中方向后，下游的 Look、Shot、出图继承这个结果，不重新设计。

## 什么时候跑 { #when }

- **只要进了正式拍摄流程就必须跑**
- 自主模式：A/B/C 每个合法方向展示前，先定完逐人发型，再跑这里
- 抽卡模式：AI 选定方向、定完发型后随即跑
- 和用户有没有用[参考图美化](beauty-prep.md)无关；美化不由系统主动询问
- 选中方向后 `makeup_design` 锁定，只有[改一个变量](reference/remix.md)判定失效或用户明确要改妆时才重跑

用户只是生成或选了精修美化图、没明确说把它当身份参考时，化妆师照旧以最初上传的真人原图为身份依据；用户明确要求用美化图做人脸参考时，才以升级后的参考为身份源。不管身份源是哪张，正式妆面都按当前方向重新设计。

## 皮肤优化的默认值 { #skin }

- **女性默认白皙柔焦影楼精修**，几项缺一不可：明显淡化斑点、泛红、肤色不均，去黑眼圈，轻微磨皮，柔和的柔焦光晕，均匀偏白皙的健康肤色
- 女性默认照样保持本人的五官和年龄印象，不靠改脸制造精修感
- 非女性的人物按人物和题材做专业、克制、上镜的肤质和气色整理，不机械套女性的白皙柔焦妆面；纯男性项目不加白皙柔焦
- 用户明确指定妆容或肤感（自然皮肤、原生肤质、不要精修）时，以用户的要求为准
- 不自动展开皮肤细节或肤色描述，不凭外貌推断族裔

## 设计维度 { #dimensions }

每个人都按当前主题独立设计：

- 皮肤优化：重点处理什么
- 底妆：质感和明暗关系
- 眉眼：眉形、眼妆、睫毛、眼神怎么强化
- 腮红与唇：腮红、唇色和整体气色
- 高光与修容：克制到什么程度
- 主题适配：和服装、正式发型、配饰、时代或作品世界、场景、光线怎么协调

## 输出 { #output }

每个人一份 `makeup_design`，写进方向卡的「妆容定稿」一行，保存工程时也写进交接文件：

```text
人物：{编号 / 称呼}
皮肤优化：{……}
底妆：{……}
眉眼：{……}
腮红与唇：{……}
高光与修容：{……}
主题适配：{……}
```

- 直接给一个专业、可执行的正式妆容结论，不新增 A/B/C 选择题
- 白皙柔焦只是女性默认的皮肤完成度，不代替主题妆面：具体妆面风格必须随主题变化
- 男性、银发、儿童、古风、婚纱、时尚 Editorial 等分别按人物和题材设计，不把女性写真妆机械套给所有人
