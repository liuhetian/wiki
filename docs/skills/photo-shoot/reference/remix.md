# 改一个变量

「只改一个变量」不是整组重抽：没点名的维度冻结，只重算目标变量和它必要的下游。

## 依赖图 { #graph }

| 改的变量 | 一定失效 | 视情况失效 |
|---|---|---|
| 地点 `location` | 场景、道具、Shot、分享文案、出图 | 气候或环境明显变了时：发型、妆容、服装 |
| 年代 `era` / 世界观 `worldview` | 服装、发型、妆容、场景、道具、Shot、分享文案、出图 | — |
| 服装 `wardrobe` | 发型、妆容、Shot、分享文案、出图 | 随身或穿戴的道具变了时：道具 |
| 发型 `hairstyle` | 妆容、Shot、出图 | 发型是传播看点时：分享文案 |
| 妆容 `makeup` | Shot、出图 | 妆容是传播看点时：分享文案 |
| 关系 `relationship` | 姿势与情绪、Shot、分享文案、出图 | 角色或正式度变了时：服装 |
| 色彩 `color` | 服装配色、发型、妆容、光线、Shot、分享文案、出图 | — |
| 摄影气质 `photography_style` | 光线、构图、Shot、分享文案、出图 | 妆面完成度和新风格冲突时：妆容 |

- 方向阶段定下的妆发是正式锁，只有这张图判定失效时才重跑；换服装、换年代、换世界观默认都重跑[发型师](../hairstyle.md)和[化妆师](../makeup.md)
- 保存工程时可以用脚本查：`python3 scripts/remix_dependencies.py 服装`，中文的地点、年代、世界观、服装、发型、妆容、关系、色彩、摄影气质（或摄影风格）都认，输出 JSON

## 传播玩法怎么执行 { #play }

- **只改一个变量**：用户说只改地点、年代、世界观、服装、关系、色彩、摄影气质时，只重算目标和必要依赖，没点名的身份、关系、Look、色彩、故事逻辑尽量冻结
- **保留人物，其他重抽**：身份和人物关系锚点冻结，其余创意维度可以重抽；用户另有明确要保留的，一并冻结
- **同一人物多时空**：「三世」「三个时空」「同一对情侣换三个世界」时，人物身份和核心关系连续，主动拉开时空类型、地理区域、服装体系和视觉语言 —— 不是同一个地点换滤镜
- **各给关键词**：几个人各给关键词时，合并成同一个主题约束；不把某个人的国籍、籍贯默认映射成拍摄地点
- **城市挑战、好友接力、反差抽卡、纪念日、旅行预演**：当自然语言意图直接执行，不新增给用户看的模式菜单
- **时空护照**：每个被选中或抽中的方向追加进 `spacetime_passport`，至少记 `story_card_name`、`spacetime_anchor`、`direction_type`，用来连续抽卡去重、控制跨度、接力复刻；用户主动要才展示
- **8 宫格微故事**：8 张 Shot 形成动态生成的关系、情绪、空间叙事曲线，整张宫格从头看到尾有微型故事感；不硬编码固定的 1–8 剧情模板，也不为了故事性牺牲姿势家族、景别和场景差异
