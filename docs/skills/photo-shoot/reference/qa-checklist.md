# 发送前自检

## 首轮入口 { #entry }

- [ ] 没有「方式 A / 方式 B / 快速推荐 / 选择进入方式」的模式菜单
- [ ] 情侣、单人这类不用补问人物结构的，第一屏直接是 A/B/C；全家福和其他多人结构缺失时，只补人数、性别、关系，然后立刻出 A/B/C
- [ ] A/B/C 是方向编号，不是模式编号
- [ ] 宽泛请求也没退化成纯风格卡
- [ ] 用户回 a/b/c 时消费的是上一轮对应的方向，没有重开流程
- [ ] 抽卡只由明确的「抽卡」触发

## 三张方向卡 { #directions }

- [ ] 三个方向都是明确的时空点
- [ ] A/B 都是现代现实世界的著名景点或地标，彼此差异明显；用户没给地点时跨大区，在文化、气候、建筑上拉得够开，没被人物国籍绑定
- [ ] C 是穿越：古代有时期 + 真实著名地点，未来有时代 + 认得出的现实地标，作品有作品 + 地点
- [ ] 没有无出处的自造世界
- [ ] 三张都不在 few-shot 排除集里，也没有和 few-shot 语义同锚点；没撞当前主题用过的时空点
- [ ] 三个方向之间差异明显，每个都能拆成 8 张不同的照片
- [ ] 「已核验」「few-shot 隔离」「去重通过」这类内部检查没有写成回执
- [ ] 字段齐全，字段名和值同一行，字段之间没有空行；每张卡在独立的 `text` 代码块里，末尾是 `出8宫格图片。`
- [ ] 情侣默认 2 人一女一男，除非用户明确覆盖；全家福和其他多人在出卡前已明确总人数、性别构成、关系结构
- [ ] 情侣和多人的卡有独立的人物关系描述
- [ ] 服装、发型、妆容都逐人一行，没有合并成一个「服装造型」字段

## 抽卡模式 { #card-draw }

- [ ] 没有输出三张卡让用户选
- [ ] 自动选的方向过了 few-shot 隔离和去重
- [ ] 自动走完：选方向、逐人发型、逐人妆容、Look 继承、场景、姿势与情绪规划、分享文案、8 张 Shot、8 宫格出图
- [ ] 没有直接输出 8 张独立图

## 选定后的方案 { #selected }

- [ ] Look 完整，场景具体到微点位
- [ ] 有本组姿势与情绪规划摘要
- [ ] 8 张 Shot 过了姿势家族语义去重
- [ ] 身体力学按景别只写关键点，没有堆参数
- [ ] 情侣的关系拓扑清楚（适用时）
- [ ] 8 张在景别、动作、姿势结构、关系、情绪动机、机位上都有变化
- [ ] 关系自然，人体动作真实可做到
- [ ] 主题、时代、世界观没有漂移
- [ ] 出图前分享文案已写好（或用户说了不要）
