# 交互模式

只有两种模式：自主模式 `user_directed`（默认）和抽卡模式 `card_draw`。两者共用同一套细节下限、地点规则、逐人 Look、姿势与情绪规则和 Shot 质量 —— 抽卡改的是谁来确认，不是内容质量。

## 自主模式（默认） { #user-directed }

自主模式本身就是轻量的逐步确认，是默认状态，不是要用户先选的菜单项。

新主题到来时：

1. 不展示「方式 A｜快速推荐 / 方式 B｜抽卡 / 两种进入方式」这类模式菜单，不做长串字段确认，不先解释模式，也不先写「正式开始」
2. 第一屏直接给 A/B/C 三张方向卡：A/B 是两个现代现实世界的著名地点，C 是一个穿越方向，规则见[时空方向](../requirements/reference/directions.md)。全家福和其他多人缺总人数、性别构成或关系结构时，先做一次人物结构确认，只问缺的，问完立即出卡 —— 这是唯一允许排在方向卡前面的确认，不得扩成通用问卷
3. 「我想拍情侣照」这类宽泛请求也不能退化成「城市日常 / 自然系 / 高级棚拍」这种纯风格卡
4. 每张卡展示前已经过 few-shot 隔离和去重，并已完成逐人正式发型和妆容
5. 每张卡完整放进一个独立的 `text` 代码块，末尾直接加一句 `出8宫格图片。`，用户点一下就能复制去别的生图模型自己出图，格式见[方向卡](../requirements/reference/direction-cards.md)
6. 结尾只做最小交互，用这一句：

    ```text
    可直接点击上方任意方案代码块一键复制提示词自行出图；或回复 A / B / C，我直接为你生成该方案的 8 宫格图片；也可以回复“抽卡”。
    ```

### 选向之后 { #after-selection }

- **回 A/B/C 就是这个方向的授权**：AI 在内部完成完整 Look、场景位点、姿势与情绪规划和 8 张 Shot，先给分享文案，再出一张 8 宫格
- 不插入 Look 二次确认或 Shot 二次确认，也不先输出冗长的方案计划文档；用户要求查看完整拆解或要微调时，再给逐人 Look（服装、面料、配色、妆发）、场景微位点与道具、姿势与情绪、8 张 Shot List
- 看到图后用户改任何字段都算修订，按[改一个变量](remix.md)只重算受影响的部分，不是新的确认门槛

## 方向卡待选状态 { #pending-cards }

- 输出 A/B/C 后记下 `pending_direction_cards = {A, B, C}`
- 下一条消息是 A/B/C（大小写不敏感）就优先消费对应的卡，直接进入该方向，不重新开启入口流程
- 消费后清空，免得旧卡在后面误触发
- 待选状态存在时，`a` 不得理解成「自主模式 / 快速推荐」，`b` 不得理解成「抽卡」

## 抽卡模式 { #card-draw }

只有用户明确说「抽卡」「抽卡模式」「随机抽一组」这类清楚的话才进入。抽卡不是再给三个方向。

1. 保留用户已有的硬约束、人物名单、身份参考和禁项
2. 不展示三张卡，AI 自选一个符合原始需求的方向；它必须先过 few-shot 隔离和当前主题去重，命中就丢掉重抽
3. 自动完成：方向 → 人物和关系 → 场景与逐人服装草案 → 发型师定稿 → 化妆师定稿 → 展开 Look 并继承妆发 → 姿势与情绪规划 → 道具 → 摄影基调 → 分享文案 → 8 张 Shot → 一张 8 宫格预览
4. 中途不逐项确认，没指定的由 AI 合理补全；完整 Look 自动确认，保存工程时交接文件记 `confirmation_source: ai_auto_confirmed`
5. 默认只出一张 8 宫格，不出 8 张独立图；用户之后说放大某格、单出某几张、全部单出才继续
6. 用户要生成本人却没给照片时，只在确实需要身份时才要照片；纯方案或通用模特预览不因此中断

抽卡池和连续抽卡的类型轮换见[时空方向](../requirements/reference/directions.md#draw-pool)。

## 模式切换 { #switching }

- 新项目默认自主模式；用户明确说「抽卡」才切，明确说「回自主模式」才切回
- 切换模式不降细节下限
- 「换主题」重建创意内容，全局硬规则不变
- 模式切换、抽卡、换主题、Remix 都不改变真人身份源

## 传播玩法不是第三种模式 { #play }

- 用户可以直接说：只改地点、只改年代、只改服装、只改关系、只改色彩、只改世界观、保留人物其他重抽、三世情侣、同一对换三个时空、两个人各给几个关键词、纪念日抽卡、城市挑战、反差抽卡、好友接力、旅行预演、看我的时空护照、1–8 选片投票。AI 直接理解并执行，不先展示玩法说明页，不做「挑战模式 / 接力模式 / Remix 模式 / 护照模式」菜单；怎么执行见[改一个变量](remix.md)
- 每个选中或抽中的方向起一个短而好记的故事卡名 `story_card_name`：方向标题优先用它，但时空坐标照样单独写清，卡名不能顶替地点、时代和作品
- 连续创作维护时空护照 `spacetime_passport`，记已选、已抽的时空、卡名和方向类型，用来去重、拉大下一次的跨度、支撑接力；用户说「看看我的护照」才展示
- 参考图美化也不是模式：用户主动要求才进，直接出三宫格，不先展示新菜单
