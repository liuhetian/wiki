# 质量下限

适用于每个新项目、新会话、新建的主题、重开的主题、每次再来一版，以及下游的每一份产物。

## 新会话不降质量 { #session-independent }

新会话或重开主题只重置**内容**，不重置**质量**。下面这些都不是降细节的理由：

- 对话是新的
- 用户说「重新开一个主题」「换个主题」「从头来」
- 人变多了
- 文档越来越长
- 同一个字段在上一个主题里已经写详细过

每个新主题都按同一细节下限重建完整的专业文档：完整的人物名单、逐人造型、完整的时空锚点地点卡。当前主题必需的字段不能用「同上」「沿用」「类似前一套」「其他人类似」「其余成员自然互动」代替。篇幅长就分页或分段，最后保存的产物仍然完整。重开主题不是「快速模式」。

## 逐人细节 { #participant-floor }

每个人都保持同样的描述深度：身份或角色、完整服装、层次结构、材质、颜色、鞋履、配饰、需要时的发型妆容整理、时代或角色逻辑、场景适配、道具、避免项。

方向卡阶段也逐人写：

- 情侣和多人的 A/B/C 卡不能只有一个合并的服装字段
- 情侣默认分「女方服装」「男方服装」两行；多人按角色名或 P01、P02 每人一行
- 共享色盘规则可以附加，不能代替逐人服装

## 禁用的压缩说法 { #no-compression }

拿来代替必需的细节时，下面这些一律不准写：

- 其他人同风格
- 其余人类似
- 剩下的人自然互动
- 同上
- 沿用前文即可
- 场景同前
- 服装统一协调即可

共享规则可以写，个人的落地照样要写。保存工程时 `validate_project.py` 也拦这些词。

## 选 A/B/C 是唯一的确认门槛 { #only-gate }

自主模式下，用户选 A/B/C 就允许把这个主题做完：

- 展开逐人 Look
- 保留时空锚点并补充可拍区域
- 做姿势与情绪规划
- 出 8 张 Shot、编分享文案、出 8 宫格

不再设「Look 再确认一次」「Shot 再确认一次」的阻塞门槛，也不插回「简版需求确认 → Look 再确认 → Shot 再确认」的旧链路。之后用户提修改，按修订处理。抽卡模式由 AI 自选方向，一路做到一张 8 宫格。

## 模式不改质量 { #mode-quality }

- 自主和抽卡共用同一条流水线和全部质量下限
- 抽卡默认不出 8 张独立图
- 模式不能被包装成首轮的 A/B 菜单，A/B/C 只属于方向卡

## 发型师和化妆师的门槛 { #styling-gates }

- [参考图美化](../beauty-prep.md)里的发型只用来找感觉
- 每个正式 Look 在主题、场景、服装确定后都要有具体可执行的发型设计。发长、卷直、分缝、刘海、轮廓都是开放变量，除非用户锁定；「根据脸型优化一下发型」这种空话不算设计。最终渲染照已定的发型执行
- 每次正式拍摄都要有化妆师方案，不管做没做过参考图美化；方案里要有明确的皮肤优化和随主题变化的妆面
- 直接用原始真人照片时，化妆师默认做到：清透自然妆容，淡化斑点、泛红、肤色不均和临时小瑕疵，需要时轻微弱化黑眼圈、提亮气色。用户要原生肤感、保留雀斑、不要修饰时照用户的
- 用精修过的身份参考图时照样走化妆师，按新主题、服装、正式发型和光线重新整合妆面
- 女性默认的白皙柔焦影楼精修，在纯男性项目里不加；纯男性项目也不跳过化妆师，只是妆面更克制，不套女性写真妆。用户要自然皮肤、原生肤质、不要精修时关掉
- 不自动展开皮肤细节或肤色描述，不凭外貌推断族裔
