# 参考图美化

正式拍摄之前，把用户上传的真人照片先做一次看得见的美化探索，得到一张用户满意、可以保存、能长期复用的精修美化图。

## 什么时候用 { #when }

- **只在用户主动要求时**：「美化参考图」「精修参考图」「做三宫格美化」「美图秀秀风格精修」
- 看到真人照片**不主动问**要不要美化，免得打断自主模式或抽卡模式
- 不用它不影响正式拍摄：方向阶段的[化妆师](makeup.md)照样处理正式妆面和皮肤优化
- 已经有用户认可的精修图就直接复用，除非用户主动要重新美化

## 流程 { #flow }

1. 不展示「轻度 / 标准 / 明显」这类文字档位
2. 直接出一张**恰好 3 格**、清晰独立的三宫格，方便按左 / 中 / 右挑；三格在皮肤、气色、妆容完成度、发丝、发型感觉、整体润色上有肉眼可见但不过度失真的差异，**中间一格必须是白皙柔焦精修**
3. 出完紧接着给用户这句提示，不能只让用户在左中右里选：

    ```text
    请选择左 / 中 / 右；也可以直接告诉我你的具体美化需求，例如“提升皮肤白皙度”“去掉所有可见斑点”“修改发型”。如果想一步到位，也可以说“做一版美图秀秀风格精修”，我会据此重新生成预览。
    ```

4. 用户提了具体要求：继承身份锚点和没点名的美化条件，只改点到的维度，重出三宫格或指定的那一格
5. 用户选了左 / 中 / 右：只放大选中的那一版，单独重新生成一张高清的精修美化图

「美图秀秀风格精修」指更明显的白皙提亮、瑕疵清理、细腻的轻磨皮、柔焦光晕、清透妆感和照片精致感；照样不改脸、不过度减龄、不出塑料皮肤、不丢真实的毛发纹理。

出图走编辑接口，原图放进 `images[]`，见[出图](reference/image-generation.md#endpoint)。

## 三格怎么拉开 { #panels }

只在内部用，不必先讲给用户：

- **左：自然修饰 + 清爽的短发或中短发**。改善肤色、斑点、泛红、不均、黑眼圈、曝光和气色；发型可以不沿用原来的发长和纹理，以清透、轻盈、五官打开为准
- **中：白皙柔焦影楼精修（必须有）+ 高完成度的肖像发型**。不改脸、不减龄、不做塑料皮肤的前提下，明显淡化斑点、泛红和肤色不均，加轻微磨皮、柔和柔焦光晕和均匀偏白皙的健康肤色，并把妆容、眼神、腮红唇色、面部高光和照片精致感都提上去；发长、卷直和轮廓可以自由重构，以最上镜为准
- **右：形象强化 + 戏剧化的形象发型**。身份照样认得出，但允许更明显地重新考虑妆容完成度、发型长度、卷直纹理、轮廓和整体气质，用来找更强的摄影形象方向

美化范围：整体提亮和清透感；肤色均匀，淡化斑点、泛红和不均；弱化黑眼圈、适度提亮面部；提亮眼神但不改眼形；自然的腮红和唇色；柔和的面部高光和整体色调；整理发丝，适度优化顶部、两侧、刘海和轮廓；轻微柔焦光晕和写真精致感（中、右更明显，左尽量克制）。

**每格的发型都先按发型师的思路推导**：从人物气质、脸型和五官重心、头颈比例、妆容、肖像景别和光线推出发型，再出图。发长可长可短、可直可卷，分缝、刘海或露额、顶部体积、两侧包裹、后区收束、必要的发色质感都能调，原图的发长、卷直、发色不是限制。**每格都要明确刘海策略**：保留原刘海、改成具体的刘海形状，或露额，而且要服务眉眼、额头比例和整体气质，不随机沿用。

## 三宫格 prompt { #board-prompt }

> 生成一张真人参考图美化三宫格。
>
> - 恰好 3 格清晰、独立的肖像，左 / 中 / 右一眼分得清
> - 同一个人，辨识度和年龄印象不变
> - 不出任何文字、数字、说明、Logo、水印；不指定单格比例和整板比例
> - 左：清透妆容，去掉斑点、泛红、肤色不均，去黑眼圈；发型师设计的清爽短发或中短发
> - 中：白皙柔焦影楼精修，必须同时有明显淡化的斑点、泛红、肤色不均，去黑眼圈，轻微磨皮，柔和的柔焦光晕，均匀偏白皙的健康肤色；不改脸、不减龄、不出塑料皮肤；发型师设计的最上镜的高完成度肖像发型
> - 右：形象强化；发型师设计的戏剧化形象发型
> - 差异主要体现在皮肤、气色、妆容完成度、发丝和发型感觉、整体润色上，不靠换人、夸张改脸制造差异
> - 每格的发型都由发型师按人物气质、五官重心、头颈比例、妆容和光线设计，可以自由变长变短、变直变卷，调整分缝、刘海或露额、体积、轮廓和必要的发色质感；每格都明确刘海策略（保留、改成具体刘海形状，或露额），让它服务眉眼、额头比例和人物气质
> - 发型探索只用来找感觉，不当成正式拍摄的发型

## 放大 prompt { #enlarge-prompt }

> 按用户选的左 / 中 / 右那一版，单独重新生成一张高清单张。保持那一版的人物身份、妆容、皮肤观感、发型感觉和整体润色方向，输出一张可以保存的精修美化图。不要把这张图里的发型当成之后所有主题都要保持的正式拍摄发型。

放大时原图在前当身份参考，三宫格放后面当造型参考，prompt 里写明取第几格。

## 身份和发型的边界 { #boundary }

- 三格都要保持同一个人认得出的脸型、核心五官和年龄印象；发型变化不能拿来掩盖身份漂移
- 这里的发型主要是**找感觉**，不等于正式拍摄的发型确认；每个正式拍摄的主题照样要过[发型师](hairstyle.md)
- 选中放大的图是派生图：选左中右、放大，都不等于切换身份参考。之后拍摄照旧用最初上传的原图锁脸；只有用户明确说「以后用这张作为人物参考」「以后以这张为准」才升级，见[真人身份参考](reference/identity-reference.md#promotion)
