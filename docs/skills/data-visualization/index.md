# 数据可视化

数据可视化相关的独立 skill，按数据与表达场景挑。这个目录只负责分类和导航；每套 skill 在自己的子目录里维护规则、参考资料、模板与可运行示例，彼此不共享隐含依赖。

- [Lieflat Charts](lieflat-charts/index.md) —— 模板驱动的单色编辑型数据可视化；从数据形状选图，逐张展示 Lupi Editorial、Lupi Basics、Glance 与交互大图

## 收录约定

- 一个子目录只对应一套可独立使用的 skill
- 每套 skill 自己拥有 `index.md`、`reference/` 与 `assets/`，不把模板或 demo 堆在数据可视化总目录
- 总目录只描述“有哪些选择”；具体选图顺序、视觉规则与代码骨架留在各自 skill 内
- 外部仓库是规范真身时，wiki 负责可读说明与在线 demo，并钉住来源版本，不把整个分类绑定成某个仓库的镜像
