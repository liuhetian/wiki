# 配图：手绘信息图的维护记录

这是写作规范里[配图](../../skills/wiki-guide/reference/infographic.md)背后的事。照着画图时不用看，要改做法时再看。

## 从哪来 { #origin }

- **起因**：2026-10-20 拆解[梨园](../../projects/liyuan/index.md)，第一张「一个场景由什么组成」照旧规范画成白底马克笔草图——一张图一个概念、不许写字。用户说「这个图太抽象了，可以参考一下 layouts/infographics/ 里面的排版吗？」，改成带标签的信息图后说「看起来还不错，其他几个部分也配图吧」，随后定了「我觉得应该先图，再配文」
- **拼法**：照[手绘风格库](../../gallery/images/handdraw-style/index.md#splice)的「画风 + 排版 + 主题色 + 主题」拼。画风固定 FH-001 Editorial Doodle，这条在上游的说明行是「靠画法特征」，所以写片段、不垫图；排版从 36 种[信息图排版](../../gallery/layouts/infographics.md)里按内容形状挑；主题、标题和标签自己写，标签文字要求原样照写
- **替换马克笔草图**：用户说「马赛克笔图太抽象了，我从来没看懂过，可以说是积怨已久哈哈」，旧规范整页删掉，地址重定向到新页。用旧规范画的 7 篇笔记配图（分类指标、贝叶斯、功效与样本量、假设检验、因果推断、抽样、抽样分布）没重画
- **用户同时定的几条**：主题色画的时候定，一篇文章一种；选了哪个排版、画风、主题色不进正文，写在这里；子页的开屏图放在标题之前；画图时机写进[细讲项目](../../skills/project-research/dissect.md)，规范只管画法

## 踩过的坑 { #pitfalls }

- **改一个词全部返工**：正文把梨园自造的「拍」改成「轮」后，用户说「对了你之前生成的图片中的 拍 的概念也要改，看是编辑还是重新生成」，11 张图逐张编辑或重画。所以规范要求叫法定下来再画
- **中文会写错字**：出过「规制」（应为规则）、「裹材」（应为素材）、字形不对的「轮」、一处糊掉的小字。用编辑接口、prompt 写「只修改一处文字……其他保持完全不变」能修好大部分；修不好的重新生成，挑写对的那次
- **返回格式不定**：这一批留下的 28 份返回，`data[0]` 里 14 次是 `b64_json`、14 次是 `url`，下载脚本两种都接；[生成、编辑图片](../../skills/agent-io/reference/image.md)已经改成两种都写

## 为什么不检查 { #no-check }

用户说「检查这个步骤先去掉吧，写明不检查，因为节约token」。逐字核对要把每张图读进上下文，11 张的开销不小；错字留给用户看到再改。
