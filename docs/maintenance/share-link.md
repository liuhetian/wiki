# 解析分享链接的维护记录：下载狗

这是[解析分享链接](../skills/agent-io/reference/share-link.md)背后的维护记录。用接口时不用看，解析出问题或者要换服务时再看。

## 接口从哪来 { #upstream }

[下载狗接口文档](https://www.xiazaitool.com/jiekou)，按次数买额度。用到的是这几点：

- `POST https://api.xiazaitool.com/api/parseVideoUrl`，JSON 正文 `{"url": …, "token": …}`。token 在正文里，不在请求头，所以中转用 `request_body` 改写正文，见 [API 中转的坑](../posts/ai-assistant/api-gateway.md#pitfalls)
- 文档说失败不计费，实测也是这样
- 文档示例里的 `www.xiazaitool.com` 和 `api.xiazaitool.com` 都能用，中转接的是 `api.`

## 实测 { #tests }

2026-10-10 从本机经国内中转测：

| 请求 | 结果 |
|---|---|
| B 站视频，走中转和直连各三次 | 都是 200，解析 0.4 秒左右，第一次走中转要建连接，0.78 秒 |
| 下载上面拿到的 B 站直链，57.5 MB | 两边都是 B 站同一个 CDN，都是 1.96 MB/s 左右，像是 CDN 单连接限速 |
| 小红书视频短链 | 200，9.3 秒，只有标题和视频直链，封面、正文、点赞都空；直链 11 MB，8.8 MB/s |
| 小红书图文短链 | 第一次 500「解析失败」，16 秒；重试 200，6.7 秒，`pics` 11 张，941×1672 |
| 同一条图文换成跳转后的完整链接 | 200，1.4 秒，多了封面；图片换了域名，但下下来字节完全一样 |

## 没做的 { #not-done }

- 抖音、快手、微博等平台没测。
- 小红书传完整链接更快，但要 Agent 先自己跟一次跳转，用法页没写。
- 文档说额度不够返回 429，没遇到过。
