# 笔记

算法、概率、统计、机器学习、编程语言等专业科目的学习与推导放在这里。笔记强调定义清楚、过程可检查、结论可复现；围绕经验、观点和方法展开的完整表达放在[文章](../posts/index.md)，给 AI 直接执行的成套资产放在 [Skills](../skills/index.md)。其中 Git 分类里有一部分是[课程](../courses/index.md)的答卷 —— 题在课程那边，答完才搬过来。

每个分类有自己的统一骨架，分类索引里每篇只留一行钩子，扫一眼决定点不点进去。

## 分类

- [概率与算法](probability/index.md) —— 概率小题、算法题的题解与技巧；骨架是**题 → 一句话 → 关键技巧 → 解 → 延伸**，价值密度在"关键技巧"——记的不是答案，是可迁移的招
- [统计学](statistics/index.md) —— 从抽样设计到统计推断；先说清楚数据怎样产生，再决定公式能回答什么
- [机器学习](machine-learning/index.md) —— 用可算的小例子拆模型概念；先说指标在回答什么问题，再算一遍，最后说明什么时候用
- [Git](git/index.md) —— 日常用法笔记；骨架是**场景 → 一句话 → 心智模型 → 操作 → 坑**，重点是分支之间该是什么关系，命令自己推得出来
- [JavaScript](javascript/index.md) —— 语言与运行时机制；例子**可以直接在页面上跑**，先猜输出再点运行核对，比读十遍规范快

Python 语言点滴还在计划里，等第一篇落地时再建目录。
