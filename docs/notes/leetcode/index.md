# LeetCode 热题 100

LeetCode 官方学习计划[「热题 100」](https://leetcode.cn/studyplan/top-100-liked/)的题解，一题一篇，分组沿用官方的 15 个题型。题单 2026-09-29 抓取，存档在 [`assets/hot100.json`](assets/hot100.json)。

每篇骨架是**题 → 一句话 → 关键技巧 → 解 → 延伸**，价值密度在"关键技巧"——为什么想得到、为什么是对的。题意用自己的话概括，原文点每篇顶部的 LeetCode 链接看。

「解」是能直接贴进 LeetCode 提交的 Python3 `class Solution`，页尾「自测」折叠块是断言。仓库里的 `scripts/check-leetcode.py` 把每篇的 python 块拼起来、垫上 LeetCode 同款预置环境（`ListNode`、`TreeNode`、常用 import）真跑一遍——**断言过不了的题解不进库**。

## 动态规划

- [70. 爬楼梯](0070-climbing-stairs.md) · 简单 —— 按最后一步分类计数：到第 n 阶的走法 = 到 n-1 阶 + 到 n-2 阶，斐波那契，滚动两个变量
- [118. 杨辉三角](0118-pascals-triangle.md) · 简单 —— 每行两端是 1，中间每个数等于上一行肩上两数之和——最朴素的「由上一行推下一行」的 DP
- [198. 打家劫舍](0198-house-robber.md) · 中等 —— 按「最后一间抢不抢」分两类：dp[i] = max(dp[i-1], dp[i-2] + nums[i])，选或不选型 DP 的原型
- [279. 完全平方数](0279-perfect-squares.md) · 中等 —— 完全平方数当硬币、n 当金额，就是「凑出 n 的最少硬币数」——完全背包求最值
- [322. 零钱兑换](0322-coin-change.md) · 中等 —— 完全背包求最值：dp[a] = 1 + min(dp[a - c])，用 amount+1 当「凑不出」的哨兵，省掉无穷大判断
- [139. 单词拆分](0139-word-break.md) · 中等 —— dp[i] 表示前缀 s[:i] 能否拆完；枚举最后一个单词的起点 j，只要 dp[j] 且 s[j:i] 在字典里就成
- [300. 最长递增子序列](0300-longest-increasing-subsequence.md) · 中等 —— O(n²) 的 dp[i] 以 i 结尾；O(n log n) 换个状态——tails[k] 存长度 k+1 的递增子序列的最小结尾，二分替换
- [152. 乘积最大子数组](0152-maximum-product-subarray.md) · 中等 —— 负数会让最小变最大，所以以 i 结尾同时维护最大积和最小积两个状态，遇到负数二者互换角色
- [416. 分割等和子集](0416-partition-equal-subset-sum.md) · 中等 —— 转成 0-1 背包：能否选出和为 sum/2 的子集；一维布尔数组倒序更新，保证每个数只用一次
- [32. 最长有效括号](0032-longest-valid-parentheses.md) · 困难 —— 栈里存「最后一个没配上的位置」当分界；每配上一个右括号，当前下标减栈顶就是以它结尾的有效长度

## 技巧

- [136. 只出现一次的数字](0136-single-number.md) · 简单 —— 异或自反：x ^ x = 0、x ^ 0 = x，且满足交换律——全体异或一遍，成对的互相抵消，剩下落单的
