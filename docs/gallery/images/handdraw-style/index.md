# 手绘风格库

这里有 280 种手绘画风，配套的 124 种版式和 36 种主题色分别在[排版](../../layouts/index.md)和[色彩](../../colors/index.md)两区，每一条都是一张图加一段 prompt。
跟其他图库不一样的是，这里的每段 prompt 都只是**片段**：风格片段只写画法特征，版式片段只管构图，
主题色片段只管颜色，画什么内容一句都没写。用的时候各挑一条，再加上你自己的主题，拼成一段完整的 prompt。

## 怎么拼 {#splice}

以「画风 Folk-Line Decorative Storybook + 版式 上文下图社媒卡 + 主题色 柿子橙，主题：秋天的第一杯奶茶」为例：

````text
主题：秋天的第一杯奶茶
小红书社媒卡。排版采用上文下图结构：上方集中放置主题文字和简短补充文案，下方放置完整主图或场景图。上下内容保持清晰的阅读顺序，图文关系自然，整体构图简洁。
主题色：柿子橙（Persimmon Orange）。
画风：民俗线描、复古配色、植物纹样、奇异群像；人物轮廓优先于细节堆砌，脸型、头身比例与手脚形状要形成清楚而独立的视觉语言。
````

上游 skill 自己拼的时候守这几条规矩，手动拼也照着来：

- **只留正面描述**：风格片段里含「避免 / 不要 / 禁止」的子句要删掉（上例已经删掉了这条画风最后那句「避免回落为统一的标准Q版表情」）
- **画面内容只由主题决定**：样片里画的人物、动物、场景都只是演示画风用的，不要写进 prompt
- **模型认不出这个画风时要垫图**：小众作者的画风，或者上游没写文字特征的那 6 条（页面上会直接提示），
  光靠文字很难把风格定住。这时把那条的样片作为参考图一起上传，并在 prompt 里加上下面这段隔离声明，
  否则样片里的人物、道具会被原样画进结果：

  ````text
  所附图片仅用于参考画风。只提取参考图的风格特征，例如线条、笔触、媒介、材质、色彩倾向和整体视觉语言；不要使用、复制或延续参考图中的任何主体、人物、动物、服装、道具、动作、姿态、场景、背景、构图、布局、文字或故事。最终画面内容完全以用户提供的主题为准。
  ````

- 主题色可以只用一种，也可以用「主色 + 点缀色」，比如主色柿子橙、点缀色普鲁士蓝
