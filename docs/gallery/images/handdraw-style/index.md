# 手绘风格库

这里有 280 种手绘画风、124 种版式和 36 种单色主题色，每一条都是一张图加一段 prompt。
跟其他图库不一样的是，这里的每段 prompt 都只是**片段**：风格片段只管画法，版式片段只管构图，
主题色片段只管颜色，画什么内容一句都没写。用的时候各挑一条，再加上你自己的主题，拼成一段完整的 prompt。

## 怎么拼

以「风格 #048 + 版式 SC-001 + 主题色 C-26，主题：秋天的第一杯奶茶」为例：

````text
主题：秋天的第一杯奶茶
小红书社媒卡。排版采用上文下图结构：上方集中放置主题文字和简短补充文案，下方放置完整主图或场景图。上下内容保持清晰的阅读顺序，图文关系自然，整体构图简洁。
主题色：柿子橙（Persimmon Orange）。
画风：风格名称：#048 · Folk-Line Decorative Storybook。参考作者/风格名称：Carson Ellis。核心风格特征：民俗线描、复古配色、植物纹样、奇异群像；人物轮廓优先于细节堆砌，脸型、头身比例与手脚形状要形成清楚而独立的视觉语言。
````

上游 skill 自己拼的时候守这几条规矩，手动拼也照着来：

- **只留正面描述**：风格片段里含「避免 / 不要 / 禁止」的子句要删掉（上例已经删掉了 #048 最后那句「避免回落为统一的标准Q版表情」）
- **画面内容只由主题决定**：样片里画的人物、动物、场景都只是演示画风用的，不要写进 prompt
- **模型认不出这个画风时要垫图**：小众作者的画风，或者没有「核心风格特征」的 #055、#263–#265、#269、#271，
  光靠文字很难把风格定住。这时把那条的样片作为参考图一起上传，并在 prompt 里加上下面这段隔离声明，
  否则样片里的人物、道具会被原样画进结果：

  ````text
  所附图片仅用于参考画风。只提取参考图的风格特征，例如线条、笔触、媒介、材质、色彩倾向和整体视觉语言；不要使用、复制或延续参考图中的任何主体、人物、动物、服装、道具、动作、姿态、场景、背景、构图、布局、文字或故事。最终画面内容完全以用户提供的主题为准。
  ````

- 主题色可以只用一种，也可以用「主色 + 点缀色」，比如主色 C-26 柿子橙、点缀色 C-03 普鲁士蓝
