# 图片

一张图配一段生成它的 prompt，看中哪张就把 prompt 拿走改一改。页面里只有图和 prompt；来源与授权记在各自的维护记录里：[GPT Image 2 图库](../../maintenance/gallery/gpt-image2.md)（收录自 wuyoscar/GPT-Image2-Skill，MIT，共 163 条，已译成中文）、[手绘风格库](../../maintenance/skills/handdraw.md)（收录自 yang0/handraw-style，MIT，365 种画风；配套的版式和主题色在[排版](../layouts/index.md)、[色彩](../colors/classic.md)两区）、[二次元平面设计风格](../../maintenance/gallery/linux-do-style.md)（整理自 linux.do @sallyn 的帖子，12 组）和 [prompt-cards 生图条目](../../maintenance/gallery/prompt-cards.md)（照录自 prompt-cards.cyanfish.site，10 条，英文的已译成中文，分散在角色设计、摄影、插画、复古与赛博朋克、字体与海报、品牌系统六页的末尾）；另有单条收进来的零散 prompt，来源记在[零散收集](../../maintenance/gallery/images-collected.md)；[拍照姿势](#poses)三页只有实拍图、没有 prompt，取自小红书「我的id是江苏美人」，来源记在[小红书拍照姿势](../../maintenance/gallery/xhs-poses.md)；[PPT 风格库](#ppt-master)收录自 hugohe3/ppt-master（MIT，已译成中文），来源记在 [PPT Master 的维护记录](../../maintenance/skills/ppt-master.md)。

怎么从一张图反推出 prompt，看 skills 里的[图片提示词反推](../../skills/image-prompt-reverse/index.md)：简化版[七维拆解](../../skills/image-prompt-reverse/seven-dimensions/index.md)和完整版[从图反推 prompt](../../skills/image-prompt-reverse/get-prompt-from-image/index.md)。
