# PPT 配图画风 · 特色（3 种）

PPT 配图画风里的特色一组。画风是什么、对比图怎么拍的，看 [PPT 风格库](index.md#renderings)；拼成 prompt 看[生成配图](../../../skills/ppt-master/image-generator.md)。条目里的色值都是示例，拼 prompt 时换成你这套 deck 的配色。

### fantasy-animation · 幻想动画 { #fantasy-animation }

<img src="assets/rendering/fantasy-animation.webp" alt="幻想动画" width="420" loading="lazy" decoding="async"/>

吉卜力、迪士尼式的手绘温暖。典型用途：儿童、绘本、品牌寓言。

受吉卜力和迪士尼启发的手绘动画温暖感。柔和的绘画式形体、温柔的光、有表现力但简化的角色、梦幻的氛围。用于儿童内容、绘本式品牌叙事、疗愈和安慰类主题、童话或奇趣的 deck。

#### 画风段落

````text
手绘动画风格，灵感来自吉卜力和经典迪士尼绘本美学。形体画得柔和，绘画式填色，轮廓温柔——从不生硬。核心颜色以 deck 的颜色角色为基准；梦幻的暖意可以靠柔和的窗光、温柔的光晕、晨雾、笔触质感、空气透视和一致的粉彩或大地色过渡带出来。角色（有的话）以友好的卡通方式风格化——大而有表现力的眼睛、简化的解剖、温暖的肢体语言。前景形体更丰富，背景更柔和。整体感觉梦幻、魔法、安慰、像绘本。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 柔和的手绘轮廓或不描边，内部绘画式填色 |
| 质感 | 淡淡的绘画笔触 + 大气的柔和感 |
| 层次 | 强烈的空气透视——远处更淡更柔 |
| 材质 | 手绘的动画赛璐璐 |
| 情绪 | 梦幻、魔法、安慰、绘本感 |

#### 怎么用 deck 配色

幻想动画把 deck 的颜色角色当识别基准，加绘本式处理：

- 主色：作为主导环境或角色色系的基准
- 辅色：作为大气底面或雾霭色系的基准
- 强调色：作为一个小小魔法焦点的基准——也许是一扇窗、一朵花或角色身上的关键元素

从这几个基准一致地推出光、雾和材质色调；只有需要的情绪会替换 deck 的识别时才换别的画风。

#### 示例片段

**半页绘本场景，图里不带字**

````text
手绘绘本动画。一间小屋坐落在山坡上，一条蜿蜒小路通向前景。天空和雾气取 deck 的次背景色系，山坡和树取主色，一扇小小的发光窗户取强调色。允许一致的明暗大气过渡；不要用一套无关的绘本配色替换这几个色系。绘画笔触、柔和的光和空气透视营造暖意：远处的山更柔和，前景的形体更有分量。前景左侧立着一棵简化的绘本式的树。作为 600×800 的半页图块，内边距 10%。任何人物都是温和的卡通剪影，没有写实的脸。不带文字或标签。
````

### pixel-art · 像素艺术 { #pixel-art }

<img src="assets/rendering/pixel-art.webp" alt="像素艺术" width="420" loading="lazy" decoding="async"/>

8-bit 复古游戏美学。典型用途：游戏、复古科技、怀旧。配套的视觉风格：[像素风](gallery-visual-styles-specialty.md#pixel-art)。

8-bit、16-bit 复古游戏美学。锐利的像素网格，有限的配色，没有抗锯齿。用于游戏 deck、复古科技 deck、怀旧内容和带游戏味的教育娱乐内容。

#### 画风段落

````text
8-bit 像素艺术风格，严格对齐像素网格，没有抗锯齿。所有元素都由离散的彩色像素构成——看得见粗大的像素边缘，色块之间转换锐利，没有柔和渐变。配色有限、刻意复古（通常一共 16–32 种颜色）。形体简化到能放进低分辨率网格——小小的角色精灵、方块化的环境、标志性的道具。可选用填充色的深一档颜色画 1 像素宽的轮廓，增加清晰度。构图常参照经典 NES、SNES、街机游戏的画面构成。整体感觉怀旧、俏皮、复古游戏——一眼认得出。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 像素台阶——轮廓由一个个像素组成，没有平滑线条 |
| 质感 | 除了像素网格本身没有别的 |
| 层次 | 靠配色分层（上方像素更亮，下方更暗做明暗） |
| 材质 | 像素网格 |
| 情绪 | 怀旧、复古游戏、俏皮 |

#### 怎么用 deck 配色

像素艺术把色值当**调色板槽位**：

- 主色：占主导的角色或物体颜色
- 辅色：背景或地形
- 强调色：高亮道具、重要标记、魔法效果
- 可选的第四色：主色的深一档（通常深 25%），用作轮廓像素

#### 示例片段

**复古主视觉横幅，图里不带字**

````text
8-bit 像素艺术主视觉横幅，严格对齐像素网格，没有抗锯齿。一个复古游戏式场景——前景正中一个小小的像素角色精灵站在瓷砖地面上，背景一座风格化的像素山，右上方一个像素太阳。角色的服装是主色深蓝 #1E40AF，用同一蓝色更深一档的颜色画 1 像素轮廓。背景的山是柔和的灰色像素块。天空是柔和的辅色桃色 #FED7AA。太阳是强调色金色 #D4AF37，画成一个粗像素的圆。所有元素都看得出像素台阶——没有平滑曲线。配色有限（一共约 12–16 种颜色）。作为 1200×500 的主视觉横条，内边距 12%。简化的像素角色——没有细节的脸。图里不出现任何文字或标签。色值只是渲染指引。
````

### nature · 自然有机 { #nature }

<img src="assets/rendering/nature.webp" alt="自然有机" width="420" loading="lazy" decoding="async"/>

有机的大地色插画。典型用途：环境、健康、可持续。

有机的大地色插画，带植物和自然图案。柔和的曲线、有机的形状，默认是大地色系。用于环境、可持续、健康、户外、食品和农业类 deck。

#### 画风段落

````text
有机插画风格，带植物和自然图案。形体柔和弯曲、不对称——叶子、枝条、有机曲线、不规则的形状，像是长出来的而不是画出来的。配色偏大地色、略微柔和——森林绿、暖土棕、赤陶色、柔和米色，偶尔一点天蓝。轮廓极少或没有；形体由颜色和质感定义。淡淡的有机质感（叶脉、木纹、石头斑点）偶尔出现。构图强调自然的平衡和呼吸感——从不对齐网格。整体感觉踏实、沉思、可持续——很适合健康、环境和户外内容。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 极少——形体由颜色定义，偶尔一条细的有机线当点缀 |
| 质感 | 淡淡的有机质感（叶脉、木纹），偶尔用 |
| 层次 | 自然元素的柔和层叠，空气透视 |
| 材质 | 大地色插画 |
| 情绪 | 踏实、沉思、可持续 |

#### 怎么用 deck 配色

自然有机强烈倾向大地色的材质提示，但 deck 定下的颜色角色仍然说了算：

- 主色：占主导的自然色（深绿、深土棕）
- 辅色：浅的大气色调（米色、柔和的天色）
- 强调色：一小处自然的亮色（一朵花、一颗果子、一条叶脉）

如果 deck 的基准色偏冷或偏商务，保留它们的语义角色，把有机的材质和光线翻译进那个色系。如果这样会毁掉想要的自然味，在规划时就换别的画风；绝不另造一套只给图片用的配色，也绝不在出图时改 deck 的颜色。

#### 示例片段

**半页可持续主题场景，图里不带字**

````text
有机插画风格，带植物图案。一幅柔和的自然场景：缓坡上一棵孤树，曲线有机，配色是大地色。树冠是主色深森林绿 #166534，带 12% 不透明度的淡叶脉质感。树干用更深一档的暖土棕。山坡是柔和的辅色米色 #FEF3C7，曲线非常平缓。天空是淡淡的柔蓝，暗示清晨。树根处一小簇暖黄 #D4AF37 的花作强调。没有硬轮廓——形体由颜色对比和柔和的有机边缘定义。作为 600×800 的半页图块，内边距 12%。图里不出现任何文字或标签。色值只是渲染指引。
````
