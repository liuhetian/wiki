# PPT 配图画风 · 手绘与教学（4 种）

PPT 配图画风里的手绘与教学一组。画风是什么、对比图怎么拍的，看 [PPT 风格库](index.md#renderings)；拼成 prompt 看[生成配图](../../../skills/ppt-master/image-generator.md)。条目里的色值都是示例，拼 prompt 时换成你这套 deck 的配色。

### sketch-notes · 手绘笔记 { #sketch-notes }

<img src="assets/rendering/sketch-notes.webp" alt="手绘笔记" width="420" loading="lazy" decoding="async"/>

暖米色纸，黑色手绘线条，粉彩填色。典型用途：教育、培训、入职引导。配套的视觉风格：[手绘笔记](gallery-visual-styles-hand-drawn.md#sketch-notes)。

暖米色纸上的黑色手绘线条和柔和的粉彩色块。最「平易近人」的画风——用于教育、培训、入职引导、科普和知识内容，那些温暖友好比企业式精确更要紧的场合。

#### 画风段落

````text
温暖的手绘笔记风格，以 deck 的浅背景色和正文色为基准。线条保持正文色的性格，带刻意的轻微抖动，从不完全笔直，像一位用心的老师在白板上画出来的手感。柔和的色块从主色、次强调色和强调色的色系里取，允许克制的粉彩浅色和纸张、材质上的过渡，但要和这几个基准色保持一致。简单的卡通图标和小涂鸦装饰（星星、闪光、圆点、下划线）用得很省，只为添点温度。构图通透、条理清楚，留白宽裕。整体感觉偏教学、友好、平易近人。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 黑色手绘墨线，带轻微抖动；统一的中等粗细 |
| 质感 | 米色背景上淡淡的纸纹，8–12% 不透明度 |
| 层次 | 平面——手绘笔记刻意保持二维 |
| 材质 | 纸 + 墨 + 粉彩色块（手涂时略微出界） |
| 情绪 | 温暖、偏教学、友好 |

#### 怎么用 deck 配色

手绘笔记天生偏向暖纸、深墨和柔和色块。把 deck 的各个颜色角色当作识别基准，再按语境推出纸张的暖度和粉彩色块，不另造一套无关的配色。

- 纸张背景：从背景色或次背景色起步；只要保持 deck 的识别和对比度，可以按语境加一点纸色
- 墨线：用 deck 的正文色
- 色块：从主色、次强调色、强调色的色系推出克制的粉彩浅色
- 唯一的强调：deck 的强调色，只在一两处有力地、省着用（一个关键箭头、一个被强调的涂鸦）

#### 示例片段

**半页教学概念图，图里带字**

````text
温暖的手绘笔记风格，以 deck 的背景色为基准。线条用正文色系，带轻微抖动，勾出三个圆角矩形信息框，排成一个松松的三角形。上方的框取主色，左下取次强调色，右下取强调色；每个框都用和它的基准色一致的克制粉彩浅色。填色不完全碰到轮廓线（手涂时略微出界）。手绘的波浪箭头连接三个框，每个箭头旁带一个很短的关键词，比如「导致」「变成」「支撑」（不超过两个词）。每个框里有一个简单的手绘卡通图标——灯泡、植物、齿轮。小涂鸦装饰用得很省。作为 600×600 的半页图块，内边距 14%，留白宽裕。
````

### ink-notes · 墨迹笔记 { #ink-notes }

<img src="assets/rendering/ink-notes.webp" alt="墨迹笔记" width="420" loading="lazy" decoding="async"/>

纯白、黑墨、少量有语义的颜色。典型用途：方法论、Before-After、宣言。配套的视觉风格：[墨迹笔记](gallery-visual-styles-hand-drawn.md#ink-notes)、[水墨](gallery-visual-styles-hand-drawn.md#ink-wash)。

纯白纸、黑墨、稀疏的语义强调色——Mike Rohde 视觉笔记的传统。比[手绘笔记](#sketch-notes)更利落、更专业、更有「宣言」感。用于方法论、Before-After 类文章、心态转变的叙事、技术宣言和专业的视觉笔记。

#### 画风段落

````text
专业的手绘视觉笔记风格，画在干净的纸面上。所有线条以 deck 的正文色为基准，带轻微抖动——自信、有意，像一场用心的白板讨论留下的手感。手写标题粗而略大（允许带字时）。颜色刻意稀少：线条占可见内容的约 85%，一两个语义强调色从 deck 的强调色系推出，合计不到 10%。背景和形状内部大多留空。小涂鸦装饰——星星、短划、圆点——极少。整体感觉专业、深思熟虑、宣言级。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 黑墨，带轻微抖动；自信的中等粗细 |
| 质感 | 纯白背景；没有纸纹 |
| 层次 | 平面 |
| 材质 | 笔在纸上 |
| 情绪 | 专业、深思熟虑、宣言感 |

#### 怎么用 deck 配色

墨迹笔记的材质语言几乎是固定的：**深墨 + 浅背景 + 一两个语义强调色**。它从不覆盖 deck 的配色；只有 deck 定下的颜色角色撑得住这种对比时才推荐它：

- 背景：用 deck 的背景色或次背景色
- 线条和文字：用 deck 的正文色
- 语义强调：从 deck 的强调色、次强调色推出，保持它们已有的含义；可以按语境做墨色和纸色的深浅变体

这让墨迹笔记成了最容易和 deck 识别打架的画风。只有背景、文字、强调这几个基准色撑得住时才推荐；不要因为这种画风传统上用珊瑚红、青绿、薰衣草紫，就换上这套现成配色。

#### 示例片段

**方法论 Before/After（[对比](../../layouts/deck-image-types/comparison.md#comparison)版型），图里带字**

````text
专业的手绘视觉笔记风格，画在 deck 定下的背景色上。构图是 Before/After 左右对开——中间一条手绘的竖向分隔线。两边都用 deck 定下的正文色作墨线，带轻微抖动。左边（「Before」）是一个简单的火柴人，姿态沮丧，一个对话气泡里用英文大写手写体写着「OLD WAY」，下面三条手绘短划，各带一两个词的简短注释（比如「manual」「slow」「fragile」）。右边（「After」）是一个自信的火柴人，头顶一个干净的对勾，手写英文大写「NEW WAY」，下面三条复选框式注释（比如「automated」「fast」「reliable」）。一条弯曲的手绘「心态转变」箭头从左跨到右，带一个手写小标签「the shift」。稀疏的语义颜色：deck 定下的强调色标左边的痛点，次强调色标右边的正面点。强调色总面积不超过画面的 10%。所有手写文字都是短关键词。作为 1200×500 的主视觉横幅，内边距 14%。
````

### chalkboard · 粉笔黑板 { #chalkboard }

<img src="assets/rendering/chalkboard.webp" alt="粉笔黑板" width="420" loading="lazy" decoding="async"/>

黑板上的粉笔，课堂感。典型用途：教学、教程、课堂 deck。配套的视觉风格：[黑板](gallery-visual-styles-hand-drawn.md#chalkboard)。

深绿或黑色板面上的粉笔——课堂美学。用于以教学为主的 deck、教程、学校和学术内容，以及复古的教学氛围。

#### 画风段落

````text
课堂黑板美学。深绿或接近黑色的石板背景，看得见淡淡的粉笔灰质感。所有笔触都是柔和的粉笔线——边缘略微晕开，米白或粉彩色，看起来是粉状的，不是饱和的。手绘线条自信，但带真实粉笔那种干性媒介的质感。构图遵循黑板教学——居中或有条理的布局、清楚的分区，偶尔的下划线和强调记号。颜色克制：白色粉笔占主导，一两种粉彩强调色（黄、淡粉、浅青）省着用。整体感觉怀旧、偏教学、温暖的课堂——教学内容和教程 deck 里常见。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 柔和的粉笔线，边缘略晕开，干性媒介质感 |
| 质感 | 整块板上看得见粉笔灰颗粒，15–25% 不透明度 |
| 层次 | 平面 |
| 材质 | 石板（深绿或近黑）+ 粉笔 |
| 情绪 | 怀旧、偏教学、温暖的课堂 |

#### 怎么用 deck 配色

粉笔黑板有很强的**材质色倾向**：深色板面 + 浅色粉笔 + 稀疏强调。它从不替换 deck 的颜色。只有 deck 定下的背景色、正文色撑得住这种对比时才推荐它。

- 板面：照原样用 deck 的背景色或次背景色
- 粉笔线：照原样用正文色；粉笔效果靠干涩的质感出来，不改色值
- 强调记号：照原样用强调色、次强调色，省着用；不要调成粉彩

#### 示例片段

**半页课堂配图，图里带字**

````text
课堂黑板美学。用 deck 定下的背景色当板面，带 20% 不透明度、看得见的粉笔灰质感。三个圆角框用 deck 定下的正文色、以柔和的粉笔线画成，排成一行，每个框里有一个简单的粉笔画图标（一棵树、一个灯泡、一架纸飞机）。框的上方是手写的英文大写标题「GROWTH」。手绘的粉笔箭头从左到右连接三个框。小粉笔星星和圆点装饰用得很省。一条下划线用 deck 定下的强调色，带刻意的干性媒介质感。作为 600×500 的半页图块，内边距 14%。粉笔字只写短关键词。
````

### paper-cut · 剪纸拼贴 { #paper-cut }

<img src="assets/rendering/paper-cut.webp" alt="剪纸拼贴" width="420" loading="lazy" decoding="async"/>

层叠的纸艺，剪刀剪出的边，柔和阴影。典型用途：教育、儿童、文化、节庆、可持续。配套的视觉风格：[剪纸](gallery-visual-styles-expressive.md#paper-cut)。

层叠纸艺美学——剪刀剪出的利落边缘、层与层交叠处淡淡的纸影、手剪的味道。用于教育、儿童内容、文化和民俗题材、可持续与环境、礼品和节庆场景、讲故事的 deck。

#### 画风段落

````text
层叠的剪纸手工美学。构图像是用彩色卡纸剪出来再一层层叠起来——每个形状都有剪刀剪出的利落边缘（略不规则、有手工感，不是数学般完美），并在下面一层投下 8–12% 的柔和投影，带出真实的触感层次。每种颜色是一张独立的纸，带 10–15% 不透明度的淡纸纹。形体简化、风格化——一看就是纸艺，不是插画。构图读起来舒适、温暖、手工做的。整体感觉平易近人、有触感、适合孩子但不幼稚——Eric Carle 绘本和当代民俗插画的美学。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 不描边——形状由纸的边缘定义（略不规则的剪口） |
| 质感 | 每张色纸上 10–15% 不透明度的纸纹 |
| 层次 | 真实的层叠层次，每层剪纸下有 8–12% 的柔和投影 |
| 材质 | 卡纸、美术纸——哑光，略带纤维感 |
| 情绪 | 温暖、有触感、平易近人、手工做的 |

#### 怎么用 deck 配色

剪纸把每个色值当作**一种颜色的纸**：

- 主色：占主导的那层纸（最大或最靠前的一张）
- 辅色：背景纸（最底层，剪纸形状下面的「桌面」）
- 强调色：顶层的一个小剪纸形状
- 层次比比例更重要——即使是一小张主色纸，放在一大张辅色纸前面，也会显得以主色为主

#### 示例片段

**教学场景，图里不带字**

````text
层叠剪纸手工场景。底纸：辅色暖米色 #FEF3C7 的纸，带 12% 不透明度的淡纸纹（整个构图所在的「桌面」）。上面：一棵简化的剪纸树，由两层剪纸形状叠成——一块主色深绿 #0F766E 的圆润树冠，剪刀剪出的边缘略不规则，在米色底纸上投下 10% 的柔和投影；下面一块更深的棕色树干剪纸。树的一侧：角落里一个强调色赭黄 #D4A017 的小剪纸太阳，带自己的柔和投影。哪里都不描边——形状只由纸的边缘定义。每一层都有 12% 不透明度的纸纹。作为 600×600 的半页剪纸场景，内边距 12%。图里不出现任何文字。色值只是渲染指引。
````
