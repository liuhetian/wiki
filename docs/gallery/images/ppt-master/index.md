# PPT 风格库

给 PPT 挑风格用：视觉风格管整套 deck 的版面长什么样，配图画风管 AI 配图怎么画，两者各选一个；配套的[配图版型](../../layouts/deck-image-types/index.md)在排版区。先在这页的目录里挑，挑中了再打开那一组的页面看全文。

## 视觉风格（18 种） { #visual-styles }

视觉风格管一套 deck 长什么样：形状语言、装饰密度、留白节奏、字体性格、质感与层次，也就是卡片、分隔线、间距、圆角、阴影怎么用。一套 deck 只用一种。它不带色值、不定配色，只管这套 deck 的配色在页面上怎么用。它也不是[沟通模式](../../../skills/ppt-master/modes/index.md)：视觉风格管「长什么样」，沟通模式管「怎么讲」，两者分开选，任意风格配任意模式。怎么挑见[规划 deck](../../../skills/ppt-master/strategist.md)。

示意图是上游确认界面给每种风格画的示意页，只示意版面气质，不是真实成品。

- **风格管处理方式，不管能用什么**：它定视觉分量、密度、重复和整体统一感；页面用图、图表、表格还是形状，图从哪来，都由页面要做的事决定，风格不缩减可用的形状，只让选中的形式属于同一个视觉系统
- **每条的「构图手法」是生成用的词汇，不是固定版式菜单**：页面要做的事需要时，可以组合或偏离
- **字体性格只管可编辑的正文和标题文字**：图里的艺术字另算，风格只影响它的处理方式
- **配套画风只是审美相近的候选**：这套 deck 有 AI 配图时，拿它跟实际要配的图对照着挑，它不替你选画风，也不等于要加配图。不是每种画风都有对应的视觉风格 —— 只有定义了整页版面语言的画风才有；[自然有机](gallery-renderings-specialty.md#nature)、[暖调场景](gallery-renderings-narrative.md#warm-scene)、[幻想动画](gallery-renderings-specialty.md#fantasy-animation)这类只管气氛的画风只用在图上，配哪种视觉风格都行。摄影当画风只是图的样子，以照片为主导的构图却是一种版面语言，所以有摄影编辑风这个视觉风格，配企业摄影画风
- **插画分量说的是选了插画之后它占多重**：主导是插画可以领衔整体观感，辅助是插画可以分担构图，克制是插画只挑着用，让这种风格的主视觉保持清楚。它不建议加插画，也不决定图从哪来；用户明说要或不要插画，以用户为准

## 配图画风（20 种） { #renderings }

画风管配图怎么画：线条、质感、层次、材质和情绪。一套 deck 只定一种画风，所有 AI 配图共用；画风里不定色值，颜色从这套 deck 的配色来，条目里出现的色值都只是示例，拼 prompt 时换成你的 deck 配色，可以按画风推出深浅、光影和材质上的过渡，但不另造一套无关的配色。拼成 prompt 的方法见[生成配图](../../../skills/ppt-master/image-generator.md)，局部信息图的构图骨架见排版区的 [PPT 配图版型](../../layouts/deck-image-types/index.md)。

对比图用同一个主体——一位职业人士站在上升的增长图表旁，占画面六到七成——和同一套冷静商务配色：主色 #1E3A5F 深海军蓝、辅色 #F8F9FA 灰白（留出六到七成的呼吸空间）、强调色 #D4AF37 金色（不到 5%），只换画风。图是上游用 gpt-image-2 生成的，换别的模型出来会不一样。条目里的「配套的视觉风格」指 [PPT 视觉风格](#visual-styles)里把它当配套画风的那几种。

### 现代商务（企业 PPT 的主力）

- [矢量插画（`vector-illustration`）](gallery-renderings-modern.md#vector-illustration) —— 干净的扁平矢量，大块形状，不用渐变。典型用途：咨询、SaaS、一般的职业 deck。
- [扁平插画（`flat`）](gallery-renderings-modern.md#flat) —— 现代几何色块，比矢量插画更有设计感。典型用途：品牌、产品展示 deck。配套的视觉风格：[柔和圆角](gallery-visual-styles-corporate.md#soft-rounded)、[孟菲斯](gallery-visual-styles-expressive.md#memphis)。
- [瑞士极简（`minimalist-swiss`）](gallery-renderings-modern.md#minimalist-swiss) —— 瑞士网格、包豪斯式的克制，大胆留白。典型用途：高端咨询、建筑、奢侈品、字体工作室。配套的视觉风格：[瑞士极简](gallery-visual-styles-corporate.md#swiss-minimal)。
- [玻璃拟态（`glassmorphism`）](gallery-renderings-modern.md#glassmorphism) —— 磨砂玻璃的半透明面板，柔和阴影。典型用途：现代 SaaS、金融科技、健康科技、高端应用。配套的视觉风格：[玻璃拟态](gallery-visual-styles-corporate.md#glassmorphism)。
- [3D 等距（`3d-isometric`）](gallery-renderings-modern.md#3d-isometric) —— 等距三维形体，带细微阴影。典型用途：技术架构、产品结构。
- [数字仪表盘（`digital-dashboard`）](gallery-renderings-modern.md#digital-dashboard) —— 精致的 UI、数据可视化美学。典型用途：SaaS 演示、数据产品。配套的视觉风格：[深色科技](gallery-visual-styles-corporate.md#dark-tech)。
- [企业摄影（`corporate-photo`）](gallery-renderings-modern.md#corporate-photo) —— 杂志式摄影，真实的人物和物件。典型用途：团队、生活方式、产品照片。配套的视觉风格：[摄影编辑风](gallery-visual-styles-editorial.md#photo-editorial)。
- [蓝图线稿（`blueprint`）](gallery-renderings-modern.md#blueprint) —— 技术示意图，带网格和等宽字体的意味。典型用途：建筑、工程、AI 系统。配套的视觉风格：[蓝图](gallery-visual-styles-corporate.md#blueprint)。
- [杂志编辑风（`editorial`）](gallery-renderings-modern.md#editorial) —— 杂志式信息图的样子。典型用途：金融、新闻、解释型内容。配套的视觉风格：[杂志编辑风](gallery-visual-styles-editorial.md#editorial)、[数据新闻](gallery-visual-styles-editorial.md#data-journalism)、[粗野主义](gallery-visual-styles-editorial.md#brutalist)。

### 手绘与教学

- [手绘笔记（`sketch-notes`）](gallery-renderings-hand-drawn.md#sketch-notes) —— 暖米色纸，黑色手绘线条，粉彩填色。典型用途：教育、培训、入职引导。配套的视觉风格：[手绘笔记](gallery-visual-styles-hand-drawn.md#sketch-notes)。
- [墨迹笔记（`ink-notes`）](gallery-renderings-hand-drawn.md#ink-notes) —— 纯白、黑墨、少量有语义的颜色。典型用途：方法论、Before-After、宣言。配套的视觉风格：[墨迹笔记](gallery-visual-styles-hand-drawn.md#ink-notes)、[水墨](gallery-visual-styles-hand-drawn.md#ink-wash)。
- [粉笔黑板（`chalkboard`）](gallery-renderings-hand-drawn.md#chalkboard) —— 黑板上的粉笔，课堂感。典型用途：教学、教程、课堂 deck。配套的视觉风格：[黑板](gallery-visual-styles-hand-drawn.md#chalkboard)。
- [剪纸拼贴（`paper-cut`）](gallery-renderings-hand-drawn.md#paper-cut) —— 层叠的纸艺，剪刀剪出的边，柔和阴影。典型用途：教育、儿童、文化、节庆、可持续。配套的视觉风格：[剪纸](gallery-visual-styles-expressive.md#paper-cut)。

### 叙事与氛围

- [水彩（`watercolor`）](gallery-renderings-narrative.md#watercolor) —— 绘画式的柔和边缘，颜色晕染。典型用途：生活方式插画、旅行故事、品牌故事。配套的视觉风格：[水墨](gallery-visual-styles-hand-drawn.md#ink-wash)。
- [暖调场景（`warm-scene`）](gallery-renderings-narrative.md#warm-scene) —— 黄金时刻的电影感暖意。典型用途：个人成长、创业故事。
- [丝网印刷（`screen-print`）](gallery-renderings-narrative.md#screen-print) —— 半调网点的海报艺术，2–5 种平涂色。典型用途：文化、媒体、电影感封面。配套的视觉风格：[粗野主义](gallery-visual-styles-editorial.md#brutalist)、[小刊](gallery-visual-styles-expressive.md#zine)。
- [复古海报（`vintage-poster`）](gallery-renderings-narrative.md#vintage-poster) —— 世纪中期现代主义海报，半调加纸纹。典型用途：文化回顾、品牌传承、老牌酒店形象、周年纪念。配套的视觉风格：[复古海报](gallery-visual-styles-expressive.md#vintage-poster)。

### 特色

- [幻想动画（`fantasy-animation`）](gallery-renderings-specialty.md#fantasy-animation) —— 吉卜力、迪士尼式的手绘温暖。典型用途：儿童、绘本、品牌寓言。
- [像素艺术（`pixel-art`）](gallery-renderings-specialty.md#pixel-art) —— 8-bit 复古游戏美学。典型用途：游戏、复古科技、怀旧。配套的视觉风格：[像素风](gallery-visual-styles-specialty.md#pixel-art)。
- [自然有机（`nature`）](gallery-renderings-specialty.md#nature) —— 有机的大地色插画。典型用途：环境、健康、可持续。
