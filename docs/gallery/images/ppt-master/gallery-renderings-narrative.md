# PPT 配图画风 · 叙事与氛围（4 种）

PPT 配图画风里的叙事与氛围一组。画风是什么、对比图怎么拍的，看 [PPT 风格库](index.md#renderings)；拼成 prompt 看[生成配图](../../../skills/ppt-master/image-generator.md)。条目里的色值都是示例，拼 prompt 时换成你这套 deck 的配色。

### watercolor · 水彩 { #watercolor }

<img src="assets/rendering/watercolor.webp" alt="水彩" width="420" loading="lazy" decoding="async"/>

绘画式的柔和边缘，颜色晕染。典型用途：生活方式插画、旅行故事、品牌故事。配套的视觉风格：[水墨](gallery-visual-styles-hand-drawn.md#ink-wash)。

绘画式的柔和边缘、颜色晕染、有机的流动。最「艺术」的画风——用于生活方式、旅行、品牌故事、个人叙事和创意内容，那些氛围比数据清晰度更要紧的场合。

#### 画风段落

````text
水彩画风格，绘画式的柔和边缘，颜色自然晕染。形体从颜料的渲染里浮现，而不是由轮廓勾出——有时主体只是靠渲染加深的地方暗示出来，没有线。颜色在边缘积聚、晕开，有典型的「湿画法」区域，一种颜色渐渐过渡到另一种。构图有机而有意——不像速写那样松散，而是流动的。留白是作品的一部分（没碰过的纸）。可选极淡的铅笔线暗示底下的结构，但不喧宾夺主。整体感觉平静、沉思、有艺术感——很适合叙事页和营造氛围的内容。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 极少——形体由颜色渲染定义，不靠轮廓 |
| 质感 | 看得见 12–18% 的纸纹，边缘有典型的渲染晕开 |
| 层次 | 靠饱和度渐变——前景饱和，背景更淡 |
| 材质 | 水彩 + 冷压纸 |
| 情绪 | 平静、沉思、有艺术感 |

#### 怎么用 deck 配色

水彩把色值当**渲染用的颜料**，不当平涂：

- 主色：占主导的渲染区，带自然的饱和度渐变
- 辅色：背景渲染，或没碰过的纸面
- 强调色：一小块颜料积聚、饱和度集中的区域

#### 示例片段

**半页叙事场景，图里不带字**

````text
水彩画风格。一片柔和的山景，由层层叠叠的颜色渲染暗示出来——远处的山峰是淡淡的主色青绿 #0F766E，晕进上方三分之一；中景的山丘是饱和一点的青绿，带自然的湿画法积色；前景是暖暖的强调色赤陶 #C2410C，暗示一条小路或暖色的土地。最顶上没碰过的纸构成安静的天空。没有轮廓线勾形——形体从颜料加深的地方浮现。整幅画带 15% 不透明度的淡纸纹。作为 600×800 的半页图块，内边距 10%。有氛围、沉思。图里不出现任何文字或标签。色值只是渲染指引。
````

### warm-scene · 暖调场景 { #warm-scene }

<img src="assets/rendering/warm-scene.webp" alt="暖调场景" width="420" loading="lazy" decoding="async"/>

黄金时刻的电影感暖意。典型用途：个人成长、创业故事。

黄金时刻的电影感暖意——带有意暖光、柔和阴影、有氛围的插画场景。介于[水彩](#watercolor)（更偏绘画）和[企业摄影](gallery-renderings-modern.md#corporate-photo)（更写实）之间。用于个人成长故事、创业故事、品牌叙事和生活方式 deck。

#### 画风段落

````text
有氛围的场景插画，带黄金时刻的电影感光线。形体画得柔和——认得出，但不是照片级写实，边缘柔和，光的方向有意为之。场景有一个清楚的主光源（低垂的太阳、灯光、窗光），投下长长的柔和阴影。核心颜色以 deck 的颜色角色为基准；情感上的暖意可以靠光的位置、光晕、对比、大气雾霭和一致的暖色过渡带出来，不替换 deck 的识别色。构图遵循叙事原则——前景主体、中景交代环境、背景营造氛围。整体感觉电影感、沉思、情感上温暖，很适合品牌故事和个人叙事内容。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 柔和——形体由光和影定义，没有硬轮廓 |
| 质感 | 淡淡的绘画笔触，可选极轻的胶片颗粒 |
| 层次 | 强——用空气透视分开前景、中景、背景 |
| 材质 | 插画，带黄金时刻的光线 |
| 情绪 | 电影感、沉思、温暖 |

#### 怎么用 deck 配色

暖调场景把 deck 的颜色角色当识别基准，靠光线和语境里的色调过渡造出暖意：

- 主色：作为阴影和中景色系的基准
- 辅色：作为受光区域或大气层次的基准
- 强调色：作为一小块集中区域的基准——太阳光晕、灯光、关键的反光

在不替换这几个核心色系的前提下推出暖光和雾霭。不要套一层通用的橙色调，把一个刻意偏冷的品牌识别抹掉；要那样替换才行的话，换别的画风。

#### 示例片段

**半页个人故事，图里不带字**

````text
有氛围的场景插画，带黄金时刻的电影感光线。一个画得柔和的人物（简化的剪影，没有细节的脸）沿着小路走——前景左侧，中景一间小小的远处木屋，背景是有空气感的柔和山丘。强烈的低角度光从右上方来，投下长长的柔和阴影。天空取 deck 的次背景色系，主要形体取主色，一小团太阳光晕取强调色；一致的光影过渡撑起氛围，但不替换这几个基准色。没有硬轮廓——形体从光影里浮现。加淡淡的光晕和 8% 不透明度的胶片颗粒。作为 600×800 的半页图块，内边距 10%。只画简化的剪影人物；不画写实的脸、文字或标签。
````

### screen-print · 丝网印刷 { #screen-print }

<img src="assets/rendering/screen-print.webp" alt="丝网印刷" width="420" loading="lazy" decoding="async"/>

半调网点的海报艺术，2–5 种平涂色。典型用途：文化、媒体、电影感封面。配套的视觉风格：[粗野主义](gallery-visual-styles-editorial.md#brutalist)、[小刊](gallery-visual-styles-expressive.md#zine)。

大胆的丝网印刷海报艺术——平涂色块、半调网点质感、有限的颜色、大胆的剪影。用于文化、媒体、观点、电影感的 deck，靠海报美学撑起页面的场合。

#### 画风段落

````text
大胆的丝网印刷海报艺术，有限的平涂配色，带典型的印刷质感。构图最多用 2–5 种平涂色——形状内部不用渐变，只有自信的纯色块。半调网点在过渡区域加出质感（网点密度从密到疏）。轻微的套色错位（某个色块偏离「本该在」的位置 1–2 像素）带出地道的丝网印刷感。主体画成大胆的剪影，边缘像镂空版刻出来的——没有精细细节，没有写实的解剖。淡淡的纸纹，15% 不透明度。构图强调留白和几何框景。整体感觉是复古海报艺术、电影感、杂志式的大胆——适合文化评论和戏剧性的封面。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 镂空版刻出的边缘，略粗糙；纯色块不描边 |
| 质感 | 过渡区域的半调网点；全画面 15% 的纸纹 |
| 层次 | 平面，带图底反转——留白讲第二层故事 |
| 材质 | 丝网印刷 + 纸 |
| 情绪 | 复古海报、电影感、杂志式的大胆 |

#### 怎么用 deck 配色

丝网印刷**最多用 2–5 种颜色**效果最好。deck 的三个色值直接对应：

- 主色：占主导的平涂色块（常占画面 40–50%）
- 辅色：背景或对比色块（占画面 40%）
- 强调色：单个焦点元素的强调色

要双色（duotone）海报的感觉，就去掉辅色，只用主色 + 强调色。

#### 示例片段

**章节过渡页的主视觉海报，图里不带字**

````text
大胆的丝网印刷海报艺术，电影感风格。构图是中央一个单一标志性形状的强烈剪影——也许是一座风格化的山，或一个自信的几何形——画成主色深青绿 #0F766E 的平涂色块，占画面下方 60%。剪影上方是对比鲜明的天空，强调色橙 #F97316 填满上方 40%，右上方靠近角落有一个米色 #FEF3C7 的小圆太阳。地平线处有轻微的半调网点质感，在两个色区之间过渡。轻微的套色错位——橙色块相对青绿剪影偏移约 2px。全画面 15% 不透明度的淡纸纹。作为 1200×400 的章节过渡横幅，内边距 10%。图里不出现任何文字或标签。色值只是渲染指引——不要把色值或颜色名当文字画出来。
````

### vintage-poster · 复古海报 { #vintage-poster }

<img src="assets/rendering/vintage-poster.webp" alt="复古海报" width="420" loading="lazy" decoding="async"/>

世纪中期现代主义海报，半调加纸纹。典型用途：文化回顾、品牌传承、老牌酒店形象、周年纪念。配套的视觉风格：[复古海报](gallery-visual-styles-expressive.md#vintage-poster)。

世纪中期现代主义（1950–1970 年代）的海报美学。有限的配色，半调或纸张质感，复古的几何性格，手绘的温度但不松散。用于文化类 deck、品牌故事、酒店餐饮、复古科技叙事、周年纪念和老字号品牌。

#### 画风段落

````text
世纪中期现代主义海报美学——1950–1970 年代旅游海报、爵士唱片封套和 Saul Bass 片头字卡的设计语言。构图用大胆的几何形，边缘圆润有机，常略微偏离轴线，制造复古的张力。颜色以有限的平涂色块铺上（通常一共 3–5 种），填色上覆一层淡淡的半调或丝网印刷质感。线条粗，但有手感——不是完全机械，带点性格。图像风格化、简化——一轮风格化的太阳、一座棱角分明的山、一个标志性的剪影——从不写实。约 10% 不透明度的纸纹覆盖整个构图，带出岁月的触感。整体感觉温暖、自信、怀旧而不俗气——Knoll、Olivetti、Pan Am 的美学。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 自信的粗线，带轻微手感；圆角 |
| 质感 | 填色上的半调网点，或 10–15% 不透明度的淡纸纹 |
| 层次 | 平面——靠形状交叠暗示层次，从不靠阴影 |
| 材质 | 印刷纸的美感——轻微的套色错位更显地道 |
| 情绪 | 温暖、自信、怀旧、复古的乐观 |

#### 怎么用 deck 配色

deck 的色值偏**大地色或饱和暖色**时，复古海报效果最好。冷静商务的主色也能用，但会少一些复古味。

- 主色：占主导的形状填充（大的几何色块）
- 辅色：纸面背景（通常是暖米色而不是纯白）
- 强调色：小的强调形状，或半调层的色调
- 如果 deck 只给了三个色值，加一两个柔和的复古中性色（暖米色、褪色象牙白）

#### 示例片段

**旅游海报式主视觉，图里不带字**

````text
世纪中期现代主义旅游海报构图。一座风格化、棱角分明的山的剪影，主色深青绿 #0F766E，横跨画面下方 60%，略微偏离轴线，制造复古张力。山的上方，一轮正圆的太阳，强调色焦橙 #C2410C，落在右上三分线交点上。背景是暖米色 #FEF3C7（deck 的辅色，略微调向纸色）。一层 12% 不透明度的淡半调网点覆盖山和太阳。沿山的边缘有细细的、略微错位的油墨偏移，带出丝网印刷的地道感。全构图 10% 不透明度的纸纹。没有别的元素。作为 1200×500 的主视觉海报横条，内边距 12%。图里不出现任何文字、字母或数字。色值只是渲染指引。
````
