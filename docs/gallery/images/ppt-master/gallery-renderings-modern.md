# PPT 配图画风 · 现代商务（9 种）

PPT 配图画风里的现代商务（企业 PPT 的主力）一组。画风是什么、对比图怎么拍的，看 [PPT 风格库](index.md#renderings)；拼成 prompt 看[生成配图](../../../skills/ppt-master/image-generator.md)。条目里的色值都是示例，拼 prompt 时换成你这套 deck 的配色。

### vector-illustration · 矢量插画 { #vector-illustration }

<img src="assets/rendering/vector-illustration.webp" alt="矢量插画" width="420" loading="lazy" decoding="async"/>

干净的扁平矢量，大块形状，不用渐变。典型用途：咨询、SaaS、一般的职业 deck。

一般 PPT 最稳妥的默认画风。干净的扁平矢量，大胆的形状、有意为之的几何、自信的留白；十五页以上的 deck 一直用下去也不会审美疲劳。

#### 画风段落

````text
干净的扁平矢量插画，大胆的几何形状，自信的纯色填充。清晰的描边（相当于 1.5–2px 的线宽，所有元素一致）勾出每个形体。形状内部不用渐变——颜色以平涂色块铺上。只在能增加层次的地方加一点阴影（8% 不透明度的柔和投影，没有硬边）。构图顾及网格、讲究平衡，刻意留出的空白和填满的区域一样有分量。图标简化到最基本的几何形，小尺寸下也认得出。整体感觉现代、专业、克制而自信——在产品和 SaaS 场景里常被称作「设计系统美学」。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 干净的矢量描边，线宽统一，转角锐利或圆角半径一致 |
| 质感 | 没有——只用平涂。没有噪点、没有纸纹、没有绘画痕迹 |
| 层次 | 浮起的元素下可加 8% 柔和投影；不做透视 |
| 材质 | 没有——颜色是信息，不模拟材质 |
| 情绪 | 中性偏积极、专业、经过设计 |

#### 怎么用 deck 配色

矢量插画把颜色当作**平涂的编码区块**，不当渐变或阴影用。色值照原样用——不调浅、不加明暗、不暗示混合模式。

- 主色：主要形状的填充、占主导的元素
- 辅色：背景或大面积的衬托色块
- 强调色：高亮、关键数据点或唯一的强调元素
- 线条和描边：深中性色（#222 或接近黑），除非 deck 的主色够深、可以直接用

#### 示例片段

**整页主视觉的氛围背景，图里不带字**

````text
干净的扁平矢量插画背景。大胆的几何形状，纯色平涂——主色深海军蓝（#1E3A5F）在下三分之一斜切出一道自信的对角线，辅色浅灰（#F8F9FA）占上方三分之二，留作安静的呼吸空间，强调色金色（#D4AF37）只以一两条细几何线出现，把视线引向中央。所有形状带清晰的 2px 描边。不用渐变，除了一处 8% 的柔和投影不加别的阴影。画面中央 70% 刻意保持安静、不繁杂，留给之后叠加的幻灯片标题。作为整页主视觉的满版 PPT 背景，四边各留 15% 边距。色值只是渲染指引——不要把色值、颜色名或任何标签当文字画进图里。图里不出现任何文字——没有字母、数字、标识、水印或书写符号。
````

### flat · 扁平插画 { #flat }

<img src="assets/rendering/flat.webp" alt="扁平插画" width="420" loading="lazy" decoding="async"/>

现代几何色块，比矢量插画更有设计感。典型用途：品牌、产品展示 deck。配套的视觉风格：[柔和圆角](gallery-visual-styles-corporate.md#soft-rounded)、[孟菲斯](gallery-visual-styles-expressive.md#memphis)。

现代扁平设计，几何色块比[矢量插画](#vector-illustration)更大胆。更有设计感，装饰上也更自信一点。deck 想显得「有品牌意识」、而不只是实用时用它。

#### 画风段落

````text
现代扁平设计插画，大胆的几何色块，自信的色区。形体简化到最基本的剪影——圆、矩形、三角、圆角方形。不描边，或者只用极细的统一描边当作刻意的点缀。颜色以纯色平涂铺上，刻意并置（一块饱和色对着一大片中性色）。微妙的层叠交错造出平面的层次，不靠阴影。构图层级清楚——一个主导色块、一个次要色块、一个强调。整体感觉当代、有品牌意识、处处是有意的设计——产品发布和营销 deck 里常见。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 常常不描边；要用时只用细的统一线条当点缀 |
| 质感 | 没有——平涂色块 |
| 层次 | 靠层叠交错和颜色对比，不靠阴影 |
| 材质 | 平面——颜色就是品牌识别，不是材质 |
| 情绪 | 经过设计、有意图，比矢量插画更外放一点 |

#### 怎么用 deck 配色

- 主色：最大的填充色块，品牌的主声音
- 辅色：次要色块或大面积留白
- 强调色：一个饱和的强调色块或几何锚点
- 可选的第四个中性色：深色的文字或锚点色（接近黑，或 deck 的正文色）

#### 示例片段

**半页产品配图，图里不带字**

````text
现代扁平设计插画。一个大的圆角矩形，主色深青绿 #0F766E，占画面左下三分之二，右上方一个较小的圆，强调色珊瑚橙 #F97316，与它略微交叠。其余区域是安静的辅色米白 #FAFAF9。不描边，不加阴影。青绿色块里放一个简单的图标——一个风格化的包裹，画成平面剪影，青绿底上白色。作为 600×500 的半页图块，内边距 12%。图里不出现任何文字、字母、数字或标签。色值只是渲染指引——不要把色值或颜色名当文字画出来。
````

### minimalist-swiss · 瑞士极简 { #minimalist-swiss }

<img src="assets/rendering/minimalist-swiss.webp" alt="瑞士极简" width="420" loading="lazy" decoding="async"/>

瑞士网格、包豪斯式的克制，大胆留白。典型用途：高端咨询、建筑、奢侈品、字体工作室。配套的视觉风格：[瑞士极简](gallery-visual-styles-corporate.md#swiss-minimal)。

瑞士网格、近包豪斯的视觉纪律。几何锁在网格上，大量留白，无衬线的字体性格，没有装饰。最克制的画风——用于高端咨询、建筑、设计事务所、奢侈品牌、字体工作室。

#### 画风段落

````text
严格的瑞士网格极简。构图建立在看得见或隐含的模块网格上——每个元素都对齐网格线，刻意的行列对齐撑起整页。形体简化到最基本的几何元——干净的矩形、正圆、单一线宽的直线。字体性格是无衬线，常接近 Helvetica，字距严谨。颜色用得很省——通常一个主色块、大片白或近白、一个强调。不用渐变、阴影、质感、装饰。留白和填满的区域一样有分量。整体感觉严谨、深思熟虑、近乎学术——Müller-Brockmann 海报和 Vignelli 设计系统的美学。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 单一统一线宽；数学般笔直或正圆 |
| 质感 | 没有——只用平涂 |
| 层次 | 没有——严格二维，不加阴影、不做透视 |
| 材质 | 没有——颜色是概念分区 |
| 情绪 | 严谨、深思熟虑、朴素、学术 |

#### 怎么用 deck 配色

瑞士极简把颜色当**概念分区**，不当装饰。色值照原样用——一种颜色占据一个刻意的网格单元，辅色铺满底面，强调色只出现在一个三分线交点上。

- 主色：一个大的网格色块（通常是方形或矩形，占画面 20–30%）
- 辅色：底面（画面的大部分——通常近白）
- 强调色：一条细线或一个小点——绝不超过画面的 2–3%
- 描边：很少用；需要时用 deck 主色的 1px 线

#### 示例片段

**半页构图，图里不带字**

````text
严格的瑞士网格极简构图。画面建立在一套看不见的 6 列网格上。一个大的主色深海军蓝 #1E3A5F 方块占据左下的几个网格单元（约占画面 25%），严格对齐网格。画面其余部分是辅色近白 #F8F9FA——安静、开阔、刻意的留白。一条细的水平强调色金色 #D4AF37 线落在上三分线上，横跨四列（约占画面 2%）。没有别的元素。不用渐变、阴影、质感、装饰。作为 600×600 的半页图块，内边距 18%。色值只是渲染指引——不要把色值或颜色名当文字画进图里。图里不出现任何文字。
````

### glassmorphism · 玻璃拟态 { #glassmorphism }

<img src="assets/rendering/glassmorphism.webp" alt="玻璃拟态" width="420" loading="lazy" decoding="async"/>

磨砂玻璃的半透明面板，柔和阴影。典型用途：现代 SaaS、金融科技、健康科技、高端应用。配套的视觉风格：[玻璃拟态](gallery-visual-styles-corporate.md#glassmorphism)。

磨砂玻璃、柔和 UI 的美学——层叠的半透明面板、模糊的背景、柔和的阴影，靠透明度出层次。「现代应用 UI」的画风——用于现代 SaaS、金融科技、健康科技、高端应用展示和产品发布。

#### 画风段落

````text
现代玻璃拟态美学。构图由层叠的半透明面板组成，带磨砂玻璃模糊——每块面板像一片抛光玻璃，悬浮在柔和渐变背景上方一点。面板边缘用细细的 1px 高光描边微妙地勾出（上沿和左沿亮、下沿和右沿略暗），暗示折射。背景是柔和的淡冷色渐变，透过面板被模糊。面板下的投影大而柔（15–25% 不透明度，扩散充分），造出真实的层次。每块面板内部的内容用干净的纯色形状和利落的字体性格。整体感觉高级、亲近未来感、精致——当代金融科技和 Apple 式产品展示的美学。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 面板上沿、左沿的 1px 细高光描边（玻璃折射的暗示） |
| 质感 | 面板上的磨砂模糊（对背景做约 10–15px 的高斯模糊） |
| 层次 | 真实的层叠层次——大而柔的投影，有视差感的错位 |
| 材质 | 柔和渐变背景上的半透明抛光玻璃 |
| 情绪 | 高级、精致、亲近未来感、乐观 |

#### 怎么用 deck 配色

玻璃拟态把 deck 的色值当作**面板内容 + 背景渐变的色标**：

- 背景渐变：从浅一档的主色柔和过渡到辅色（比如淡蓝 → 淡灰）
- 面板填充：主色或近白的半透明（约 40–60% 不透明度）浅色
- 面板内容形状：纯主色，强调色只留给最需要强调的那个数据点或 CTA 元素
- 避免高饱和——玻璃拟态用中浅色调最好看；deck 主色很深时，只用在面板内部的内容形状上，不进渐变

#### 示例片段

**金融科技产品展示，图里不带字**

````text
现代玻璃拟态产品展示。柔和的淡冷色背景渐变，从左上方浅一档的主色 #1E3A5F（约 30% 不透明度）过渡到右下方的近白 #F8F9FA。上方浮着两块层叠的磨砂玻璃面板——一块较大的主面板（约占画面 55%，居中，略带旋转暗示三维纵深），一块较小的卡片从主面板后面探出来。每块面板左上沿有一道细细的 1px 白色高光，下方有 20% 不透明度的柔和投影（扩散充分，暗示真实的纵深）。内部内容：干净的纯色形状——一根主色 #1E3A5F 的风格化柱状条，一个强调色金色 #D4AF37 的小指示点标出一个数据点。清晰、精致、高级。作为 600×500 的半页 UI 展示图，内边距 12%。色值只是渲染指引——不要把色值当文字画出来。图里不出现任何文字或标签；文案之后在页面上叠加。
````

### 3d-isometric · 3D 等距 { #3d-isometric }

<img src="assets/rendering/3d-isometric.webp" alt="3D 等距" width="420" loading="lazy" decoding="async"/>

等距三维形体，带细微阴影。典型用途：技术架构、产品结构。

控制得当的等距三维形体——方块、层、设备、堆叠，用 30°/30°/30° 投影画出。现代 deck 里技术架构、产品结构、系统组成配图的首选。

#### 画风段落

````text
三维等距插画，干净的几何形体，用标准的 30°/30°/30° 投影画出。所有边都清晰、一致——没有透视变形，没有消失点。表面用纯色平涂加细微的明暗变化（背光面用一档更深的颜色，比受光面深约 15%）表现体积，不用绘画式渲染。边缘可以有细的统一描边，也可以直接靠颜色对比分开。构图突出可堆叠、模块化的形体——方块、积木、层、卡片悬浮排布。悬浮元素下方 8% 的柔和投影把它们锚定在空间里。整体感觉技术、有结构、当代——SaaS 产品图、云架构配图、系统组件拆解里常见。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 细的统一边线，或不描边、靠颜色对比 |
| 质感 | 表面没有——平涂 |
| 层次 | 标准等距投影（30°/30°/30°），背光面做明暗，悬浮元素下可加 8% 投影 |
| 材质 | 平涂加明暗——不反光，不写实 |
| 情绪 | 技术、模块化、当代 |

#### 怎么用 deck 配色

- 主色：主体方块受光面的填充
- 辅色：背景底面
- 强调色：一个高亮方块或一条连接线
- 背光面：主色加深约 15%（prompt 里这么写就会自动出来，不用另给色值）

#### 示例片段

**半页系统架构，图里不带字**

````text
三维等距插画，标准 30°/30°/30° 投影。三块堆叠的方块从干净的等距平面上升起——底层一块宽的基座，主色深蓝 #1E40AF，上面叠一块中等大小、颜色略深的蓝色方块，再往上一块更小的。右侧两张同一蓝色系的悬浮卡片飘在堆叠上方，用细细的斜线连着。所有方块的受光面用主色蓝，背光面用同一蓝色加深 15%。强调色金色 #D4AF37 只出现为一条细线，连接最上面的方块和一张悬浮卡片。背景是安静的辅色 #F8FAFC。悬浮卡片下有 8% 的柔和投影。作为 600×500 的半页图块，内边距 15%。图里不出现任何文字、标签或数字。色值只是渲染指引。
````

### digital-dashboard · 数字仪表盘 { #digital-dashboard }

<img src="assets/rendering/digital-dashboard.webp" alt="数字仪表盘" width="420" loading="lazy" decoding="async"/>

精致的 UI、数据可视化美学。典型用途：SaaS 演示、数据产品。配套的视觉风格：[深色科技](gallery-visual-styles-corporate.md#dark-tech)。

精致的 UI 和数据可视化美学。图看起来像产品或分析仪表盘的截图——干净的卡片、柔和的阴影、克制的字体、像图表的视觉元素。用于 SaaS 演示、数据产品展示、B2B 分析类 deck。

#### 画风段落

````text
精致的数字 UI、仪表盘美学。干净的卡片式布局，圆角（8–12px 半径），统一的柔和阴影（8% 不透明度，略向下偏移），像素对齐的清晰边缘。表面平整，颜色克制——主要是一个中性背景、几张品牌色的卡片或图表元素，再加一个强调色给焦点数据。像图表的视觉元素（柱状图、折线图、迷你走势线、环形图片段、KPI 方块）画得风格化——一看就是图表，但不带具体数值。万一出现字，也会是小号、中性、几乎当纹理用的字，但默认不带字。整体感觉像产品截图——现代、克制、懂数据。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 卡片不描边；图表元素用细的统一线条（约 1–1.5px） |
| 质感 | 没有——干净的数字表面 |
| 层次 | 卡片下统一的 8% 柔和投影；不做内凹或凸起效果 |
| 材质 | 平面，靠阴影做出有意的高低层级 |
| 情绪 | 精致、克制、懂产品 |

#### 怎么用 deck 配色

- 主色：占主导的图表元素、重点卡片的页眉
- 辅色：背景画布（通常是浅色或近白）
- 强调色：唯一高亮的数据点或焦点指标
- 可选的第四色：次要图表元素用的柔和中性色（灰色柱、淡化的走势线）

#### 示例片段

**半页产品演示，图里不带字**

````text
精致的数字仪表盘 UI 美学。三张圆角卡片在柔和的辅色背景 #F8FAFC 上整齐排成网格。最大的一张（上方，占 60% 面积）是一条风格化的上升折线图，主色蓝 #0EA5E9——三段线、平滑曲线、峰值处有锚点。下面两张小卡片：（左）一个风格化环形图，主色填满环的约 70%；（右）一个简单的 KPI 方块，里面一个大大的上升箭头图标，强调色绿 #10B981。所有卡片 8–12px 圆角，统一 8% 柔和投影。像素对齐的边缘。作为 600×500 的半页图块，内边距 10%。图里没有文字、数字、图表标签、坐标轴——只有纯视觉的图表元素。色值只是渲染指引。
````

### corporate-photo · 企业摄影 { #corporate-photo }

<img src="assets/rendering/corporate-photo.webp" alt="企业摄影" width="420" loading="lazy" decoding="async"/>

杂志式摄影，真实的人物和物件。典型用途：团队、生活方式、产品照片。配套的视觉风格：[摄影编辑风](gallery-visual-styles-editorial.md#photo-editorial)。

杂志式摄影——真实的主体、自然的构图、专业的调色。用于团队照、生活方式照、产品摄影和真实场景。

#### 画风段落

````text
杂志式摄影风格，构图自然，调色专业。主体是真实的人、真实的产品、真实的环境——带景深、用心布光拍下。构图遵循摄影原则：三分法、引导线、刻意分开前景和背景。光线自然或是柔和的棚拍光，从不刺眼。调色贴合 deck 配色的气质——企业 deck 偏冷而克制，生活方式 deck 偏暖、带金色。团队或职场场景里的人物多元、着装专业。背景交代环境、略微虚化，让焦点留在主体上。整体感觉真实、高级、杂志级。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 不适用——摄影 |
| 质感 | 自然——保留皮肤、布料、环境的质感 |
| 层次 | 真实景深——主体清晰，背景微微虚化 |
| 材质 | 真实的物理材质，专业布光 |
| 情绪 | 真实、高级、杂志感 |

#### 人物

按[生成配图](../../../skills/ppt-master/image-generator.md)里「人物随画风」那条规矩，用这个画风的摄影语法来写：

````text
多元、着装专业的人物，以照片级写实呈现。杂志式摄影构图，自然光或柔和的棚拍光。人物看起来真实、当代——没有图库照片的僵硬摆拍，没有夸张表情，没有时装大片的造作。
````

这条不是说只有这个画风能写实；别的画风按同一条规矩，各自决定人物的五官细节、解剖、质感和写实程度。

#### 怎么用 deck 配色

企业摄影和色值的关系是**调色**，不是填色：

- 主色：整张图往哪个色调调（主色是海军蓝就调冷，是赤陶色就调暖）
- 辅色：受光区域的高光色调
- 强调色：环境里一处不显眼的颜色（一件毛衣、一面墙的点缀、一个产品细节），呼应 deck 的强调色
- 色值在描述里只当**颜色提示**，不会以色值字符串出现在图里

#### 示例片段

**团队办公照，图里不带字**

````text
杂志式摄影：一个小型现代团队在当代风格的办公室里围着一台笔记本电脑协作。三到四位多元、着装专业的成年人——不同族裔、不同年龄——在真诚地交谈，没有图库照片的僵硬摆拍。自然的侧窗光，柔和的阴影。调色是冷静的商务感——整张图微微调向深蓝，呼应 deck 的主色 #1E3A5F，背景是柔和浅灰 #F8F9FA 的墙，台灯带来一处暖木色或琥珀色的点缀，呼应强调色 #D4AF37。浅景深——人物清晰，背景柔和虚化。作为 1200×600 的主视觉横条，内边距 8%。多元、着装专业的人物，以照片级写实呈现。杂志式摄影构图。真实，不是图库照片式的造作。色值只是渲染指引——色值本身不要以文字出现在图里。
````

### blueprint · 蓝图线稿 { #blueprint }

<img src="assets/rendering/blueprint.webp" alt="蓝图线稿" width="420" loading="lazy" decoding="async"/>

技术示意图，带网格和等宽字体的意味。典型用途：建筑、工程、AI 系统。配套的视觉风格：[蓝图](gallery-visual-styles-corporate.md#blueprint)。

技术示意图美学——网格上干净的线条、等宽字体的意味、克制的颜色。传达工程上的精确和分析的深度。用于架构图、AI 系统、工程类 deck、技术深挖。

#### 画风段落

````text
技术蓝图示意风格。干净精确的线条画在隐含或淡淡的网格上，几何上刻意严谨——直角、平行线、量过的间距。元素简化成最基本的示意形——方框、圆角矩形、连接线、锚点、标注记号。颜色克制，常接近单色，加一两个有语义的强调（一种颜色表示「主路径」，一种表示「备选」或「警告」）。可选一层极低不透明度（5–8%）的淡网格背景，强化示意图的感觉。不用质感、明暗、绘画痕迹。整体感觉工程般精确、偏分析、有意图——系统设计和架构汇报里常见。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 清晰的统一线条，约 1–1.5px；完全笔直或精确的曲线 |
| 质感 | 没有；可选极低不透明度的网格背景 |
| 层次 | 平面——示意，不做透视 |
| 材质 | 没有——抽象示意 |
| 情绪 | 偏分析、工程般精确、克制 |

#### 怎么用 deck 配色

- 主色：主要的示意线条和主要方框
- 辅色：背景（通常近白；想要蓝图氛围就用很淡的蓝）
- 强调色：高亮路径、警告或焦点元素
- 可选网格：辅色，5–8% 不透明度

#### 示例片段

**半页系统架构，图里不带字**

````text
技术蓝图示意图。六个圆角矩形整齐排成两行，用精确的直线连着，线端带小箭头。所有矩形都是清晰的 1.5px 统一描边，主色深蓝 #1E40AF，画在近白的辅色背景 #FAFAFA 上。一层 6% 不透明度的主色蓝淡网格带出示意图的感觉。其中一个矩形的描边换成强调色橙 #F97316 来高亮——这是焦点组件。每个矩形里有一个简单的图标——数据库圆柱、齿轮、聊天气泡、上升箭头、锁、网络节点——同样用主色蓝，不填充。连接线走直角，交汇处有小圆点锚点。作为 600×500 的半页图块，内边距 14%。图里没有文字、标签、数字——只有纯粹的示意结构。色值只是渲染指引。
````

### editorial · 杂志编辑风 { #editorial }

<img src="assets/rendering/editorial.webp" alt="杂志编辑风" width="420" loading="lazy" decoding="async"/>

杂志式信息图的样子。典型用途：金融、新闻、解释型内容。配套的视觉风格：[杂志编辑风](gallery-visual-styles-editorial.md#editorial)、[数据新闻](gallery-visual-styles-editorial.md#data-journalism)、[粗野主义](gallery-visual-styles-editorial.md#brutalist)。

杂志式信息图的样子——讲究的版面、精致的「字形当形状用」的元素、克制的颜色、杂志的节奏。金融、新闻、解释型内容、观点文章和讲究的 B2B 内容的默认选择。

#### 画风段落

````text
杂志式编辑插画，视觉层级讲究，留白自信。元素按杂志的节奏排布——一个主导的焦点区，刻意对齐看不见的栏，块与块之间留宽裕的栏间距。颜色克制、平衡——通常一个浓郁的品牌色、一个中性色、一个低调的强调色。几何形体简单，但画得有杂志的自信：大胆的色块、精致的分隔线、强调用的细线。可选双色调或限色处理，强化杂志感。构图像一页用心的杂志跨页——不吵，也不极简，而是经过斟酌。整体情绪聪明、高级、克制，适合分析和观点内容。
````

#### 线条、质感、层次

| 维度 | 处理 |
|---|---|
| 线条 | 精致——细而准的分隔线；干净的填充形状 |
| 质感 | 极少——可选极淡的纸纹，5–10% 不透明度 |
| 层次 | 平面，有意的层叠；不加阴影 |
| 材质 | 没有——抽象的编辑构图 |
| 情绪 | 精致、聪明、高级而克制 |

#### 怎么用 deck 配色

- 主色：占主导的色块；想要饱和的杂志氛围时也可以当背景底面
- 辅色：栏间距、分隔线、背景底面（通常是中性色）
- 强调色：一条强调细线、一个高亮元素

#### 示例片段

**半页金融解释图，图里不带字**

````text
杂志式编辑插画。画面刻意分成两栏——左边一块高高的色块占宽度的 40%，填主色深海军蓝 #0F2C4C，右边 60% 是安静的辅色米白 #FAF7F2 底面。米白区域里，三根风格化的柱状图元素从基线升起，高度各不相同，用主色海军蓝，宽度一致而纤细。一条强调色焦橙 #C2410C 的细线横贯下三分之一，把海军蓝色块和柱子连起来。最高那根柱子顶端有一个同样橙色的小圆形强调标记。整幅画面带 8% 不透明度的淡纸纹。作为 600×500 的半页图块，内边距 15%。图里不出现任何文字、标签、数字。色值只是渲染指引。
````
