把一张照片重构成 2:3 竖版的九十年代旧刊物电影海报：一种高饱和色平涂铺满背景，主体压成高反差的硬边形状，一端横一行金黄色的粗重压缩大写标题，脚下一块描述场景的密排小字，全幅盖着旧纸颗粒和磨损，整张不超过四种颜色。它不是滤镜——先读图，按有没有要认出来的脸选主体怎么处理，再编成生图 prompt。白天、夜景的照片都行。

用户给了照片、要做成这种海报，Agent 就照下面的[流程](#workflow)走，生图调[生成、编辑图片](../../../skills/agent-io/reference/image.md)的编辑接口。右边那张是 2026-10-17 拿同一张原图实测的，那次的 prompt 和问题见[实测](#test)。

## 交付什么 { #deliver }

- 一张成图，加一到三句中文的**创作思路**：底色用了什么、主体走哪一档和为什么、压平时牺牲了什么、标题放在哪。用户要才给完整 prompt
- 生不了图的环境，交编好的四段 prompt，再加一行配方：[变化引擎](#variation)每轴选了什么
- 用户给了照片又说要做海报，就当同意生成，不再问
- 只把最终 prompt 和要用的原图发给生图接口；不搜索、不另存、不外传用户的素材；用户没要求，就不把原图和成图存进项目

## 流程 { #workflow }

1. 看照片，填[场景卡](#scene-card)
2. 做人脸检查，按它选[主体档位](#tiers)
3. 在[变化引擎](#variation)每轴选一个，过一遍兼容规则
4. 定背景色，写出完整色板，三到四色
5. 定压平时牺牲哪些细节
6. 定标题的词、位置、字形：用用户给的词，绝不用真片名
7. 定副标题、小字块、边框、磨损
8. 编[四段 prompt](#prompt)
9. 原图当参考[调接口](#generate)
10. 全尺寸和缩略图各看一遍，对照[质检](#quality-gate)
11. 最多[定向修正](#fix)一次
12. 交图和创作思路

## 冲突时听谁的 { #priority }

按这个顺序让步：

1. 色板不超过四色
2. 主体和背景的每条边界都是硬的——这种风格没有柔边、没有渐变
3. 标题金黄、粗重、压缩、全大写
4. 印刷质感要在——没有颗粒就成了现代扁平设计
5. 原图里要认出来的脸，保住
6. 保住主体的剪影和空间布局
7. 背景用平涂色，不用照片里的天空和墙
8. 小字块小、安静、从属

先压平再上风格；先去掉明暗层次，再上色。

## 风格借来，片子不借 { #identity }

- **海报上绝不放真实片名**：用用户给的词；没给就自己起一个原创短语
- **任何地方都不放真实演员、导演、片厂名**，小字块里也不放
- 小字块是给这张图写的场景描述，可以被读出来，但不能点名真人、真片、真片厂
- 不照搬任何现有海报的版式：拿的是印刷语言，不是设计

## ① 读图：场景卡 { #scene-card }

在心里填一张场景卡：

- **人脸检查**：有没有必须认出来的脸？这一个答案决定主体走哪一档
- **主体**：这张海报讲的那一样东西
- **剪影质量**：主体和背景分得多干净。硬几何好压，软的、乱的边压不好
- **背景区**：哪些地方平到能整块换成一个颜色——天空、墙、水面、路面、天花板
- **原有反差**：照片本来明暗就分得开的地方，在这上面加强
- **要牺牲的细节**：压平时必须消失的纹理、材质、枝叶、零碎杂物
- **标题区**：哪块空到能放标题又不压主体
- **原有颜色**：主色调有哪些，有没有接近能直接当背景色的

## ② 配色 { #colour }

**全画三到四色，这是整套做法里最硬的约束。**

- **一种背景色铺满画面**：从变化引擎里选，或者把照片里已有的色相提上来。它是平的：没有渐变、云、纹理、暗角
- **标题是金黄**，约 `#F2B610`。不是柠檬黄、不是橙、不是琥珀色，背景换什么它都是这个色
- **剩下一两色**是近黑和米白，扛主体和小字
- 保留人脸时，皮肤算一色，压成单一的暖色调，不留完整的肤色过渡
- 不为点缀、高光、氛围加第五色。要分开什么，用明暗，不用新颜色

同一色系的参考值：金黄 `#F2B610`、朱红 `#B80102`、米白 `#F7F7F7`、近黑 `#010100`。

## ③ 主体：按人脸选档 { #tiers }

三档，**按人脸检查选，不按喜好选**。

### 一档：实拍直出 { #tier-1 }

有必须认出来的脸时用。

- 留住照片里真实的五官、比例、表情，**不重画脸**
- 皮肤推成一个暖色，衣服压成平的亮或暗，阴影压成背景色的深色版
- 反差往狠了拉：高光溢出，暗部堵死，中间调变薄
- 背景照样换成平涂色，只有主体保持实拍

### 二档：二阶、三阶压缩 { #tier-2 }

建筑、物件、车、风景，以及不需要认出来的人，默认走这档。

- 主体压成两到三阶，阶与阶之间没有平滑过渡
- 剪影原样保留，内部纹理全部牺牲
- 窗户、招牌、小开口变成干净的几何孔洞，孔里填背景色——建筑读不读得出来就靠这个
- 阶里可以有网点或粗网纹

### 三档：平涂矢量 { #tier-3 }

只在主体简单、没有脸时用。

- 用不带明暗的平涂形状重画主体
- **绝不用在脸上**：重画的脸会崩

**一张图里可以混档**：人走一档，背景建筑走二档。拍人在某个地方的照片，这是最强的配法。

## ④ 文字 { #type }

- **标题**：粗重、压缩、全大写、方头收笔，复古粗衬线或无衬线。字高占画面高度 8%–15%，金黄。可以加一层同字形、背景色的错位投影
- **位置**：顶部、底部，或压在主体上，必须落在场景卡标出的空白区
- **用词**：照用户给的；没给就自己起一个一到三个词的原创短语，绝不用真片名
- **副标题**：可选，标题下一行，小一号，米白或金黄
- **小字块**：脚下一块很小的密排字，**四到七行**，每行**八到十四个英文词**，宽度占画面 60%–80%。内容是照着场景卡写的一段完整英文白话，描述原照片里的场景：在哪、在发生什么、光线和时辰、天气、表面和材质、主体穿什么做什么。写连贯的句子，不写列表。最后一行明显短一截、居中，像真海报的署名块那样收尾
    - 用米白或金黄。字号按把行排满来定，不按固定字高——**要的是密度**：海报尺度下没人读它，它是当字体肌理用的
    - 直接印在已有的平涂底色上，底色和纸纹从每一行字后面不间断地穿过。**绝不给小字块垫底**：没有底板、方框、色带、飘带、标签、描边、轮廓、文字阴影、发光，字后面也不能局部变深或变浅
    - 用真句子，不用编的字：真词给模型连贯的字形去排，编的字会塌成一条噪点带。不出现真人名、片名、片厂名
- 所有字同一方向，不旋转、不弯曲、不散排

## ⑤ 印刷质感 { #print }

必须有。没有它，出来的是现代扁平设计，不是印出来的海报。

- 全幅旧纸颗粒，平涂色场里也有
- 边缘磨损、一道浅折痕、轻微污渍或霉斑
- 轻微套印错位：一块色版偏一根头发丝
- 平涂区油墨不匀：细微斑驳，绝不是渐变
- 可选内框：距裁切边 3%–5% 一圈米白细线，框外露纸色

## ⑥ 画幅 { #frame }

- **满版出血**：内容铺满整张竖版画布。默认
- **宽银幕嵌入**：画面是竖版画布中间的一条宽横带，上下是平涂深色带
- **斜切嵌入**：内容块转几度、切掉角，四周平涂色
- 后两种要精确几何，生图模型画不稳——带子会漂、会出渐变、会被忽略。用户要这两种，就按宽比例出图，再到图像编辑器里合成边带；直接跟用户说明，别跟模型较劲

## 变化引擎 { #variation }

编 prompt 前每轴选一个：

| 轴 | 选项 |
|---|---|
| 背景色 | 朱红 / 钴蓝 / 深黑 / 暖奶油 / 交通橙 |
| 主体档位 | 实拍调色 / 二阶 / 三阶 / 平涂矢量 |
| 标题位置 | 顶部 / 底部 / 压在主体上 |
| 标题字重 | 特粗粗衬线 / 压缩无衬线 / 圆头复古粗衬线 |
| 小字块 | 底部居中 / 底部右对齐 / 不要 |
| 边框 | 米白细线内框 / 不要 |
| 印刷磨损 | 只有颗粒 / 颗粒加折痕 / 重度磨损加污渍 |
| 画幅 | 满版出血 / 宽银幕嵌入 / 斜切嵌入 |

兼容规则：

- 人脸检查为阳性，不许选平涂矢量
- 深黑底只能配二阶或平涂矢量：实拍主体放在黑底上会丢边
- 标题压在主体上，要求主体占画面不到 60%
- 画幅不是满版出血，就照[画幅](#frame)最后一条办

## 编四段 prompt { #prompt }

按顺序定下这些字段，只编会变成像素的东西：

1. **画布**：默认 2:3 竖版，加画幅
2. **背景色**：确切色相，铺满多少
3. **主体**：哪一档、几阶
4. **色板**：完整列出三到四色，各叫什么
5. **边界**：哪里必须硬、去掉了哪些柔
6. **标题**：确切用词、位置、字高占比、颜色、字形
7. **副标题和小字块**：副标题有没有、在哪；小字块在哪，场景描述逐字写全
8. **印刷质感**：颗粒、磨损、套印错位、油墨不匀
9. **牺牲的细节**
10. **硬性避免**

最终 prompt 写成紧凑的四段：

1. **画布和颜色**：比例、确切背景色和铺满多少、完整色板逐个点名，并写明不许有第五色
2. **主体**：哪一档、几阶、什么要认得出、牺牲什么纹理，每条边界都硬、没有渐变
3. **文字和印刷**：标题的确切用词、位置、字高占比、颜色、字形；副标题；小字块的场景描述逐字写出、位置和大小，写明小字直接印在不间断的平涂底上，没有垫底、描边、阴影、局部变色；颗粒、磨损、套印错位，有没有边框
4. **硬性避免**：照抄[下一节](#avoid)

消失什么和留下什么写得一样清楚。prompt 用中文写就行，标题和小字的英文单独成行、注明逐字照印——实测那次就是这么写的。

## 硬性避免 { #avoid }

不要：照片写实、电影剧照感、电影光、现代扁平设计、渐变背景、暗角、柔化或羽化的主体边缘、景深虚化、发光、霓虹、泛光、3D 渲染、主体投影、干净无颗粒的表面、五种及以上颜色、为氛围加的强调色、粉彩或低饱和配色、用柠檬黄或橙色代替金黄、细字标题、手写或花体标题、旋转或弯曲的文字、编造或乱码的小字、小字后面的任何底板、方框、色带、飘带、标签、描边、轮廓、阴影、发光或局部变色、真实片名、真实演员或导演名、真实片厂 logo、照搬现有海报的版式、重画的脸、多出来或畸形的手指、水印。

## 调接口 { #generate }

走[生成、编辑图片](../../../skills/agent-io/reference/image.md)的编辑接口，原图写成 data URI 放进 `images[].image_url`：

- `size` 写 `"2:3"`，出来是 1024×1536；`image_resolution` 写 `"1k"`
- 原图先缩到长边 1024 左右再传
- 2:3 改图实测要 204 秒，超时设 400 秒以上；用 curl 发，HTTP 版本的坑见那一页

## 质检 { #quality-gate }

交图前逐条看：

- 整张数得出来不超过四种颜色吗？
- 背景是一种平涂色，没有渐变、云、暗角吗？
- 标题是指定的金黄，粗重、压缩、全大写吗？
- 标题字高占 8%–15%，避开了主体的关键部位吗？
- 主体和背景的每条边界都是硬切，哪里都没有羽化和发光吗？
- 全幅都看得到纸纹，平涂色场里也有吗？
- 有边缘磨损，至少有一点套印错位吗？
- 人脸检查为阳性时，脸还是实拍、认得出吗？
- 压阶的，剪影还在、内部纹理没了吗？
- 窗户和开口读起来是填了背景色的干净孔洞吗？
- 小字块读起来是排好的铅字而不是一条噪点带，也没点名真人、真片、真片厂吗？
- 小字直接印在不间断的平涂底上，后面没有垫底、描边、阴影、发光、局部变色吗？
- **整张没有真实片名、演员名、导演名、片厂 logo 吗？**
- 版式和任何现有海报都不一样吗？
- 缩成缩略图，标题还读得出、主体还立得住吗？
- 看的人会说这是一张印出来的海报，而不是一张加了滤镜的照片吗？

## 定向修正 { #fix }

最多重做一次，只改看到的那一个问题：

| 问题 | 怎么改 |
|---|---|
| 颜色多了 | 点名多出来的颜色，要求并进色板里最近的那一色 |
| 边软了 | 重申主体和背景的每条边界都是硬切，没有羽化、发光、渐变 |
| 背景不平 | 重申天空或墙是一整片纯色，没有云、渐变、暗角 |
| 标题颜色跑了 | 写出确切的金黄色值，说明它既不是柠檬黄也不是橙 |
| 标题太细或太宽 | 重申粗重、压缩、全大写、方头收笔 |
| 没有印刷质感 | 重申全幅纸纹、边缘磨损、轻微套印错位 |
| 脸崩了 | 降到一档，说明脸必须保持实拍、不重画 |
| 主体淹在背景里 | 拉高边界处的反差，或者把背景换成明度差得更远的颜色 |
| 小字成了噪点或乱码 | 逐字重写原句，再一档一档降密度：七行降到五行，五行降到四行，直到字成形。别低于四行，太薄就没了肌理 |
| 小字被垫了底板、描边或阴影 | 重申字直接印在不间断的平涂底上，去掉每一种底板、方框、色带、飘带、标签、描边、轮廓、阴影、发光和字后的局部变深变浅 |
| 出现真片名或真人名 | 换成用户的用词重跑——这是硬失败，不是风格问题 |
| 边带漂了或出渐变（宽银幕、斜切） | 别较劲：按宽比例出图，到编辑器里合成边带 |

小字只是个别字母拼错、整块读起来仍是铅字，不算失败，别把这一次修正花在它上面——[实测](#test)时专门修过，错字只少了一个。

## 实测 { #test }

2026-10-17 用页首那张楼群照片（上游的示例原图，裁掉右边一条黑边）跑了一次：

- **配方**：朱红底（从晚霞的粉色提上来）· 二阶 · 标题顶部 · 压缩无衬线 · 小字底部居中 · 米白内框 · 颗粒加折痕 · 满版出血
- **一次就对的**：平涂朱红底、楼体两阶硬边、窗洞填底色、金黄标题和米白副标题、全幅颗粒和磨损
- **没做到的**：小字有 4 个词拼错（blure、windews、villow、ligets）；排得比规定的松，宽度只到画面一半多；米白内框没画出来，只在四边留了一圈纸色
- **修小字**：把成图当原图再调一次编辑接口，要求只改小字、逐字照五行原句、字号小一号、行距更紧。别处几乎原样保住了，可拼写还是错：错字从 4 个变成 3 个（blure、yillow、ilghts），字小了，整块反而更窄。254 秒
