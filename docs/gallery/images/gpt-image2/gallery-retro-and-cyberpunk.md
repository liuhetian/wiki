# 复古与赛博朋克

### 海上要塞上空的赛博朋克机甲少女

<img src="assets/retro-cyberpunk/cyberpunk-mecha.png" alt="cyberpunk mecha" width="420"/>

```text
一名十五六岁的机甲少女，苍白的皮肤上沾着煤灰和海盐飞沫，锐利的琥珀色眼睛里亮着发光的 HUD 准星，齐腰的灰白长发扎成高马尾，在海风中甩动，肩部、前臂和小腿覆盖着哑光枪灰色外骨骼装甲，关节处露出液压活塞，胸挂上有发光的青色冷却液管线，一件沾满油污的超大机库夹克从一侧肩膀半滑下来，右肩扛着一门巨大的轨道炮，领口挂着狗牌和一条磨破的红丝带；她偏左站在一座倾斜钢铁平台锈蚀的边缘上，平台伸出在漆黑的水面之上，重心压在一条腿上，左手握着炮的背带，头微微转向镜头，目光安静而倔强，背部推进器喷出蒸汽，马尾和夹克在咸湿的海风中向一侧飘扬；背景是黄昏时一座广阔的废弃海上城市，用途不明的巨型构筑物从海中升起，形成错落的剪影，骨白色的巨石塔楼与长满藤壶的钢铁熔为一体，巨大的环形构造以断裂的角度倾斜，锈蚀的骨架龙门吊上缠着废弃的电缆，暗色的涌浪在塔柱之间翻滚，半被吞没的沉船躺在它们脚下，浓重的海雾贴着底部，而上层结构刺入淤青色的天空，塔楼高处零星闪烁着微弱的灯光，像远处的眼睛；阴郁的低调光，阴云天空带来冷青色环境光，镜头右侧远处的建筑漏出温暖的琥珀色钠灯光，塔楼后方低垂的太阳形成硬逆光，勾勒出她的轮廓，体积光（god rays）穿透海雾，装甲上有湿润的镜面高光；35mm 变形宽银幕镜头（anamorphic），轻微仰角，越过她的肩膀望向那些构筑物，中远景，浅景深，前景的铁锈虚化，水平镜头光晕，细腻的大气薄雾把远处的巨型构筑物压缩成层叠的剪影；电影感动画主视觉（key visual），带清晰线稿的绘画感数字插画，去饱和的海洋配色：青色、骨白和铁锈色，点缀少量温暖的强调光，胶片颗粒，高反差杂志海报美学。画幅 16:9。
```

### Neon Orchid District 设定板

<img src="assets/retro-cyberpunk/neon-orchid-district-board.png" alt="neon orchid district board" width="420"/>

```text
制作一张赛博朋克角色与城市设定板，采用高级杂志版式，横版 16:9。标题文字："NEON ORCHID DISTRICT"。设定板分成五个不对称的面板：一个大尺寸的电影感街景，画面是被雨淋透的高架夜市；两个特写肖像面板，画原创的成年赛博朋克快递员，身上有发光的兰花纹身；一个小的等距视角地图面板，显示小巷和无人机航线；一个道具面板，展示加密的交通通行证、赛博义体手套和自动售货机贴纸。使用层叠的霓虹洋红、青色、酸性绿，湿沥青路面的倒影，全息招牌，构图密集但清晰易读，杂志式页边距，小号标签，统一的复古未来动漫/赛博朋克风格。只用原创角色，不涉及任何现有 IP，不含露骨内容。
```

### Synth Moon Crew 外星夜生活网格图

<img src="assets/retro-cyberpunk/synth-moon-crew-grid.png" alt="synth moon crew grid" width="420"/>

```text
制作一张方形的赛博朋克外星夜店名录图，名为 "SYNTH MOON CREW"。版式：干净的 3×3 网格，九张卡片，带细细的铬金属边框。每张卡片展示一个不同的原创外星人或仿生人夜生活角色：玻璃角 DJ、锦鲤鳞片调酒师、蛾翼黑客、铬金属艺伎贝斯手、水母快递员、霓虹女祭司、爬行类时装模特、自动售货机神谕者和戴面具的舞者。每张卡片都有一个清晰可读的小名牌和独特的强调色，但整个网格共享一种精致的 90 年代末动漫赛博朋克美学：黑色背景、荧光轮廓光、光亮材质、贴纸般的 UI 图标、俏皮时髦的活力，无血腥，无露骨内容，只用原创设计。
```

### 霓虹雨巷空镜

<img src="../prompt-cards/assets/img-scene-neon.webp" alt="霓虹雨巷空镜" width="420"/>

```text
广角建立镜头（establishing shot）：夜晚下雨的霓虹小巷，密集的竖排招牌只是发光的抽象形状（没有可辨认的文字），湿漉漉的反光路面，街边通风口冒着蒸汽，深品红与电光青绿的灯光，电影感氛围，细节极其丰富的场景概念图，画面里没有人，阴郁的赛博朋克城市。无文字，无水印。
```
