# 更多插画风格

### 扁平设计：现代身心健康

<img src="assets/more-illustration-styles/flat-design-editorial-wellness.png" alt="flat design editorial wellness" width="420"/>

```text
一张干净的矢量扁平设计插画，用于一篇现代健康与身心养护的杂志文章。画面里是一群形象多元、经过风格化处理的人，在一座极简公园里做瑜伽和冥想。人物比例简化而优雅，没有五官，穿着运动服，配色为“灰鼠尾草绿（Muted Sage）”“灰玫瑰粉（Dusty Rose）”和“沙色（Sand）”。背景由代表山丘的几何半圆和深浅不一的绿色简单叶形组成。没有渐变也没有阴影；整张图由边缘利落、相互叠压的纯色色块构成。构图平衡通透，留白充足。光线只用一个代表太阳的黄色圆形表示，不投下任何阴影。整体审美友好、专业，非常“Behance 2024”，强调清晰与平静。
```

### Q 版风格：星星面包房

<img src="assets/more-illustration-styles/chibi-kawaii-bakery.png" alt="chibi kawaii bakery" width="420"/>

```text
一张超级可爱的“Q 版”（chibi）插画，画的是一家由一群森林小动物经营的迷你魔法面包房。角色们头大、眼睛又大又亮、四肢短小，戴着迷你厨师帽、系着围裙。它们正在装饰巨大的、发着光的纸杯蛋糕，蛋糕看起来像一颗颗星球。配色是“马卡龙彩虹（Pastel Rainbow）”：薄荷绿、草莓粉、薰衣草紫和柠檬黄。线稿柔和圆润，用深巧克力棕而不是黑色。背景是一间温馨、线条圆润的厨房，摆着装满闪亮星尘的罐子，窗外能看到一弯新月。光线温暖、闪闪发亮，有许多小小的“闪烁”特效，糕点周围有柔和的白色光晕。氛围甜腻、奇趣、极其治愈，适合做一套贴纸或一本儿童绘本。
```

### 低多边形几何：阿尔卑斯日落

<img src="assets/more-illustration-styles/low-poly-mountain-voyage.png" alt="low poly mountain voyage" width="420"/>

```text
一张完全由锐利、平面着色的几何多边形构成的风格化风景插画。主体是日落时分的一列雪山。每个面都是三角形或四边形，没有曲线也没有渐变。光线由多边形的角度决定，形成分明的明暗切面。配色从山谷里的“深靛蓝（Deep Indigo）”过渡到山峰上的“烈焰绯红（Fiery Crimson）”和“金色（Gold）”。前景里，一片低多边形松林用简单的绿色四面体表示。天空是一条条水平色带，低多边形太阳由同心的黄色圆组成。整体观感让人想起早期 3D 电子游戏的美学，但带着现代的高分辨率质感。氛围干净、数字化，在数学般的简洁中透着一种奇异的宁静。
```

### 贴纸设计：赛博探险俱乐部

<img src="assets/more-illustration-styles/holographic-sticker-badge.png" alt="holographic sticker badge" width="420"/>

```text
一组五枚高品质异形模切贴纸设计，排列在深色碳纤维背景上。中央的贴纸是一枚圆形徽章，上面是一个风格化的宇航员头盔，配有粗体未来感字体的文字 'EXPLORE'。其他贴纸包括一枚复古风格火箭、一颗带环的行星和一道闪电。美术风格是“新传统贴纸（Neo-Traditional Sticker）”，带粗白边，色彩鲜艳饱和。部分区域叠加“镭射”质感，形成随光线变化的彩虹光泽。光线带有明亮的镜面高光，让贴纸有立体、塑料、略带光泽的质感。颜色为“电光紫（Electric Purple）”“青色（Cyan）”和“霓虹黄（Neon Yellow）”。每枚贴纸都有细微的投影，看起来像是正从表面微微翘起。
```

### 卡哇伊贴纸包：墨西哥元素

<img src="assets/more-illustration-styles/kawaii-sticker-pack-mexico.png" alt="kawaii sticker pack mexico" width="420"/>

```text
设计一套可爱的卡哇伊（kawaii）贴纸包，内容是墨西哥的著名事物，包括标志性美食、地标和传统物件，全都带着萌萌的表情，柔和的马卡龙色，圆润的造型，极少的阴影，Q 版风格，亮面贴纸质感，高分辨率，排成一整张贴纸页。
```

### 孔版印刷：城市阴影

<img src="assets/more-illustration-styles/risograph-urban-landscape.png" alt="risograph urban landscape" width="420"/>

```text
一张城市风景插画，采用双色孔版印刷（Risograph）风格。配色限定为“荧光粉（Fluorescent Pink）”和“青蓝（Teal Blue）”，两种油墨叠印处形成深海军蓝。画面具有 Riso 印刷特有的颗粒感和触感，网点清晰可见，还有轻微、刻意的“套印偏移（misregistration）”，颜色没有完全对齐。主体是一条城市街道的高反差视图，有消防梯和电线。光线通过网点图案的疏密来表现，营造粗粝的低保真（lo-fi）美学。构图使用扁平形状和大胆的剪影，粉色油墨用于天空，青色用于建筑阴影。氛围独立、文艺，带着对 DIY zine（独立小志）文化的怀旧。底部角落用一种扭曲、墨迹浓重的字体印着文字 'SHIFT'。
```
