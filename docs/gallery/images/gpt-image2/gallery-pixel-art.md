# 像素艺术

### 像素风汽车精灵图集

<img src="assets/pixel-art/pixel-sprite-cars.png" alt="pixel sprite cars" width="420"/>

```text
一张 10x10 的复古电子游戏汽车像素精灵图集（sprite sheet），16-bit 时代美学。十行十列的小型车辆精灵，排在干净的浅灰色网格背景上，每格 64x64 像素。精灵种类多样：轿车、跑车、肌肉车、SUV、皮卡、厢式货车、出租车、警车、敞篷车和改装热棒车（hot rod），颜色覆盖整个彩虹色谱。所有精灵统一采用 3/4 俯视角度，明暗处理一致，像素边缘清晰，不做抗锯齿，每个精灵的调色板限制在约 16 种色调，承袭 SNES / Super Nintendo 卡丁车赛车游戏的传统。
```

### 像素风早餐静物

<img src="assets/pixel-art/pixel-breakfast.png" alt="pixel breakfast" width="420"/>

```text
制作一幅怀旧的像素艺术早餐静物。画一大摞蓬松金黄的松饼，淋着亮晶晶的枫糖浆，上面放着草莓和蓝莓，像素化的热气袅袅升起。盘子放在一块粉彩色桌布上，背景里放着一杯热咖啡。使用丰富的早餐色彩、讲究的光线和诱人的质感细节，同时忠于干净、清晰可读的像素艺术。
```
