# 经典电影参考

### 对称马卡龙色：大温室

<img src="assets/cinematic-film-references/anderson-symmetric-pastel-hotel.png" alt="anderson symmetric pastel hotel" width="420"/>

```text
一张完美对称的广角电影镜头，承袭 Wes Anderson 的奇趣美学。场景是一座宏大的玻璃温室，满是奇花异草和粉色火烈鸟，正中央端端正正摆着一张黄色丝绒沙发。配色严格限定为马卡龙色系：“千禧粉（Millennial Pink）”“开心果绿（Pistachio Green）”和“芥末黄（Mustard Yellow）”。画面里每个元素都经过一丝不苟的摆放，采用扁平的正面视角，像一座玩偶屋。光线柔和均匀，没有生硬的阴影，让画面带着超现实的绘画质感。画面中央，一个身穿薰衣草紫行李员制服的男人一动不动地站着，手里拿着一枝红玫瑰。摄影机是一台老式 Panavision，拍出清晰、细节丰富的画面，带一点怀旧的暖意。氛围古怪、迷人、高度受控，强调强迫症式秩序之美。
```

### 巨碑科幻：黑曜石之门

<img src="assets/cinematic-film-references/villeneuve-monolithic-desert.png" alt="villeneuve monolithic desert" width="420"/>

```text
一张震撼的电影感远景镜头，承袭 Denis Villeneuve 的巨碑式科幻。一个孤零零的渺小人影站在一块巨大、毫无特征的黑曜石板前，石板直插数英里高、尘土弥漫的橙色天空。尺度大到难以理解，让人看起来就像一粒沙。环境是一片辽阔平坦的盐原，头顶是朦胧昏暗的太阳。光线低反差、充满大气感，巨碑表面反射出暗沉的油亮光泽。配色是“工业单色（Industrial Monochrome）”：深黑、板岩灰和低饱和的沙土赭色。画面有一种巨大的重量感和远古的寂静。摄影机使用广角镜头和大景深，强调这座结构令人恐惧的尺度。氛围是敬畏、恐惧，以及某种先进外星智慧带来的崇高神秘感。设计上极简而粗野。
```

### 梦境：漂浮花园

<img src="assets/cinematic-film-references/miyazaki-floating-island-garden.png" alt="miyazaki floating island garden" width="420"/>

```text
一帧丰饶的手绘电影画面，承袭宫崎骏（Hayao Miyazaki）梦幻般的动画。场景是一串长满青草的小岛，漂浮在蓬松洁白的积云之海中，头顶是明亮的松石蓝天空。覆满鲜艳“祖母绿（Emerald Green）”苔藓的古老石头遗迹，坐落在开花的果树之间。长草的摇曳和白鸟的飞翔让和风清晰可见。光线是夏日清晨明亮而乐观的通透感，阴影柔和如绘，每个表面都有温柔的光晕。配色丰富而自然：天蓝、嫩绿和花粉色。构图开阔通透，带着无尽的惊奇与宁静。质感柔和，像水粉画，每片叶子、每根草都显得鲜活、被人细心照料。这是一个纯粹想象、与自然和谐共处的世界。
```

### 慢电影：雾中果园

<img src="assets/cinematic-film-references/tarkovsky-misty-dacha-morning.png" alt="tarkovsky misty dacha morning" width="420"/>

```text
一帧沉思的长镜头电影画面，承袭 Tarkovsky（塔可夫斯基）的慢电影。黎明时分，浓重的银色雾气笼罩着一片荒废的苹果园。画面中央，一张简朴的木桌立在高高的湿草丛中，桌上只有一杯水。色彩几乎是单色的，以“苔绿（Mossy Green）”“冷灰（Cold Grey）”和“潮褐（Damp Brown）”为主，只有远处一盏提灯透出一点琥珀色的火光。光线自然而忧郁，经过浓雾和树冠的过滤。画面有一种深沉的时间流逝感、寂静感和精神上的重量。摄影机静止，带着缓慢、几乎察觉不到的推近。质感可以触摸：木头上的腐朽、玻璃杯上的露珠、空气里的潮湿。氛围富有哲思、孤独，深深扎根于自然世界和对一个家的记忆。
```

### 新黑色电影：橙色迷雾

<img src="assets/cinematic-film-references/blade-runner-neo-noir-orange.png" alt="blade runner neo noir orange" width="420"/>

```text
一张电影感远景镜头，承袭 Blade Runner 2049（银翼杀手 2049），描绘一座被浓厚、有毒的橙色辐射迷雾吞没的未来城市。坍塌的古老雕像和参差的摩天楼的剪影在雾霭中若隐若现。一辆亮着蓝色推进器灯光的悬浮飞行器孤身穿过橙色的阴霾，形成鲜明的色彩对比。光线压抑而弥散，看不见太阳，只有一片持续不断、诡异的橙色辉光，把所有轮廓都压平。配色是醒目的“琥珀与钴蓝（Amber and Cobalt）”双色调。构图采用低角度，仰望城市压迫感十足的建筑。摄影机使用 35mm 变形宽银幕镜头（anamorphic），形成电影宽画幅和细微的镜头光晕。氛围末日、孤独，荒凉中透着视觉上的震撼，着重表现大气的浓度和废墟的尺度。
```

### 表现主义黑色电影：发条小巷

<img src="assets/cinematic-film-references/expressionist-noir-clockwork-alley.png" alt="expressionist noir clockwork alley" width="420"/>

```text
一帧戏剧性的电影宽画幅画面，灵感来自德国表现主义黑色电影和早期默片的布景设计，呈现午夜一条被雨水浸湿、闪着光的发条小巷。高耸歪斜的建筑像舞台布景板一样向内倾斜，在湿漉漉的鹅卵石上投下参差的三角形阴影。画面中央，一名身穿炭灰色长大衣的孤独信使，提着一只玻璃笼子，笼里是一只发着光的小黄铜机械鸟。配色是深墨黑、失去光泽的黄铜色、骨白色，以及一处克制的猩红点缀，来自远处一块写着 "MIDNIGHT COURIER" 的剧院招牌。光线是高反差明暗对照（chiaroscuro），配合强烈逆光、通风口冒出的蒸汽、水洼倒影和锐利的剪影。摄影机：32mm 变形宽银幕远景，低角度，强烈的引导线，大景深，细微的胶片颗粒。画面应当像一张高规格的剧照：超现实、图形感强、情绪浓郁、构图一丝不苟，不要血腥恐怖，不要像任何真实人物。
```
