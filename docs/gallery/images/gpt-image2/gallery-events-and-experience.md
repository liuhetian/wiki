# 活动与体验

### 动物园游客导览地图

<img src="assets/events-experience/zoo-visitor-wayfinding-map.png" alt="zoo visitor wayfinding map" width="420"/>

```text
为一座名为 "RIVERGATE ZOO" 的虚构现代城市动物园设计一张精致的游客导览地图。横版 3:2 画幅（1536×1024），亲切的插画式导航地图风格，路径和分区清晰，标签可读，可爱的动物图标，实用的游客标识。画面中要有清晰的文字："RIVERGATE ZOO"、"Main Gate"、"Panda Forest"、"Savanna Loop"、"Aviary"、"Reptile House"、"Kids Farm"、"Cafe"、"Restrooms"、"First Aid" 和 "Exit"。展示按颜色区分的步行路线、编号地标、小图例、指北针、无障碍图标和柔和的植物细节。配色：温暖的奶油色纸张、动物园绿、天蓝、珊瑚色、琥珀色，以及炭灰色标签。让它讨喜、实用、像一张真正的地图，而不是普通海报；避免虚假的赞助商标志和杂乱的小字。
```

### 华山 5A 景区导览地图

<img src="assets/events-experience/huashan-5a-scenic-wayfinding-map.png" alt="huashan 5a scenic wayfinding map" width="420"/>

```text
为华山设计一张精致的中国 5A 级景区游客导览地图，标题是清晰的中文 "华山游览导览图"，副标题 "国家5A级旅游景区"。横版 3:2 画幅（1536×1024），游客中心宣传册用的高级插画地图风格。展示险峻的山脊、索道路线、步道、景点节点和安全图标。包含清晰可读的标签："北峰"、"西峰"、"南峰"、"东峰"、"中峰"、"游客中心"、"索道"、"栈道"、"观景台"、"卫生间"、"急救点"。加上小图例、路线配色、海拔提示、指北针，以及一行简短提示 "请量力而行 注意安全"。配色：水墨山石灰、松绿、日出金、朱砂红路线标记，以及干净的黑色中文字体。让它实用、美观、有中国文化气质，适合做景区导览标识牌；不要伪造官方印章，不要赞助商标志。
```
