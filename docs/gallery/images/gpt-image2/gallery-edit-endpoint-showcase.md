# 编辑接口示例

### 棋盘 → 冬日傍晚（通过 `/v1/images/edits` 编辑）

<img src="assets/photography/chess-midgame.png" alt="Chess mid-game original" width="420"/>

<img src="assets/edit-endpoint-showcase/edit-chess-winter.png" alt="Chess mid-game restyled as winter scene" width="420"/>

```text
把它改成一个大雪纷飞的冬日傍晚，棋盘和棋子上落了一层薄雪，空气中有呼出的白气，冷调的蓝灰色光线，棋局依然清晰可辨。严格保留原来的棋盘构图和横版画幅比例；棋盘和棋子保持对齐、清晰可辨。
```

### 茶饮海报 → 地铁灯箱样机

<img src="assets/edit-endpoint-showcase/tea-poster-metro-lightbox.png" alt="tea poster metro lightbox" width="420"/>

<img src="assets/typography-posters/tea-poster.png" alt="tea poster" width="420"/>

```text
把提供的茶饮海报改成一张写实的地铁站灯箱样机，尽可能保留海报画面和中文字体排印。海报装在一个竖向发光广告框里，位于干净的地铁站台墙面上，前面罩着光亮的玻璃。加上细微的反光、拉丝金属边框、地砖、柔和的站台顶灯，以及远处几个虚化的通勤者。海报保持端正、清晰可读，并占据画面主体；不要重新设计海报，不要改动它的主要文字，不要添加虚假的品牌标志。
```
