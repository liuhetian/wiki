# 科普与教育

### 人体解剖海报

<img src="assets/scientific-educational/human-anatomy-muscular-poster.png" alt="human anatomy muscular poster" width="420"/>

```text
制作一张干净的教学用解剖海报，在浅奶油色背景上展示人体肌肉系统的前视图和后视图。采用学术但视觉精致的风格：线条精准，肌肉群用低饱和的红色和赭褐色，骨骼用冷灰色，标签用细炭黑色字。在中央放一个标题，画面内文字清晰锐利："Human Muscular System"，副标题 "Anterior and Posterior Views"。标注关键结构，如 "Deltoid"、"Pectoralis Major"、"Rectus Abdominis"、"Biceps Femoris"、"Gastrocnemius" 和 "Trapezius"。加一条简短的比例说明 "Adult height reference 175 cm"，以及一个包含 "Superficial" 和 "Deep" 的小图例。保持构图对称，外观上科学准确，适合做教室挂图。优先保证标签正确、字体清晰、层级干净、明暗过渡细腻，以及出版级的教学清晰度，不要血腥或过度写实。
```


### 元素周期表光谱变体

<img src="assets/scientific-educational/periodic-table-spectral-variant.png" alt="periodic table spectral variant" width="420"/>

```text
设计一张与众不同的元素周期表海报变体：每个元素格按虚构的发射光谱族上色，同时保持干净的科学版式。使用深藏青背景，搭配明亮但克制的颜色：青、品红、琥珀、青柠绿和银白。准确排列周期表，周期和族清晰分明，镧系和锕系单独成行。加一个清晰的标题 "Periodic Table of the Elements" 和副标题 "Spectral Classification Variant"。确保代表性元素格上的标签清晰可见，如 "H 1"、"He 2"、"C 6"、"Fe 26"、"Ag 47" 和 "U 92"。在侧边加图例，标题分别为 "Alkali"、"Transition"、"Metalloid"、"Noble Gas" 和 "Actinide"。加上小号的族序号 "1" 到 "18" 和周期序号 "1" 到 "7"。成品应当有教育意义、现代感、高度易读，字体精确，格子对齐整齐，发光效果均衡，表格结构准确。
```

### 生命之树海报

<img src="assets/scientific-educational/tree-of-life-phylogeny-poster.png" alt="tree of life phylogeny poster" width="420"/>

```text
生成一张优雅的科学海报，在象牙白背景上把风格化的生命之树呈现为放射状系统发育图。使用植物图谱与科学图示相结合的精细线条，配色克制：苔藓绿、深青、琥珀、梅紫和炭黑。图从中央的根部向外分支，根部标注清晰的画面内文字 "Last Universal Common Ancestor"。主要演化支标注为 "Bacteria"、"Archaea" 和 "Eukaryota"，外层分支包括 "Plants"、"Fungi"、"Animals"、"Protists" 和 "Cyanobacteria"。顶部加标题 "Tree of Life" 和副标题 "Simplified Radial Phylogeny"。加一条小号比例说明 "Approximate branching only"。保持标签可读、分支几何均衡，层级干净，科普清晰。整体设计应像一张博物馆科学展板图形：结构分明，精神上准确，视觉丰富，文字清晰，细节精致。
```

### 天气系统图解

<img src="assets/scientific-educational/weather-systems-fronts-diagram.png" alt="weather systems fronts diagram" width="420"/>

```text
制作一张精致的气象学信息图，以俯视的天气图视角展示一个中纬度气旋系统。使用冷色调配色：海洋蓝、云白、风暴灰、深红和钴蓝，等值线平滑，符号清晰。包含气压等压线、云带、暖锋和冷锋、表示风向的箭头以及降雨区。加入清晰的画面内文字："Mid-Latitude Cyclone"、"Low Pressure 984 hPa"、"Warm Front"、"Cold Front" 和 "Occluded Front"。加入城市标签 "Northport"、"Elmside" 和 "Cedar Bay" 作为参照，外加一个图例，内容为 "Rain"、"Snow" 和 "Thunderstorm"。在不同气团中显示温度标记 "8 C"、"14 C" 和 "21 C"。构图应有教育意义、可直接出版，标签锐利，层级干净，符合图示规范，视觉可读性强，适合教科书或科学展览展板。
```

### 地质地层剖面图

<img src="assets/scientific-educational/geological-strata-cross-section.png" alt="geological strata cross section" width="420"/>

```text
制作一张精细的地质剖面海报，展示切穿一个虚构峡谷盆地的层状地层。使用自然的科学配色：砂岩米色、氧化铁红、页岩灰、石灰岩奶油色、玄武岩炭黑，地表以上是低饱和的绿色植被。清晰区分各个地层，并展示一条断层线、一个含水层、含化石岩层和一处火山侵入体。加入清晰的画面内文字："Geological Cross-Section"、"Solterra Basin"、"Scale 0-500 m"，以及标签 "Sandstone"、"Shale"、"Limestone"、"Coal Seam"、"Aquifer" 和 "Basalt Dike"。加一条竖向比例尺，刻度为 "0 m"、"100 m"、"250 m" 和 "500 m"。加上带箭头的小注释 "Marine fossils" 和 "Groundwater flow"。构图应高度易读、有教育意义、图示整洁，线条干净，标签位置正确，注释密度均衡，具备出版级科学插图的清晰度。
```
