# 屏幕翻拍

### 音乐 App + 摄像头预览

<img src="assets/screen-photography/laptop-music-webcam-screen.png" alt="laptop music webcam screen" width="420"/>

```text
制作一张用手机拍笔记本屏幕的原始照片，不是截图。画幅 3:4，高角度俯视的第一视角，夜里低头看着桌上的一台笔记本电脑。屏幕占满画面的大部分，底部露出一窄条实体键盘。突出可见的 RGB 像素网格、细微的摩尔纹条带、玻璃上的微尘、淡淡的指纹、柔和的环境反光、手持手机拍摄的噪点、轻微的透视倾斜、不完美的玻璃。macOS 深色模式。后台 App：一个通用音乐播放器，停在 Liked Songs 视图，可见的虚构曲目有："City Lights"、"Late Night Walk"、"Summer Static"、"Blue Hour"。前台 App：一个小的摄像头预览窗口悬浮在中间偏右，画面里只有一个温馨的桌角：一只陶瓷马克杯、一本笔记本、一只小毛绒熊、一盏暖色台灯和一面米白色墙。让它看起来像一张不经意间用手机真实拍下的屏幕照片，随手、不加修饰。不要人物，不要人脸，不要名人名字，不要像任何真人，不要截图，不要扁平 UI，不要完美干净的玻璃，不要影棚光，不要卡通，不要 3D 渲染，不要水印。
```

### 备忘录 + FaceTime 工作屏幕

<img src="assets/screen-photography/laptop-notes-facetime-screen.png" alt="laptop notes facetime screen" width="420"/>

```text
制作一张用手机拍笔记本屏幕的原始照片，不是截图。画幅 3:4，高角度俯视的第一视角，像是夜里有人站在书桌前往下拍。笔记本屏幕占满画面的大部分，底部露出一窄条黑色键盘和触控板。强烈的真实感：可见的 RGB 子像素网格、细微的摩尔纹条带、小灰尘点、淡淡的指纹、不均匀的玻璃反光、手持手机拍摄的噪点、轻微的透视倾斜，没有影棚级的精修。macOS 深色模式。后台 App：Apple Notes，打开一条深夜学习笔记，标题是 "Design Critique"，可见几条简短的要点："layout"、"lighting"、"source links"、"ship tomorrow"。前台 App：FaceTime 实时预览窗口悬浮在右下方，画面里是一个虚构的二十多岁成年男性，坐在杂乱的书桌前，穿连帽衫，表情疲惫但被逗乐，身后有一盏暖色台灯，房间里有书和便利贴。它后面还半露着第二个小的 Finder 窗口，里面是图片缩略图。让它感觉像一张不经意间用手机真实拍下的、正在工作的笔记本屏幕照片。不要像任何真人，不要美颜滤镜，不要完美的 UI，不要截图，不要水印，不要卡通，不要 3D 渲染。
```
