# 插画

### 复古阿马尔菲海岸旅行海报

<img src="assets/illustration/amalfi-poster.png" alt="amalfi poster" width="420"/>

```text
一幅现代铅笔插画，画的是意大利阿马尔菲海岸的复古旅行海报插图，全景的海岸悬崖公路场景，一辆经典的 1960 年代白色汽车沿着弯曲的海滨公路行驶，深蓝色的地中海上有几艘小帆船，色彩缤纷的粉彩山坡村庄，明亮的蓝天和柔软的云朵，挂着鲜黄柠檬的柠檬树枝在前景构成画框，温暖的夏日阳光，大胆鲜艳的色彩，复古 1950 年代旅行海报风格，电影感构图，高细节，丝网印刷质感，平面插画。手绘风格，笔触松弛、轮廓明确的插画。高反差配色，同时保持背景与各元素之间的色彩和谐。当代、装饰性的美学。
```

### 剪纸风森林夜市

<img src="assets/illustration/papercut-forest-market.png" alt="papercut forest market" width="420"/>

```text
制作一幅横版杂志插画，采用层叠剪纸风格：一个藏在巨大蘑菇和蕨叶下的小小森林夜市。包括卖橡果蛋糕的暖光灯笼摊位、甲虫出租车、一只写书法的狐狸、一只卖茶的獾、撑着树叶伞的孩子们，以及萤火虫连成的柔和虚线小路。风格锚点：世纪中期（mid-century）儿童绘本插画结合当代层叠纸艺微缩景观，剪纸边缘清晰可见，层与层之间有柔和的阴影，配色是低饱和的苔藓绿、南瓜橙、奶油色和墨蓝。第一眼：一个温馨发光的集市剪影。第二眼：许多小摊贩的故事。第三眼：手工纸的纹理、小小的招牌和俏皮的动物姿态。不要照片写实，不要 3D 塑料感，不要杂乱难辨的脸。
```

### 厚涂森林精灵

<img src="../prompt-cards/assets/img-illust-gouache.webp" alt="厚涂森林精灵" width="420"/>

```text
奇幻角色插画：一位森林精灵少女，尖耳朵，飘逸的金绿色长发，披着半透明的树叶斗篷，手捧一颗发光的小光球，站在黄金时刻长满苔藓的古老森林空地上。浓郁的水粉（gouache）与油画笔触，颜料肌理清晰可见，温暖的轮廓光，绘本风奇幻美术，细节丰富。无文字，无水印，不要照片写实感。
```
