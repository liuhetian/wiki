# 水彩

### 梦幻水彩：睡莲池边的年轻女子

<img src="assets/watercolor/watercolor-lily-pond.png" alt="watercolor lily pond" width="420"/>

```text
一幅梦幻的水彩插画：一位身穿奶油色亚麻连衣裙的年轻女子坐在一张饱经风雨的石凳上，在傍晚的金色时刻凝望一池睡莲。带印象派光感的美学，松弛而自信的笔触，低饱和青色与暖赭色调的透明罩染，配以柔和的薰衣草色阴影。池面上睡莲和倒映的云朵柔和模糊。温柔的阳光穿过低垂的柳枝洒下。整幅画都能看到冷压纸的纹理，有湿画法（wet-on-wet）晕染的边缘，光线细腻，构图干净，大面积留白，极简地聚焦于氛围，传达平静、轻盈和转瞬即逝的美。高品质的杂志插画，承袭 Turner 水彩习作和现代杂志插画的传统。
```

### 雨中植物温室水彩

<img src="assets/watercolor/rainy-botanical-greenhouse.png" alt="rainy botanical greenhouse" width="420"/>

```text
制作一幅精致的水彩插画，画清晨下着雨的植物温室。横向构图，透明罩染，颗粒化的颜料沉淀，柔和的湿画法晕染花，可见的冷压纸纹理。场景：拱形的玻璃温室骨架，雨滴顺着玻璃往下流，垂吊的蕨类、兰花、陶土花盆、一条窄窄的石径、一张木长椅上放着一本摊开的园艺笔记本，以及漫射的银色天光。配色：鼠尾草绿、桉树灰、淡薰衣草紫、暖赤陶色，以及点点黄色小花作点缀。画面保持通透、有诗意，保留白纸作为高光，不要生硬的数码渐变，不要照片式的镜头效果，不要粗重的轮廓线。
```
