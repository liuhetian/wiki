### 精灵弓箭手速写本概念设定页

<img src="assets/character-design/elven-archer-sheet.png" alt="elven archer sheet" width="420"/>

```text
制作一页奇幻概念设计速写本，中心是一位身披飘逸长袍的神秘精灵弓箭手。主体人物用松弛的石墨笔触绘制，辅以精确的墨线细节。主角速写周围环绕着：探索斗篷变体的侧面图、一张标有尺寸的半成品弓的研究稿、动作姿势小草图、关于附魔刺绣图案的手写注释，以及渗进页边的淡淡森林绿和银色水彩试色。这一页要像一张真正的美术总监开发稿：有探索性、优美、清晰可读、充满手作质感。
```

### 甜酷辣妹四视图设定

<img src="../prompt-cards/assets/img-char-sweetcool.webp" alt="甜酷辣妹四视图设定" width="420"/>

```text
生成一张现代都市甜酷辣妹风女性角色的标准四视图设定图，是短剧、时尚拍摄或3D建模的专业参考物料，完整呈现角色的造型、体态与细节。

样貌特征：偏鹅蛋脸，五官精致立体，眼型偏长，自带冷感，适配甜酷辣妹、街头潮人、都市酷飒女主等人设。
神态与气质：眼神清冷，表情无多余情绪，传递出「又甜又拽」的矛盾感，完美契合甜酷辣妹的设定。

1. 发型与妆容
发型：黑色长卷发，搭配两侧编发，整体蓬松有层次，自带慵懒甜酷感。
妆容核心：以清透伪素颜为基底，眼妆偏冷调，强化眼尾的锐利感；唇色偏裸棕，打造「拽姐」氛围感，妆面干净通透，突出清冷甜酷的气质。

2. 服装造型
- 核心色系：以白+灰+黑为主色调，简约低饱和配色，自带高级感与街头感。
- 服装形制：白色抹胸短款上衣+深灰色高腰包臀短裙，搭配灰色蕾丝边过膝丝袜与黑色尖头高跟鞋，是现代辣妹穿搭的经典款式，兼具性感与酷飒。
- 面料材质：主体为针织面料，上衣柔软亲肤，裙子垂坠感强；丝袜通透自然，高跟鞋挺括有型，材质区分度高，光影下质感分明。

构图：生成一张16:9画幅的4K超高清角色设计图，背景为白色。内容必须包含：从左往右依次是肩部以上与头部的大特写（突出面部特征和发型细节）、正面全身视图、左侧面全身视图、背面全身视图。严格确保所有视角的形象、服装、身体比例绝对一致，并以专业、均衡的布局呈现，角色居中，画面饱满。

布光：棚拍均匀柔光，背景为中性白/浅灰，光线柔和，精准勾勒出服装的肌理感、发丝的蓬松感与肌肤的通透感，强化清冷甜酷的氛围。

风格：真人写实风格，风格全程一致保持不变。无文字，无水印，无UI。
```

### 赛博朋克浪人：霓虹雨巷

<img src="../prompt-cards/assets/img-char-cyber.webp" alt="赛博朋克浪人：霓虹雨巷" width="420"/>

```text
电影感角色肖像：一位年轻的东亚赛博朋克浪人，二十五岁上下，下颌线锐利，凌乱的黑色短发里挑染了一缕霓虹青色，左眼是发着青光的义眼，身穿被雨淋透的黑色战术外套，接缝处走着橙色电路纹。四分之三侧身站在下雨的东京霓虹小巷前，湿漉漉的柏油路面映出品红与青绿的反光。浅景深，面部和衣料细节丰富，写实风科幻概念图。无文字，无水印。
```
