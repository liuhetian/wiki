# IP 设计（13 种）

拼接方法见[手绘风格库](../images/handdraw-style/index.md)：画风片段 + 排版 + 色彩 + 你的主题。

### IP-001 · IP定位卡

<img src="../images/handdraw-style/assets/images/layouts/ip-characters/IP-001.webp" alt="IP定位卡" width="320" loading="lazy" decoding="async"/>

````text
IP定位卡。
核心目的：回答 IP 为什么存在与商业/情绪定位。
卡片内容：IP名称（中/英）、一句话定位（身份 + 核心价值 + 情绪作用）、3个核心调性标签、目标受众画像。
画面构成：角色全身主形象居中或偏侧大图展示，视觉记忆点用小图标注，搭配大字排版的名称与定位金句，背景留白充足，具备品牌封面感。纯色背景。
IP网感强，形象高度概括，用色克制，如果风格是2d则线条简洁，如果风格不是2d则材质、配件和装饰数量使用克制。小图情况下也有较高辨识度。
默认从主题获取设计需求后先设计视觉隐喻，再设计一个好玩的 ip形象。
默认使用2d 简笔画风，如果有风格指定，则以指定风格优先。
IP默认采用非人的吉祥物形象。
避免：额外的道具（除非是IP形象固定部分），和IP无关的氛围感元素。
主题：{这里是主题描述}，请帮我设计一个好玩的ip形象
````

### IP-002 · 角色形象三视图基准图

<img src="../images/handdraw-style/assets/images/layouts/ip-characters/IP-002.webp" alt="角色形象三视图基准图" width="320" loading="lazy" decoding="async"/>

````text
排版：角色三视图与头像基准图。画面呈现角色设定基准图，整齐水平排列展示。左侧为脖子以上的头像特写近照（HEADSHOT）；右侧依次为角色的全身正视图（FRONT VIEW）、全身侧视图（SIDE VIEW）、全身背视图（BACK VIEW）。各视图人物保持标准中立直立站姿，视角水平平视，身体比例与高度一致，下方附有简短视图标签。避免：不要歪头，不要拿道具，不要插兜，无倾斜动作。
````
