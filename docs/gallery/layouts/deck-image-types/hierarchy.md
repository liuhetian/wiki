# PPT 配图版型 · 结构与层级（3 种）

PPT 配图版型里的结构与层级一组。版型是什么、哪些图不用版型、对比图怎么拍的，看 [PPT 配图版型](index.md)；拼成 prompt 看[生成配图](../../../skills/ppt-master/image-generator.md)。条目里的色值都是示例，拼 prompt 时换成你这套 deck 的配色。

### framework · 框架 { #framework }

<img src="../../images/ppt-master/assets/type/framework.webp" alt="框架" width="420" loading="lazy" decoding="async"/>

内部构图：一个中心节点加放射的卫星（中心辐射）。典型用途：关系系统、框架、架构图。默认画幅 700×700 方形（1:1）；对比图里同一主题画成中央一个「生意」节点，团队、产品、客户、增长四颗卫星围着它。

一个中心概念被相关的子概念围着，或者一个多组件系统画成关系结构。图的任务是让一个关系系统或架构**一眼看懂**时用它。

在 PPT 图块里，框架指的是：图**本身**是一张小小的关系图——中心加放射卫星，或一个带标签的矩阵，或一个分层堆叠。这张图放在页面哪里、旁边配什么文字，是另一回事；这里只管图的矩形里面画什么。

#### 构图骨架

三种可选子结构。每张图选一种，不要混用。

**子结构一：中心辐射（最常见）**

```
        ◯
         \
   ◯ ─── ◆ ─── ◯
         /
        ◯
```

| 维度 | 要求 |
|---|---|
| 版式 | 一个中心元素（几何锚点：圆、圆角方形、菱形、六边形），周围放 3–6 颗卫星 |
| 元素 | 卫星节点视觉一致——同一形状家族、同样大小、同样的配色处理。连接线细、干净、粗细相同 |
| 留白 | 宽裕的放射状呼吸空间——卫星不要挤着中心或画布边缘 |
| 平衡 | 对称（卫星均匀分布），或刻意的不对称加权（强调某一颗卫星）——绝不能是无意的失衡 |

**子结构二：矩阵（2×2 或 3×3）**

```
   ┌──────┬──────┐
   │      │      │
   ├──────┼──────┤
   │      │      │
   └──────┴──────┘
```

| 维度 | 要求 |
|---|---|
| 版式 | 网格里等大的单元格；每格一个概念 |
| 元素 | 每格一个图标或象征形状；各格视觉平等，除非刻意强调某个区域 |
| 留白 | 单元格内边距宽裕——内容只占每格中间 70% |

**子结构三：分层堆叠**

```
   ╔══════════════╗
   ║   layer 3    ║
   ╠══════════════╣
   ║   layer 2    ║
   ╠══════════════╣
   ║   layer 1    ║
   ╚══════════════╝
```

| 维度 | 要求 |
|---|---|
| 版式 | 3–5 条横向色带纵向堆叠；视觉分量单调递增或递减 |
| 元素 | 每层处理一致；每层一个图标或形状 |
| 留白 | 等高的色带，层间间隔一致；上下离画布边缘留出内边距 |

#### 图里不带字

图里只画几何结构和图标；标签之后用页面上叠加的可编辑文字补上。

````text
纯粹的几何结构——图里任何地方都不出现标签、说明、文字、字母或数字。每颗卫星、每个格子、每一层里只放一个简单的图标（齿轮、箭头、图表等）。
````

#### 图里带字

每颗卫星、每个格子或每一层里面或旁边，放一个简洁、稳定的关键词，用内容要求的文字。

````text
每颗卫星带一个简短的手写关键词（不超过两个词）——比如「数据」「流程」「增长」。关键词是画面的一部分，不是标签。不写长句，不写数字；每个关键词都要短。
````

#### 示例片段

**[矢量插画](../../images/ppt-master/gallery-renderings-modern.md#vector-illustration) + 冷静商务配色，中心辐射，图里不带字，700×700 半页**

````text
干净的扁平矢量插画，大胆的几何形状，自信的纯色填充。清晰的 2px 描边，不用渐变，浮起的元素下只加一道 8% 的柔和投影。构图是一个中心辐射式框架：画面正中一个主色深海军蓝 #1E3A5F 的圆角方形中心节点；四个同样海军蓝的卫星圆均匀分布在它周围（上、右、下、左），用深一档中性色的细直线连到中心。每颗卫星里一个简单的白色图标——齿轮、柱状条、上升箭头、聊天气泡——挑的都是小尺寸下也一眼认得的。背景是安静的辅色浅灰 #F8F9FA，占画面 65%。强调色金色 #D4AF37 只出现为中心节点外的一道细强调环——不到画面的 5%。作为 700×700 的半页图块，四边各留 16% 内边距——卫星在画布内舒展，没有元素碰到边缘。图里任何地方都不出现文字、字母、数字或标签——标签之后另行叠加。色值只是渲染指引——不要把色值或颜色名当文字画出来。只用简化的图标，没有写实的脸。
````

### pyramid · 金字塔 { #pyramid }

<img src="../../images/ppt-master/assets/type/pyramid.webp" alt="金字塔" width="420" loading="lazy" decoding="async"/>

内部构图：下宽上窄的分层。典型用途：层级、价值堆叠、能力分层。默认画幅 600×800 竖幅（3:4）；对比图里同一主题画成四层向上收窄的「文化 → 团队 → 产品 → 增长」。

一个**分层的三角堆叠**——下宽上窄——每层有自己的标签、颜色或概念。用于能力栈、价值层级或软件架构分层。

在 PPT 图块里，金字塔指的是：一个**向上收拢**的分层结构，体现「地基托起价值」——宽而稳的底座，窄窄的意义顶点。和[漏斗](sequence.md#funnel)（向下收窄，讲筛选）不同，金字塔向上收窄，讲**价值或层级的堆叠**；和[框架](#framework)（中心枢纽）不同，金字塔**严格纵向分层**。

#### 构图骨架

```
              ┌──────┐                ← Apex (smallest)
              │ T 5  │
            ┌─┴──────┴─┐
            │   T 4    │
          ┌─┴──────────┴─┐
          │     T 3      │
        ┌─┴──────────────┴─┐
        │       T 2        │
      ┌─┴──────────────────┴─┐
      │         T 1          │       ← Foundation (widest)
      └──────────────────────┘
```

| 维度 | 要求 |
|---|---|
| 版式 | 3–6 层横向层级纵向堆叠；每层比下面一层窄。可以是真正的三角轮廓（斜边），也可以是台阶式（直角分层） |
| 元素 | 每层一个简单图标 + 这一层本身作为主导色块。层的颜色通常从底部更深更重渐变到顶部更亮更浅（也可以反过来，看比喻） |
| 留白 | 层变窄，两侧边距随之变大——上方几层两侧的外围底面留出空间 |
| 平衡 | 纵向中轴是金字塔的脊梁——所有层都居中对齐 |

#### 图里不带字

层级标签之后用页面上叠加的可编辑文字补上。每层只放图标，层名之后放在旁边或里面。

````text
图里不出现任何文字、字母、数字或层级标签。每层只放一个简单的图标；层级名称之后另行叠加。
````

#### 图里带字

一张自成一体的金字塔，层名排进画面里。层名简洁、稳定，用内容要求的文字，字体呼应 deck 的正文字体。标签必须准确或要能改、或者层里的空间放不下时，把这些标签挪到页面上用可编辑文字；否则看图检查过后，图里的字照样能用。

#### 示例片段

**[矢量插画](../../images/ppt-master/gallery-renderings-modern.md#vector-illustration) + 冷静商务配色，能力金字塔，图里不带字，600×800**

````text
干净的扁平矢量插画，一个层级金字塔。五个横向台阶式层级纵向堆叠，每层都居中对齐画布的纵轴，比下面一层窄约 18%。从下往上：第 1 层（地基，最宽）更深的主色 #1E3A5F；第 2 层主色 #3B5478；第 3 层浅一点的主色 #5A7099；第 4 层辅色调的蓝 #A8BDDD；第 5 层（顶点，最窄）强调色金色 #D4AF37。每层正中一个简单的白色图标——砖块、盾牌、齿轮、上升箭头、星星。细细的辅色米白 #F8F9FA 分隔线隔开各层。背景是辅色米白。作为 600×800 的竖幅金字塔图块，内边距 12%。图里不出现文字或标签——层级名称之后另行叠加。色值只是渲染指引。
````

### matrix · 矩阵 { #matrix }

<img src="../../images/ppt-master/assets/type/matrix.webp" alt="矩阵" width="420" loading="lazy" decoding="async"/>

内部构图：两条垂直相交的轴切出 2×2 象限。典型用途：2×2 象限、优先级、风险、投入产出。默认画幅 800×800 或 1280×720（1:1 / 16:9）；对比图里同一主题画成 2×2 象限，四格分别是团队、产品、客户、增长的图标。

一个 **2×2 象限网格**（偶尔 3×3），每格有自己的标签、颜色或图标。凡是两条正交的轴把画面切成几个离散的定性区域，都用它。

在 PPT 图块里，矩阵指的是：画布被垂直相交的轴**严格地等分成几个象限**。和[框架](#framework)（中心加放射卫星）不同，矩阵没有中心——意义在四个格子里；和[对比](comparison.md#comparison)（左右两个区）不同，矩阵**横竖都**切开。

#### 构图骨架

```
   ┌────────────────┬────────────────┐
   │                │                │
   │   Quadrant 1   │   Quadrant 2   │
   │   (icon + )    │   (icon + )    │
   │                │                │
   ├────────────────┼────────────────┤
   │                │                │
   │   Quadrant 3   │   Quadrant 4   │
   │   (icon + )    │   (icon + )    │
   │                │                │
   └────────────────┴────────────────┘
        ↑                ↑
   Two perpendicular axes split the canvas
```

| 维度 | 要求 |
|---|---|
| 版式 | 一横一竖两条轴在画布中心相交，切出 4 个等大的象限 |
| 元素 | 每个象限一个简单图标 +（可选）轴端的指示（箭头或标签）。每个象限用 deck 配色里不同的颜色或深浅 |
| 留白 | 每个象限内部宽裕——图标占象限面积的 40–60% |
| 平衡 | 四个象限视觉分量相等——没有哪一个占主导 |

#### 图里不带字

象限里只放图标；轴标签和象限名之后用页面上叠加的可编辑文字补上。生图模型在四个位置画出的轴标签常常不一致，所以标签要准的时候，这条路风险更低。

````text
图里不出现任何文字、字母、数字、轴标签或象限名。每个象限只放一个简单的图标；轴标签和象限名之后另行叠加。
````

#### 图里带字

矩阵的辨识度来自图里的字，或者轴标签本身就是画面的一部分时，标签要简洁、稳定，用内容要求的文字。字体写成呼应 deck 正文字体的样子；必须准确或要能改的标签，挪到页面上用可编辑文字。

#### 示例片段

**[矢量插画](../../images/ppt-master/gallery-renderings-modern.md#vector-illustration) + 冷静商务配色，象限矩阵，图里不带字，800×800**

````text
干净的扁平矢量插画，一个 2×2 的定性矩阵。两条主色深海军蓝 #1E3A5F 的细线在画布正中垂直相交，把画布切成四个等大的象限。每个象限有淡淡的背景色：左上是 10% 不透明度的淡主色海军蓝，右上是 15% 不透明度的淡强调色金色 #D4AF37，左下是淡灰 #F8F9FA，右下是 18% 不透明度、稍深一点的淡海军蓝。每个象限正中一个主色海军蓝的简单图标——指南针、闪电、靶心、警示三角。每个图标约占所在象限的 45%。四个外角各有一个强调色金色的小圆点。作为 800×800 的参考矩阵图块，内边距 10%。图里任何地方都不出现文字、字母、轴标签或象限名——标签之后另行叠加。色值只是渲染指引。
````
