# PPT 配图版型 · 对比与汇总（2 种）

PPT 配图版型里的对比与汇总一组。版型是什么、哪些图不用版型、对比图怎么拍的，看 [PPT 配图版型](index.md)；拼成 prompt 看[生成配图](../../../skills/ppt-master/image-generator.md)。条目里的色值都是示例，拼 prompt 时换成你这套 deck 的配色。

### comparison · 对比 { #comparison }

<img src="../../images/ppt-master/assets/type/comparison.webp" alt="对比" width="420" loading="lazy" decoding="async"/>

内部构图：对称的左右（或前后）对开。典型用途：对比、Before-After、A/B、VS、优缺点。默认画幅 1200×500 对开横幅，或每边 600×500（2.4:1 / 1.2:1）；对比图里同一主题画成小团队对规模化团队（之前 / 之后）。

对开构图，展示两个对立的面——左对右、之前对之后、A 对 B、传统对新式。用于优缺点页、心态转变叙事、方案评估、转型故事。

在 PPT 图块里，对比指的是：图内部有**两个对称或近乎对称的半边**，中间有清楚的分隔。每半代表一个选项或状态。和其他所有版型都不同，对比的标志是**明确的二元**。

#### 构图骨架

**子结构一：左右对开（最常见）**

```
   ┌────────────┬────────────┐
   │            │            │
   │   LEFT     │   RIGHT    │
   │   (before, │   (after,  │
   │   option A)│   option B)│
   │            │            │
   └────────────┴────────────┘
```

**子结构二：上下对开**

```
   ┌──────────────┐
   │    TOP       │
   │  (before)    │
   ├──────────────┤
   │   BOTTOM     │
   │  (after)     │
   └──────────────┘
```

| 维度 | 要求 |
|---|---|
| 版式 | 两个近乎等大的半边，有清楚的分隔（竖向或横向）。每半有自己的内容 |
| 元素 | 每边有自己的锚点元素（一个人物、一组图标、一张图表、一个风格化场景）。视觉处理结构对称、内容不同 |
| 留白 | 外沿 12–15% 内边距；分隔可以是一条细线、一个几何形，或者只是留白 |
| 分隔 | 干净——一条手绘线、一条竖线、一个几何形，或者只是空白。要显得是有意的 |

#### 图里不带字

每边放一个视觉锚点（人物、图标、场景），不放文字标签。「Before / After」或「A / B」的标签之后用页面上叠加的可编辑文字补上。

#### 图里带字

每边可以有简短的手写标签：顶上「BEFORE」/「AFTER」，里面再加两三个短词（比如「慢 / 手工 / 脆弱」对「快 / 自动 / 可靠」）。

[墨迹笔记](../../images/ppt-master/gallery-renderings-hand-drawn.md#ink-notes)画风 + 对比版型 + 图里带字是经典组合——「宣言式 Before/After」页。

#### 示例片段

**[墨迹笔记](../../images/ppt-master/gallery-renderings-hand-drawn.md#ink-notes) + 黑白墨色配色，Before/After 左右对开，图里带字，1200×500**

````text
专业的手绘视觉笔记风格，画在纯白背景 #FFFFFF 上。构图是 Before/After 左右对开，中间一条干净的手绘竖向分隔线。两边都用自信的黑色墨线，带轻微抖动。左边（「Before」）：一个简化的火柴人，姿态沮丧，一个对话气泡里用英文大写手写体写着「OLD WAY」，下面三条手绘短划，各带一个词的简短注释（「manual」「slow」「fragile」）。右边（「After」）：一个自信的火柴人，头顶一个对勾，手写英文大写标签「NEW WAY」，下面三条复选框式注释（「automated」「fast」「reliable」）。一条弯曲的「shift」箭头在半高处从左跨到右。稀疏的语义强调：珊瑚红 #E8655A 只用在左边的痛点标记上（约 4% 面积）；柔和青绿 #5FA8A8 只用在右边的正面标记上（约 3% 面积）。颜色强调总面积不到 8%。作为 1200×500 的主视觉横幅，内边距 14%。手写文字只写短关键词。色值只是渲染指引。
````

### infographic · 信息图 { #infographic }

<img src="../../images/ppt-master/assets/type/infographic.webp" alt="信息图" width="420" loading="lazy" decoding="async"/>

内部构图：2–5 个并列分区，每区一个图标加极少的标签或关键词。典型用途：数据汇总、指标一览、步骤清单。默认画幅 600×500 或 700×700（约 1.2:1）；对比图里同一主题画成团队、产品、客户、收入四个 KPI 区。

2–5 个有序分区，每区一个图标加极少的标签或关键词。用于数据汇总、KPI 一览、步骤清单、功能亮点、价值主张的可视化。**作为局部图块使用**——这张 AI 图是嵌在幻灯片里的一小块信息面板。

在 PPT 图块里，信息图指的是：图内部是一块 2–5 区的信息面板。和[框架](hierarchy.md#framework)（中心加放射的卫星）或[流程图](sequence.md#flowchart)（有箭头的先后顺序）不同，信息图是**并列的分区**，没有严格的顺序或方向。

#### 构图骨架

**子结构一：网格（信息图最常用）**

```
   ┌──────┬──────┐         ┌──────┬──────┬──────┐
   │      │      │         │      │      │      │
   ├──────┼──────┤   or    └──────┴──────┴──────┘
   │      │      │
   └──────┴──────┘
   2×2 (4 zones)            3×1 (3 zones)
```

**子结构二：放射（4–5 个分区围着一个小的中心锚点）**

```
       ◯
        \
   ◯─── · ───◯
        /
       ◯
```

| 维度 | 要求 |
|---|---|
| 版式 | 2–5 个同等分量的分区，排成网格或放射状。每个分区视觉上各不相同（自己的颜色、图标），结构上平等 |
| 元素 | 每区一个图标 +（可选）一个短关键词。不需要连接线（和框架、流程图不同） |
| 留白 | 分区之间宽裕（10–15% 的间隔），分区内部也宽裕（内容占分区的 60–70%，其余是内边距） |
| 平衡 | 各分区视觉上平等——没有哪个区占主导 |

#### 图里不带字

每个分区只放一个图标。标签之后在图的周围或下方用页面上叠加的可编辑文字补上。

````text
每个分区放一个简单的图标——柱状条、灯泡、靶心等。图里不出现标签、说明、文字或数字。标签之后另行叠加。
````

#### 图里带字

每个分区放一个图标 + 一个短关键词（不超过两个词）。

````text
每个分区放一个图标和一个简短的手写关键词（一两个词，比如「速度」「覆盖」「信任」）。关键词是画面的一部分。不写长句，不写数字；每个关键词都要短。
````

#### 示例片段

**[矢量插画](../../images/ppt-master/gallery-renderings-modern.md#vector-illustration) + 冷静商务配色，2×2 网格，图里不带字，600×600**

````text
干净的扁平矢量插画信息图。构图是一个 2×2 的网格，四个等大的圆角矩形分区，中间用干净的间隔隔开（约为画面宽度的 12%）。每个分区用 deck 配色里不同的深浅纯色填充：左上主色深海军蓝 #1E3A5F，右上稍浅一档的海军蓝，左下再一档海军蓝，右下用强调色金色 #D4AF37 作为高亮分区（强调色总面积约占画面 7%）。清晰的 2px 描边，每个分区下一道 8% 的柔和投影。每个分区里一个简单的白色图标——柱状条（左上）、灯泡（右上）、靶心（左下）、上升箭头（右下）。辅色浅灰 #F8F9FA 的背景从间隔里透出来。作为 600×600 的半页图块，网格四周留 14% 内边距。图里不出现任何文字、字母、数字或标签——标签之后另行叠加。色值只是渲染指引。简化的图标，没有写实的脸。
````
