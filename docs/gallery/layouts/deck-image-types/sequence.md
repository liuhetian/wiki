# PPT 配图版型 · 顺序与流程（4 种）

PPT 配图版型里的顺序与流程一组。版型是什么、哪些图不用版型、对比图怎么拍的，看 [PPT 配图版型](index.md)；拼成 prompt 看[生成配图](../../../skills/ppt-master/image-generator.md)。条目里的色值都是示例，拼 prompt 时换成你这套 deck 的配色。

### flowchart · 流程图 { #flowchart }

<img src="../../images/ppt-master/assets/type/flowchart.webp" alt="流程图" width="420" loading="lazy" decoding="async"/>

内部构图：一串有先后的方块，用带方向的箭头连起来。典型用途：流程、工作流、流水线、带箭头的步骤。默认画幅 1200×400 横幅（3:1）；对比图里同一主题画成箭头依次连起的「想法 → 团队 → 产品 → 客户 → 增长」。

用箭头连起来的一串方块，表现流程、工作流、流水线。用于「它怎么运作」的配图、入职步骤、流水线图、有先后的方法论。

在 PPT 图块里，流程图指的是：图内部按清楚的方向排出 3–6 个阶段。和[信息图](comparison.md#infographic)（并列分区）不同，流程图有**方向**；和[框架](hierarchy.md#framework)（中心加卫星）不同，流程图有**先后**。

#### 构图骨架

**子结构一：横向流程（最常见）**

```
   ┌───┐ → ┌───┐ → ┌───┐ → ┌───┐
   │ 1 │   │ 2 │   │ 3 │   │ 4 │
   └───┘   └───┘   └───┘   └───┘
```

**子结构二：纵向流程**

```
   ┌───┐
   │ 1 │
   └─┬─┘
     ↓
   ┌───┐
   │ 2 │
   └─┬─┘
     ↓
   ┌───┐
   │ 3 │
   └───┘
```

**子结构三：回环**

```
   ┌───┐ → ┌───┐
   │ 1 │   │ 2 │
   └───┘   └─┬─┘
     ↑       ↓
   ┌───┐ ← ┌───┐
   │ 4 │   │ 3 │
   └───┘   └───┘
```

| 维度 | 要求 |
|---|---|
| 版式 | 3–6 个阶段方块，用明确的连接符（箭头或带箭头的线）表示方向 |
| 元素 | 各阶段视觉一致（同样的形状、差不多的大小）；连接线线宽统一；箭头样式一致 |
| 留白 | 流程周围宽裕——阶段不碰边，连接线不拥挤 |
| 方向 | 流程方向没有歧义 |

#### 图里不带字

每个阶段只放一个图标。阶段标签之后在图的上方或下方用页面上叠加的可编辑文字补上。

#### 图里带字

每个阶段里面或旁边可以放一个短关键词（不超过两个词）。

#### 示例片段

**[矢量插画](../../images/ppt-master/gallery-renderings-modern.md#vector-illustration) + 冷静商务配色，横向四阶段流程，图里不带字，1200×400**

````text
干净的扁平矢量插画流程图横幅。四个圆角矩形阶段横向排开，间隔均匀。每个阶段填主色深海军蓝 #1E3A5F，带清晰的 2px 描边和 8% 的柔和投影。每两个阶段之间一条细而统一的水平箭头，带干净的三角箭头，颜色用辅色 #F8F9FA 或接近黑。第三个阶段（作为焦点高亮）外面一圈细细的强调色金色 #D4AF37 圆环——强调色面积不到 5%。每个阶段里一个简单的白色图标——依次是输入箭头、齿轮、放大镜、输出箭头。背景底面是辅色浅灰 #F8F9FA。作为 1200×400 的主视觉横条，内边距 14%。图里不出现任何文字、字母、数字或标签——标签之后另行叠加。色值只是渲染指引。
````

### cycle · 循环 { #cycle }

<img src="../../images/ppt-master/assets/type/cycle.webp" alt="循环" width="420" loading="lazy" decoding="async"/>

内部构图：闭环，3–6 步，箭头回到起点。典型用途：闭环流程、迭代、生命周期、持续改进。默认画幅 700×700 或 800×800 方形（1:1）；对比图里同一主题画成「构建 → 发布 → 学习 → 扩张」，箭头回到起点。

一个**闭环流程**——3–6 步排成一圈（或圆角环），用带方向的箭头连起来，最后回到起点。用于迭代流程、持续改进循环、生命周期图。

在 PPT 图块里，循环指的是：一个**闭合的环形流动**——每一步通向下一步，最后一步回到第一步。和[流程图](#flowchart)（线性、单向）不同，循环没有终点；和[框架](hierarchy.md#framework)（中心枢纽加被动的卫星）不同，循环沿周长有方向地运动。

#### 构图骨架

```
             ┌─────────┐
       ┌────▶│ Step 1  │────┐
       │     └─────────┘     │
       │                     ▼
   ┌───┴───┐             ┌─────────┐
   │ Step 4│             │ Step 2  │
   └───────┘             └────┬────┘
       ▲                      │
       │     ┌─────────┐      │
       └─────│ Step 3  │◀─────┘
             └─────────┘
```

| 维度 | 要求 |
|---|---|
| 版式 | 3–6 个步骤节点排在圆形（或圆角方形）周长上；箭头把每个节点连到下一个，最后闭合回第一个 |
| 元素 | 每步一个简单图标 + 步骤之间弯曲或笔直的方向箭头。可选一个中心锚点（一个标签，或代表这个循环名字的小图标） |
| 留白 | 圆心安静——要么空着，要么只放一个小锚点 |
| 平衡 | 步骤节点沿周长均匀分布；箭头粗细统一 |

#### 图里不带字

每一步只放图标；步骤标签之后用页面上叠加的可编辑文字补上。

````text
图里不出现任何文字、字母、数字或步骤标签。每个步骤节点只放一个简单的图标；步骤名称之后另行叠加。
````

#### 图里带字

一张自成一体的循环图，步骤名排进画面里。每个名字简洁、稳定，用内容要求的措辞和文字，字体呼应 deck 的正文字体。

#### 示例片段

**[矢量插画](../../images/ppt-master/gallery-renderings-modern.md#vector-illustration) + 冷静商务配色，四阶段循环，图里不带字，700×700**

````text
干净的扁平矢量插画，一个闭环流程循环。四个步骤节点在画布周长上排成正圆——分别在 12 点、3 点、6 点、9 点的位置。每个节点是一个圆角方形（约相当于 130×130px），填主色深海军蓝 #1E3A5F，正中一个简单的白色图标——指南针、一只手、放大镜、齿轮。弯曲的方向箭头用强调色金色 #D4AF37，顺时针把每个节点连到下一个，闭合成环。圆心安静——辅色浅灰 #F8F9FA 的底面，正中一个强调色金色的小圆点作为循环的锚点。清晰的 2px 描边，每个节点下 8% 的柔和投影。作为 700×700 的半页循环图块，内边距 15%。图里任何地方都不出现文字、字母或步骤标签——所有步骤名之后另行叠加。色值只是渲染指引。
````

### timeline · 时间线 { #timeline }

<img src="../../images/ppt-master/assets/type/timeline.webp" alt="时间线" width="420" loading="lazy" decoding="async"/>

内部构图：一条线性轴，上面标着里程碑。典型用途：历史、演进、路线图、时间线。默认画幅 1200×350 横幅（3.4:1）；对比图里同一主题画成时间轴「第 1 年 → 第 2 年 → 第 3 年 → 第 5 年」。

沿时间轴的线性推进——里程碑、演进、路线图、历史。用于公司历程页、产品演进、项目路线图、分时代的叙事。

在 PPT 图块里，时间线指的是：图内部有一条清楚的**轴（横向或纵向）**，上面有 3–6 个里程碑标记。和[流程图](#flowchart)（带箭头的流程）不同，时间线讲的是**时间位置**；和[框架](hierarchy.md#framework)（关系）不同，时间线是**按先后、按年代的**。

#### 构图骨架

**子结构一：横向时间线（最常见）**

```
   ──●─────●─────●─────●─────●──
     |     |     |     |     |
   2020  2021  2022  2023  2024
   icon  icon  icon  icon  icon
```

**子结构二：纵向时间线**

```
   ●─── milestone 1
   │
   ●─── milestone 2
   │
   ●─── milestone 3
   │
   ●─── milestone 4
```

| 维度 | 要求 |
|---|---|
| 版式 | 一条清楚的轴（线），上面放 3–6 个里程碑标记（圆点、小形状）。每个里程碑附近有对应的视觉元素（图标、插画） |
| 元素 | 轴线细而统一；里程碑标记视觉一致；每个里程碑的图标元素简单、风格并列 |
| 留白 | 轴的上下（或左右）留宽裕的空间，给里程碑呼吸 |
| 时间方向 | 方向没有歧义（从左到右 = 从早到晚） |

#### 图里不带字

每个里程碑只放图标。日期标签和里程碑说明之后用页面上叠加的可编辑文字补上。

#### 图里带字

每个里程碑可以带一个短日期（比如「2020」「Q1」「v1.0」），画成画面的一部分。标签越少越好——只写日期或短锚点，不写说明。

#### 示例片段

**[矢量插画](../../images/ppt-master/gallery-renderings-modern.md#vector-illustration) + 冷静商务配色，横向五个里程碑，图里不带字，1200×500**

````text
干净的扁平矢量插画时间线横幅。一条主色深海军蓝 #1E3A5F 的细水平轴线在半高处横贯画布。五个圆形里程碑标记沿轴均匀分布——每个标记填主色海军蓝，带 2px 描边。第三个里程碑（正中）外面一圈强调色金色 #D4AF37 的圆环作为高亮（强调色面积不到 5%）。每个标记上方一个简单的小图标——种子、嫩芽、植株、大树、森林——讲一个生长的序列。每个标记下方一条细竖刻度落到轴上。背景是安静的辅色浅灰 #F8F9FA。作为 1200×500 的主视觉横幅，轴的上下各留 12% 内边距。图里不出现文字、日期或标签——标签之后另行叠加。色值只是渲染指引。
````

### funnel · 漏斗 { #funnel }

<img src="../../images/ppt-master/assets/type/funnel.webp" alt="漏斗" width="420" loading="lazy" decoding="async"/>

内部构图：上宽下窄的转化堆叠。典型用途：转化漏斗、销售管线、招聘漏斗。默认画幅 600×800 竖幅（3:4）；对比图里同一主题画成四条逐级收窄的色带「认知 → 兴趣 → 参与 → 转化」。

一叠**上宽下窄**的横向色带，代表一级级的转化阶段。每条色带都比上一条窄，暗示随着过程推进的流失和筛选。营销漏斗、销售管线、招聘漏斗、用户旅程转化的标准骨架。

在 PPT 图块里，漏斗指的是：一个**向下收拢**的堆叠——越往下视觉分量越小，体现「很多人从顶上进来，很少人走到底」。和[金字塔](hierarchy.md#pyramid)（两个方向都行，但通常向上收窄，表示层级、价值）不同，漏斗**永远是从宽到窄往下走**，讲的是**筛选**，不是层级。

#### 构图骨架

```
   ┌──────────────────────────────────┐ ← Band 1 (widest)
   │             Awareness            │
   ├────────────────────────────────  ┤
    ┌────────────────────────────┐    ← Band 2 (narrower)
    │           Interest         │
    ├──────────────────────────  ┤
      ┌──────────────────────┐         ← Band 3
      │      Consideration   │
      ├────────────────────  ┤
        ┌──────────────┐               ← Band 4
        │   Conversion │
        └──────────────┘
```

| 维度 | 要求 |
|---|---|
| 版式 | 3–6 条横向色带纵向堆叠；每条比上一条窄约 15–25% |
| 元素 | 每条色带一个简单图标（左侧）+ 色带本身作为主导色块。色带之间可选细分隔线 |
| 留白 | 色带变窄，两侧边距随之变大——下方色带两侧的外围底面留出呼吸空间 |
| 平衡 | 纵向中轴是漏斗的脊梁——所有色带都居中对齐这条轴 |

#### 图里不带字

每条色带只放图标；阶段标签之后用页面上叠加的可编辑文字补上。

````text
图里不出现任何文字、字母、数字或阶段标签。每条色带只放一个简单的图标；阶段名称之后另行叠加。
````

#### 图里带字

一张自成一体的漏斗图，色带名排进画面里。每个名字简洁、稳定，用内容要求的文字，字体呼应 deck 的正文字体。标签必须准确或要能改、或者色带太窄保不住清晰度时，把这些标签挪到页面上用可编辑文字；否则看图检查过后，图里的字照样能用。

#### 示例片段

**[矢量插画](../../images/ppt-master/gallery-renderings-modern.md#vector-illustration) + 冷静商务配色，营销漏斗，图里不带字，600×800**

````text
干净的扁平矢量插画，一个营销转化漏斗。四条横向色带纵向堆叠，每条都居中对齐纵轴，每条比上一条窄约 20%。第 1 条（最上、最宽）：主色深海军蓝 #1E3A5F 纯色填充，左侧居中一个简单的白色喇叭图标。第 2 条：浅一档的海军蓝，一个爱心图标。第 3 条：强调色金色 #D4AF37，一个购物车图标。第 4 条（最下、最窄）：更深一档的强调金色，一个星星图标。每条色带边缘笔直利落，下方有 8% 的投影。细细的辅色米白 #F8F9FA 分隔线隔开各条色带。背景是安静的辅色米白。作为 600×800 的竖幅漏斗图块，内边距 12%。图里任何地方都不出现文字、字母、数字或阶段标签——所有色带名之后另行叠加。色值只是渲染指引。
````
