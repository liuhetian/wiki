# PPT 配图版型（11 种）

版型是局部结构信息图的构图骨架：模型画的那个矩形里，元素怎么排。2×2 网格不是闭环，向上收窄的金字塔不是上宽下窄的漏斗，线性时间线不是有先后的流程图——每种骨架决定元素放在哪，彼此不能互换。版型按每张图选，不按整套 deck 定；一套 deck 用两三种版型很正常，画风和配色不变，只换版型。

版型不管这张图在页面上扮演什么角色，也不管图里画什么主体。封面、章节过渡、情绪转场、大数字、金句、单主体这类整页主视觉不用版型；局部的单个物件、单人头像或人物简介照也不用，直接写构图；目录里没有合适骨架的局部信息图，同样直接用一段话写构图。这 11 种是帮你想起常见骨架的，不是封闭的清单。拼成 prompt 的方法见[生成配图](../../../skills/ppt-master/image-generator.md)，画风见图片区的 [PPT 配图画风](../../images/ppt-master/index.md#renderings)。

对比图固定[矢量插画](../../images/ppt-master/gallery-renderings-modern.md#vector-illustration)画风和同一套冷静商务配色（主色 #1E3A5F 深海军蓝、辅色 #F8F9FA 灰白、强调色 #D4AF37 金色），主题都是「团队把一门生意做大——协作、增长、结构」，只换版型；每种版型用自己天然的画幅。图是上游用 gpt-image-2 生成的，换别的模型出来会不一样。

先在下面的目录里挑，挑中了再打开那一组的页面看全文。

### 顺序与流程

- [流程图（`flowchart`）](sequence.md#flowchart) —— 内部构图：一串有先后的方块，用带方向的箭头连起来。典型用途：流程、工作流、流水线、带箭头的步骤。默认画幅 1200×400 横幅（3:1）；对比图里同一主题画成箭头依次连起的「想法 → 团队 → 产品 → 客户 → 增长」。
- [循环（`cycle`）](sequence.md#cycle) —— 内部构图：闭环，3–6 步，箭头回到起点。典型用途：闭环流程、迭代、生命周期、持续改进。默认画幅 700×700 或 800×800 方形（1:1）；对比图里同一主题画成「构建 → 发布 → 学习 → 扩张」，箭头回到起点。
- [时间线（`timeline`）](sequence.md#timeline) —— 内部构图：一条线性轴，上面标着里程碑。典型用途：历史、演进、路线图、时间线。默认画幅 1200×350 横幅（3.4:1）；对比图里同一主题画成时间轴「第 1 年 → 第 2 年 → 第 3 年 → 第 5 年」。
- [漏斗（`funnel`）](sequence.md#funnel) —— 内部构图：上宽下窄的转化堆叠。典型用途：转化漏斗、销售管线、招聘漏斗。默认画幅 600×800 竖幅（3:4）；对比图里同一主题画成四条逐级收窄的色带「认知 → 兴趣 → 参与 → 转化」。

### 结构与层级

- [框架（`framework`）](hierarchy.md#framework) —— 内部构图：一个中心节点加放射的卫星（中心辐射）。典型用途：关系系统、框架、架构图。默认画幅 700×700 方形（1:1）；对比图里同一主题画成中央一个「生意」节点，团队、产品、客户、增长四颗卫星围着它。
- [金字塔（`pyramid`）](hierarchy.md#pyramid) —— 内部构图：下宽上窄的分层。典型用途：层级、价值堆叠、能力分层。默认画幅 600×800 竖幅（3:4）；对比图里同一主题画成四层向上收窄的「文化 → 团队 → 产品 → 增长」。
- [矩阵（`matrix`）](hierarchy.md#matrix) —— 内部构图：两条垂直相交的轴切出 2×2 象限。典型用途：2×2 象限、优先级、风险、投入产出。默认画幅 800×800 或 1280×720（1:1 / 16:9）；对比图里同一主题画成 2×2 象限，四格分别是团队、产品、客户、增长的图标。

### 对比与汇总

- [对比（`comparison`）](comparison.md#comparison) —— 内部构图：对称的左右（或前后）对开。典型用途：对比、Before-After、A/B、VS、优缺点。默认画幅 1200×500 对开横幅，或每边 600×500（2.4:1 / 1.2:1）；对比图里同一主题画成小团队对规模化团队（之前 / 之后）。
- [信息图（`infographic`）](comparison.md#infographic) —— 内部构图：2–5 个并列分区，每区一个图标加极少的标签或关键词。典型用途：数据汇总、指标一览、步骤清单。默认画幅 600×500 或 700×700（约 1.2:1）；对比图里同一主题画成团队、产品、客户、收入四个 KPI 区。

### 空间与场景

- [地图（`map`）](spatial.md#map) —— 内部构图：风格化的地理轮廓，加带注释的标记。典型用途：办公室分布、市场覆盖、区域数据、供应链、地理。默认画幅 1280×720 或 1200×500（16:9 / 2.4:1）；对比图里同一主题画成风格化世界地图，标着办公室位置和协作弧线。
- [场景（`scene`）](spatial.md#scene) —— 内部构图：带叙事的氛围环境。典型用途：团队、生活方式、故事、情境、案例（有人物、有环境）。默认画幅 1200×720 宽幅或 800×600（16:10 / 4:3）；对比图里同一主题画成团队在会议室里协作的叙事场景。
