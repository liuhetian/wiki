# PPT 配图版型 · 空间与场景（2 种）

PPT 配图版型里的空间与场景一组。版型是什么、哪些图不用版型、对比图怎么拍的，看 [PPT 配图版型](index.md)；拼成 prompt 看[生成配图](../../../skills/ppt-master/image-generator.md)。条目里的色值都是示例，拼 prompt 时换成你这套 deck 的配色。

### map · 地图 { #map }

<img src="../../images/ppt-master/assets/type/map.webp" alt="地图" width="420" loading="lazy" decoding="async"/>

内部构图：风格化的地理轮廓，加带注释的标记。典型用途：办公室分布、市场覆盖、区域数据、供应链、地理。默认画幅 1280×720 或 1200×500（16:9 / 2.4:1）；对比图里同一主题画成风格化世界地图，标着办公室位置和协作弧线。

一个**风格化的地理轮廓**（国家、区域、大洲、世界），加带注释的标记——图钉、圆点、高亮区域、连接线。用于办公室分布、市场覆盖、区域数据分布、供应链路线、扩张路线图、市场进入的地理布局。

在 PPT 图块里，地图指的是：一张**示意性的地理可视化**，不是照片级的地球视图。风格化的陆地、简化的轮廓、有意的标记位置、极少的制图细节。和[信息图](comparison.md#infographic)（抽象的数据分区）不同，地图有**真实的地理形状**撑起构图。

#### 构图骨架

```
   ┌────────────────────────────────────┐
   │        ▓▓▓▓▓                        │
   │     ▓▓▓     ▓▓▓     ●               │
   │   ▓▓          ▓▓▓                   │
   │   ▓ Stylized    ▓▓     ●            │
   │   ▓▓ landmass    ▓▓                 │
   │    ▓▓▓          ▓▓                  │
   │      ▓▓▓     ●▓▓                    │
   │         ▓▓▓▓▓                       │
   │                                     │
   │   ●  = location markers             │
   └────────────────────────────────────┘
```

| 维度 | 要求 |
|---|---|
| 版式 | 画布上放一块或几块简化的陆地轮廓；标记点或图钉放在有意义的地理位置；标记之间可选细连接线 |
| 元素 | 陆地（平涂或风格化轮廓）+ 3–12 个标记 + 可选的区域高亮（一两个区域用更深的颜色）+ 可选的连接弧线 |
| 留白 | 陆地周围的海洋或留白——至少占画布 25%。标记不要挤在陆地边缘 |
| 平衡 | 地理上大致准确但认得出——一眼就能认出是哪个区域 |

#### 图里不带字

城市、国家、区域名之后用页面上叠加的可编辑文字补上。地图只画标记，标签之后逐个标到标记位置上。

````text
图里不出现任何文字、字母、数字、国家名、城市名或标记标签。标记只画成圆点或图钉；所有标签之后另行叠加。
````

#### 图里带字

一张自成一体的参考地图，地名排进设计里。字确实是视觉语言一部分的时候用（比如复古地图、地图集风格的海报），用之前核对拼写和位置。必须准确或要能改的标签，放到页面上用可编辑文字。

#### 示例片段

**[矢量插画](../../images/ppt-master/gallery-renderings-modern.md#vector-illustration) + 冷静商务配色，世界办公室分布图，图里不带字，1280×720**

````text
干净的扁平矢量插画，一张风格化的世界地图。简化的大陆轮廓（认得出但不写实），主色深海军蓝 #1E3A5F 纯色填充，以大致准确的地理位置铺在画布上。海洋和留白是辅色浅灰 #F8F9FA。八个强调色金色 #D4AF37 的小圆形标记放在有意义的办公室位置——北美三个、欧洲两个、东亚一个、南亚一个、澳洲一个。每个标记带一圈 30% 不透明度的细脉冲光晕（圆点周围一圈淡淡的环）。两条强调色金色的细连接线（略弯，像航线）连起其中三个标记。陆地带清晰的 1.5px 描边。大陆内部不画国界——每块陆地是单色的纯色剪影。作为 1280×720 的满版世界地图，内边距 12%。图里任何地方都不出现文字、国家名或标签——所有标签之后另行叠加。色值只是渲染指引。
````

### scene · 场景 { #scene }

<img src="../../images/ppt-master/assets/type/scene.webp" alt="场景" width="420" loading="lazy" decoding="async"/>

内部构图：带叙事的氛围环境。典型用途：团队、生活方式、故事、情境、案例（有人物、有环境）。默认画幅 1200×720 宽幅或 800×600（16:10 / 4:3）；对比图里同一主题画成团队在会议室里协作的叙事场景。

带叙事的氛围环境——一个时刻、一个地方、一个情境，画成一个小故事。用于案例研究、品牌故事、生活方式页、个人叙事页。

在 PPT 图块里，场景指的是：图内部是**一个地方的一个时刻**——环境、人物（有的话）、氛围、情绪。和单一主体的主视觉不同，场景有**语境和叙事**；和没有主体的背景不同，场景里**有人**。

#### 构图骨架

```
   ┌────────────────────────────────────┐
   │  sky / atmosphere (foreground      │
   │                    or upper area)  │
   │                                     │
   │    figure / subject in environment  │
   │           ↑ foreground              │
   │  ────────────────────────────       │
   │   middle ground (context, objects)  │
   │  ────────────────────────────       │
   │   background (atmospheric depth)    │
   └────────────────────────────────────┘
```

| 维度 | 要求 |
|---|---|
| 版式 | 三层构图：前景（主体 + 紧挨的语境）、中景（衬托的环境）、背景（大气纵深）。观者像读一个小故事一样读这个场景 |
| 元素 | 一个或多个人物，按选定的画风和这张图要表达的意图处理，放在环境里。环境元素（太阳、灯、树、书桌）支撑叙事 |
| 留白 | 空气透视造出呼吸空间——背景比前景更淡 |
| 氛围 | 光的方向、色温和情绪都是有意定的（黄金时刻、傍晚的光、晨雾等） |

#### 图里不带字

场景是视觉叙事——大多数场景把文字放到页面上叠加更好读。

#### 图里带字

只在装饰性氛围字或场景内的字这两种情况下合理：

- 装饰性氛围字——出血位置的一个大号风格化单词，营造视觉情绪（「WANDER」「QUIET」）。描述艺术处理即可，拼写不关键
- 场景内的字——场景里的一块招牌、书上的标签。常常画不对；只在叙事非用不可时用

#### 示例片段

**[暖调场景](../../images/ppt-master/gallery-renderings-narrative.md#warm-scene) + 暖调大地色配色，个人故事，图里不带字，1200×600**

````text
有氛围的场景插画，带黄金时刻的电影感光线。构图是三层叙事：前景左侧——一个画得柔和的简化人物剪影沿小路走，暖暖的长影投向右边；中景——暖色的小路蜿蜒进一片风格化的山坡，暗示着几棵树；背景——空气透视造出淡淡的暖色远景，天空从地平线的琥珀色 #D97706 过渡到顶上的柔和米色 #FEF3C7。光是来自右上方的暖色黄金时刻光。前景用更深的暖主色 #9A3412；被阳光照到的表面带一点强调色金色 #D4AF37 高光。没有硬轮廓——形体从光影里浮现。淡淡的胶片颗粒，8% 不透明度。作为 1200×600 的主视觉场景，内边距 10%。只画简化的剪影人物——没有写实的脸。图里不出现文字或标签。色值只是渲染指引。
````
