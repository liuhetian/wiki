# 排版

每条排版是一张版式示意图加一段中文 prompt，只写构图和文字怎么摆，不管画风和颜色。
挑一条，再配上[画风](../images/handdraw-style/index.md)、[色彩](../colors/index.md)和你的主题，拼成完整的 prompt。

- [社媒卡（23 种）](social-cards.md) —— 上文下图、双格对比、签名卡……「自适应双拼照片转译社媒卡」和「姓名四款签名设计展示卡」是长模板，要先填占位符
- [信息图（36 种）](infographics.md) —— 金字塔、流程、时间轴、四象限、地图、拆解爆炸图、等距轴测全景……
- [漫画分镜（71 种）](comic-storyboards.md) —— 规则网格、四格、跨页、蒙太奇……
- [IP 设计（13 种）](ip-characters.md) —— IP 定位卡、三视图基准图、16 宫格表情包、角色家族、商业应用……一个 IP 形象从定位到周边的一套卡
- [电商（24 种）](ecommerce.md) —— 单品主图、卖点标注、参数尺寸、场景图、SKU 差异、促销 KV……商品保持写实，周边场景才套画风
