# 视频

视频成品配生成它的 prompt 或制作方法。别人的成品按[图片](../images/index.md)那边的格式收：一条一个成品，来源写进[维护记录](../../maintenance/index.md#gallery)；本站自己做的，成品和做法写在同一页。

- [花卉动态生长海报](flower-growth-poster.md) —— 本站自己做的：一枝洋桔梗从空白米纸上长出、开花，标题随后浮现，定格成海报，循环播放；下面是五步做法，每步一段 prompt，花名、颜色和海报文字填空
- [彩色手绘三维穿梭视频](collected/gallery-parallax-ink.md) —— 收录自 makerjackie/parallax-ink-video-skill：照片画成彩色手绘、拆成六层笔触放进同一个三维空间，镜头穿梭散开再拼回下一个主体；作者成品和本站实测两支，下面是底稿 prompt、配乐、带渲染工程的整套做法；来源与改动见[维护记录](../../maintenance/gallery/video-collected.md)
