# Gallery

现成的东西，通用到不用提问题就能挑：一套配色给网站、给 PPT、给图片都能用，「这页用什么配色」谁都懂，不用先定义。一个选择摆着很多选项，没有对错，看口味和需要。分九类，每条都是「成品 + 怎么做出来的」：图片配生成它的 prompt，前端特效配能跑的 demo，本站自己做的视频配五步做法，3D 模型和游戏玩法配能转、能玩的 demo 和做出它的 prompt。别人的原样收录，来源与授权记在[维护记录](../maintenance/index.md#gallery)里；有上游仓库、直接能用的效果只放 demo 加一句仓库地址；本站自己做的，成品和做法写在同一页。只存一个链接的外部站点在轴外的[收藏夹](../bookmarks/index.md)。

- [图片](images/index.md) —— 图配 prompt 的图库，7 大类 175 条：GPT Image 2 的 163 条（中译）+ linux.do 二次元平面设计风格 12 组，另有 prompt-cards.cyanfish.site 的 10 条生图 prompt和 1 条待出图的人像写真模板，以及一套把照片做成[旧刊物海报](images/collected/gallery-pulp-posters.md)的做法；另有小红书收来的[拍照姿势](images/index.md#poses)实拍图 59 组 529 张，只有图；还有给 PPT 挑风格的[PPT 风格库](images/index.md#ppt-master)：18 种视觉风格、20 种配图画风
- [排版](layouts/index.md) —— 167 种版式：社媒卡、信息图、漫画分镜、IP 设计、电商，每条一张示意图加一段只管构图的排版 prompt；另有 11 种 PPT 配图版型
- [色彩](colors/index.md) —— 36 种经典单色主题色和 9 套意象渐变配色，每条一张色卡加一句主题色 prompt
- [视频](video/index.md) —— 视频成品配生成它的 prompt 或制作方法；已收 2 条：本站自己做的[花卉动态生长海报](video/flower-growth-poster.md)，收录的[彩色手绘三维穿梭视频](video/collected/gallery-parallax-ink.md)
- [音频](audio/index.md) —— 还没有收录
- [前端特效](web/index.md) —— 成品前端美学，一种风格一个可抄走的活 demo，另有 Open Design / HAOQI / ORYZO 三个官网逐效果拆解；另收了 [Hairline](web/collected/gallery-hairline.md) 的 33 张等距线稿交互图形
- [3D 模型](models/index.md) —— 能在浏览器里转着看的三维模型，一个模型一页，demo 配做出它的 prompt；已收 3 个，都是本站用代码拼的：照像素画做的[低多边形小橘猫](models/orange-cat.md)，牧场里的[绵羊](models/sheep.md)和[树](models/tree.md)
- [人设](personas/index.md) —— 角色设定，一人一页，定妆照加基本资料；已收 1 位：[SEOA｜徐星澄](personas/seoa.md)，24 岁，主舞兼创作型歌手
- [游戏玩法](games/index.md) —— 能直接在浏览器里玩的小游戏和玩法原型，一个玩法一页，能玩的 demo 配做出它的 prompt；已收 1 条：本站自己做的[低多边形 3D 牧场](games/lowpoly-ranch.md)，11 只绵羊能点选、拖动、切四种动画
