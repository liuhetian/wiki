# Gallery

收录的成品参考，分成七区。每条都是「成品 + 怎么做出来的」：图片配生成它的 prompt，网页配能跑的 demo 和源码，本站自己做的视频配五步做法。别人的原样收录，来源与授权记在[维护记录](../maintenance/index.md#gallery)里；本站自己做的，成品和做法写在同一页。

- [图片](images/index.md) —— 图配 prompt 的图库，7 大类 175 条：GPT Image 2 的 163 条（中译）+ linux.do 二次元平面设计风格 12 组，另有 prompt-cards.cyanfish.site 的 10 条生图 prompt和 1 条待出图的人像写真模板，以及一套把照片做成[旧刊物海报](images/collected/gallery-pulp-posters.md)的做法；另有小红书收来的[拍照姿势](images/index.md#poses)实拍图 59 组 529 张，只有图
- [排版](layouts/index.md) —— 167 种版式：社媒卡、信息图、漫画分镜、IP 设计、电商，每条一张示意图加一段只管构图的排版 prompt
- [色彩](colors/index.md) —— 36 种经典单色主题色和 9 套意象渐变配色，每条一张色卡加一句主题色 prompt
- [视频](video/index.md) —— 视频成品配生成它的 prompt 或制作方法；已收 2 条：本站自己做的[花卉动态生长海报](video/flower-growth-poster.md)，收录的[彩色手绘三维穿梭视频](video/collected/gallery-parallax-ink.md)
- [音频](audio/index.md) —— 还没有收录
- [网页](web/index.md) —— 成品前端美学，一种风格一个可抄走的活 demo，另有 Open Design / HAOQI / ORYZO 三个官网逐效果拆解
- [人设](personas/index.md) —— 角色设定，一人一页，定妆照加基本资料；已收 1 位：[SEOA｜徐星澄](personas/seoa.md)，24 岁，主舞兼创作型歌手
