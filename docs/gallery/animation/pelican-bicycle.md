点画面或按钮暂停、继续；滑杆调速度，0 到 2.5 倍，左右方向键每次加减 0.1。速度不是一下跳过去，是逐帧追上滑杆的值。底部里程表按轮径约 0.7 米折算。

## Prompt { #prompt }

> /goal 创建一个html，内容是svg绘制一个鹈鹕骑自行车的2D动画

原话只有这一句，2026-11-06 在 Claude Code 里用 `/goal` 交出去，中间没有追加要求。

## 怎么做出来的 { #how }

从建目录到写出文件约 12 分钟，按文件时间戳算；文件只写了一次，之后没有改过。成品是一个 html：约 330 行 SVG 画场景和角色，约 270 行脚本驱动动画，没有图片、字体和运行库，双击就能跑。

- **形状全是 SVG 图元**：云、圆冠树、松树、草丛、小花在 `<defs>` 里各定义一次，用 `<use>` 摆满场景；鹈鹕的身体、翅膀、喙、喉囊是贝塞尔路径，明暗靠渐变
- **一个时钟推动全身**：车轮累计转角是唯一的状态。公路位移等于转角乘轮半径，所以轮子不打滑；曲柄转角等于车轮转角除以传动比，牙盘 20、飞轮 12；链条靠虚线偏移往前走
- **腿是两段骨骼 IK**：大腿、小腿各 84，髋钉在车座上、脚踩在踏板上，每帧用余弦定理反解膝盖，膝盖朝前。曲柄每转一圈蹬两次，身体跟着起伏
- **会变形的地方直接重写路径**：喉囊每帧改一次 `d` 晃动；围巾是沿正弦波每帧重算的燕尾丝带，角度和振幅随速度变，骑得越快飘得越平
- **七层视差**：云、山、远丘、近丘、树、路面、草地各是一块平铺两份的图块，按 0.04 到 1.25 的系数平移。山丘是周期正好 900 的正弦叠加曲线，接缝处无缝
- **小动作**：每 3.6 秒眨一次眼，用竖向缩放；点头、羽冠随风、车筐里的两条鱼各按自己的频率摆；速度线和扬尘随速度显隐

## 拿去改 { #tweak }

几何常量都在脚本开头：

```js title="pelican-bicycle.html:438-448"
--8<-- "gallery/animation/assets/pelican-bicycle.html:438:448"
```

- 轮径、曲柄长、传动比、腿长、髋的位置、1 倍速时的车轮角速度都在这里改
- 颜色在 `<defs>` 的渐变里：天空、公路、身体、翅膀、喙、喉囊；车架是 `#17a398`
- 视差快慢是 `render` 末尾每层 `shift` 的系数

!!! warning "常量和 SVG 坐标是两份"

    注释写着「与 SVG 中坐标一致」：改了车轮或中轴的位置，SVG 里车轮的 `translate` 和车架的线段端点要一起改，否则腿蹬的踏板和画出来的踏板对不上。
