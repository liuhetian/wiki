# 色彩

每条是一张色卡加一句主题色 prompt，只管颜色，不管画风和构图。
挑一条，再配上[画风](../images/handdraw-style/index.md)、[排版](../layouts/index.md)和你的主题，拼成完整的 prompt。

- [经典主题色（36 种）](classic.md) —— 克莱因蓝、普鲁士蓝……蓝、绿、红绿、粉紫、大地、中性六个色系，一条一个颜色名
- [意象渐变配色（9 套）](collected/gallery-imagery-gradients.md) —— 深邃、格调、考究、甜美……每套主色加两种辅色，写到 HEX

经典主题色收录自 yang0/handraw-style（MIT），来源见[维护记录](../../maintenance/skills/handdraw.md)；意象渐变配色照录自抖音，来源见[维护记录](../../maintenance/gallery/colors-collected.md)。
