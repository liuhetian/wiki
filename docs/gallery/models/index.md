# 3D 模型

能在浏览器里转着看的三维模型，一个模型一页：上面是能转、能缩放的 demo，下面是做出它的 prompt 和做法。本站自己做的，成品和做法写在同一页；别人的照[图片](../images/index.md)那边的格式收，来源写进[维护记录](../../maintenance/index.md#gallery)。

- [低多边形小橘猫](orange-cat.md) —— 本站自己做的：照一张像素画用代码拼的小橘猫，举爪挥手、眨眼、歪头、摇尾；没有模型文件、贴图和骨骼绑定，442 行代码、8276 个三角面，AI 约 10 分钟做完

- [低多边形绵羊](sheep.md) —— [低多边形 3D 牧场](../games/lowpoly-ranch.md)里的羊单独拿出来看：34 个小毛团拼成羊毛，脸、耳朵和两节腿挂在关节上；切待机、吃草、行走、跳跃四种动画，走路原地踏步，换一只看毛团变体；15 个网格 4530 个三角面
- [低多边形树](tree.md) —— 牧场里的 13 棵树单独拿出来看，含粉紫色那棵：七棱圆台树干加 4–5 团鼓包的二十面体树冠，树冠轻轻摇摆；一棵 348–428 个三角面

绵羊和树共用一个查看页，模型代码直接用牧场那份，不另存。
