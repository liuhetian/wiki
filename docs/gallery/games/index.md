# 游戏玩法

能直接在浏览器里玩的小游戏和玩法原型，一个玩法一页：上面是能玩的 demo，下面是做出它的 prompt 和做法。本站自己做的，成品和做法写在同一页；别人的照[图片](../images/index.md)那边的格式收，来源写进[维护记录](../../maintenance/index.md#gallery)。

- [低多边形 3D 牧场](lowpoly-ranch.md) —— 本站自己做的：米白底上一块方形微缩草地，河、小路、树和 11 只白色绵羊；鼠标和触控都能转视角、点选、拖羊，选中后切 Idle、Graze、Walk、Jump 四种动画，旋转、复制、删除；下面是整段 prompt，交给 AI 一次做完，约 30 分钟
- [压路机修出来的小镇](duck-road.md) —— 本站照小红书 AFTERSTILL 的视频「aha鸭马路也是艺术」复刻：米色纸上只有铅笔线稿，压路机开过才铺出蓝色马路，两旁房子和树接连弹出；路无限延伸，斑马线前一家小鸭搭车过马路回家；下面是原片、原话 prompt、Claude Code 约 45 分钟做完的经过和完整源码
- [3D 像素幸存者](terrace-survivors.md) —— 本站自己做的：台地悬崖地形上的 roguelite 小游戏，8 方向像素精灵、6 种武器、Boss 和三张地图，美术全由代码生成；下面是做出它的 prompt、四问问答（地图怎么做成 3D、命中看不看高低差、2D 角色进 3D 叫什么、8 个方向怎么画）和完整 Vite 工程，Claude Code 约 85 分钟做完
- [果冻码头](harbor-jelly.md) —— 本站照小红书「你的提示音」的视频《果冻码头》复刻：一块方形果冻海上的港口沙盘，吊机搬箱、货轮离港绕圈，点水起涟漪、长按推浪、双击从三面墙掀起大浪，7 段海报式导览；下面是原片和 AI 读过的 13 张原片帧、原话 prompt、Claude Code 约 80 分钟做完的经过、四问问答（水面五层浪怎么叠、大浪怎么反射和被防波堤挡住、清水靠折射看出浪、水下为什么从切口看也对）和完整 Vite 工程
