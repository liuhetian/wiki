## 核心机制

压路机开过的地方，世界才「长出来」：

- 前方：米色纸面上只有**铅笔线稿**。地块是空心矩形，里面写店名；路只有两条边线和虚线中线；斑马线是空心条纹
- 滚筒压过：路面变成**蓝色**，有白色边线、车道虚线、箭头、井盖，边缘是刷漆一样的毛边
- 路两旁的地块**依次弹出**：填上颜色和花纹，房子、树、花、栅栏冒出来，地面上扩散一圈**白色光环**

## 时间线

| 时间 | 画面 |
|---|---|
| 0–3 s（KF 01–08） | 镜头跟着压路机，3/4 俯视，路从左上到右下；房子和树带着光环陆续弹出 |
| 3–5 s（KF 08–12） | 前方铅笔斑马线上排着 6 只小鸭（5 只黄的，1 只更小更白的），压路机开到跟前停下 |
| 6 s（KF 13–14） | 小鸭飞起来，落在滚筒和顶棚上 |
| 7–8 s（KF 15–18） | 斑马线变成白漆，小鸭红绿灯（图标是绿色小鸭）变绿，小鸭排队过马路 |
| 9–11 s（KF 19–24） | 继续修路，房子接连弹出，桌面上投着窗框的影子 |
| 12–16 s（KF 25–36） | 镜头拉高到俯视；一道巨大的白色光环扫过整张地图；整条 S 形街道露出来，两侧各 4–5 排地块；右下角是作者签名 |

## 镜头

- 长焦感，估计竖屏 FOV 约 25–30°，俯角约 45–55°
- 移轴景深：焦点在压路机，上下两端明显糊
- 暖色斜光，影子朝右上；纸面上有大片柔和的窗框阴影（十字形窗棂）
- 轻微胶片颗粒、暗角，整体略低饱和

## 模型清单

- **压路机**：两个后轮（黑胎、黄轮毂）；红色车身，底边一条白饰条；引擎盖上有 4 条散热缝；烟囱是黑色加黄环、红帽；驾驶座上坐着戴白色安全帽的小鸭，背后一个蓝黄相间的横置水箱；顶棚是 4 根细黑杆撑着橙黄色平顶，白边上挂一圈小红灯，顶上一个小钮；车前两条红色臂架，上面盖着黄黑警示条板；蓝色滚筒，两端是奶白端盖，中心黄色法兰；几根黑色软管
- **小鸭**：圆身子、圆头、扁橙色嘴、小翅膀、小脚，表面是毛线编织的质感
- **房子**：方块墙加三棱柱屋顶，也有四坡顶、平顶、A 字顶；高塔楼；白框深色窗；墙是粉彩色，屋顶带点状花纹
- **树**：棕色树干，上面堆 2–4 个球
- **其他**：白色尖桩栅栏、小花、细黑路灯、小鸭红绿灯
- **铅笔标注里的店名**：老街、车站、邮局、外婆家、家、小卖部、煎饼、花店、面馆、文具、水果、书店、诊所、操场、公园……

## 交互版的改编

- 压路机：按住拖着走，或者按住空格自动开
- 小鸭：开到斑马线前停下，小鸭飞上压路机搭车；开过斑马线后，斑马线刷白、灯变绿，小鸭跳下来过马路，回到「家」
- 路无限延伸，每隔三段路有一家小鸭；原片结尾的俯视镜头做成了随时可切换的「俯瞰」
- 不复制原片的签名、音乐和画面
