## 版式（竖版海报）

- 背景米白纸色 `#edeae0`，左上角小字 `● VIBE CODING / HARBOR JELLY`（红点，字距很大）
- 大标题两行，粗黑体，深青 `#2a4b4a`
- 底部：`0N / 段名`（小字、字距大）→ 一句副标题 → 一条细线（深色那段随段号变长，像进度条）→ 署名
- 特写时 3D 画面上下用米白渐变淡出到纸面；全景时整块沙盘放在纸上，往右下投一片淡影

## 布局（本复刻的坐标）

- 沙盘 40×40，水面 y=0；从相机看，左前方是西南角
- 陆地是东边一条（x 9→20），码头墙面朝西；北段是集装箱堆场和两台吊机，货轮船头朝南靠在北段；中南段是街区和鱼市场；南端有木渔台，栈道往西伸进海里，尽头是灯塔
- 水域其余全部是海：两条帆船、浮标、轮胎、水下的东西
- 侧面：水的截面是半透明青色，下面一层浅沙，再下面是土层条纹（浅棕、灰绿、棕、粉棕、灰）
