# LINE//SYSTEM LAB

## 来源与模式

- 来源：`线性设计风 2026-7-5 10-04-57 前端到全栈.mp4`（85.3 秒，2160×2160）
- 模式：视觉复刻 + 教学化内容重构
- 复杂度：L2（静态图形系统 + 轻量 DOM/SVG 动效）
- 许可：仅依据用户提供的视频做本地学习型视觉重构；未复制第三方代码或原始素材。

## 提取出的设计 DNA

- 瑞士网格 / 工业控制台 / 航天档案 / 未来复古标签系统
- 0.5–1px 超细线、零圆角、低对比纸张噪点
- 等宽小字、超大编号、英文与中日文混排
- 条码、刻度、参数表、波形、定位角、校准十字等功能语义组件
- 底色 + 墨色 + 单一信号色的 2+1 配色法

## 实现

单文件 `index.html`，无依赖、无外链、可离线打开；另包含两张由内置生图能力生成的原创案例资产。内含：

- 5 套主题色
- 随机版式内容生成
- 提示词复制
- 风格技能、设计令牌、负面提示词教学
- 扫描线、波形绘制、雷达与切换过渡
- 4 张原创完整海报方向（ImageGen）
- 9 类原创微型组件图鉴（ImageGen）
- 9 个程序化 HTML/SVG 小组件及用途说明
- 档案编号型、控制面板型、实验标签型三组独立提示词

## 生成资产

- `assets/poster-cases.png`：4 张完整海报构图案例
- `assets/component-atlas.png`：9 类工业视觉微组件图鉴

两张资产均为本项目重新生成的原创图，不是视频截图或原案例裁切。

## 运行

直接双击 `index.html`，或在 `task3` 目录运行：

```bash
python3 -m http.server 8765
```

然后访问 `http://127.0.0.1:8765/`。
