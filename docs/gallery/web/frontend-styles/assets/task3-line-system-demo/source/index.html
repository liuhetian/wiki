风格技能 / STYLE SKILLS

01

信息层级工程

一个大编号或短词做视觉锚点；其余信息降到 6–10px，形成“大声主标题 + 低声系统注释”。

02

工业语义组件

条码、刻度尺、波形、参数表、校准十字、边角定位符。每个元素都像“有用途”，避免纯装饰。

03

单色信号系统

底色 + 墨色 + 1 个强调色。荧光绿代表运行，橙红代表警报，灰紫代表实验档案。

04

受控的不完美

叠加 6–12% 纸张颗粒，线条保持 0.5–1px，拒绝渐变与厚重阴影，获得印刷/档案质感。

05

多语种科技感

英文等宽体承担系统标签，中文/日文做视觉事件，数字使用紧凑无衬线粗体。
