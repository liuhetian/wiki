# 档案袋开启动画拆解

## 视频证据

- 约 5.5–6.3 秒：选中档案袋位于最前；卡片本身的双股 8 字绳结松开为柔和的 X，再从原位置淡出；上下铆钉仍然留在原卡片上。
- 约 6.3–6.8 秒：袋口状态变化，顶部铆钉随袋盖退出，正面内容随后才退出视觉焦点。
- 约 6.8–7.3 秒：一张空白纸从档案袋的几何位置快速扩展至屏幕主体。
- 约 7.3 秒后：标题、索引和正文出现在展开纸张内。

## React 实现

1. 点击时用 `getBoundingClientRect()` 读取档案卡片的真实位置和尺寸。
2. `OpeningLetter` 固定覆盖视口，并将纸张的初始几何参数设为上述矩形。
3. 下一动画帧添加 `is-expanded`，利用同一元素的 `left/top/width/height` 过渡实现 FLIP 式扩展。
4. 不再创建独立覆盖层。原卡片 `Mark` 中的两条 Bézier 绳股连续经过“放松中央环—从上铆钉两侧滑脱—绳尾向外下方垂落”三个阶段；原有铆钉和卡面始终是同一个 DOM/SVG 本体。
5. 解结用时 `.68s`，展开纸张延迟到解绳完成后才出现并在 `.62s` 内完成；`1.34s` 后添加正文。仍保留“先解结、再打开、后显字”的层次，但总等待时间比原来的 `2.05s` 缩短约三分之一。

这种方案不依赖 WebGL，DOM 文字仍然清晰、可滚动且可访问。

## Hover 命中轨道

未激活卡片使用负 `translateZ`，父舞台设为 `pointer-events: none`，卡片显式设为 `pointer-events: auto`。每张档案通过自身的 `pointerenter` / `mouseenter` 立即进入 Hover，避免依赖父舞台冒泡在不同浏览器中失效；页面级 `pointermove` 再根据档案架矩形、固定轨道起点和当前拖动偏移持续校正唯一索引，并在指针移出档案架时可靠复位。放大和前移不会改变状态真源，因此不会因为视觉卡片离开初始位置而丢失 Hover。

Hover 只改变当前档案。其他档案的横向轨道、缩放、纵深与 `rotateY` 全部保持原值，不会朝向当前档案，也不会在 Hover 后重新排成一列。侧转角度会根据档案总数增加：5 张时约为 `18°`，8 张时约为 `45°`，数量较多时仍能用更窄的投影宽度露出后方档案的标签区域。

卡片不再同时依赖 CSS `:hover` 和 React 状态；只有唯一的 `is-active` 可以触发转正动画，避免指针压住一张卡、固定轨道又选中另一张卡时两张同时放大。

## 横向拖动轨道

档案使用固定 `16.5%` 的横向间距，超过舞台宽度的档案留在右侧画面外。拖动 `.file-stack` 会更新继承给所有卡片的 `--stack-offset`，范围钳制在 `0%` 到最后一张完整进入画面的负偏移之间。拖动期间取消过渡以保持跟手，结束后恢复 Hover。按下时记录原始卡片，移动不超过 `5px` 的正常抬起明确作为点击打开；超过 `5px` 才进入拖动并抑制随后的合成 click。`pointercancel` 只负责释放捕获和清理状态，避免移动端滚动或系统手势意外打开档案。Hover 命中计算会同时扣除当前拖动偏移，因此拖动前后都只会激活指针所在轨道的一张档案。

鼠标滚轮与触控板滚动同样控制 `--stack-offset`：横向和纵向 delta 取绝对值较大的一个，普通鼠标向下滚对应档案向左移动，反向滚动返回开头。监听器使用非被动的 window wheel 事件；只要详情尚未打开，鼠标位于首页任意位置都能浏览档案，并阻止页面本身随之纵向漂移。

## 详情与无障碍

八份档案共用同一套五章节长文结构，标题和编号由当前档案数据替换。详情层使用模态对话框语义；打开后背景页面进入 `inert`，正文出现时焦点落到返回按钮，关闭后恢复到原档案。开启“减少动态效果”时跳过解结与铺纸等待，直接显示正文。
