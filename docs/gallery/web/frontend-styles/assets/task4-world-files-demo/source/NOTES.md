# World Files · React 复刻

- 原始素材：`作品集进度｜新加一个档案袋交互 2026-7-13 16-09-12 海盐夏气泡水.mp4`
- 复刻模式：根据本地演示视频进行视觉与交互复刻（无原站源码、无外部 API）
- 复杂度：L3，核心是卡片层叠、悬停景深与 FLIP 开袋转场
- 技术栈：React + Vite + CSS/SVG
- 运行：`npm install && npm run dev`
- 构建：`npm run build`

## 已实现

- 八份档案袋的立式层叠、悬停转正、景深变化与横向拖动/滚轮浏览
- 原卡片绳扣本体松开 → 纸张从原卡片位置扩展 → 详情内容淡入的连续开袋动画（无额外贴片或替身绳结）
- 共用的长文详情模板、五个真实章节锚点、返回与 Escape 关闭
- 桌面、平板和手机响应式布局
- `prefers-reduced-motion` 无等待降级、详情模态焦点隔离与焦点恢复

## 已知差异

原始输入只有一段 21 秒视频，无法取得原站的字体文件、真实文案和图片资产；当前的水彩图、纸张纹理、档案内容均为本地 SVG/CSS 重建，不含原站追踪或外链业务逻辑。
