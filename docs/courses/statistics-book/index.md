# 统计学（教材伴读）

跟着**向蓉美、王青华主编《统计学》（第三版），西南财经大学出版社 2018** 走，一章一课。这本书是西财的国家精品课教材，经管类核心课，路线是先描述统计、后推断统计，通篇配 Excel。

这个分类和[笔记 / 统计学](../../notes/statistics/index.md)分工不同：**笔记讲通用的统计学**（覆盖面更宽，含因果推断、缺失数据、贝叶斯、重抽样这些书里没有的主题）；**这里是这本书的伴读**，跟着它的章节走，讲透这一章的心智模型，然后出一组不自己算就答不出来的题。两边正文互链。

## 一条方法上的硬规矩：公式不信 OCR

原书是扫描版，OCR（RapidOCR，300dpi）跑出来的文本**数学内容全是坏的，而且坏得像正常文本**：

- `χ²` 被识别成 `x²` —— 卡方变成"x 的平方"
- `n₁` 被识别成 `n,`（下标 1 变逗号），`n₂` 被识别成 `n²`（下标 2 变上标）
- 分式被拆成三行：分子一行、等号一行、分母一行
- 表格塌成一列，列关系全丢；插图只剩坐标轴上的刻度数字

这类失真不会自己暴露 —— 它读起来像正常文字，抄进来就是一个自由度写错、整段推导报废。所以**每一课的每个公式、每张表、每处下标，都是对着 300dpi 原书页图重打的，OCR 文本只用来定位段落和抄纯中文叙述**。写完另有一轮只拿页图、不给 OCR 文本的独立校对，专门抓这类失真。

原书是在版教材，所以**这里不镜像全文**：正文只摘关键句（标书页码）并跟自己的分析，其余全部用自己的话重写。要原貌请自己找书。
