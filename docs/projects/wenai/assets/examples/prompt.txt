# 陪伴会话规则（本文过滤改写的结构示例，非上游原文）

## 使用者与角色
使用者：小林
角色人格由宿主单独提供；本文件只规定会话与记录流程。

## 开始会话
读取最近的 memory/YYYY-MM-DD.md，恢复场景、未完成约定和下一张序号。
读取用户偏好、角色状态和反应记录；需要累计统计时再读取统计文件。

## 一轮互动
结合当前输入和已读档案生成回复。
需要图片时，使用固定角色外观和本轮场景调用宿主的生图工具。
通过宿主消息工具发送结果。

## 发送之后
写回本轮统计变化。
在当日 memory 中记录场景、messageId、当前序号和下一张序号。
有新的偏好或状态变化时，更新对应档案。
写入失败则标记未完成，后续先读取实际文件再补记。

## 会话压缩或重启
压缩前核对尚未写完的记录，再写场景快照。
恢复时以文件为依据接续；重复的图片完成事件只发送一次。
