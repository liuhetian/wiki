# PawzoChat：不是角色扮演前端，是住进微信的 AI 伙伴

它和[梨园](../liyuan/index.md)、[酒馆](../sillytavern/index.md)不是一类。那两个是角色扮演前端，用户进它们的界面和角色演故事；PawzoChat 是 AI 伙伴引擎，接上一个微信或 QQ 的 bot 账号，这个号就是角色，用户在自己的聊天软件里跟它日常聊[^repo]。

和酒馆只共用卡的格式。导入角色卡时丢掉开场白——微信里总是用户先开口；世界书各条目的关键词并成整本一组，只扫用户这一轮的话，命中就整本注入。预设、深度注入、按预算裁历史都没有，system 只是人设、输出示例、系统指令三段加世界书和记忆。

重心是像真人发消息。用户连发几条，停 7 秒没新消息才合成一轮调模型；默认系统指令要回复 30 字内、用反斜线分句，程序按反斜线切成几条气泡逐条发。开了主动消息，用户沉默 1 到 3 小时，程序塞一条不入库的指令让角色先开口。

和梨园比，它也跑工具循环，但工具是生图、记忆和 MCP；没有场景状态，也没有重来和分支，一个角色一条会话。收发、切气泡、TTS、记忆满 50 条叫模型合并归程序；人设、账号、API 归用的人；说什么、记什么由模型定。
