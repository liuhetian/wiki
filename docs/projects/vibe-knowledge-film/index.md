# Vibe 知识短片：让 AI 做「讲解」，不做「配图」

Vibe 知识短片是给 coding agent 用的一个 skill，做没有旁白的字幕科普片 —— 抖音「Vibe知识大赏」里那类代码直出的知识短片：2–5 分钟、16:9，没有人声，观众读底部一行字幕，同时看屏上把这句话演出来。全片由代码逐帧画出：Canvas 上每一帧是时刻 t 的函数，Playwright 打开 Chrome 拨到 t 截图，ffmpeg 合成，再混上按事件合成的音效。

最简单的做法是给模型一句话。这波视频里流传最广的就是这一句（原文 · `references/prompts.md:19`）：

> 制作一段 15 秒的动态图形视频，充分展现你作为动态设计师的出色实力，尽情发挥创意。

它出的是炫技片：同样的配色、同样的方块网格、同样的收尾 logo。再进一步，把参考片的颜色、字体、节奏量下来照抄，片子像了，观众还是看不懂 —— 这个 skill 自己就这样做坏过一次。**它的答案是：色、字、辉光都是皮，核心是讲解设计** —— 文案说到的每一样东西，屏上都认得出、看得见它在变。七篇参考文档里，讲解设计那篇开头就说自己是整个 skill 的核心，流程里找形象、写分镜表、看图改图三步都在为它服务。本页沿着这条线讲，引擎和外观只交代到看得懂主路径。

**主路径**是从第 0 步「看清手里有什么」到第 9 步终检，每步带过关标准，没过不往下走：立题和事实表 → 找形象 → 文案和分镜表一起写 → 选外观 → 建工程、先做最难的一镜 → 前 30 秒 → 铺全片 → 声音 → 终检。

**分工**：模型写事实表、形象、分镜表和每一镜的 `film.js`；引擎只给画布、辉光、字幕和几样常用件，`new_film.py` 建出来的骨架一行画面都没有；用户在三个时机拍板 —— 形象方案、分镜表、前 30 秒。

照着做用 [Vibe 知识短片](../../skills/vibe-knowledge-film/index.md) 这个 skill。

## 配图和讲解：同一段《折叠》做了两版 { #fold }

**判一个画面是配图还是讲解，看它换给别的文案还成不成立。** 第一版《折叠》讲蛋白质折叠，主体是一串星点连成的折线。颜色、字体、节奏都像参考片，每句也都「有画面」—— 可观众从头到尾没见过蛋白质长什么样，也不知道错一个字母坏在哪。那串星点换给任何一段文案都成立，它是配图。

查出问题的工具是**每一镜过三问**：屏上这是什么（用一个日常的词答，遮住字幕和标签也认得出）、它在干什么（一个动词，就是字幕里那个）、观众因此明白了什么（一句话，和上一镜不一样）。第一版前 30 秒逐句过三问（原文 · `references/visualization.md:296-302`）：

答出来是「一串点」「卷」「它变红了」—— 三问答得含糊，就是没讲。重做换了一个形象和一台摄影机：血管里的红细胞 → 细胞里的血红蛋白 → 一串珠子，镜头只推近和拉远，不换场。九镜里两镜不画，分镜表在[下文](#storyboard)。

## 六种画法，五句里一句不画 { #six }

**一句字幕出来，屏上能做的只有六种事；该停的地方停住，比硬配图强。** 作者把四条参考片每 2–2.5 秒截一帧、对着字幕逐句看，归成六种画法（改写压缩自 `references/visualization.md` 第一、二节）：

| 画法 | 做什么 | 参考片里的例子 |
|---|---|---|
| 亲自试 | 屏上摆一个东西让观众先起反应，字幕晚半拍说出观众刚想到的 | 「床前明月＿」空位停 3 秒再填上「光」 |
| 照着句子画 | 句子说到什么屏上就是什么，句子里的动词真的做 | 蛎鹬丢下自己的蛋，爬上比它还大的假蛋 |
| 当场做一遍 | 拿最小的题目把方法走完，状态和计数看得见，数是真算的 | 1 到 1024 猜数，每问一次盖掉一半 |
| 并排比 | 两样东西放进同一个版式，只留一处不同 | 广州明天不下雪对下雪 |
| 摆到一张图上 | 把出过场的东西摆进坐标图，轴用人话，排在例子后面 | 「甜 × 油」坐标中间空着一圈，奶茶掉进去 |
| 只上字 | 规则卡、引文卡、命名、公式加一句人话；或者把上一幕停住 | 「十个是或否，就是十个比特」只多一行 log₂1024 = 10 bits |

另有两个贯穿全片的动作不算新画法：**回场**（开头的道具、尺子再出现一次）和**合体**（把全片的形象和观众生活里的东西放进同一个画面 —— 手机坐在鸟窝里）。

一条片里几种画法怎么接，看《信息论 · 惊奇之学》开头六句（原文 · `references/visualization.md:34-41`）：

--8<-- "skills/vibe-knowledge-film/references/visualization.md:34:41"

亲自试 → 提问不加画面 → 当场做一遍 → 只上字，最后连香农都只是一行小字贴在那个 693 上。参考片里**大约每五句有一句不配新画面** —— 那句后面的停顿，是观众把刚看到的想明白的时间。规则按这句话在做什么来定：提问停住上一幕，留一个问号或光标；起名字、下结论只上字；某年某人一行小字贴在已有画面上，不换场、不画脸；刚演过的事，结论句不再画一遍 —— 再配一张图表，等于不相信刚才那一幕。

这个比例也是分镜表的自查尺子：「不画」一个都没有，是把结论也画了；占了一半，是没找到形象。

## 给概念找形象：按顺序问五句 { #image }

**画不出来，多半是文案的问题：句子里没有东西。** 所以不是先写完文案再配画面，是先给每个概念找到形象，再把形象里的东西和动作写进句子。找形象按顺序问，前面有答案就不往后问（`references/visualization.md` 第五节）：

1. **它本身是个东西吗？** 画它本身：红细胞、蛋、骰子、探测器
2. **是一个过程或方法吗？** 找小到能把每一步画出来的题目走一遍：1 到 1024、甲 50 比乙 20、12 个程序
3. **是一个量、一种程度吗？** 给它一把尺子，用同一把尺子量三样东西 ——「惊奇」那把尺子量过古诗、烽火、下雪、推荐流
4. **是观众脑子里的事吗？** 设计一个五秒的小测试，让它当场发生
5. **是一条规律吗？** 先画两三个例子，再摆到一张图上
6. 都不是 —— 一个判断、一个态度、一句总结 —— 不画，上字

找到以后再加三问把形象做强：观众在生活里哪儿见过它（锚）；换一个尺度看是什么样（一颗珠子 → 一团分子 → 一根长杆 → 一个细胞，原因和结果就连上了）；它坏了会怎样（正常时看不出它在干活，坏了才看得出 ——《折叠》讲的正是错一颗）。形象还要**画得像它本身**：红细胞有厚度、中间凹下去、边上一道高光；先给血管再推进去，不把珠串直接摆在黑底上；箭头、虚线框、代表分子的小圆点只当小字，不当主体。

## 分镜表：一句字幕一行，一路管到代码 { #storyboard }

**没有分镜表不建工程；分镜表的每一列，代码里都对得上一处。** 文案和画面分头写，画面就会自己长出别的东西。分镜表一句字幕一行，七列：时间、字幕、画法、屏上是什么在干什么、屏上的小字、观众明白了什么、声音。表前写一句话论点、全片的形象、那把尺子、哪两镜是同一个画面、每种颜色的意思；表后写屏上的数怎么来、哪些是示意。写完遮住字幕一列，只读「屏上是什么」，看得出在讲什么才算过。

## 看着截图改：每帧是 t 的函数 { #review }

**第一次渲出来的画面几乎都有毛病；这种片子是看着图改出来的，不是写完代码就完了。**《折叠》那 33 秒从第一张拼图到成片改了三轮。流程要求每做完一镜就截图看，至少改两轮再给用户看，交片时把不满意的地方直说。

引擎为此定了一个前提：每一帧是 t 的纯函数，随机数按种子取，模拟按 t 重算，没有状态跨帧保留：

```js title="原文 · engine/vk.js:1-8"

```

所以 `render.py` 能跳着截任意时刻：`--sheet` 拼一张看全局，`--stills` 截原尺寸，`--motion` 在一段时间里抽 12 帧看转场，`--det` 把同一批时刻乱序再截一遍、逐字节比。看的时候当自己是第一次看的观众，遮住字幕和小字过三问，再对着毛病表逐条查：

## 两套外观：跟着题材选 { #worlds }

**外观在分镜表之后才定，只有两套。** 寓言给心理、行为机制：从动物实验或生活场景讲到「你该怎么办」，每场一幅代码画的扁平插画，角色要有动作，最费工。夜曲给抽象概念：拆成几个当场可演的小实验，用大字、带刻度的仪器和画得像实物的东西演，声音全部合成。拿不准选夜曲 —— 它对「画」的要求最低，对「想」的要求最高（改写自 `references/worlds.md:9-17`）。两套的色、字、版式、片名卡、声音都量自参考片，引擎里的默认值就是这张规格表。

## 谁管什么，局限在哪 { #roles }

| 谁 | 管什么 |
|---|---|
| 程序 | `vk.js`、`vk-kit.js` 给画布、辉光、字幕、章节标和几样常用件；`render.py` 截帧、拼图、渲染、确定性自检；`audio.py` 按事件表合成音效；`new_film.py` 只建空骨架 |
| 模型 | 事实表、形象、文案、分镜表、每一镜的 `film.js`，看截图改图 |
| 宿主 | 本机 Chrome、ffmpeg 和几个 Python 包；模型要能看图，否则看图改图这一步做不了 |
| 使用者 | 给题目或文案；在形象方案、分镜表、前 30 秒三处拍板；寓言要自己给配乐 |

- **讲解设计没有程序闸门**：三问、五分之一不画、毛病表都是模型照着自查的清单，脚本只验渲染和确定性
- **每一镜现写代码，费工**：《折叠》33 秒的 `film.js` 273 行、改了三轮；一整条 2–5 分钟的片子按这个倍数估
- **只做 16:9，没有人声**；外观只有两套，规格是从四条别人的片子量出来的
- **仓库里的样片都是开头几十秒**，没有一条完整成片
- 本页没有实跑：材料取自仓库自带的分镜表、代码、作者渲的拼图和样片；版本和改动见[维护记录](../../maintenance/skills/vibe-knowledge-film.md)
