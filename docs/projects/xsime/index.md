# 犀术IME：输入法里多一个上屏前的暂存区

犀术IME（XSIME）是五端中文输入法，编码和候选交给 Rime 引擎[^repo]。它自己加了上屏前的暂存区 Buffer，省掉找 AI 改句话要复制、切窗口、再粘回来的来回。macOS 版功能最全。

平时打字照常上屏。打开 Buffer 后，敲出的字按 Rime 每次上屏切块存着，不进当前应用；交给 Codex、Claude Code 或 OpenAI 兼容 API 改写、翻译，结果切成短块，回车一块块发回原输入框。发前要核对：每换一个输入客户端就换一个焦点编号，旧的作废，网页里再靠辅助功能认具体的框；AI 结果晚回来、光标已去别处，发送就被拦下。

意识流输入把一长串没断开的全拼整段交给模型，停手约 0.2 秒请求一次，给最多 5 个整句候选；本地切音发现 fangan 有两种切法，就要求至少给两个[^stream]。Capsule 存剪贴板历史、笔记和本机加密的密码；Mailbox 收 AI 对话、终端任务和外部推送，点接受才进 Buffer。

编码和候选归 Rime，猜字改写归模型，发到哪个框由程序核对，按不按回车由人定。

[^repo]: [scholay/xsime](https://github.com/scholay/xsime/tree/6c657da3013a7b94d4902382f2ee3cb6559a25eb)，读的是 commit `6c657da`（v1.2.0 之后，2026-11-01），官方插件子模块 `b8b79be`，2026-11-03 读；正式发布正迁往 scholay-xsime/xsime。Apache-2.0 许可。
[^stream]: 插件说明写的是本地 Rime + Octagram 先解码、难的再交给 AI；代码里这条路现在只走 AI 连接器，本地解码器还编译在程序里，没接上。
