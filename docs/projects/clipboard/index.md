# 牛牛便利贴

家里几个人共用的几块白板：这台设备贴上便利贴、链接、图片、文件、位置，那台设备拿走；AI 带密码也能读写。线上是 https://clip.liuhetian.life 。

**要通过接口读写白板的 AI，直接读[给 AI 的接口说明](ai-api.md)。**

各处的名字不一样，搜的时候都试：

| 在哪 | 叫什么 |
|---|---|
| 本地目录、`package.json`、EdgeOne Blob 存储 | `clipboard` |
| GitHub 仓库 | `sticky-notes` |
| EdgeOne Makers 项目、COS 子账号 | `clip` |
| 登录 cookie | `clip_auth` |

**功能和规则以[需求](requirements.md)为准**，别的页面讲到功能都链过去，不转述。目录结构和设计决定写在仓库根的 `README.md`，这里不重复。

本站 wiki 在 https://clip.liuhetian.life/wiki/ 。这份文档被别的站点收录后，那边的 `.md` 是原文、不带实时数据；要实时值就带密码读本站的 `/wiki/<页>.md`。

## 背景

- **要解决的是跨设备传东西**：A 设备放进去，B 设备能查看或下载。做成白板而不是列表，每个元素单独设到期时间
- **用的是家里几个人，外加带密码的 AI agent**：所有白板人人能看能改，「牛牛」「香蕉」只是分类，不是私有空间
- **评判标准是「小而美」**：能复用就不另写；不做旧数据兼容，格式变了就清库重来

<这里可以补充：最初是谁提的需求、在这之前用什么办法在设备之间传东西>

## 现状（截至 2026-11-18）

数据量和健康度是 2026-11-18 上午查的线上，其余来自仓库和本机的备份文件。

- **谁在用**：牛牛、香蕉从登录页进；大米只在名字映射里，走请求头；每人手机上一份 iPhone 快捷指令；AI 用单独的密码，只能调 `/api/ai/`（规则见[需求](requirements.md)「登录与权限」）
- **数据量**：11:07 共用 2 个、牛牛 1 个、其他白板空着，废纸篓 6 个 —— 新格式上线前清过库，清库前最后一份本地备份（11-17 09:39）有 68 个
- **健康度**：没有告警。页面调接口遇到的 5xx 和网络不通会报到「故障」白板（设置里打开「显示故障白板」才看得到），11:07 是空的。函数包 308 KB，其中代码 188 KB（预算 350 KB，只算代码），只有一个入口。545 是冷启动被平台掐掉（见[开发 · 平台的坑](dev.md#platform)）：模拟打开页面（静默 30 秒再并发 6 个）0/72，钉住两个节点各连发 200 次 0 个。本地 111 个测试用例全过
- **HTTPS**：强制 HTTPS 已开，`http://` 回 302 跳到 `https://`；HSTS 不开
