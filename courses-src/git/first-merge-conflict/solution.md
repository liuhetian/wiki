# 参考解法：第一次合并冲突：读懂那三行标记

原关卡 `2-0-0` 设计时写的标准流程。

标准流程：1) 进入项目目录 cd math-project；2) 先尝试 git push，确认被远程更新拒绝；3) 执行 git pull，把远程改动拉下来并触发冲突；4) 打开 math_tool.py，识别 <<<<<<< HEAD 到 ======= 之间是本地的 mul 函数，======= 到 >>>>>>> 之间是远程的 sub 函数；5) 手动删除所有冲突标记，同时保留 add、sub、mul 三个函数；6) git add math_tool.py，告诉 Git 这个冲突文件已经解决；7) git commit 生成合并提交；8) git push 推送结果。关键教学点：冲突不是 Git 坏了，而是 Git 无法替人决定保留哪部分修改；编辑文件只是第一步，add 和 commit 才是正式完成合并。
