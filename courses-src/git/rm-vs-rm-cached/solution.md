# 参考解法：已经推上去的敏感文件，删得掉吗

原关卡 `1-1-2` 设计时写的标准流程。

标准流程：1) 进入项目目录 cd night-watch；2) 先用 git status、git ls-files 理清三个文件现在都处于被跟踪状态；3) 对 `.env` 和 `db.sqlite3` 使用 git rm --cached，让它们退出版本控制但保留本地文件；4) 对 run.log 使用 git rm，让它同时退出工作区和 Git 跟踪；5) 把这三个名字写进 .gitignore；6) 提交这次清理；7) 推送到 origin/main。关键教学点：同样叫“删除”，Git 里至少分成删除工作区、删除暂存区/跟踪关系、以及理解历史是否已经传播出去这几个层次。
