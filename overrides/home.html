细看几处

为 agent 铺好的路

llms.txt 入口

站点根目录提供 /llms.txt，内容就是首页索引的 Markdown 副本 —— 服从 llms.txt 协议的爬虫和 agent 一进门就能拿到全站地图， 不需要任何约定之外的先验知识。

llms.txt
$ curl wiki.liuhetian.work/llms.txt
# 牛合天's wiki
> AI 友好的个人知识库：每个页面在同域提供 .md 源…
## 文章 / ## 笔记 / ## Skills …

远程 skill 挂载

skills 板块按 Claude skill 的标准目录组织：SKILL.md 写约定， reference/ 放按需加载的细则。给 agent 一个 URL， 它就多了一套现成的工作方式。

skills/fastapi/
skills/fastapi/
├── SKILL.md        # 总约定，入口
└── reference/
    ├── 项目布局.md
    ├── 数据库.md
    └── 测试.md      # …按需加载

部署即校验

这个站的 AI 入口是相对链接，不是 nav —— 漏挂链接的文章对 agent 等于不存在。 所以每次部署前有一道闸门：每篇 .md 都必须能被某个祖先索引页直接链到， 另查死链。挂不上链，部署不了。

deploy.sh
$ ./deploy.sh
✅ 链路校验通过 —— 全部文章
   都能从上一级索引走到
